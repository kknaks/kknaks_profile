# Graph RAG 실전 설계 노트

## 요약
문서 그래프를 검색 context 로 삼아 LLM 답변 근거를 명시하는 접근.

## 핵심 설계
- retriever ranking = keyword score + edge distance (MVP)
- evidence document 를 답변에 함께 노출
- 근거 부족 시 단정하지 않고 수집 제안

## 우리 적용점
[[agent-experience]] 를 설계 기준점으로, [[axkg-baseline]] 근거로 연결.
