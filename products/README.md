# Products

여름별컴퍼니에서 운영하거나 출시하려는 제품별 SSOT 공간이다.

규칙: `rules/product-doc-pipeline.md`

## 제품 목록

새 제품을 등록하면 관리 화면이 이 표에 행을 추가한다([[decision-017-product-registry-and-admin-scaffold|KDEV-DEC-017]] D15). 손으로 지우거나 순서를 바꾸는 것은 자유롭게 하되, **표를 통째로 재생성하지 않는다** — `Context` 열의 메모가 날아간다.

| Product | Context |
|---|---|
| ax-knowledge-graph | `products/ax-knowledge-graph/` |
| cloud-file-organizer | `products/cloud-file-organizer/` |
| kknaks-dev | `products/kknaks-dev/` — kknaks.dev 사이트 + 이 레포 |
| language-diary | `products/language-diary/` |
| mac-remote | `products/mac-remote/` |
| mini-game | `products/mini-game/` |
| mykakao | `products/mykakao/` |
| open-kknaks | `products/open-kknaks/` |
| persona-counselor | `products/persona-counselor/` |
| study-timelapse | `products/study-timelapse/` |
| summer-star-company | `products/summer-star-company/` |
| wine-log | `products/wine-log/` |

회사 제품(`mediness`·`linky`·`nexus`·`centurion-*`)은 여기 없다. **회사 레포는 문서 트리도 공개 카드도 갖지 않고 잔디 레지스트리에만 등록된다**(DEC-017 D9).
