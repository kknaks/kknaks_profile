# Personal Current

## 목적

개인 학습의 현재 상태와 우선순위를 관리한다.

자주 바뀌는 정보만 둔다. 학습으로 쌓인 지식 자체는 `resources/` 가 갖는다.

## 현재 상황

개인 영역은 회사 업무도 여름별컴퍼니 제품도 아닌 **배우는 일**을 담는다.

배운 것은 자료(`resources/source/`)로 남기고 개념(`resources/concept/`)으로 자란다. 그 개념이 제품 결정의 근거가 되거나 글(`persona/posts/`)로 나가는 것이 이 영역의 산출이다.

## 현재 우선순위

| Priority | 무엇 | State | Next |
|---|---|---|---|
| P0 | 학습 노트 이관 | done | 원본 폴더 비움 · source 146 · concept 363 |
| P1 | 개념 ↔ 제품 결정 연결 | building | decision 64건 연결 완료, 신규 결정은 훅이 강제 |
| P2 | 개념 → 글 | 미착수 | `persona/posts/` 1건뿐. 개념이 글로 나가는 경로가 거의 안 돈다 |

## 경계

- 학습으로 쌓인 지식의 SSOT 는 `resources/` 다. 이 문서는 **무엇을 지금 하고 있나**만 둔다.
- 개념 자체를 여기 쓰지 않는다 — 상세는 `resources/concept/` 한 곳이 소유한다.
- 회사에서 배운 것이라도 **개념**은 여기로 온다. 회사 경험 기록(챌린지·성과)은 `context/company/` 다.
