# Studio Projects

## 목적

여름별컴퍼니에서 실제로 운영하거나 출시하려는 개인 프로젝트 목록과 경계를 관리한다.

현재 우선순위와 진행 상태는 `context/studio/current.md`에 둔다.

## 상태 값

| State | 의미 |
|---|---|
| idea | 아이디어만 있음 |
| validated | 만들 가치가 어느 정도 확인됨 |
| building | 개발 중 |
| release | 출시 준비 중 |
| live | 운영 중 |
| paused | 보류 |

## 경계

- 이 문서는 여름별컴퍼니 프로젝트의 안정적인 목록과 경계만 둔다.
- 출시 우선순위, 이번 주 작업, blocker는 `context/studio/current.md`에 둔다.
- 블로그/공개 정보도 별도 외부 영역이 아니라 studio 제품 중 하나로 본다.
