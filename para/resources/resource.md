# resources/

## 1. 개요

**정의**
- 밖에서 들어온 자료와, 내가 쓰고 다시 고치지 않는 글.

**특징**
- 불변성 : **쓰고 나면 고치지 않는다.** 박제다. 그 자료가 한 말은 변하지 않는다.
  계속 자라는 것은 여기가 아니라 `areas/concept/` 다.
- 출처 분류 : `areas/` 는 주제로 나누지만 여기는 **어디서 왔나**로 나눈다.
  들어오는 경로마다 다루는 방식이 다르다 — 영상은 자막, 기사는 본문, 세션은 현장 노트.

**구조**

```text
para/resources/
├── note/          내가 쓴 글 — 필기 · 정리 · 실무 기록
├── youtube/       영상 교안 (C-NNN)
├── algorithms/    매일 자동으로 쌓이는 알고리즘 풀이 (A-NNN)
├── docs/          공식 문서 · 스펙 · 논문
├── book/          책
├── article/       뉴스 · 언론 기사
├── blog/          개인 · 회사 블로그 · 쓰레드 · SNS
└── session/       컨퍼런스 · 밋업 · 개발 세션
```

`article` 과 `blog` 를 나누는 이유는 **읽는 법과 믿는 정도가 다르기** 때문이다 —
기사는 사실 전달, 블로그 · 쓰레드는 개인 경험과 주장.

**여기가 `areas/concept/` 의 재료다.** 자료를 읽거나 글을 쓰면서 알게 된 것이 개념으로
올라가고, 개념의 `up:` 이 이 층의 stem 을 가리킨다. 자료는 그 자리에 남고 개념만 자란다.

---

## 2. note/

**무엇**
- 내가 쓴 글. 학습 필기 · 코딩테스트 풀이 · 실무 기록.
- 출처가 남의 자료일 필요 없다 — **겪은 일도 출처다.** 실무 기록에서 개념이 자란다.

**하위** — 과정 · 주제로 나눈다.

| 디렉토리 | 담는 것 |
| --- | --- |
| `bitcamp/` | 비트캠프 부트캠프 필기 — Day01~ (2024-05 ~ 2024-10) |
| `likelion/` | 멋쟁이사자처럼 백엔드스쿨 필기 — Day01~ 재시작 (2024-12 ~ 2025-02) |
| `codingtest/` | 코딩테스트 풀이 — Pr/pr. 알고리즘 기법 개념들의 출처 |
| `network/` | 네트워크 교재 정리 — chapter |
| `db/` | DB 실무 기록 — 마이그레이션 |
| `elk/` | 검색 · 성능 실무 기록 |
| `monitoring/` | 모니터링 · 측정 기록 |
| `backend/` | 서버 설계 기록 — 동기/비동기 · 멱등성 |

Day 파일이 두 계열이다 — **2024-12-30 에 Day01 이 다시 시작**한다. 파일명이 아니라
날짜와 폴더로 가른다.

**DB** — 공개할 글만 어드민에서 `note` 행으로 등록한다. 모든 글이 자동으로 뜨지 않는다.

## 3. youtube/

**무엇**
- 영상 하나 = 교안 하나(`C-NNN-<slug>.md`). 영상을 안 보고도 이 문서만으로 학습할 수 있게 쓴다.
- **유튜브 개념의 출처층이다.** 유튜브에서 자란 개념의 `up:` 이 C-NNN stem 을 가리킨다.

**DB** — 카드 메타(`title` · `summary` · `youtube_id` · `duration` · `speaker` · `tags` ·
`published_on`)는 인박스 승인 시점에 `content` 행으로 들어가고, 파일 경로가 `detail_path` 가
된다. md 는 frontmatter 없이 H1 제목 + 출처 줄 + 본문만 갖는다 — 시드의 frontmatter
읽기는 이관용으로 종결.

**파이프라인 상태를 문서에 두지 않는다.** 처리 상태는 DB `queue` 가 갖는다.

양식은 `templates/resources/youtube.md`.

---

## 4. algorithms/

**무엇**
- 매일 스케줄러가 문제 하나를 만들어 커밋한다(`A-NNN-<slug>.md`). 승인도 검증도 없다.
- **개념으로 올리지 않는다** — 매일 자동으로 도는 것이라 잡음이 쌓인다.
  풀면서 알게 된 것이 있으면 `note/` 에 따로 쓴다.

**DB** — `algorithm` 표의 씨드. `today` 는 한 번에 하나 — 새 문제를 박으면서 어제 것을
같은 커밋에서 내린다.

---

## 5. session/

**무엇**
- 컨퍼런스 · 밋업 · 개발 세션의 **발표 하나 = 노트 한 장**(`S-NNN-<slug>.md`).
- **다시 볼 수 없는 자료다.** 영상은 재생하면 되고 글은 다시 열면 되지만 현장은 그
  자리에서 끝난다. 그래서 이 층은 녹취와 슬라이드 사진을 함께 남긴다 —
  `resources/` 에서 **부속물을 갖는 유일한 층**이다.

**부속물** — `session/assets/S-NNN/`. **발표마다 폴더 하나**를 갖는다.

| 파일 | 무엇 |
| --- | --- |
| `transcript.txt` | 녹취 원문. STT 그대로 두고 손대지 않는다 |
| `NN-<what>.webp` | 슬라이드 사진. 발표 순서대로 `01` 부터 |

원본 HEIC 는 커밋하지 않는다 — 옵시디언·웹에서 열리지 않고 한 장에 2~3MB 다.

**사진은 근거지 본문이 아니다.** 무대 사진을 md 에 박지 않는다. 슬라이드가 담은
구조는 mermaid 로, 대조·분류는 표로 **다시 그려서** 본문에 넣고, 사진은 `assets/` 에
남겨 문서 끝의 목록이 가리킨다.

**없는 것을 채우지 않는다.** 사례 발표는 회사 정책상 가려진 자리가 반드시 생긴다.
그 빈칸을 일반론으로 메우면 「그 회사가 그렇게 했다」는 거짓이 된다. 가려진 것은
가려졌다고 적는다 — 유튜브 교안과 갈리는 지점이다.

**DB** — 행이 없다. 출처는 md 머리의 출처 줄이 갖고, **발표자의 소속을 반드시 넣는다.**
사례 발표는 어느 회사가 했는지가 곧 신뢰도다.

양식은 `templates/resources/session.md`.

## 6. 비어 있는 것 — docs · book · article · blog

자료 캡처(어드민 모달 → `queue` → 게이트 승인)의 도착지다. 승인 시점에 md 가 생긴다.
양식은 `templates/resources/` 의 `docs` · `article` · `blog`. 이 셋은 DB 행이 없다 —
출처는 md 머리의 출처 줄이 갖는다.

`book` 은 v1 에서 로직 없이 버튼만 둔다 — 가져올 원문이 없어서 메모가 유일한 입력이다.

---

## 7. 규약

- **쓰고 나면 고치지 않는다.** 자료에 새로 배운 것이 생기면 이 파일이 아니라
  `areas/concept/` 의 개념을 보강한다.
- **개념을 재서술하지 않는다.** 자료 노트는 요지만 갖고 상세는 `[[개념 stem]]` 으로
  위임한다 — 상세의 SoT 는 개념 노트다.
- **리소스 md 는 frontmatter 를 갖지 않는다.** H1 제목 + 출처 줄 + 본문뿐이다. 카드
  메타는 인박스 승인 시점에 DB 로 들어간다 — md 에도 두면 같은 메타의 둘째 원천이 된다.
  `note/` 만 예외다 — 사람이 직접 쓰는 층이라 별개 규약을 따른다.
- **부속물은 `session/` 만 갖는다.** 다른 층은 md 한 장이 전부다 — 원문을 다시 열
  수 있으니 사본을 둘 이유가 없다. 세션만 원문이 사라진다.
- **파이프라인 상태를 문서에 두지 않는다.** 옛 구조의 `status: pending` 문제.
  상태는 DB `queue` 가 갖는다.
- **stem 을 바꾸지 않는다.** 개념의 `up:` 이 여기 stem 을 가리킨다.

회사 회의록은 여기 두지 않는다. 밖에서 들어온 자료가 아니라 내 일이라
`areas/personal/company/` 다.

## 8. 미결

- **note 신규 글이 어느 하위로 가나** — 지금 여덟 폴더는 이관하면서 생긴 것이다.
  새 주제가 오면 폴더를 만들지, 몇 건부터 가르는지 안 정했다.
- **`book` 캡처 로직** — v1 은 버튼만.
- **session 이 어드민을 타나** — 지금은 사람이 `inbox/` 에 넣고 손으로 만든다.
  녹취·사진이 입력이라 캡처 모달로는 안 들어간다. 스킬로 갈지 큐로 갈지 안 정했다.
