# Docker in 100 Seconds

출처: [Fireship — Docker in 100 Seconds](https://www.youtube.com/watch?v=Gjnup-PuquQ)

## 요약

Docker는 애플리케이션과 의존성을 이미지로 묶고, 어느 환경에서든 일관되게 실행되는 컨테이너를 만드는 도구다. 컨테이너는 하드웨어 전체가 아니라 운영체제 계층을 가상화하므로 가상 머신보다 가볍고 빠르다.

## 핵심 내용

- 가상 머신은 애플리케이션마다 운영체제와 가상 하드웨어를 포함해 크고 느려질 수 있다.
- Docker 컨테이너는 호스트의 단일 커널을 공유하면서 애플리케이션별 실행 환경을 격리한다.
- Docker의 세 가지 기본 요소는 `Dockerfile`, 이미지, 컨테이너다.
- `Dockerfile`은 이미지를 만드는 절차를 코드로 선언한다. `FROM`으로 기반 이미지를 선택하고, `RUN`으로 의존성을 설치하며, 환경 변수와 기본 실행 명령도 지정할 수 있다.
- 이미지는 애플리케이션과 운영체제 수준의 의존성을 담은 불변 스냅샷이다. 하나의 이미지에서 여러 컨테이너를 실행할 수 있다.
- 컨테이너는 이미지가 실제로 실행된 인스턴스다.
- `docker build`는 Dockerfile의 각 단계를 레이어별로 처리해 이미지를 만들고, `docker run`은 그 이미지를 컨테이너로 실행한다.
- 같은 이미지를 여러 머신, 클라우드 또는 온프레미스 환경에서 실행할 수 있어 배포 환경의 재현성이 높아진다.
