# 공유폴더 데이터 이전을 위한 메달리온 아키텍처 개요

출처: 2026-09-09~10 고객사 데이터 이전 설계 대화. 고객사 레퍼런스의 내용은 아직 분석하지 않은 시점의 초기 경계 정의다.

## 목표

고객사가 LAN 기반 공유폴더에서 관리하던 데이터를 새 시스템으로 이전하면서, AI가 업무에 활용할 수 있는 데이터로 만든다. 원본을 보존하고, 내용을 정제하며, 업무 의미와 원문 근거를 연결하는 것을 목표로 한다.

메달리온의 일반 개념은 [[medallion-architecture]]를 따른다. 이 기록은 이번 이전 작업에 적용할 각 레이어의 역할과 경계만 정리한다.

## 레이어별 역할과 경계

| 레이어 | 역할 | 책임의 경계 |
| --- | --- | --- |
| 브론즈 | 수집한 원본과 이력을 보존한다. | 파일 원본, 원래 경로, 수집 시각, 버전 식별 정보 등을 남겨 추적과 재처리의 출발점으로 삼는다. 업무 목적의 정제·집계는 후속 단계에서 수행한다. |
| 실버 | 원본의 내용을 추출하고 공통으로 재사용할 수 있게 정제·통합한다. | 형식·단위 표준화, 중복 식별, 개체 연결, 품질 검증을 담당한다. 추출·정제한 내용에서 원본 위치를 추적할 수 있어야 한다. |
| 골드 | 특정 업무와 사용 목적에 맞는 데이터를 제공한다. | 실버 데이터를 바탕으로 업무별 집계·조합·조회용 데이터셋을 만든다. 각 사용 목적에 필요한 품질 기준을 적용한다. |
| 시맨틱 | 데이터의 업무 의미를 일관되게 정의한다. | 업무 용어, 개체 간 관계, 지표 계산 기준, 동의어와 실제 데이터의 대응을 관리한다. 실버·골드의 변환과 활용에서 같은 정의를 참조한다. |

## 레이어 간 관계

데이터 가공의 기본 흐름은 `공유폴더 → 브론즈 → 실버 → 골드`로 둔다.

시맨틱 레이어는 실버·골드에 업무 의미를 연결하는 별도 책임으로 둔다. 브론즈와 실버 사이의 순차 가공 단계로 두지 않는다. 업무 의미의 정의는 설계 초기부터 시작할 수 있으며, 그 정의를 실제 데이터에 적용하는 처리는 실버·골드에서 수행한다.

접근권한, 출처 추적, 최신성은 전 레이어와 최종 활용 단계에 걸쳐 유지할 공통 조건으로 둔다. AI가 데이터를 읽을 수 있는 것에 더해, 의미와 근거를 확인하고 허용된 범위에서 사용할 수 있어야 한다.

## 이번 개요의 범위

위 레이어 정의는 초기 설계안이다. 고객사 데이터 분석 후 실제 입력·출력과 품질 기준을 구체화한다.

파이프라인은 자체 구축한다. 이번에는 Airflow를 도입하지 않는다. 자체 파이프라인의 세부 구현 범위와 저장 기술은 후속 설계에서 정한다.
