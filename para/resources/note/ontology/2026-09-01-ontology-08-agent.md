# 온톨로지 실행 기록 08 — Agent 검증 데모

이 문서는 [[2026-09-01-ontology-01-roadmap|기록 01]]의 마지막 스텝 「08 Agent 검증
데모」의 기록이다. 검증 명제는 S-001 의 것이다 — **관계는 Instruction 이 아니라
데이터에 있다.** Agent(이 데모에서는 Claude 세션)는 어떤 관계 지식도 프롬프트에
갖지 않은 채, [[2026-09-01-ontology-05-kpi|기록 05]]의 골드 View 와
[[2026-09-01-ontology-07-meta|기록 07]]의 nodes/edges 를 조회해서만 답한다.
경계는 S-002 를 따른다 — Agent 는 판단만 하고, 집계·조회는 명세된 View 가 수행한다.

## 1. 현황 질문 경로 — "최근 4주 노쇼율 추이는?"

골드 `gold_kpi_daily` 단독 조회로 답이 나온다. 온톨로지 탐색 불필요.

| 주 (시작일) | 노쇼율 | 부도 / 내원 |
| --- | --- | --- |
| 2026-08-03 | 5.3% | 54 / 958 |
| 2026-08-10 | 4.8% | 46 / 921 |
| 2026-08-17 | 5.2% | 53 / 961 |
| 2026-08-24 | 5.0% | 56 / 1,066 |

답: 최근 4주 노쇼율은 4.8~5.3% 횡보. 상태 기준(주의 7.14% / 경고 8.7% — 기록 05
백분위 경계)으로는 전 주 「양호」다. 계산식은 글로서리 노쇼율 정의(부도 ÷ (내원 +
부도)) 그대로이며 View 컬럼으로 역추적된다.

## 2. 원인 질문 경로 — "8월 매출이 왜 떨어졌어?"

원인 질문은 세 단계를 거쳤다: **전제 검증 → 엣지 역추적 → 근거 수치 병기.**

### 2.1 전제 검증 — 질문이 사실과 다르다

KPI View 확인 결과 **8월 매출은 떨어지지 않았다** — 3.69억 원으로 7월(2.91억) 대비
+27%, 8개월 중 2위. 실제로 떨어진 것은 **내원(5,428 → 4,196, 기간 최저)과
예약(9,057 → 6,852, 최저)**이다. 원인 분석형 Agent 의 첫 임무는 전제를 데이터로
바로잡는 것임이 이 시나리오에서 확인됐다.

### 2.2 엣지 역추적 — 확정 Meta 만 사용

교정된 질문 「내원·예약은 왜 떨어졌고 매출은 왜 버텼나」에 대해 edges.csv 의 확정
엣지만 밟았다.

- **매출이 버틴 경로** — 매출 ⟵(산출 0) 결제 내원 × 객단가: 결제 내원이 오히려
  641건(+23%), 객단가 58만 원 유지. 고액(100만 원+) 결제의 금액 비중 69%
  (기록 06 부기 ② 구조).
- **예약 하락 원인 후보 1** — 취소율 →(−, 조기 경보) 예약: 취소율이 7월 36.3%
  기간 피크, 8월 35.5% 고공. 채택 근거(Granger p<0.001)와 정합.
- **예약 하락 원인 후보 2** — 네이버 리뷰 →(+) 예약: 주별 네이버 리뷰가 7월 말
  96건 → 8월 12 → 8 → 4건으로 급감 — 개입(리뷰 확보 캠페인) 중단이 예약 하락과
  동행.
- **선행 경고** — 강남언니 리뷰 →(+, 2주, 신뢰 낮음) 신환: 8월 유기 리뷰가 거의
  0이라 9월 신환 하락 위험. 리텐션 35%(기록 06 부기 ①)와 겹치면 「내원 기반이
  마르는데 고액 결제가 매출을 가리는」 구조가 8월에 가장 극단적이다.

### 2.3 답변 구조가 증명한 것

- 관계 지식이 프롬프트에 없어도 nodes/edges 조회만으로 인과 경로를 서술할 수 있다.
- 기각 엣지도 일했다 — 「프로모션 때문 아닌가」는 edges.csv 의 기각 행(효과 미검출
  + 사유)으로 즉시 배제된다. 같은 질문이 반복되지 않는다.
- 모든 수치는 골드 View 컬럼으로 역추적된다(2.1·2.2 의 수치 전부).

## 4. 로드맵 완주 — 남기는 것

스텝마다 「명세 확인 → 빌드 → 게이트 → 승인」을 통과했고, 실버 채점기 재실행
2회(기록 04)와 명세 개정 2회(기록 04·05·06 — 프로모션 구성, 재방문 전환율)가
게이트·담당자 요청 경로로 이뤄졌다.

**범위 밖으로 남긴 것** — ① 상시 질의 서비스(Agent 에 골드 View·온톨로지 조회
도구를 붙인 배포)는 별도 구축 과제다. ② 라인아이템(예약-시술상품) 수집은 다음
수집 과제(기록 07 한계 1). ③ 시각화 대시보드·운영 루프는 로드맵 선언대로 08 이후의
일이다.
