# 상품 기획

상품 기획은 목표와 가용 자원을 바탕으로 누구에게 어떤 가치를 제공할지 정하고, 제작·판매·운영이 가능하도록 의사결정을 연결하는 활동이다. 상품의 아이디어뿐 아니라 고객에게 전달하고 사용을 지원하는 과정까지 포함한다.

## 정의

출처 사례는 상품 기획을 세 질문으로 설명한다.

1. **무엇을 하고 싶은가:** 원하는 결과와 우선순위를 정한다. 추상적인 희망을 사업 방식과 책임 범위를 선택할 수 있는 수준까지 구체화한다.
2. **가진 무기는 무엇인가:** 사용 경험, 전문성, 고객 접점, 협업 관계, 실행 역량 등 현재 활용 가능한 자원을 확인한다.
3. **그 무기로 어떻게 실행할 것인가:** 목표와 자원에 맞춰 상품·타깃·일정·제작·판매·운영을 연결한다.

실행 단계에서는 다음 결정들이 서로 영향을 준다.

| 결정 | 다음 단계에 주는 기준이나 제약 |
| --- | --- |
| 상품과 타깃 | 해결할 사용 문제와 설명해야 할 가치 |
| 컨셉 | 디자인과 사용성의 구체적인 판단 기준 |
| 출시 시점 | 디자인·생산·입고·판매 준비 일정 |
| 생산량 | 초기 현금 투입, 보관 공간, 재고 부담 |
| 가격과 비용 구조 | 감당할 수 있는 광고비·유통 수수료·배송 지원 |
| 직접 수행과 위탁의 범위 | 내부 업무량과 협력사에 전달할 작업 기준 |
| 고객 응대 | 사용상의 문제와 설명 자료를 개선할 근거 |

무빙워터의 플래너 사례에서 목표는 ‘생존 기반 마련 → 커머스 → 자체 브랜드’로 좁혀졌다. 유튜브 채널은 고객 접점으로, 3년간의 플래너 사용 경험과 협업 경험은 상품 선택의 근거로 쓰였다. ‘성장’이라는 컨셉은 넓은 기록 공간과 단순한 디자인으로 구체화됐다.

판매 목표 5,000개와 최초 생산량 3,000개를 분리했고, 보관·포장·배송은 외부에 맡겼다. 초기 고객 문의는 직접 받아 사용자의 질문을 확인했다. 이처럼 직접 만드는 브랜드라도 업무별 수행 주체는 다를 수 있다.

웹·앱 서비스에서도 목적과 자원, 실행을 연결하는 관점이 적용된다. [[it-service-planning-purpose-plan-execution]]은 이용자에게 필요한 가치와 회사가 얻을 이익을 검토하고, 인력·장비·예산·일정을 계획한 뒤 기능·정책 정의와 화면 설계, 구현 결과 확인과 테스트로 이어지는 기획 업무를 설명한다. 의뢰자가 목적을 정하고 기획자가 계획과 실행을 맡는 경우에도 전체 과정은 유지된다.

목적은 계획을 바꾸고, 실행 가능성 검토는 서비스 범위와 방향을 다시 조정하게 한다. 출처의 가상 사례에서 여름용 서비스가 가을에야 완성될 것으로 예상되면 다음 해로 출시를 미루거나 범위를 줄인다. 기대 효과에 비해 예산이 과도하면 서비스 기획 자체를 다시 검토한다. 생일 파티 사례 역시 ‘평생 기억에 남는 감동’이라는 목적이 더해지면 시간·장소·선물 준비에 영상 편지나 공연이 추가되는 방식으로 목적과 실행의 관계를 설명한다.

## 왜 중요한가

아이디어와 디자인만 정하면 실제 판매에 필요한 비용·물류·고객 지원이 뒤늦게 드러난다. 상품 기획의 범위를 운영까지 연결하면, 제작을 마친 뒤 보관 공간이나 배송 방법을 찾느라 출시가 막히는 문제를 줄일 수 있다.

목표와 자원을 명시하면 대안 사이의 선택도 설명할 수 있다. 자체 브랜드의 자율성, 협업 방식의 책임 분담, 기존 채널을 활용한 판매는 각각 다른 목표와 역량에 맞는 선택이다.

## 경계와 오해

- **기획과 계획은 범위가 다르다.** 웹·앱 기획 출처는 계획을 할 일의 순서와 자원을 정리하는 과정으로, 기획을 목적 설정과 계획·실행을 포함하는 활동으로 설명한다. 화면 설계는 그 실행 업무의 일부다.
- **웹·앱 제작 순서는 보편적인 표준으로 단정하지 않는다.** 출처가 제시하는 화면 기획·디자인·퍼블리싱·개발·QA의 순서와 담당 역할은 조직에 따라 달라질 수 있다.
- **세 질문은 사례의 기획 방식이다.** 모든 상품 기획이 반드시 같은 순서로 진행된다는 표준 절차는 아니다.
- **목표는 수요 예측이 아니다.** 원하는 판매량과 실제 구매 가능성을 구분해야 한다. 사례의 구독자 증가에 따른 판매량 추정도 보편적인 비례 법칙은 아니다.
- **자체 브랜드는 모든 업무의 직접 수행을 뜻하지 않는다.** 위탁하더라도 품질 기준과 고객에게 전달되는 결과를 관리할 책임은 남는다.
- **컨셉은 추상적인 구호에 머물지 않는다.** ‘성장’처럼 넓은 표현은 기록 공간이나 사용 장면처럼 확인 가능한 기준으로 번역되어야 실행에 쓰인다.
- **자산의 존재가 성과를 보장하지 않는다.** 기존 시청자와의 관계에서 얻은 판매 결과를 신규 고객 시장에 그대로 적용할 수는 없다.
