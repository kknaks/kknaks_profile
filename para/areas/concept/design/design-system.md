# 디자인 시스템

디자인 시스템은 여러 화면에서 일관된 UI를 만들기 위해 시각적 값, 컴포넌트와 그 사용 규칙을 재사용 가능한 기준으로 정리한 체계다. 개별 화면을 만들 때 반복되는 디자인 결정을 공유한다.

## 정의

- **시각적 값:** 색상, 글자 크기, 간격, 모서리 반경 등을 [[design-token]]으로 정의한다.
- **적용 규칙:** 본문에 사용할 글자 크기, 제목의 위계, 주요 행동에 사용할 버튼 스타일처럼 값의 용도를 정한다.
- **컴포넌트 기준:** 카드와 버튼 같은 반복 요소에 동일한 규칙을 적용한다.

`16px`라는 값을 확보하는 것과 ‘본문 기본 크기는 16px로 사용한다’고 정하는 것은 다른 단계다. 시스템은 값을 사용하는 맥락까지 전달한다.

AI 디자인 작업에서는 서비스 목적에 맞는 레퍼런스를 선정하고, 반복되는 값을 추출한 뒤, 시스템으로 정리해 UI 생성의 기준으로 제공할 수 있다. 이는 시스템을 구축하고 활용하는 한 가지 작업 흐름이다.

## 사용 예시

출처의 교안은 기본 본문 크기 16px, 제목 크기 28px, 카드 여백 32px와 모서리 반경 12px를 학습용 기준으로 정한다. 다음 CSS는 토큰과 적용 규칙의 관계를 보여 준다.

```css
:root {
  --font-body: 16px;
  --font-heading: 28px;
  --space-large: 32px;
  --radius-card: 12px;
}
body { font-size: var(--font-body); }
h1, h2 { font-size: var(--font-heading); }
.card {
  padding: var(--space-large);
  border-radius: var(--radius-card);
}
```

변수는 공통 값을 담고 선택자 규칙은 적용 대상을 정한다. 이 예제는 최소 원리만 보여 주며 완전한 디자인 시스템은 아니다.

영상은 이러한 기준을 먼저 정리한 뒤 ‘더 세련되게’ 같은 요청 대신 정의한 글자 체계, 간격, 색상과 컴포넌트 기준을 적용해 화면을 생성하도록 요청한다.

## 왜 중요한가

공유 기준이 없으면 화면을 생성하거나 수정할 때마다 비슷한 디자인 결정을 반복한다. 시스템을 제공하면 AI가 새로 결정해야 하는 선택지가 줄어들어 여러 화면의 일관성을 높이는 데 도움이 된다.

기준을 명시하면 수정 요청도 구체화할 수 있다. 막연한 인상을 전달하는 대신 어떤 글자 체계나 간격 규칙을 적용할지 지정할 수 있기 때문이다.

## 경계와 오해

- **레퍼런스의 완성도와 서비스 적합성은 별개다.** 기업용 AI SaaS에 화려한 브랜드 사이트의 규칙을 적용하면 정교하더라도 목적에 맞지 않을 수 있다.
- **토큰 추출만으로 시스템이 만들어지지는 않는다.** 값의 역할과 컴포넌트 적용 규칙을 정리해야 한다.
- **시스템은 콘텐츠 검수를 대신하지 않는다.** UI 생성 후 문구를 따로 읽어 의미와 자연스러움을 검토하고, 수정 반영 후 줄바꿈과 배치를 확인한다.
- **특정 AI 도구에 종속되는 개념은 아니다.** 출처는 클로드 디자인 활용 사례이며, 공유 가능한 디자인 기준이라는 원리는 도구를 바꿔도 남는다.
- **일관성 향상이 모든 품질의 향상을 보장하지는 않는다.** 출처의 비교는 발표자의 사례이며 정량적인 효과 검증으로 제시되지는 않았다.

## 함께 보는 개념

- [[design-token]] — 시스템에서 반복해서 사용하는 시각적 값을 이름으로 관리한다.
