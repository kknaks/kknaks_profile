# 단위를 표시하는 상향 대체

계층 데이터(대분류 → 중분류 → 항목)에서 항목에 없는 값을 상위 값으로 채우되, **그 값이 어느 단위의 사실인지 화면에 남기는 것**. 「V빔의 금기」 자리에 레이저 전체 금기를 보여 주면서 「레이저 전체 기준」을 붙인다.

## 정의

1. **칸마다 따로 찾는다** — 항목 → 상위 → 최상위 순으로 첫 값이 있는 노드를 쓴다. 섹션 단위로 출처 노드가 다를 수 있다(원리는 항목, 금기는 대분류)
2. **비어 있는 중간층은 건너뛴다** — 중분류가 묶음 이름만 갖고 본문이 null 이면 다음 층으로
3. **출처 노드를 값과 같이 돌려준다** — `{ value, sourceId }`. 화면은 `sourceId ≠ 요청 id` 일 때만 「◯◯ 전체 기준」을 그린다
4. **시험은 출처를 단언한다** — 「항목 X 의 금기 출처 = 대분류」 「본문이 없는 중분류의 모든 섹션 출처 = 대분류」

## 경계와 오해

- **숨기기도 조용한 대체도 틀렸다** — 숨기면 상담에 필요한 금기가 사라지고, 표시 없이 대체하면 「이 시술 고유의 금기」로 읽힌다
- **단위를 추측으로 정하지 않는다** — 원천 구조를 실물로 확인해야 한다. 대분류만 보고 「모달이 대분류 설명이 된다」고 예측했지만 실제로는 항목이 자기 본문을 갖고 있어 대부분 항목 단위가 됐다
- 원천에 항목 노드 자체가 없는 이름(카드 시술명은 있는데 원천엔 없음)은 상향 대체가 아니라 **매핑 표**의 문제다 — 후보가 여럿이면 근거 없이 고르지 말고 뺀다
- 원문을 고쳐 쓰지 않는 것과 짝이다 — 원문 + 출처 · 단위 표기로 「누구의 말인가」를 남긴다
