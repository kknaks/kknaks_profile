# DFS (깊이 우선 탐색)

**갈 수 있는 데까지 들어갔다가 막히면 돌아 나오는 탐색.** 재귀 호출이 그 「돌아 나오기」를 대신해 준다 → [[recursion]]

## 정의

```cpp
void dfs(int y, int x) {
    visited[y][x] = 1;                       // 왔다고 표시하고
    for (int i = 0; i < 4; i++) {            // → [[grid-traversal]]
        int ny = y + dy[i], nx = x + dx[i];
        if (경계 밖 || visited[ny][nx] || 못 가는 칸) continue;
        dfs(ny, nx);                          // 더 깊이 들어간다
    }
}

int count = 0;
for (모든 칸)
    if (갈 수 있는 칸 && !visited)
        dfs(y, x), count++;                   // 한 번 부를 때마다 덩어리 하나
```

**바깥 반복문이 「덩어리 개수」를 세는 자리**다 — `dfs` 를 한 번 부르면 **이어진 칸 전부**가 방문 표시되므로, 부른 횟수가 곧 덩어리 수다.

## 왜 중요한가

**「이어진 것을 하나로 묶는」 문제가 전부 이 모양이다.**

| 문제 | 세는 것 |
|---|---|
| 배추 덩어리 수 | `dfs` 를 부른 **횟수** |
| 안전 영역 개수 | 같은 것을 **높이마다** 반복 → [[brute-force]] |
| 영역 넓이 | 부른 횟수 + **각 호출이 방문한 칸 수** |

**바뀌는 것은 「무엇을 세는가」뿐**이고 탐색 코드는 같다.

**그리고 최단 거리에는 안 맞는다.** 깊이부터 파고들므로 **먼저 닿았다고 가장 가까운 것이 아니다** — 그 자리는 [[breadth-first-search]] 다.

## 경계와 오해

- **재귀 깊이가 스택을 넘길 수 있다** — 100×100 격자가 한 덩어리면 호출이 만 겹까지 쌓인다. 격자가 커지면 **스택 오버플로**가 나므로 반복문 + 명시적 스택으로 바꾼다 → [[jvm-stack]] · [[stack]]
- **방문 표시를 들어갈 때 해야 한다** — 나올 때 표시하면 같은 칸으로 서로 들어가 **무한 재귀**가 된다
- **DFS 로 최단 거리를 구하려면 모든 경로를 봐야 한다** — 가능은 하지만 비싸다. 「최단」이면 BFS 를 먼저 떠올린다
- **덩어리를 세는 것과 크기를 재는 것은 다른 반환값이다** — 개수만 필요하면 `void` 로 충분하고, 크기가 필요하면 **방문한 칸 수를 돌려주거나 전역에 누적**한다
- **격자 밖에서도 같은 논리가 성립한다** — 인접이 「상하좌우」가 아니라 「간선으로 이어짐」이면 그래프 DFS 다. **격자는 그래프의 특수한 경우**다
