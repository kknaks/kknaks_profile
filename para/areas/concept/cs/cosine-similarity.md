# 코사인 유사도 (Cosine Similarity)

코사인 유사도는 두 벡터의 길이 영향을 제거하고 방향이 얼마나 비슷한지 비교하는 척도다. 같은 좌표계의 0이 아닌 벡터를 대상으로 정의된다.

## 정의

`cosine(a, b) = (a · b) / (||a|| × ||b||)`

내적을 두 벡터의 유클리드 노름의 곱으로 나눈다. 값의 범위는 -1부터 1까지이며, 같은 방향이면 1, 직교하면 0, 반대 방향이면 -1이다. 비음수 좌표만 사용하는 TF-IDF 벡터에서는 값이 음수가 되지 않는다.

유클리드 거리는 두 점 사이의 직선 거리다. 두 벡터를 단위 길이로 정규화하면 다음 관계가 성립한다.

`||a - b||² = 2 × (1 - cosine(a, b))`

따라서 단위 벡터들에 대해서는 코사인 유사도가 큰 순서와 유클리드 거리가 작은 순서가 같다. 정규화하지 않은 일반 벡터에서는 길이의 영향 때문에 순위가 달라질 수 있다.

## 사용 예시

```python
from math import sqrt


def cosine(a, b):
    if len(a) != len(b):
        raise ValueError("벡터 차원이 달라 비교할 수 없습니다.")
    norm_a = sqrt(sum(x * x for x in a))
    norm_b = sqrt(sum(x * x for x in b))
    if norm_a == 0 or norm_b == 0:
        raise ValueError("영벡터의 코사인 유사도는 정의되지 않습니다.")
    return sum(x * y for x, y in zip(a, b)) / (norm_a * norm_b)


# 크기가 달라도 방향이 같으면 유사도는 1이다.
print(round(cosine([1, 2], [2, 4]), 6))
# 서로 직교하는 방향이면 0이다.
print(cosine([1, 0], [0, 1]))
```

도서 제목을 비교할 때는 TF-IDF 또는 임베딩으로 만든 원래 벡터에 이 연산을 적용한다. 문서 N개끼리 비교하면 N × N 유사도 행렬이 생긴다. 자기 자신과의 유사도는 1이므로 유사 도서 추천에서는 자기 자신을 제외한다.

## 왜 중요한가

벡터의 크기보다 특징의 상대적인 구성이 중요한 경우 방향 비교가 유용하다. 다만 유사도 공식이 같아도 TF-IDF에서는 어휘의 겹침을, 임베딩에서는 모델이 학습한 관계를 반영한다. 척도와 입력 표현을 함께 해석해야 한다.

## 경계와 오해

- **유사도 0.8 ≠ 정답 확률 80%** — 확률이 아니라 방향의 유사성을 나타내는 점수다.
- **같은 차원 수 ≠ 비교 가능한 좌표계** — 다른 모델이나 다른 어휘 순서로 만든 벡터는 차원이 같아도 직접 비교할 근거가 없다.
- **화면 회전 ≠ 원래 거리의 변화** — 함께 회전한 벡터의 내적과 거리는 유지된다. 반면 차원 축소는 정보를 잃어 관계를 왜곡할 수 있다.
- **코사인 유사도 ≠ Transformer의 표준 어텐션** — scaled dot-product attention은 Q와 K의 내적을 조정하고 softmax를 적용하며, 벡터 노름으로 나누는 코사인과 동일하지 않다.
- **영벡터 처리 규칙 ≠ 수학적 정의** — 라이브러리가 영벡터에 특정 값을 반환하더라도, 수식의 분모가 0인 문제를 별도로 인식해야 한다.
