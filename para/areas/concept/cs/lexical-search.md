# 어휘 검색 (Lexical Search)

어휘 검색은 검색어와 문서에 나타난 단어나 문자열의 일치를 바탕으로 결과를 찾는 검색 방식이다. 문서를 토큰화하고 각 용어의 출현과 희소성을 점수화하는 BM25가 대표적인 방법이다.

## 정의

어휘 검색은 문서와 검색어를 검색 가능한 용어 단위로 나눈 뒤, 일치한 용어를 기준으로 관련도 점수를 계산한다. BM25는 문서 안의 용어 빈도, 전체 문서 집합에서 그 용어가 얼마나 드문지, 문서 길이 등을 반영해 결과의 순위를 정한다.

토큰화 결과는 검색 가능성을 좌우한다. 공백으로 나뉘지 않은 한국어 복합어를 토크나이저가 부분어로 분리하지 못하면, 전체 표현의 일부만 입력한 검색어와 일치하지 않을 수 있다.

## 사용 예시

노트 이름이 `안보위기`일 때 토큰화 결과에 `안보`만 검색 가능한 형태로 남고 `위기`가 독립된 토큰으로 만들어지지 않았다면, `안보` 검색에는 노트가 나타나지만 `위기` 검색에는 나타나지 않을 수 있다.

QMD의 BM25가 이런 한국어 검색을 충분히 처리하지 못하는 환경에서는 Grep이나 Glob 같은 파일 검색을 별도로 사용하고, 의미가 비슷한 문서를 찾을 때만 [[semantic-search]]를 사용할 수 있다.

## 왜 중요한가

파일명, 식별자, 오류 메시지처럼 정확한 표현을 알고 있을 때 어휘 검색은 직접적이고 결과를 설명하기 쉽다. 그러나 대상 언어에 맞지 않는 토큰화는 문서에 실제로 존재하는 표현도 찾지 못하게 하므로, 검색 엔진을 선택할 때 점수 알고리즘뿐 아니라 분석기와 토크나이저를 함께 확인해야 한다.

어휘 검색과 의미 검색은 서로 다른 실패 양상을 갖는다. 둘을 조합하면 정확한 단어 일치와 의미적 유사성을 함께 활용할 수 있다.

## 경계와 오해

- **어휘 검색 ≠ 단순한 전체 문자열 포함 검사** — Grep 같은 문자열 검색도 어휘적 일치를 사용하지만, BM25 기반 검색은 토큰화와 관련도 점수로 결과 순위를 계산한다.
- **BM25의 실패 ≠ BM25 공식 자체의 실패** — 한국어 복합어를 찾지 못하는 문제는 점수 계산보다 앞선 토큰화 단계에서 생길 수 있다.
- **어휘 검색 ≠ [[semantic-search]]** — 문서에 같은 표현이 없어도 의미가 가까워서 반환되는 검색은 의미 검색이다.
- **하이브리드 검색 ≠ 언제나 단일 엔진 내부의 결합** — 서로 다른 도구로 어휘 검색과 의미 검색을 수행해 결과를 조합할 수도 있다.
