# 조건 연산자 (삼항 연산자)

조건에 따라 두 값 중 하나를 고르는 연산자. 조건이 참이면 앞, 거짓이면 뒤를 돌려준다.

## 정의

```plaintext
조건 ? 표현식1 : 표현식2
```

피연산자가 셋이라 **삼항 연산자**라고도 부른다. 핵심은 **값을 돌려준다**는 것이다 — 문장이 아니라 [[expression-vs-statement]] 의 표현식이다.

## 사용 예시

값으로 받는 쪽과 인자로 넘기는 쪽 둘 다 된다.

```java
int age = 20;
String a = "성년", b = "미성년";

// case 1. 결과를 변수로 받는다
String message = age > 18 ? a : b;
System.out.printf("나이 %d는(은) %s이다.\n", age, message);

// case 2. 메서드 인자로 넘긴다
test(age > 18 ? "성년" : "미성년");
```

돌려주는 값을 쓰는 자리가 반드시 있어야 한다. 없으면 문법 오류다 — 자세한 세 경우는 [[expression-vs-statement]] 에 있다.

## 왜 중요한가

**값을 고르는 일이 한 줄로 끝난다.** `if-else` 로 쓰면 변수를 먼저 선언하고 양쪽 가지에서 각각 대입해야 하는데, 조건 연산자는 선언과 결정을 한 번에 한다. Java 의 `if` 가 값을 돌려주지 않기 때문에 이 자리를 메우는 것이 조건 연산자다.

## 경계와 오해

- **양쪽은 값이어야 한다** — `System.out.println(...)` 처럼 값을 돌려주지 않는 것은 올 수 없다. `if-else` 와 바꿔 쓸 수 있다고 생각하면 여기서 막힌다.
- **양쪽 타입이 맞아야 한다** — 결과를 받는 변수의 타입과 어긋나면 컴파일 오류다.
- **중첩하면 읽기 어려워진다** — `a ? x : b ? y : z` 처럼 겹칠 수 있지만, 이때는 `if-else` 나 [[switch-statement]] 가 낫다. 짧게 쓰는 것이 목적이 아니라 **값을 고르는 일임을 드러내는 것**이 목적이다.
- **`if` 의 대체가 아니다** — `if` 는 흐름을 가르는 문장이고 이것은 값을 고르는 표현식이다. 하는 일이 다르다.
