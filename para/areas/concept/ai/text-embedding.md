# 텍스트 임베딩 (Text Embedding)

텍스트 임베딩은 문장이나 문서를 의미적 관계를 비교할 수 있는 수치 벡터로 변환한 표현이다. 임베딩 모델은 의미가 비슷한 텍스트를 벡터 공간에서 가깝게, 다른 텍스트를 멀게 배치하도록 학습된다.

## 정의

임베딩 모델은 텍스트를 `[0.2, -0.5, ...]`와 같은 고정 차원의 벡터로 변환한다. 같은 모델로 만든 문서 벡터와 검색어 벡터는 코사인 유사도 등의 거리·유사도 척도로 비교할 수 있으며, 이 비교가 [[semantic-search]]의 기반이 된다.

긴 문서를 임베딩할 때는 문서를 여러 청크로 나누고 청크마다 벡터를 만들 수 있다. 고정된 토큰 수에서 무조건 자르면 문장이나 문맥이 갈라질 수 있으므로, 마크다운 문서에서는 헤딩과 절 같은 구조를 청킹 경계로 활용할 수 있다.

임베딩 품질은 모델과 언어에 따라 달라진다. 특정 언어의 표현 관계를 충분히 학습하지 못한 모델은 그 언어로 작성된 문서와 검색어를 적절히 가까운 벡터로 만들지 못할 수 있다.

임베딩은 [[text-vectorization]]의 한 방법이다. [[tokenization]]이 텍스트를 처리 단위로 나누는 과정이라면, 임베딩은 학습된 관계를 밀집 벡터로 표현한다. [[tf-idf]] 결과를 반드시 거쳐야 하는 것은 아니다. 밀집 벡터에도 0이 들어갈 수 있으며, 저차원이라는 표현은 대개 큰 어휘 공간과 비교한 것이다.

정적 단어 임베딩은 단어마다 고정된 벡터를 부여하고, 문맥적 표현은 주변 문맥에 따라 달라질 수 있다. 문장·문서 임베딩은 텍스트 전체를 비교하기 위한 표현이며, 임의의 문맥 모델 출력을 평균 낸다고 검색 품질이 보장되지는 않는다.

벡터를 재사용하려면 문서 ID, 원문 위치, 모델 식별자, 차원 수, 전처리 방식과 원문 변경 여부를 함께 관리한다. 벡터와 메타데이터를 별도 파일로 내보낼 때는 같은 행이 같은 문서를 가리켜야 한다.

## 사용 예시

QMD에서 한국어 노트를 임베딩할 때 모델을 Qwen3 Embedding 0.6B로 지정하고 기존 벡터를 다시 만들 수 있다.

```sh
export QMD_EMBED_MODEL="hf:Qwen/Qwen3-Embedding-0.6B-GGUF/Qwen3-Embedding-0.6B-Q8_0.gguf"
qmd embed -f
```

문서가 바뀌면 인덱스를 갱신하고 새 내용의 임베딩을 생성해야 한다.

```sh
qmd update && qmd embed
```

도서 제목 50개를 임베딩한 출처 실습에서는 각 제목이 1,536차원 벡터가 되고, 『밑바닥부터 시작하는 딥러닝』 시리즈가 서로 높은 유사도를 보였다. 이는 제목의 유사성에 대한 관찰이며 책 본문 전체의 유사성을 입증하지 않는다.

이 벡터를 PCA로 3차원에 투영하고 TensorFlow Embedding Projector에서 탐색할 수 있다. 검색 순위는 원래 벡터의 [[cosine-similarity]] 등으로 확인하고, 축소된 좌표는 관계를 설명하고 탐색하는 용도로 구분한다.

## 왜 중요한가

임베딩은 단어가 정확히 일치하지 않아도 의미가 가까운 텍스트를 계산으로 비교하게 한다. 따라서 노트 검색, 검색 증강 생성, 추천, 군집화처럼 비정형 텍스트 사이의 관련성을 찾아야 하는 작업의 입력 표현으로 쓰인다.

반대로 모델의 언어 성능이나 청킹 방식이 맞지 않으면 이후의 유사도 계산이 정확하더라도 유용한 결과를 얻기 어렵다. 모델 선택과 임베딩 갱신은 검색 운영의 일부다.

## 경계와 오해

- **텍스트 임베딩 ≠ 원문의 완전한 보존** — 벡터는 비교에 필요한 특징을 압축한 표현이며 원문 전체를 복원하는 저장 형식이 아니다.
- **임베딩 생성 ≠ 검색** — 임베딩은 텍스트를 벡터로 바꾸는 단계이고, [[semantic-search]]는 이 벡터를 인덱싱하고 비교해 결과를 반환하는 과정이다.
- **큰 모델 ≠ 모든 언어에서 항상 우수한 모델** — 모델 크기뿐 아니라 학습 데이터와 대상 언어의 성능을 확인해야 한다.
- **파일 갱신 ≠ 임베딩 자동 갱신** — 사용하는 도구가 변경을 자동 반영하지 않는다면 재인덱싱과 재임베딩을 별도로 실행해야 한다.

- **시각화 좌표 ≠ 원래 임베딩** — 차원 축소는 정보를 잃는다. 화면에서 가까운 점이 원래 공간에서도 반드시 가까운 것은 아니다.
- **임베딩 유사도 ≠ 정답 확률** — 점수의 해석은 모델과 데이터에 따라 달라지며, 기대 문서가 상위에 나오는지로 평가한다.
