# 멀티모달 모델 (Multimodal Model)

둘 이상의 데이터 형태(모달리티)를 처리할 수 있는 모델이다. 「대규모 언어모델」이 [[foundation-model]]로 이름을 바꾸게 만든 직접적인 이유다.

## 정의

입력과 출력의 형태 조합으로 갈린다.

| 방향 | 예 | 모델 |
| --- | --- | --- |
| 이미지 + 텍스트 → 텍스트 | 사진 넣고 「이거 무슨 오류야?」 | GPT-4V, Claude, Gemini |
| 텍스트 → 이미지 | 문장으로 그림 생성 | DALL·E, Midjourney, Stable Diffusion |
| 음성 → 텍스트 | 회의 녹음 전사 | Whisper |
| 텍스트 → 음성 | TTS 읽어주기 | - |
| 텍스트 → 동영상 | 문장으로 영상 생성 | Sora |

필요한 이유는 **사람이 세상을 받아들이는 방식이 원래 멀티모달**이기 때문이다. 차트·스크린샷·도면에 든 정보는 텍스트로 옮겨 적으면 상당 부분이 손실된다. 입력을 텍스트로만 받으면 그 손실을 사람이 메워야 한다.

서로 다른 형태를 한 모델이 다루려면 같은 벡터 공간에 놓아야 한다. 그 방법의 대표가 [[contrastive-learning]]이다.

## 왜 중요한가

제품에서 「전처리로 텍스트만 뽑아 넣는」 설계의 대가를 드러낸다. OCR 로 표를 읽어 텍스트로 바꾸는 순간 레이아웃·강조·도형 관계가 사라지고, 그 손실은 뒤에서 복구되지 않는다. 입력 형태를 무엇으로 받을지가 파이프라인 첫 단계에서 결정되는 품질 상한이다.

## 경계와 오해

- **멀티모달 ≠ 모든 형태를 다 처리** — 지원하는 방향 조합이 모델마다 다르다. 이미지를 읽는 것과 이미지를 만드는 것은 별개 능력이다.
- **텍스트로 변환 ≠ 동등한 입력** — 옮겨 적는 과정에서 정보가 줄어든다.
- **멀티모달 ≠ 더 정확** — 다루는 형태가 늘어난 것이지 각 형태의 정확도가 보장되는 것은 아니다.
