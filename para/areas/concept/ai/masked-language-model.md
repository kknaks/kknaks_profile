# 마스크 언어모델 (Masked Language Model)

누락된 토큰의 **전후 컨텍스트를 모두 사용해** 시퀀스의 어느 위치에서든 가려진 토큰을 예측하는 [[language-model]]이다. 빈칸 채우기(cloze) 방식이고 대표 모델은 BERT다.

## 정의

입력 토큰의 일부(BERT는 15%)를 `[MASK]`로 가리고 원래 토큰을 맞히게 학습한다. 정답은 원문 자체에서 나오므로 사람이 라벨을 달지 않는다([[self-supervised-learning]]).

```text
입력   내가 가장 좋아하는 [MASK]는 파란색이다
정답   색상
```

앞뒤를 다 보기 때문에 **문장 전체를 보고 판단하는 작업**에 맞는다. 「이 영화 진짜…」까지만 보면 호평인지 혹평인지 모르고 뒤까지 봐야 정해진다. 코드도 아래쪽 줄을 봐야 위쪽의 버그가 보인다. 그래서 감정분석·코드 디버깅·분류가 주 용도다.

한계가 셋이다.

1. **생성에 적합하지 않다.** 빈칸은 채우지만 임의 길이로 이어 쓰는 구조가 아니다.
2. **학습과 사용 조건이 어긋난다.** 학습 때만 쓰는 `[MASK]`가 실제 입력에는 없다.
3. **학습 신호가 적다.** 한 문장에서 15%만 신호로 쓰므로 같은 데이터에서 얻는 양이 [[autoregressive-language-model]]보다 적다.

파운데이션 모델의 주류에서는 벗어났고 임베딩·분류·검색 리랭킹 쪽에 남아 있다.

## 왜 중요한가

「LLM = 다음 토큰 예측」이 전부가 아님을 보여주는 반례다. 지금도 [[text-embedding]] 모델과 리랭커의 상당수가 이 계열이므로, 검색 파이프라인을 짤 때 생성 모델과 임베딩 모델이 왜 다른 물건인지가 여기서 갈린다.

## 경계와 오해

- **마스크 언어모델 ≠ 구식 모델** — 주류 생성 모델에서 밀려난 것이지 쓸모가 없어진 것이 아니다. 임베딩·분류·리랭킹의 현역이다.
- **양방향 ≠ 더 똑똑함** — 보는 문맥이 넓은 것과 생성 능력은 별개다. 양방향이라 오히려 이어 쓰지 못한다.
- **`[MASK]` ≠ 실제 입력에 나타나는 토큰** — 학습 전용 장치다. 이 불일치 자체가 이 방식의 약점이다.
