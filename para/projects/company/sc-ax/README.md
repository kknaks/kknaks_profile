# sc-ax

sc 경영관리 AX 프로젝트. 회사 일이라 `sot: external` — 기획·스펙의 원천은 회사 레포
mediness 의 `sc-ax` 브랜치(`products/sc-ax/`)다. 여기 남는 것은 **내 경험뿐**이다.

## 구조

- `log/` — 작업 회고, `YYYY-MM-DD-<slug>.md` (오케스트레이션 SUMMARY 착지)
- `showcase.md` — 아직 없다. 공개 카드 등록 때 만든다

## 연결

- 오케스트레이션 설정: `orchestration/config/projects/sc-ax.json`
- 지난 발주 기록: `orchestration/work/_archive/sc-ax/`
- 인터뷰 원료: 프로필 레포 `references/2026-08-28-sc인터뷰-경영관리부/`
