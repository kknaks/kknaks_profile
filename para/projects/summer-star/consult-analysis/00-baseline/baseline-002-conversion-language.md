# BASE-002 예약 전환 · 언어별 특징 분석 요구

## 요구 (사용자)

- 「지금 대화를 가지고 **예약까지 가는 대화는 어떤 대화**고, **각 언어별로 어떤 특징**이 있는지 **언어적 통계**를 내는 작업을 할 거야」
- 판정은 규칙 + LLM(문의 주제 · 시술), 번체/간체는 규칙
- 결과는 분석 보고서(md) + 차트 페이지

## 1층 DB 대략치 (2026-11-16, 코디 · 판정 아님)

고객 메시지의 문자 종류(유니코드 범위)로 방마다 가장 많은 문자를 센 값.

| 방의 고객 문자 | IG | FB | 합 |
|---|---|---|---|
| 한자(번체 · 간체 미구분) | 427 | 1,277 | 1,704 |
| 라틴 | 48 | 63 | 111 |
| 한글 | 22 | 26 | 48 |
| 가나 · 태국 | 2 | 2 | 4 |
| 글자 없음 | 6 | 10 | 16 |

- 고객 메시지 8,726 · 우리 메시지 19,980 (1층 SPEC-001 §7)
- 고객 메시지에 예약표 칸 낱말(國籍 · 国籍 · 姓名 · nationality · 국적)이 있는 방: IG 40 · FB 50 ≈ **90방(약 5%)**
- 한자권이 89% — 언어 특징의 중심은 **번체 / 간체 구분**이다. 문자 범위로는 구분되지 않는다

## 아직 모르는 것

- 번체 · 간체 · 혼용 비율
- 라틴 문자 방의 실제 언어(영어 외)
- 예약표를 쓰지 않고 다른 방식(전화 · 다른 메신저 · 링크)으로 예약을 넘긴 대화가 있는지
- 페이스북 예약표 문구가 인스타그램과 같은지
