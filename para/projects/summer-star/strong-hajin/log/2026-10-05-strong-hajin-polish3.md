## 1. 무엇을 했나

운영을 쓰며 나온 요청 여섯(로그인 문구 · 회의 내보내기 단추와 데스크톱 다운로드 · 회의 제목 수정 · 업무 상세 편집 흐름 · 선행업무 안내 · 헤더 여백)을 모았다.
업무 상세는 「보려고 열었다 닫을 때 푸터의 완료 처리를 누르게 되는」 구조였고, 사용자와 와이어프레임을 다시 그려 **푸터·편집 모드를 없애고 값마다 그 자리에서 바로 저장**하는 화면으로 바꿨다(헤더 = 제목 + ×, 메타 정보 구역, 상태 셀렉트, 걸린 일 상자).
데스크톱 앱은 회의 「내보내기」가 HTML 을 앱 창에 그려 갇히던 것을, 셸이 `/api/` 링크를 가로채 직접 받아 다운로드 폴더에 저장하게 했다. 서버는 바꾸지 않았다.

## 2. 적용한 기술·개념

- **인라인 즉시 저장 + 낙관적 잠금 직렬화** [[optimistic-lock]] — 편집 모드·「변경 저장」을 없애고 필드 하나 = PATCH 하나로
  - 왜 이걸 골랐나: 서버가 업무를 바꾸는 **모든 명령마다 version 을 올리고 어긋나면 422**를 준다(be-survey §4-3). 필드별 자동 저장을 그냥 붙이면 두 필드를 연달아 고칠 때 둘째가 422 다. 서버에 일괄 저장을 새로 만드는 대신, 화면이 **한 줄 대기열**로 보내고 앞 응답의 version 을 다음 요청에 싣는 쪽을 골랐다 — 서버 변경 0
  - 무엇이 어려웠나: 처음엔 인라인 저장만 대기열에 넣었는데, 검수가 「상태 전이·체크리스트·제안·자료·완료 보고가 줄 밖이라 저장 중에 누르면 422」를 두 번에 걸쳐 짚었다(2a W1 → 2b W1). **version 을 올리는 명령 전부**를 세어서 한 줄에 태워야 닫혔다. 422 stale 은 「남길 입력 칸이 없으니」 다시 읽은 서버 값으로 맞춘다(코디 W3)
  - 근거: `review-fe-p2a-report.md` W1 · `review-fe-p2b-report.md` W1 · SPEC-007 §2.10.4 · `cc64d18` · `58e591a`

- **상태 전이 = 서버 허용표를 그대로 비추는 셀렉트** [[server-authoritative-transition]] — 푸터 단추 11종을 셀렉트 하나로
  - 왜 이걸 골랐나: 상세 응답에 「지금 갈 수 있는 상태」 목록이 없다. 화면이 규칙을 새로 만들면 서버와 어긋난다 → 서버 허용표(be-survey §4-5) × 역할을 SPEC 표로 옮기고, 화면은 그 표만 비춘다. 선행 미완도 화면이 미리 막지 않고 서버 409 문장을 토스트로
  - 무엇이 어려웠나: 「진행과 판단」 구역이 담당자 변경 버튼 하나인 줄 알았는데 조사하니 **조건부 구획 여덟**(완료 확인 대기·제안 응답·막힘 사유…)이 있었다. 지우면 기능이 사라질 뻔했다 → 「걸린 일 상자」로 옮겼다. 확인 대기 상태처럼 표가 말하지 않는 칸은 기존 계약(SPEC-005 관문 다)을 계승해 「글자만」으로 닫았다
  - 근거: `fe-survey-report.md` §4-3·§4-4 · SPEC-007 §2.10.3·§2.10.5 · `review-spec-report.md` W7

- **Tauri(wry) 웹뷰의 첨부 응답 처리** [[webview-attachment-download]] — 셸이 같은 origin `/api/` 를 가로채 Rust 가 쿠키를 실어 직접 받는다
  - 왜 이걸 골랐나: wry 0.55.1(macOS)은 응답 정책에서 `canShowMIMEType` 만 보고 `Content-Disposition` 을 읽지 않는다. `text/html` 첨부는 표시 가능이라 **Allow → 창에 그려지고** download handler 는 불리지 않는다(소스 확인). 웹에서 fetch+blob 으로 바꾸는 안(C)은 링크 10자리와 Phase 1·2 파일을 건드려 버렸고, 경로 패턴을 셸이 아는 안(A) 대신 `/api/` 접두 하나만 아는 안(B)을 골랐다 — 새 파일 엔드포인트도 자동으로 덮는다
  - 무엇이 어려웠나: macOS 는 `_blank` 도 opener 의 이동 훅을 먼저 지나 셸이 같은 탭/새 창을 못 가른다 → inline 응답을 「다시 navigate」 하면 채팅 링크가 앱 창을 덮는다. inline 은 어느 쪽이든 아무것도 안 하는 것(X)으로 닫았다. 쿠키는 `cookies_for_url` 이 메인 스레드 콜백이라 별도 스레드에서. 알림은 `eval` + `CustomEvent` 로 capabilities 변경 0
  - 근거: `fe-p3-decision.md` §0·§5 · `review-fe-p3-report.md` · SPEC-006 U-5 · `9c15934`

- **화면 결정은 와이어프레임으로 사용자와 닫는다** [[wireframe]] — 「편집 버튼 위치」 → 「푸터 자체가 이상」 → 「인라인」 → 「메타 정보 구역」 → 「상태도 메타에」로 다섯 번 좁혀졌다. 조사 리포트가 나온 뒤 권고 7건(a~g)을 한 번에 물었고, 사용자는 번호로 답했다
