## 문제

메시지함에 쌓인 메일·슬랙·카톡을 AX 가 읽고 내 프로젝트·업무를 탐색해 업무 생성/업데이트/패스를 제안하는 2단계가 아직 없다.

## 기대 결과

- 메시지(또는 흐름 묶음) 도착 = 이벤트 → AX 판단 → 생성·업데이트 제안은 업무 > 수신함에서 사람이 승인
- 패스는 메시지함에만 남음

## 관련

- 사람이 메시지를 직접 골라 AX 업무 생성 → [SH-IMP-015](SH-IMP-015-message-hover-actions.md)
