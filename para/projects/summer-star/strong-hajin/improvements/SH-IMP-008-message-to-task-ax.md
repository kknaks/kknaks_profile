# SH-IMP-008 — 메일 → AX 업무 생성 · 요약(수동 먼저 · 자동 추천은 다음)

출처: DEC-008 「다음 단계로 미룬 것」 · 사용자 2026-10-07

## 문제

메시지함에 쌓인 메일·슬랙·카톡을 AX 가 읽고 내 프로젝트·업무를 탐색해 업무 생성/업데이트/패스를 제안하는 2단계가 아직 없다.

## 범위 (사용자 확정 2026-10-07)

- **메일로 좁힌다.** 슬랙·카톡은 SH-IMP-015(사람이 고르는 호버 막대)로 가고 자동 추천은 하지 않는다 — 그래서 「흐름의 이벤트 단위」 미결이 사라진다
- **수동 먼저**: 메일 머리의 **[답장] [전체 답장] 옆에 「업무 생성」 · 「요약」 단추 둘** — SH-IMP-015 와 **같은 흐름**. 넘기는 맥락은 서버가 DB 에서 조합한 그 메일(우리 모양 JSON)
  - 업무 생성: 오른쪽 AX 채팅 서랍이 열린다 → 「이 메일 읽고 업무를 생성해 줘」 말풍선 → 기존 AX 업무 생성 흐름 → 추천
  - 요약: 오른쪽 AX 채팅 서랍이 열린다 → 「이 메일 요약해 줘」 말풍선 → 요약(저장하지 않음)
- **자동은 다음**: 메일 도착 이벤트가 같은 「메일 맥락 → AX 업무 초안」 로직을 부른다. 수동 로직을 이벤트 기반으로 바꾸는 것이라 지금 그 로직을 **입구(단추 · 이벤트)와 떼어** 만든다
- 「업데이트」(기존 업무 갱신) 추천은 이번 범위 밖 — 생성만

## 기대 결과

- 메시지(또는 흐름 묶음) 도착 = 이벤트 → AX 판단 → 생성·업데이트 제안은 업무 > 수신함에서 사람이 승인
- 패스는 메시지함에만 남음

## 관련

- 사람이 메시지를 직접 골라 AX 업무 생성 → [SH-IMP-015](SH-IMP-015-message-hover-actions.md)
