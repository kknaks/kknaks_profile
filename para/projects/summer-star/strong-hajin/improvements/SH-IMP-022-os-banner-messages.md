# SH-IMP-022 — 메일 · 슬랙 · 카톡 OS 알림 배너가 안 뜬다

상태: 조사 중  
생성일: 2026-10-12  
갱신일: 2026-10-12  
출처: 사용자 2026-10-12 (운영 DB 를 비우고 시드를 다시 넣은 뒤 — 「알림은 오는데 배너가 안 온다」)

## 문제

알림 목록(앱 안)에는 메시지 알림이 오는데, macOS **시스템 알림 배너**가 안 뜬다(메일 · 슬랙 · 카톡).

## 코디 확인 (2026-10-12 · 운영 DB SELECT · 이 Mac)

| 채널 | 들어온 메시지 | 알림 | 판정 |
|---|---|---|---|
| 슬랙 | 연결 때 과거 4,074건 + **12:11 · 12:12 실시간 DM 2건** | **2건 생성**(`message.slack` · `created`) | 서버 정상 → **배너는 앱(셸) 쪽** |
| 메일 | 과거 1,698건(최근 메일 10/11) | 0 | 연결 뒤 새 메일 없음 — 판정 불가(과거분은 알리지 않음 · OQ-1101) |
| 카톡 | 과거 62건(최근 10/08) | 0 | 10:05 뒤 새 업로드 없음 — 새 메시지가 없었나 · **수집기가 멈췄나** 확인 필요 |

- macOS 알림 설정: `app.ax.desktop` 등록 · 허용(auth=6 = 배너 + 소리) — 권한 문제 아님
- 앱은 `/Applications/medi-ax.app` 실행(dmg 볼륨 실행 아님)
- 셸 로그(`log_event`)는 stdout 이라 설치 앱에서는 남지 않는다 → 배너 경로를 볼 기록이 없다

## 가설

1. **의도한 생략** — 그 DM 방을 보고 있으면 OS 배너를 생략한다(DEC-010 D-39 ①). 12:11 에 그 방을 열어 두었나(사용자 확인)
2. 웹 발송기(`osNotifier`)가 `notification.upserted` 를 못 받음 · `created`/`replayed` 거름 · 묶음 창
3. 셸 `notify_show` 가 `{shown:false}` — UN 이 앱 앞에 있을 때 `willPresent` · 번들/서명 · 권한 상태 읽기
4. 카톡: 수집기 업로드가 멈춤(기기 토큰 재연결 뒤)

## 진행 관리

- [ ] 사용자 확인 — 12:11 에 조상아 DM 방을 보고 있었나
- [ ] 셸 로그를 파일로 남기기(진단) — 배너 경로 각 단계(받음 · 거름 · 생략 · `notify_show` 결과)
- [ ] 실시간 메일 1통 · 카톡 1건으로 재현
- [ ] 원인 확정 → 고침 → dmg
