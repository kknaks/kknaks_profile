# SH-IMP-001 — AX 회의 생성 흐름과 회의록 작성 통합

상태: 미착수  
생성일: 2026-10-06  
갱신일: 2026-10-07  
출처: [BASE-007](../00-baseline/baseline-007-meeting-creation-improvements.md)

## 문제

AX 회의 생성 확인 카드가 현재 AX 회의록 작성 흐름과 다르다. 참고자료는 업무 생성 AX
카드와 동일한 동작을 사용해야 한다.

## 사용자 정리 (2026-10-07)

- 대상은 **AX 채팅에서 「회의 생성해 줘」 했을 때의 흐름**이다
- AX 업무 생성은 **스텝 바이 스텝**으로 진행되는데, AX 회의 생성은 그와 UI·흐름이 다르다 — AX 회의 생성 흐름을 업무 생성처럼 고친다

## 조사 항목

1. AX 채팅 「회의 생성」 과 AX 업무 생성의 현재 흐름·UI 비교 — 업무 생성의 스텝(무엇을 어떤 순서로 묻고 확인하는지 · 참고자료를 어떻게 찾고 보여 주는지)과 회의 생성 카드(`action-meeting-card`)가 어디서 갈라지는지

## 기대 결과

- AX 회의 생성이 AX 업무 생성처럼 스텝 바이 스텝으로 진행된다.
- 업무 생성 AX 카드와 동일한 기준으로 참고자료를 찾고 확인할 수 있다.
- 회의 예약에만 필요한 단계는 기존 흐름과 구분해 자연스럽게 연결한다.
