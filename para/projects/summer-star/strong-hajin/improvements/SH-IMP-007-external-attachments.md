# SH-IMP-007 — 외부 채널 첨부 받기 — 카톡 안 받아짐 · 슬랙/메일 운영 확인

상태: 조사 중  
생성일: 2026-10-07  
갱신일: 2026-10-07  
출처: WORK-011 운영 E2E(사용자), 2026-10-07

## 문제

운영에서 카톡 대화의 첨부(사진·앨범·파일)를 받을 수 없다. 슬랙 첨부는 로컬에서 중계 3/3 을 확인했지만 운영 확인은 안 했고, 메일 첨부 받기는 로컬·운영 모두 실물 확인이 없다.

## 사용자 확인 (2026-10-07)

- **웹(브라우저)에서는 첨부가 받아진다. 데스크톱 앱(medi-ax)에서는 안 받아진다** — 채널 문제가 아니라 앱의 내려받기 경로 문제일 가능성이 크다 → [SH-IMP-014](SH-IMP-014-desktop-download.md)

## 기대 결과

- 카톡: 사진·앨범·파일은 수집 순간 CDN 에서 받아 hostPath 에 저장되고 메시지함에서 열린다(DEC-008 카톡 첨부 결정) · 만료된 것은 「만료됨」
- 슬랙: 사용자 토큰으로 중계(저장 안 함) · 썸네일/원본
- 메일: Gmail 첨부 ID 로 중계(저장 안 함) · 25MB 보내기 한도

## 진행 관리

- [ ] 카톡 수집기의 첨부 다운로드·업로드 경로 운영 로그 확인(수집기 로그 · back 업로드 응답)
- [ ] 운영 hostPath(`/mnt/mac/strong-hajin/external-channels`)에 파일이 생기는지
- [ ] 슬랙·메일 첨부를 운영에서 각 1회 받아 보기
- [ ] 채널별 결과 표로 남기고 수정
