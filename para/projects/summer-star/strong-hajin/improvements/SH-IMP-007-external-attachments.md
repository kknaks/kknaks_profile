# SH-IMP-007 — 외부 채널 첨부 받기 — 카톡 안 받아짐 · 슬랙/메일 운영 확인

상태: 조사 중  
생성일: 2026-10-07  
갱신일: 2026-10-07  
출처: WORK-011 운영 E2E(사용자), 2026-10-07

## 문제

운영에서 카톡 대화의 첨부(사진·앨범·파일)를 받을 수 없다. 슬랙 첨부는 로컬에서 중계 3/3 을 확인했지만 운영 확인은 안 했고, 메일 첨부 받기는 로컬·운영 모두 실물 확인이 없다.

## 사용자 확인 (2026-10-07)

- **운영 웹(`ax.medisolveai.xyz`)에서 카톡·슬랙·메일 첨부가 모두 받아진다** — 카톡은 수집·hostPath 저장, 슬랙·메일은 중계가 운영에서 동작한다
- 데스크톱 앱(medi-ax)에서는 네 갈래 모두 다운로드 자체가 뜨지 않는다 — 수집·저장이 아니라 앱 셸의 받기 문제다 → [SH-IMP-014](SH-IMP-014-desktop-download.md)

## 기대 결과

- 카톡: 사진·앨범·파일은 수집 순간 CDN 에서 받아 hostPath 에 저장되고 메시지함에서 열린다(DEC-008 카톡 첨부 결정) · 만료된 것은 「만료됨」
- 슬랙: 사용자 토큰으로 중계(저장 안 함) · 썸네일/원본
- 메일: Gmail 첨부 ID 로 중계(저장 안 함) · 25MB 보내기 한도

## 진행 관리

- [x] 슬랙·메일 첨부 중계 — 운영 웹에서 받아짐(2026-10-07 사용자)
- [ ] **앱(medi-ax)에서 세 채널 첨부가 받아진다** — 사용자는 앱만 쓰므로 이것이 완료 조건. SH-IMP-014 수정 뒤 확인
- 따로 확인하지 않은 것: 카톡 「만료됨」 표시 · 메일 25MB 보내기 한도
