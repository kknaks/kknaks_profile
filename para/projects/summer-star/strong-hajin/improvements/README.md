# Strong Hajin — 개선 목록

운영 화면을 쓰며 발견한 버그와 고도화 항목을 계속 기록하고 상태를 관리한다. 초기
피드백의 원문과 맥락은 연결된 baseline에 두고, 이 문서는 현재 상태와 다음 조치의
목록으로 쓴다.

## 상태 규약

| 상태 | 의미 |
|---|---|
| 미착수 | 확인된 개선 항목이며 조사나 구현을 시작하지 않음 |
| 조사 중 | 현재 동작·원인·영향 범위를 확인 중 |
| 진행 중 | 결정된 동작을 구현하거나 검수 중 |
| 완료 | 반영과 필요한 사용자 확인을 마침 |
| 보류 | 이유를 기록하고 당분간 진행하지 않음 |

항목을 갱신할 때 상태, 다음 조치, 갱신일을 함께 고친다. 해결한 항목도 삭제하지 않고
완료일과 결과를 남긴다. 구현 계약이 확정되면 해당 SPEC/WORK를 연결한다.

## 변경 이력

- 2026-10-06 — 운영 화면 피드백 네 건으로 목록을 시작했다. 원문·화면 근거: [BASE-007](../00-baseline/baseline-007-meeting-creation-improvements.md).
- 2026-10-06 — 수동으로 작성한 안건이 ‘지난 회의에서 넘어옴’으로 표시되는 문제를 추가했다. 회의 정보만 불러온 경우의 출처 표기 기준을 확인한다.
- 2026-10-07 — 운영 버그 기록 BUG-001(reference)을 SH-IMP-006 으로 이관했다. WORK-011(외부 채널) 운영 E2E 에서 나온 후속 일곱 건(SH-IMP-007~013)을 추가했다.
- 2026-10-07 — 데스크톱 앱에서 첨부 받기·회의록 내보내기가 안 되는 문제를 SH-IMP-014 로 추가했다(웹은 정상).
- 2026-10-07 — 메시지 호버 행동 막대(스레드 열기 · AX 업무 생성) 제안을 SH-IMP-015 로 추가했다.
- 2026-10-07 — SH-IMP-015 막대 구성 확정: 슬랙 = 스레드 열기·AI 업무 생성·AI 내용 요약, 카톡 = AI 업무 생성·AI 내용 요약.
- 2026-10-07 — SH-IMP-007: 운영 웹에서 카톡·슬랙·메일 첨부가 모두 받아진다(사용자) — 서버 쪽 근거. 사용자는 앱만 쓰므로 앱에서 받아질 때 완료한다. 앱에서 네 갈래 모두 다운로드가 뜨지 않는 것은 SH-IMP-014 에 기록했다.
- 2026-10-07 — SH-IMP-002 를 버그로 정리했다. SH-IMP-003 에 회의 수정 때의 회의실 재검색·「선택 안 함」·Connect 예약 수정을 더했다. AX 채팅으로 회의를 바꾸는 흐름을 SH-IMP-016 으로 추가했다.
- 2026-10-07 — SH-IMP-009 완료: 운영에서 각자 본인 계정을 연결해 혼동이 없다(원인은 로컬 시험 방식). 연결 계정 표시·불일치 거절은 필요할 때 재개.
- 2026-10-07 — SH-IMP-008 을 메일로 좁혔다: 수동 단추(답장 옆) 먼저, 메일 도착 이벤트 자동 추천은 같은 로직으로 다음에. 슬랙·카톡은 SH-IMP-015. SH-IMP-010 은 inbox stream 사건(A)으로 결정.
