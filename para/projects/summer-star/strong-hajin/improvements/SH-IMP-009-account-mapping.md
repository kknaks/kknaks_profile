# SH-IMP-009 — 앱 사용자 ↔ 연결 계정 표시·검사

상태: 완료  
생성일: 2026-10-07  
갱신일: 2026-10-07  
출처: WORK-011 로컬 E2E · 사용자 2026-10-06

## 문제

연결한 슬랙·Google 계정이 로그인한 앱 사용자와 같은 사람인지 표시·검사하지 않는다(로컬 시험에서 데모 계정에 본인 토큰을 붙여 혼동).

## 기대 결과

- 설정·답장 칸에 실제 연결된 계정 표시(「이건학으로 보냅니다」)
- 연결 때 계정 이메일이 로그인 이메일과 다르면 거절(회사 계정 전제)

## 진행 관리

- [x] 운영에서 각자 본인 계정 연결로 실제 문제가 되는지 관찰 — 문제 없음
- 안전장치(연결 계정 표시 · 이메일 불일치 거절)는 필요할 때 새 항목으로 재개

## 완료 기록

- 2026-10-07 — 원인은 로컬 시험 방식(데모 계정 jiho 에 본인 슬랙 토큰을 강제로 붙임)이었다. 운영에서는 이건학 계정으로 로그인해 본인 메일·슬랙을 직접 연결했고 혼동이 없다. 완료.
