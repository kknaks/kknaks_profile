# SH-IMP-013 — 카톡 수집기 남은 확인 — 이름 없는 방 · 데스크톱 수동 확인

## 문제

단체방 이름 복원 뒤에도 실DB 78개 중 8개(멤버 0·시스템방)는 이름이 없다. 창을 닫아도 수집이 이어지는지, 전체 디스크 접근 권한 안내가 뜨는지는 GUI 수동 확인을 못 했다.

## 기대 결과

- 이름 없는 방은 목록에서 숨기거나 의미 있는 이름으로
- 창 닫기 = 웹뷰 파괴 뒤에도 메뉴 막대 상주 수집 지속
- 권한 없을 때 「카카오톡을 읽을 수 없음 — 권한」 안내
