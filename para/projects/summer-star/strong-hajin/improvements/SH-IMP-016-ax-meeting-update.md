# SH-IMP-016 — AX 채팅으로 회의 변경(시간·인원·회의실) + The Connect 연동

상태: 미착수  
생성일: 2026-10-07  
갱신일: 2026-10-07  
출처: 사용자 2026-10-07 (SH-IMP-001·003 논의 중)

## 문제

AX 채팅으로 회의를 만들 수는 있지만, 만들어진 회의의 시간·참석 인원·회의실을 AX 채팅에서 바꾸는 흐름과 그 변경을 The Connect 에 반영하는 연동이 정의되어 있지 않다.

## 기대 결과

- AX 채팅에서 생성된 회의의 **시간 변경 · 인원 변경 · 회의실 변경**을 할 수 있다
- 변경은 The Connect 의 회의 수정 기능으로 예약에 반영된다
- 시간·인원이 바뀌면 가능한 회의실을 다시 조회한다(SH-IMP-003 과 같은 기준)

## 조사 결과 (2026-10-07 · BE §1.5)

- AX 채팅 회의 수정 카드 `meeting_update` → `meeting.info.update` 가 **이미 있다**(시간 · 참석자 · 장소 텍스트). `room_id` 가 없어 회의실은 못 바꾼다 → SH-IMP-003 회의실 셀렉트 결정(기존 유지 / 예약 없음 / 가능 목록)을 AX 카드에도 같게 적용

## 관련

- AX 회의 생성 흐름(스텝 바이 스텝) → [SH-IMP-001](SH-IMP-001-meeting-creation.md)
- Connect 회의실 조회·수정 → [SH-IMP-003](SH-IMP-003-meeting-rooms.md)

- [ ] 운영에서 생성 → AX 변경 → Connect 반영 확인
