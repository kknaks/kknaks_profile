# SH-IMP-005 — 「이전 회의 정보 불러오기」 버그 — 시간 복사 · 안건 출처 표시

## 문제

사용자가 안건을 직접 만들었고 회의 정보만 불러왔는데, AI 회의록 화면의 안건 아래에
`지난 회의에서 넘어옴`이라고 표시된다. 표시가 실제 안건 출처를 잘못 설명한다.

## 사용자 정리 (2026-10-07)

**버그다 — 코드에서 원인을 파악한다.** 재현 경로: 회의 생성 → **이전 회의 정보 불러오기**.

| # | 버그 | 기대 |
|---|---|---|
| 1 | 이전 회의의 **시간이 새 회의에 들어간다** | 시간은 가져오지 않는다 — 새 회의에서 정한(또는 비어 있는) 시간을 그대로 둔다 **(제안 — 기본값)** |
| 2 | 회의 생성 때 **수기로 쓴 안건**이 회의 시작 화면에서 「지난 회의에서 넘어옴」 으로 표시된다 | 아래 출처 규칙 |

**안건 출처 규칙(사용자 확정):**

- 이전 회의 정보를 불러오면 **지난 회의에서 결론이 안 난 항목**이 안건으로 들어간다 → 「지난 회의에서 넘어옴」
- 새로 추가한 안건 → 「새로 추가된 안건」

## 기대 결과

- 이전 회의 정보 불러오기가 시간을 덮어쓰지 않는다.
- 지난 회의의 미결 항목에서 온 안건만 「지난 회의에서 넘어옴」, 새로 추가한 안건은 「새로 추가된 안건」 으로 표시한다.
