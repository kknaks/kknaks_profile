# SH-IMP-005 — 수동 작성 안건의 출처 표시 오류

상태: 미착수  
생성일: 2026-10-06  
갱신일: 2026-10-06  
출처: 운영 화면 피드백, 2026-10-06

## 문제

사용자가 안건을 직접 만들었고 회의 정보만 불러왔는데, AI 회의록 화면의 안건 아래에
`지난 회의에서 넘어옴`이라고 표시된다. 표시가 실제 안건 출처를 잘못 설명한다.

## 기대 결과

- 안건을 직접 입력한 경우 수동 작성 또는 출처 없음으로 표시한다.
- 지난 회의에서 실제 안건 내용을 가져온 경우에만 ‘지난 회의에서 넘어옴’을 표시한다.
- 회의 정보만 복사·불러온 동작이 안건 출처로 잘못 연결되지 않게 한다.

## 화면 근거

- URL: `https://ax.medisolveai.xyz/`
- 뷰포트: 1676×936
- 영역: AI 회의록 안건 블록의 `p.scax-agenda-block__source`
- 표시 문구: `지난 회의에서 넘어옴`
- 사용자 설명: 안건은 수동 작성했고, 회의 정보만 불러왔다.
