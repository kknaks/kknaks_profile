# SH-IMP-004 — 날짜·시작·종료 시간 배치 조정

상태: 완료  
생성일: 2026-10-06  
갱신일: 2026-10-07  
출처: [BASE-007](../00-baseline/baseline-007-meeting-creation-improvements.md)

## 문제

날짜, 시작 시간, 종료 시간과 참석자 검색 영역이 가까이 배치되어 컨트롤을 혼동할 수 있고,
일정 필드를 한 묶음으로 읽기 어렵다.

## 사용자 정리 (2026-10-07)

- **버그다** — 왼쪽 열의 `[날짜][시작][종료]` 가 열 폭을 넘쳐, **종료 시간 칸이 오른쪽 열의 「조직도 내 이름 검색」 입력 밑에 깔린다**(화면 캡처 2026-10-07, 날짜 `2026/10/07` · 시작 `16:30` 까지 보이고 종료 칸은 검색 입력 뒤로 일부만 비침)
- 고치는 방향: **날짜 칸 폭을 좁혀** 세 칸이 왼쪽 열 안에 들어가게 한다
- SH-IMP-002 의 「검색 입력 뒤 버튼」 은 이 깔린 종료 시간 칸으로 보인다 — 같은 원인 **(확인 필요)**

## 기대 결과

- 날짜·시작 시간·종료 시간을 폭을 줄여 왼쪽 한 열에 배치한다.
- 세 필드를 일정 정보로 묶어 보이게 한다.
- 좁은 화면에서도 필드가 잘리지 않고 유효성 오류가 해당 입력에 연결된다.

- [ ] 화면 수정 및 일정 유효성 확인
