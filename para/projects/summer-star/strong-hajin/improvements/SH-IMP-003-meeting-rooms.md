# SH-IMP-003 — Connect 회의실 가용성 조회

상태: 미착수  
생성일: 2026-10-06  
갱신일: 2026-10-07  
출처: [BASE-007](../00-baseline/baseline-007-meeting-creation-improvements.md)

## 문제

장소가 자유 입력이라 선택 시간의 실제 회의실 가용성과 연결되지 않는다. AX 응답은
요청 시간에 예약 가능한 4인실이 없다고 했지만, 수정 모달 사례에는 `회의실 2 (4인)`이
표시되어 가용성 정보와 장소 값의 관계를 판단하기 어렵다.

## 사용자 정리 (2026-10-07)

- 회의 정보 **수정** 때도 바뀐 내용(날짜·시간·참석 인원)을 반영해 The Connect 에서 **가능한 회의실을 검색**하고, **회의실 선택 또는 「회의실 선택 안 함」** 을 고른다
- The Connect 에 **회의 수정 기능이 있다** — 우리 쪽 수정이 Connect 예약 수정으로 이어진다
- 수정 때 회의실 셀렉트 구성(사용자 제안):

  ```text
  기존 — 회의실 3 (변경 안 함)      ← 수정 때만 · 맨 위
  ─────────────────
  회의실 예약 없음
  가능한 회의실 목록 …              ← Connect 조회 결과
  ```

  - 생성 때는 첫 줄(기존 유지)이 없다
  - 시간·인원이 바뀌어 기존 회의실을 새 조건에서 쓸 수 없으면, 기존 줄을 비활성 + 이유 표시(「새 시간에 예약 불가」) **(제안 — 기본값)**
- AX 채팅으로 회의를 바꾸는 경우도 같은 연동을 탄다 → [SH-IMP-016](SH-IMP-016-ax-meeting-update.md)

## 조사 결과 (2026-10-07 · BE §2) — 결정과의 차이

- 지금 수정은 Connect 에 **시간만 PUT**(같은 방 · 가용 조회 없음 · 참석자 미반영) · 회의실 고르기 UI 는 생성 화면(`BookingModal`)에만 있다
- 위 「수정 때 회의실 셀렉트」 결정(2026-10-07)이 곧 **수정에서 방 변경 + 가용 조회**로 넓히는 것이다 — 수정 모달 · AX 수정 카드(SH-IMP-016 `room_id`) 모두

## 기대 결과

- Connect에서 날짜·시간·인원 조건으로 예약 가능한 회의실을 조회한다.
- 사용자가 회의실을 고르거나 `회의실 없음`을 명시적으로 선택한다.
- 가용 회의실이 없거나 조회에 실패한 상태를 구분해 안내한다.
- 필요하면 회의 생성 직전에 가용성을 다시 확인한다.
- 회의 수정(시간·인원·회의실 변경)이 Connect 의 예약 수정으로 반영된다.
