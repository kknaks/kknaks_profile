# SH-IMP-002 — 참석자 조직도 검색·선택 UI

상태: 미착수  
생성일: 2026-10-06  
갱신일: 2026-10-07  
출처: [BASE-007](../00-baseline/baseline-007-meeting-creation-improvements.md)

## 문제

회의 정보 수정 모달의 조직도 검색 입력 뒤 버튼의 기능이 불분명하다. 검색 결과를 고르고
참석자로 반영하는 흐름도 명확히 확인할 필요가 있다.

## 사용자 정리 (2026-10-07)

- **버그다** — 조직도 검색 입력 뒤 버튼은 의도한 UI 가 아니다. 재현·원인은 조사 때 확인한다
- 그 「버튼」 은 왼쪽 열에서 넘친 **종료 시간 칸**이 검색 입력 밑에 깔린 것으로 보인다 → [SH-IMP-004](SH-IMP-004-meeting-time-fields.md) 와 같은 원인 **(확인 필요)**

## 기대 결과

- 검색, 결과 선택, 참석자 추가의 단계와 완료 상태가 분명하다.
- 버튼이 필요하면 목적과 활성 조건을 드러낸다.
- 중복 참석자를 막고 키보드로도 검색·선택할 수 있다.

## 진행 관리

- [ ] 버튼의 현재 동작과 검색 결과 상호작용 확인
- [ ] 결과 선택·중복 방지·키보드 동작 결정
- [ ] UI 수정 및 사용자 확인
