# BASE-007 — AX 회의 생성·편집 개선 입력

## 출처

- 운영 화면 `https://ax.medisolveai.xyz/` 피드백, 2026-10-06
- 브라우저 뷰포트 1919×936
- 대상: AX 대화의 회의 생성 확인 카드, 회의 정보 수정 모달

## 배경

사용자가 회의 생성과 정보 수정 화면을 확인하며 발견한 고도화 지점이다. 네 항목은
구현 계약이 아니라 운영 화면에서 관찰한 문제와 기대 동작이다. 조사·결정 후 필요한
항목만 SPEC과 WORK로 구체화한다.

## 관찰과 요구

### 1. AX 회의 생성과 회의록 작성 흐름 연결

AX 대화가 회의 생성 확인 카드를 만들지만, 기존 AX 회의록 작성 흐름과 다르다. 카드의
참고자료는 업무 생성 AX 카드와 같은 기준·동작을 사용해야 한다. 사용자가 내용을
확인·수정한 뒤 생성하는 흐름은 유지하되, 회의록 작성에서 재사용할 단계와 회의 예약
전용 단계를 조사한다.

화면 근거: `section.scax-actioncard.action-task-card.action-meeting-card`
(`data-state="rejected"`). 회의명·주최자·참석자·날짜·시간·첨부가 보였으며 첨부 목록은
비어 있었다.

### 2. 조직도 참석자 검색 UI

회의 정보 수정 모달의 `조직도 내 이름 검색` 입력 뒤에 별도 버튼이 있으나, 입력과 버튼의
역할이 명확하지 않다. 검색·선택·참석자 추가 동작을 조사해 입력과 버튼의 필요성 및
배치를 정리한다.

화면 근거: `input.search-input-box[aria-label="조직도 내 이름 검색"]`.

### 3. 회의실 가용성 조회와 ‘회의실 없음’ 선택

장소는 자유 입력이다. 대화 응답은 요청 시간에 예약 가능한 4인실을 찾지 못했다고 했고,
별도 모달 화면에서는 `회의실 2 (4인)`이 입력된 상태가 관찰됐다. Connect와 연동해 선택한
시간의 예약 가능한 회의실을 조회하고, 회의실 선택 또는 ‘회의실 없음’을 명시적으로
고를 수 있게 한다. 조회·예약 계약, 인원 조건, 최종 저장 직전 재확인 여부는 조사해
결정한다.

화면 근거: `input#meeting-head-place`, placeholder `회의실 이름을 적으세요`.

### 4. 날짜·시작·종료 시간 배치

참석자 검색 입력 뒤에 종료 시간 필드가 이어져 컨트롤을 혼동할 수 있다. 날짜·시작 시간·
종료 시간 필드의 폭을 줄여 모달 왼쪽 한 열에 배치하고 일정 정보로 묶어 보이게 한다.
좁은 화면에서의 반응형 배치와 유효성 오류 표시 위치도 확인한다.

## 미결

- 회의록 작성 흐름과 회의 예약 흐름에서 공유할 단계 및 데이터 연결 시점
- 업무 생성 AX 카드 참고자료의 실제 계약과 회의 카드에서의 재사용 범위
- 조직도 검색 결과의 선택·중복 방지 및 키보드 동작
- Connect 회의실 조회·예약 기능, 권한, 가용성 재확인 계약
- 날짜·시간 필드의 정확한 그리드 및 좁은 화면 대응

## 제외

- 회사 제품 스펙의 복사·수정. 구현 계약은 이 프로젝트에서 결정한 뒤 이 레포의 SPEC에 기록한다.
