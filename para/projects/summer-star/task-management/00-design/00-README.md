# 내 업무 (Managment) — 핸드오프 패키지

개인용 업무 관리 도구. 이 패키지만으로 구현 가능하도록 화면·데이터·규칙을 분리해 정리했다. 범위는 내 업무 · 로그인/개인 설정 · 회의록 · 캘린더 · 문서함(자료함) · 메시지함.

## 구성

| 파일 | 내용 |
|---|---|
| `01-screens.md` | 화면 목록과 정의서 보드 매핑 |
| `02-data-model.md` | 업무 데이터 필드, 타입, 필수/선택 |
| `03-create-task.md` | 업무 생성 (드로어) |
| `04-task-detail.md` | 업무 상세 (드로어 / 전체 페이지), 인라인 편집·자동 저장 |
| `05-status.md` | 상태 전이 규칙, 완료·취소 처리 |
| `06-related-tasks.md` | 연관업무 연결 (검색 팝오버) |
| `07-list-kanban.md` | 리스트·칸반 뷰, 필터·정렬 |
| `08-responsive.md` | 1920 / 1440 / 1280 규칙 |
| `09-design-tokens.md` | 색·타입·간격·컴포넌트 토큰 |
| `10-open-questions.md` | 미해결 항목 (구현 전 확정 필요) |
| `11-auth-profile.md` | 로그인 · 개인 설정(프로필/경력/목소리) · 비밀번호 변경 |
| `12-meeting-notes.md` | 회의록 — 안건/줄 구조, 진행 상태, 근거 타임칩, 드로어 3종 |
| `13-calendar.md` | 캘린더 — 월/주/일 뷰, 기간 연속바·종일 반드, 유형 필터, 생성·상세 드로어 재사용 |
| `14-library.md` | 문서함(자료함) — 디렉토리 트리, 문서 상세·편집(md), 메타데이터·연결, 업로드 |
| `15-messages.md` | 메시지함 — 채널·처리 상태, 첫 진입 빈 상태, 읽음 처리 규칙 |

| `로그인 · 계정 · 프로필.dc.html` | 로그인·설정 화면 원본 |
| `회의록.dc.html` | 회의록 화면 원본 |
| `캘린더.dc.html` | 캘린더 화면 원본 |

## 읽는 순서

1. `02-data-model.md` — 무엇을 다루는지
2. `01-screens.md` — 어떤 화면이 있는지
3. `03`~`07` — 기능별 동작
4. `08`, `09` — 레이아웃·스타일 규격
5. `11-auth-profile.md` — 로그인·설정 영역
6. `12-meeting-notes.md` — 회의록 영역
7. `13-calendar.md` — 캘린더 영역
8. `14-library.md` — 문서함 영역
9. `15-messages.md` — 메시지함 영역
10. `10-open-questions.md` — 확정되지 않은 것 (임의 결정 금지)

## 전제

- 개인용 단일 사용자 도구. 담당자·요청자·작성자 표기 없음. 아바타는 사이드바 프로필에만.
- 데스크톱 전용. 1280 미만 미지원.
- HTML 정의서의 좌표·크기는 1920×1080 기준 실측값이며 그대로 구현 기준으로 사용한다.
