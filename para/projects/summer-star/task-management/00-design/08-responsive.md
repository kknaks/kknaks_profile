# 반응형

데스크톱 전용. 지원 폭 1280 이상. 1280 미만은 최소 폭 안내 화면.

| | 1920 (기준) | 1440 | 1280 (하한) |
|---|---|---|---|
| 사이드바 | 200px 고정 | 200px 고정 | 숨김 + 좌상단 햄버거(오버레이) |
| 좌우 여백 | 240 | 80 | 48 |
| 본문 폭 | 1640 | 1080 | 1184 |
| 리스트 컬럼 | 전체 | 전체 | 시작일 숨김 |
| 칸반 | 4컬럼 (1fr) | 4컬럼 | 컬럼 320 고정 + 가로 스크롤 |
| 드로어 | 840 | 840 | 전체 화면 |

## 규칙

- 사이드바는 아이콘만 남기는 축소형을 만들지 않는다. 200px 아니면 숨김.
- 드로어가 전체 화면으로 바뀌면 스크림이 사라지고 헤더 좌측에 `←` 닫기가 생긴다. 헤더는 74px 한 줄(breadcrumb + 제목 + 상태 + 완료 처리).
- 칸반은 컬럼을 좁히지 않는다. 기본 320, 최소 240. 안 들어가면 가로 스크롤하고 리스트로 자동 전환하지 않는다.
- 본문은 유동. 최대폭 제한을 두지 않고 좌우 여백만 240 → 80 → 48로 줄인다.
- 1280 상세는 좌(유동) + 우(400 고정) 2단.

해당 보드: `리스트 · 1440`, `리스트 · 1280`, `칸반 · 1280 가로 스크롤`, `업무 상세 · 1280 전체 화면`.
