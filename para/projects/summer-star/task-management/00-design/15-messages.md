# 15 — 메시지함

원본: `메시지함.dc.html` (화면 2종). 외부 채널(메일 · 카카오톡 · 슬랙)에서 들어온 메시지를 모아 업무 후보로 넘기는 화면. 노션 등 문서 도구 알림은 v1 범위에서 제외한다.

## 화면

| 라벨 | 내용 |
|---|---|
| 메시지 · 첫 진입 | 좌측 필터(260) + 목록(792 자리) + 우측 빈 상태 「메시지를 선택하세요」 |
| 메시지 | 메시지 선택 상태 — 원문·업무 등록 패널 |

## 레이아웃

- 필터 카드 260 @ left 240, 목록·상세 패널 792 @ left 1088, 카드 높이 900 (top 140).
- 필터: 채널(전체 / 메일 / 카카오톡 / 슬랙) + 처리 상태(확인 필요 / 업무로 등록됨 / 보관).
- 채널 색은 출처 표시 전용 축이며 업무 유형 배지와 섞지 않는다(디자인 시스템 02 CHANNEL).

## 읽음 처리

- **첫 진입에서 메시지를 자동 선택하지 않는다.** 여는 순간 읽음이 DB에 기록되므로, 자동 선택은 사용자가 보지 않은 메시지를 읽음으로 만든다.
- 그래서 첫 진입 우측은 빈 상태: 안내 문구 + 「안 읽음만 보기」 · 「채널 연동 상태」 진입점.
- 안 읽음 표시는 목록 행의 #33AAFF 도트. 읽음 처리는 메시지를 열 때만 발생한다.

## 미확정

- 업무로 등록 시 원문 인용 범위(전문 / 선택 구간).
- 보관과 삭제의 구분, 채널 재연동 실패 시 표시.
