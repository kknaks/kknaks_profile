# 연관업무 연결

보드: `새 업무 · 연관업무 연결`

## 왜 팝오버인가

연결은 "검색 → 선택 → 끝"이라 화면을 덮을 필요가 없다. 드로어 위에 모달을 겹치면 레이어가 3겹이 된다. 여러 건을 연달아 고를 때도 팝오버가 열린 채 유지된다.

## 사양

- 폭 382px (= 트리거 `업무 연결` 버튼 폭), 트리거와 좌측 정렬, 8px 띄움
- 기본은 아래로, 아래 공간이 모자라면 위로 연다 (정의서 보드는 위로 열린 상태)
- 스크림 없음. 바깥 클릭·Esc로 닫힘

## 구성

1. 검색 입력 (포커스 상태, 테두리 `#7181F8` + 3px 글로우)
2. 필터 칩 — `이 프로젝트`(선택) / `최근 30일` / `전체`, 우측에 `312건 중 6`
3. 결과 목록 — 각 행 52px: 체크박스 + 제목(검색어 `#FFF3B0` 하이라이트) + `프로젝트 · 날짜 상태` + 상태 dot
4. 푸터 52px — `n건 선택됨`, `새 업무로 만들기`, `연결`(#7181F8)

선택된 행은 배경 `#F4F5FF` + 체크박스 `#7181F8`. 아카이브 항목은 opacity 0.55.

## 후보가 많을 때 (300건 이상)

- 전체를 나열하지 않는다. 검색어가 없을 때 기본 정렬: **같은 프로젝트 → 종료일 ±7일 → 최근 열람** 순으로 10~20건
- 그래도 못 찾으면 `전체 목록에서 고르기`로 리스트 화면에 필터가 걸린 상태로 이동해 다중 선택 후 일괄 연결 (미설계)
- 한 업무에 연결이 수십 건 이상 쌓이면 그건 연관업무가 아니라 프로젝트다. 상세에는 최근 5건 + `전체 n 보기`만 노출한다

## 연결 결과

- 연관업무 카드에 `상태 dot + 제목 + 상태 텍스트` 한 줄로 추가
- 양방향 연결. A에 B를 걸면 B의 연관업무에도 A가 생긴다
- 로그에 `연관업무 n건 연결` 기록
