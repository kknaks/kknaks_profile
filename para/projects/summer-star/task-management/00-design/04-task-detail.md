# 업무 상세

보드: `업무 상세 · 드로어`(기본), `업무 상세`(전체 페이지), `업무 상세 · 제목 편집 중`

## 두 가지 형태

| | 드로어 | 전체 페이지 |
|---|---|---|
| 진입 | 리스트 행·칸반 카드 클릭 | 드로어 헤더 ⤢ 버튼 |
| 폭 | 840px | 1920 (좌 1080 / 우 528) |
| 용도 | 확인·간단 수정 | 긴 배경·메모·로그를 길게 볼 때 |
| 뒤 화면 | 스크림 너머로 보임 | 없음 |

기본은 드로어다. 1280 미만에서는 드로어가 전체 화면으로 바뀐다(`08-responsive.md`).

## 드로어 구성

헤더(고정)
- 유형 배지 + 프로젝트 칩
- 제목 26px/700
- 상태 드롭다운 · 기간 · `완료 처리` 버튼 · ⋯ · ⤢ · ×

본문(스크롤)
1. 배경 / 목표 — 라벨 좌측 정렬 2줄 카드
2. 할일 — 진행률 `2 / 5` + 바, 체크 목록, 하단 입력 행
3. 참고자료 · 연관업무 — 2열
4. 결과자료 — `완료 시 필수`
5. 메모 — 시간(78px) + 내용 2단, 하단 입력 행
6. 로그 — 내용 + 시간 한 줄

## 인라인 편집 (보드 7)

- 제목·배경·목표는 클릭하면 그 자리에서 편집. 별도 편집 모드 없음
- 편집 중 표시: 배경 `#F5F6F8` + 내부 테두리 `#E1E3E8` + 캐럿 `#7181F8`
- 드로어 우측 상단에 검정 바 — `편집 중 · 제목 · 배경 · 목표는 클릭해 수정, 벗어나면 자동 저장`
- 저장 시점: **포커스가 벗어나면 자동 저장**. 저장/취소 버튼 없음
- 저장되면 로그에 기록하지 않는다(제목·배경·목표 수정은 로그 대상 아님)

## 항목 추가

- 할일: 하단 입력 행 + `추가` 버튼 (Enter 동시 지원)
- 메모: 하단 입력 행 + `등록` 버튼. 등록 즉시 최상단에 추가
- 참고자료: `자료 첨부` → 자료함 선택
- 결과자료: `결과물 등록`. 완료 처리 시 비어 있으면 `05-status.md`의 규칙 적용
- 연관업무: `업무 연결` → 검색 팝오버 (`06-related-tasks.md`)

## 로그에 기록되는 것

상태 변경, 할일 완료/추가, 참고자료·결과자료 첨부, 연관업무 연결, 업무 생성, 취소 사유.
