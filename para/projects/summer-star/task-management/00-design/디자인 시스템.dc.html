10 — RULES

화면을 추가할 때 어기면 안 되는 것들.

사람 표기 없음
요청자·담당자·수신자 아바타를 카드나 리스트에 넣지 않습니다. 그 자리는 업무 유형 배지가 씁니다. 사이드바 프로필만 예외.
#7181F8은 액션과 완료에만
버튼·전송·D-day·AI 강조, 그리고 완료 상태(dot·진행률 바·로그 최신 마커). 진행중은 #33AAFF, 시작전은 #9EA2AE에서 가져옵니다.
그라디언트는 홈만
Hero Gradient는 홈 상단 400px과 로그인 좌측 브랜드 패널에만. 앱 안쪽 화면은 흰 배경 + breadcrumb + 타이틀로 시작합니다.
업무 유형은 4개 고정
미팅·회의 / 개인 업무 / 문서·보고 / 취소. 새 배지 색을 임의로 만들지 않습니다.
채널 색은 별개 축
메일·카카오톡·슬랙 색(02 CHANNEL)은 출처 표시 전용이며 업무 유형 배지와 섞어 쓰지 않습니다. 채널이 늘어나면 여기에 먼저 등록합니다.
검정은 위치, 보라는 선택
#1E1E1E는 현재 위치 표시(사이드바 메뉴, 뷰 전환, 탭)에만 쓰고 화면당 하나씩. 필터 칩·체크·선택 카드는 #F1F2FE + #7181F8로 표현합니다. 토스트는 배경이 아니라 띄운 서페이스라 예외입니다.
설정은 패널 스택
설정 화면은 좌측 메뉴 카드 260 + 우측 패널 스택 1356(gap 20). 성격이 다른 묶음은 패널을 나눕니다(프로필 / 경력 / 목소리). 두 컬럼의 아래 끝은 항상 같은 y에 맞추고, 로그아웃·계정 삭제는 메뉴 카드 맨 아래에 둡니다.
자동 저장 화면엔 저장 버튼이 없다
설정 값은 포커스 해제 시 저장합니다. 패널 헤더에는 저장·되돌리기 대신 "입력을 마치면 자동으로 저장됩니다"만 둡니다. 저장 버튼은 드로어 안에서만 씁니다.
한 줄짜리 개체는 인라인
목록의 한 줄로 끝나는 개체(경력, 할일)는 목록 자리에서 인라인으로 추가·편집합니다. 드로어는 탭·로그·첨부가 붙는 개체(업무, 회의록)에만 씁니다. 필드가 4개 이하면 드로어를 열지 않습니다.
편집은 드로어, 결정은 모달
값을 여러 개 넣는 화면은 드로어(840px), 되돌리기 어려운 결정 하나는 모달(600px), 고르기는 팝오버. 드로어 위에 모달을 겹치지 않습니다.
단축키는 보조
Enter·Esc로 동작하더라도 화면에는 버튼을 둡니다. 단축키 안내 칩을 푸터에 나열하지 않습니다.
테두리 구분
외곽은 #D9D9D9, 내부 구분은 #EBEBEB, 리스트 행은 #F1F2F5, 사이드바만 #E5E7EA.
스코프 표시 필수
내 업무·회의록 등 기간이 있는 화면은 타이틀 옆 Period Stepper로 현재 범위(월 단위)를 항상 노출합니다.

범례 색과 칩 색은 같아야 한다
