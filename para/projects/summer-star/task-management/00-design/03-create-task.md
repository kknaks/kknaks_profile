# 업무 생성

보드: `새 업무`, `새 업무 · 연관업무 연결`

## 진입

리스트·칸반 헤더의 `새 업무` 버튼(#7181F8), 칸반 컬럼 하단 `업무 추가`. 어느 쪽이든 같은 드로어를 연다. 칸반 컬럼에서 열면 그 컬럼의 상태가 아니라 항상 `시작전`으로 생성된다.

## 형태

- 우측 드로어 840×1080. 스크림 `rgba(30,30,30,0.32)`, 그림자 `-24px 0 60px rgba(0,0,0,0.18)`
- 모달 아님. 뒤 리스트가 보여야 생성 후 어디에 들어가는지 확인 가능
- 헤더 72px: `새 업무` + 임시저장 배지 + 확장(⤢) + 닫기(×)
- 푸터 76px: `취소` / `업무 만들기`(#7181F8). 단축키 안내 칩은 두지 않는다

## 필드 순서

1. 제목 — 열자마자 포커스, 캐럿 표시
2. 유형(240) · 프로젝트(250) · 일정 시작–종료 — 한 줄
3. 배경 · 목표 — 2열
4. 할일 — 체크리스트 + 하단 입력 행
5. 참고자료 · 연관업무 — 2열
6. 메모 · 결과자료 — 2열 (결과자료는 `완료 처리 시 등록` 안내만)
7. 로그 — `생성 시점부터 자동 기록` 안내만

상태 필드는 없다. 생성 시 항상 `시작전`.

## 할일 입력 행

- 목록 맨 아래 고정, 배경 `#FAFBFC`
- 플레이스홀더 `할일 입력 후 Enter`
- Enter로 등록되지만 우측 `추가` 버튼도 항상 함께 둔다
- 등록 후 입력 행은 비워지고 포커스 유지

## 저장

- `업무 만들기`로 생성. 임시저장은 헤더 배지로만 표시(`임시저장 08:42`)
- 생성 후 드로어는 닫히고, 리스트/칸반에서 새 업무가 하이라이트된다
- 필수값은 제목뿐. 나머지가 비어도 생성 가능
