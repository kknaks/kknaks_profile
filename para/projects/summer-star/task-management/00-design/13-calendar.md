## 뷰 규격

- 카드: 월 1180×890 / 주 1180×910 / 일 1180×890, 좌측 240 · 우측 레일 420(left 1460).
- 시간 그리드: 08:00–20:00, 1시간 = 61px. 헤더 60 + 종일 밴드 + 그리드 합이 카드 높이 안에 들어와야 하며 헤더·밴드는 `box-sizing:border-box`.
- 현재 시각 라인: 1px #7181F8 + 좌측 9px 도트.

## 일정 표시 규칙

1. **시간 있는 일정** → 시간 그리드 블록. 유형색 tint 배경 + 좌측 3px 액센트.
2. **기간 일정** → 월: 날짜 아래 고정 라인의 채움 연속바(흰 텍스트), 주 경계에서 잘린 쪽 라운드 제거 후 다음 주에서 제목 재표기. 주·일: 종일 밴드.
3. **종일 일정** → 종일 밴드의 tint 칩.
4. **취소 일정** → 시간 그리드에서 제거, 종일 밴드에 점선 취소 칩(취소선, #B3B3B3). 시간 슬롯은 비워 둔다.
5. 칸당 표시 한계를 넘으면 `+n건 더`.

## 유형 · 필터

- 유형 4색 고정: 미팅·회의 #7181F8 / 개인 업무 #929BF5 / 문서·보고 #7E9BD6 / 취소 #B3B3B3(취소선). 범례 막대·칩 액센트·기간 바 채움이 모두 같은 값.
- 유형 분포 카드가 필터다. 선택 행 = #F3F5FF 필 + 라벨 700 + 카운트 #7181F8, 미선택 = 라벨 #5F6470 + 막대 #E3E5EA.
- 활성 필터 칩은 타이틀·기간 이동 옆(왼쪽 그룹). 해제는 카드 우측 상단 `필터 n ✕`.
- 필터가 걸리면 그리드에서 해당 유형만 남긴다(다른 유형의 종일바·시간블록 모두 숨김).

## 생성 흐름

「+ 새 일정」 → 팝오버(미팅 · 회의 / 개인 업무 / 문서 · 보고, 취소 없음) → 미팅은 회의록 생성 드로어, 개인·문서는 업무 생성 드로어. 캘린더 전용 생성 폼은 만들지 않는다. 서버 요청은 드로어의 만들기 버튼에서만 발생.

## 상세 흐름

월·주·일 어느 뷰에서 눌러도 동일한 드로어가 열린다.
- 업무 → `04-task-detail.md`의 업무 상세 드로어.
- 회의 → 회의 상세 드로어(840): 유형·종료 상태 칩 / AI 한 줄 요약 / 안건별 논의·결정·액션(액션엔 업무 생성) / 첨부 파일 / 스크립트 열기 / 하단 일정 변경 · 회의록 편집 · 액션에서 업무 생성.
