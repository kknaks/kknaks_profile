# 디자인 토큰

원본: `디자인 시스템.dc.html` (01~09 섹션). 아래는 이 기능에서 실제로 쓰는 값만 추린 것.

## 색

| 용도 | 값 |
|---|---|
| Primary (액션 · 완료) | `#7181F8` / hover `#5F71F5` |
| Ink (현재 위치 · 토스트 배경) | `#1E1E1E` |
| 본문 | `#1E1E1E` / 보조 `#5F6470` / 메타 `#757575` / 캡션 `#9EA2AE` |
| 선택 배경 | `#F1F2FE`, 텍스트 `#4B52A8` |
| hover fill | `#F5F6F8` / 행 hover `#FAFBFC` |
| 외곽선 | `#D9D9D9` / 내부 구분 `#EBEBEB` / 행 구분 `#F1F2F5` / 사이드바 `#E5E7EA` |
| 배경(캔버스) | `#F4F5F7`, 컬럼 `#F9FAFB` |

**검정은 위치, 보라는 선택.** `#1E1E1E`는 사이드바 현재 메뉴·뷰 전환·탭에만 쓰고 화면당 하나. 필터 칩·체크·선택 카드는 `#F1F2FE + #7181F8`. 토스트는 오버레이 서피스라 예외.

## 상태 · 유형

상태 dot 8px: 시작전 `#9EA2AE` / 진행중 `#33AAFF` / 완료 `#7181F8` / 취소 `#B3B3B3` / 지연 `#E2685B`

유형 배지 h20 r4 11px/600:
- 미팅·회의 `#EEF1FE` / `#4A55B8`
- 개인 업무 `#F1F2FE` / `#4B52A8`
- 문서·보고 `#F4F7FF` / `#3F5F94`
- 취소 `#F4F5F7` + 테두리 `#E1E3E8` / `#5F6470` (굵기 없음)

## 타입

Pretendard Variable. letter-spacing -0.02em 기본.
페이지 타이틀 28/700/-0.03 · 상세 제목 26~32/700 · 패널 16/700 · 섹션 14~15/700 · 본문 14 · 메타 13/#757575 · 캡션 12/#9EA2AE

## 형태

- radius: 카드 12~16 / 컨트롤 8 / 배지·칩 4~6
- 컨트롤 높이: 버튼·필터 34, 입력 38~48, 리스트 행 52, 할일 행 42~46
- 그림자: 카드 `0 1px 2px rgba(16,24,40,0.04), 0 8px 20px rgba(16,24,40,0.06)` / 드로어 `-24px 0 60px rgba(0,0,0,0.18)` / 모달 `0 32px 80px rgba(0,0,0,0.28)` / 팝오버 `0 16px 40px rgba(0,0,0,0.16)`

## 오버레이 3종

| | 폭 | 스크림 | 용도 |
|---|---|---|---|
| Drawer | 840 | `rgba(30,30,30,0.32)` | 값을 여러 개 넣는 편집 |
| Modal | 600 | `rgba(30,30,30,0.36)` | 되돌리기 어려운 결정 하나 |
| Popover | 200–400 | 없음 | 고르기 |

드로어 위에 모달을 겹치지 않는다.

## 그 외 규칙

- 사람 표기 없음 (아바타·이름·작성자). 사이드바 프로필만 예외
- 그라디언트는 홈 상단과 로그인 좌측 패널에만
- 단축키로 동작하더라도 화면에는 항상 버튼을 둔다. 단축키 안내 칩을 푸터에 나열하지 않는다
- 로그·메모는 `내용 + 시간` 한 줄
