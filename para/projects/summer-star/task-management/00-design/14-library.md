# 14 — 문서함 (자료함)

원본: `문서함.dc.html` (화면 5종). 문서는 폴더에 놓이고, 프로젝트 · 업무 · 회의와 링크로 이어지는 위키다. v1 본문 렌더는 마크다운(.md)만.

## 화면

| 라벨 | 내용 |
|---|---|
| 자료함 | 좌측 디렉토리 트리(300) + 파일 목록(1316) |
| 문서 상세 · 마크다운 | 트리(300) + 렌더 본문(872) + 메타데이터·연결·버전 레일(420) |
| 문서 편집 · 마크다운 | 같은 3열, 본문이 마크다운 소스 + 서식 툴바 |

| 자료함 · 업로드 드로어 | 업로드 드로어(840), 파일 단위 메타데이터 입력 |

## 트리

- 들여쓰기 12px 단위: 1단 8 / 2단 20 / 3단 32, 파일은 한 단 더 44.
- 단마다 세로 가이드선(#EBEBEB, 선택 계열 #C9D1FB)을 배경 그라디언트로 깐다.
- 폴더 행 오른쪽 = 하위 폴더 `+` 버튼. 항목 수는 표시하지 않고, 헤더에 「새 폴더」 버튼도 두지 않는다.
- 파일 행에는 `+`가 없다. 문서 선택 필(#F1F2FE)은 상세·편집 화면에서만 표시.
- 하단에 사용 용량 바.

## 목록

`즐겨찾기(36) | 이름 | 연결된 업무(200) | 유형(110) | 크기(110) | 수정일(130)`

- 즐겨찾기: 채운 별 #7181F8 / 미지정 #C9CBD1 외곽선. 상세·편집 헤더에도 34px 별 토글.
- 파일 아이콘 색은 업무 유형 4색. AI가 만든 문서는 「AI 생성」 배지.

## 문서 화면

- 카드 탭 축은 상세·편집 공통: **읽기 / 편집 / 원문(.md)**. 편집 화면은 「편집」이 활성이고, 헤더 주 액션은 연보라 「편집 완료」, 상태는 회색 칩 「편집 중」(검정은 위치 표시 전용).
- 저장 버튼 없음 — 「입력을 마치면 자동으로 저장됩니다」 + 「버전으로 저장」.
- 편집 본문은 마크다운 소스에 문법 기호(`##`, `-`, `>`, `**`)를 #B3B3B3으로 흐리게, 표는 모노스페이스.
- 우측 레일 순서: **메타데이터 → 연결 → 버전**. 목차는 두지 않는다.

## 메타데이터 (DB 저장 대상)

id, 형식, 위치(전체 경로), 출처, 생성/수정(+버전), 크기·글자수, 태그[], AI 색인 상태.

## 연결

- 나가는 링크: 프로젝트(PJ) · 업무(TK) · 회의(MT) 배지 행.
- 들어오는 링크: 「이 문서를 참조 (백링크)」 묶음.
- 헤더에 `나가는 n · 들어오는 n`.

## 업로드 (드로어 840)

- 드롭 영역 + 파일 선택. 파일마다 카드로 저장 위치 · 연결된 프로젝트 · 연관 업무 · 태그를 각각 입력.
- 미입력 파일은 「메타데이터 미입력」 배지, 반복 입력은 「첫 파일 값 모두 적용」 토글.
- 업로드는 하단 버튼(`n개 업로드`)에서만 발생.

## 사람 vs 백그라운드

- 사람: 태그, 연결된 프로젝트, 연관 업무.
- 백그라운드: 문서 간 링크, 백링크, 본문 임베딩·색인. 완료 전 메타데이터에 「색인 중」.

## 경로 일관성

트리 · breadcrumb · 메타데이터 「위치」는 같은 문자열(`01 Projects / 소개서 개정 / 문서 · 보고`)을 쓴다.

## 미확정

- .docx·.pdf 본문 렌더 시점(v1은 목록·메타데이터만).
- 업무·회의 상세에도 같은 「연결」 카드를 넣어 양방향으로 맞출지.
