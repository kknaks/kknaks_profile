# 미해결 항목

정의서 우측 메모지에 적힌 질문들. **구현 전에 확정해야 하며, 임의로 결정하지 말 것.**

## 1. 프로젝트 설정은 어디서 하나?

업무 생성 드로어에 `프로젝트` 선택 필드는 있으나, 프로젝트를 만들고 관리하는 화면이 없다.

정할 것
- 프로젝트 CRUD를 어디에 둘지 (사이드바 메뉴 / 설정 / 드롭다운 안 `+ 새 프로젝트`)
- 프로젝트의 필드 (이름, 색, 기간, 상태)
- 업무 목록을 프로젝트 단위로도 볼 수 있어야 하는지

## 2. 필수값 / 선택값 확정

현재 문서는 제목만 필수로 잡았다(`02-data-model.md`). 실제 정책 확인 필요.

정할 것
- 유형은 필수인가, 미지정 허용인가
- 프로젝트 없는 업무를 허용하는가
- 완료 처리 시 결과자료를 강제할 것인가 (현재: 강제하지 않고 안내만)

## 3. 일정은 미정이어도 되나?

현재는 시작일·종료일 모두 null 허용으로 그렸다.

정할 것
- 종료일 없는 업무를 리스트에서 어떻게 정렬할지 (현재 정렬 기본값이 종료일)
- 종료일 없는 업무의 D-day 표시 (현재: 미표시)
- 월 뷰가 기본인데 일정이 없는 업무는 어느 달에 속하는지 (생성일 기준?)

## 4. 상태 변경 인터랙션 범위

정할 것
- 리스트 표에서도 상태 셀을 눌러 바로 바꿀 수 있는가 → 현재 `상태 변경 · 드롭다운` 보드는 **가능**을 전제로 그림
- 칸반은 드래그 앤 드롭을 지원하는가 → 화면 미설계. 지원한다면 드롭 대상 컬럼 하이라이트·플레이스홀더 규격 필요
- 완료 컬럼으로 드래그했을 때도 토스트 + 실행취소가 뜨는가 (현재 완료 처리 흐름과 동일하게 가정)
