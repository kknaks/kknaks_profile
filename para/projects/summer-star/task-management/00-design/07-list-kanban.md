# 리스트 · 칸반

보드: `내 업무 · 리스트`, `내 업무 · 칸반`

## 공통 헤더

- breadcrumb `홈 › 내 업무` (top 38)
- 타이틀 `내 업무` 28/700 + 월 이동 `‹ 2026년 8월 ›` (top 66)
- 우측: 뷰 전환(리스트/칸반) · 정렬 · 상태(리스트) 또는 유형(칸반) 필터 · `새 업무`
- 뷰 전환의 선택은 `#1E1E1E`. 필터 칩의 선택은 `#F1F2FE + #7181F8`

## 리스트

- 유형 탭: `전체 24` / `미팅·회의 8` / `개인 업무 9` / `문서·보고 4` / `취소 3`. 선택 탭은 하단 2px `#1E1E1E`
- 컬럼: 업무명(flex) · 유형 170 · 상태 140 · 시작일 150 · 종료일 180 · 메모 120
- 행 52px, 구분선 `#EBEBEB`, hover `#FAFBFC`
- 종료일 칸에 D-day를 함께 표시
- 하단: `2026년 8월 · 24건 중 12건 표시` + 페이지네이션
- 월 단위가 기본. 이전 달은 월 이동으로만 본다

## 칸반

- 4컬럼: 시작전 / 진행중 / 완료 / 취소. 컬럼 배경 `#F9FAFB`, radius 16
- 카드: 유형 배지 → 제목 → 하단 메타(기간·D-day·메모 수·장소)
- 선택/강조 카드만 테두리 `#7181F8` + 그림자
- 완료 컬럼 헤더는 건수 대신 `8월 12`처럼 월 기준 표시, 하단에 `8월 완료 12건 · 이전 달은 월 이동으로 보기`
- 취소 컬럼 카드에는 취소일과 사유를 함께 적는다
- 시작전·진행중 컬럼 하단에만 `업무 추가` 점선 버튼

## 정렬 · 필터

- 정렬 기본값: 종료일 오름차순. 옵션 화면 미설계
- 리스트는 상태 필터, 칸반은 유형 필터를 헤더에 둔다
- 유형 탭과 헤더 필터는 AND로 동작

## 미설계

검색 결과, 정렬 드롭다운, 빈 상태(이번 달 없음 / 필터 결과 없음), 지연 뱃지 리스트, 로딩 스켈레톤, 칸반 드래그 중, 카드 우클릭 메뉴.
