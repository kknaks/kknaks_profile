## 데이터 구조

```
MeetingNote
  id, title, projectId?, type(미팅·회의 | 반복 | 개인)
  startAt, endAt, status(scheduled | recording | ended)
  aiHeadline?            // 종료 후 배치가 채움
  agendas[]
    id, title, order, state(완료 | 다음으로)
    lines[]
      id, kind(discussion | decision | task | action), order
      text
      detail?            // 비면 배치가 채움
      evidence[]         // [{ from, to }] 스크립트 타임코드
      taskId?            // kind=task
      pendingChange?     // kind=task: { dueDate?, status?, note? }
  transcript[]  // { speaker, at, text }
  attachments[] // { id, name, ext, size, source(local | library), createdAt, agendaId? }
```

한 회의록 = 안건의 목록, 안건 = 줄의 목록. 줄은 항상 어떤 안건에 속합니다(안건 없는 줄은 만들지 않습니다).

## 줄 종류와 서버 요청

| kind | 라벨 | 색 | 버튼 | 요청 |
|---|---|---|---|---|
| discussion | 논의 | #9EA2AE | — | 회의록 저장에 포함 |
| decision | 결정 | #1663B5 | — | 회의록 저장에 포함 |
| task | 업무 | #5F6470 | 업무 갱신 | `PATCH /tasks/{taskId}` |
| action | 액션 | #4B52A8 | 업무 생성 | `POST /tasks` |

- 줄을 적는 것만으로는 업무가 생기지 않습니다. **버튼을 눌러야 요청이 나갑니다.**
- 업무 줄의 `pendingChange`는 갱신 전까지 줄에 남고, 갱신 후 버튼은 회색 '갱신 완료'로 바뀝니다.
- 액션 → 생성 성공 시 그 줄은 `kind=task`로 전환되고 `taskId`가 붙습니다(드로어 토글로 제어).
- 라벨 폭 34, 줄 padding 8/10, 안건 기준선 `border-left:2px #EBEBEB`(margin-left 37).

## 상태별 화면

**시작 전** — 상태 바 회색 '기록 대기 00:00:00' + [회의 시작]. 프롬프트는 안건 생성만 실행(다른 종류 불가). 우측은 "아직 회의 전입니다".

**진행 중** — 상태 바에 경과 시간. 프롬프트로 줄 추가(`/`로 종류 선택). 우측 스크립트가 실시간 누적.

**종료** — 헤더 우측 회색 '종료된 회의' + [편집]. 상단 AI 한 줄 요약 바(1640×56, #EEF1FE / #C9D1FB). 요약·상세 설명·근거는 종료 후 배치가 채웁니다.

## 근거(타임칩)

- 결정·논의 줄 hover 시 우측에 펼치기 화살표가 나타납니다. **줄 전체 클릭은 인라인 편집**이므로 펼치기는 화살표 전용.
- 펼침 = AI 상세 설명 + 근거 칩(`09:34 – 09:36`).
- 칩 클릭 → 우측 스크립트가 해당 구간으로 스크롤하고 그 발화를 #F4F5FF / #C9D1FB로 표시.

## 편집 모드

- 헤더 우측: `변경은 자동 저장됩니다` · 되돌리기 · 편집 완료 (gap 10).
- 안건 제목·논의·결정 텍스트가 입력 필드가 되고, 줄 종류 라벨은 셀렉터(4종 전환).
- 줄 추가는 안건별 `+ 논의 / + 결정 / + 연관 업무 / + 액션 아이템` → 각각 드로어.
- 편집 중에는 하단 프롬프트 바를 감춥니다(줄 추가 경로가 둘이 되지 않도록).
- 저장은 포커스 해제 시 자동. 회의록 삭제만 모달.

## 드로어 3종 (840)

**논의 · 결정** — 종류 선택 · 안건 셀렉터 · 내용 · 상세 설명(비우면 배치가 채움) · 근거 구간 칩 추가.

**연관 업무** — 내 업무 검색 → 단일 선택(라디오) → 반영할 변경(기한 / 상태) + 진행 메모. 고른 항목만 PATCH 페이로드에 들어갑니다. 하단 '연결하고 갱신'.

**액션 아이템** — 업무 생성 양식(제목 · 유형 · 프로젝트 · 기한 · 시작 상태 · 메모) + '회의록 줄을 연관 업무로 바꾸기' 토글(기본 켜짐). 하단 '업무 생성'.

## 첨부 파일

- 우측 탭에서 리스트(아이콘 · 이름 · 용량 · 시각 · 출처). 항목 클릭 → 파일 드로어(미리보기 / 원문 텍스트 탭, 다운로드 · 자료함에서 열기).
- 로컬 파일은 OS 파일 선택창, 자료함에서 고르는 경우만 드로어. 모달은 쓰지 않습니다.
- 회의 중 작성된 md는 `source=local`, `agendaId`가 붙습니다.
