# 메시지함 정책

BASE-006 의 영역 정책. **v1 은 목록 화면만, 기능은 v2** (2026-09-03 사용자 확정).

> 근거 표기: 「확정」 = 2026-09-03 사용자 논의, `P/Q-xx` = 분석 리포트, 파일명 = `00-design/`.

## 1. 범위

- In: 사이드바 메뉴, 목록 화면 UI(필터 카드 + 목록 영역 + 빈 상태)
- Out(v2): 메시지 수신·적재, 상세·원문, 읽음 처리, 업무 등록, 일정 추가, AI 업무 추출, 답장 컴포저, 연결된 기록, 보관·삭제

**이유**: 수신 경로가 연동 관리에 걸려 있는데 연동이 목 UI 다(DEC-001 §1). v1 에서는 받을 메시지가 없다.

## 2. 권한·소유 정책

| 결정 | 내용 | 근거 |
|---|---|---|
| 소유·접근 | DEC-001 승계 | DEC-001 §2 |

## 3. 필드 정책

v1 에 저장 대상이 없다. 메시지 스키마는 **v2 에서 연동과 함께 정의**한다.

## 4. 생명주기

| 결정 | 내용 | 근거 |
|---|---|---|
| v1 화면 상태 | **빈 상태 고정** — 목록에 표시할 데이터가 없다. 「v2에서 제공됩니다」 안내 | 확정 |
| 첫 진입 자동 선택 금지 | 여는 순간 읽음이 기록되므로 자동 선택하지 않는다 — **v2 구현 시 지킬 규칙**으로 보존 | 15-messages §읽음 처리 |

## 5. CRUD 정책

v1 에 CRUD 없음. 전부 v2.

## 6. 기록 정책

해당 없음(v1).

## 7. 저장·실패 정책

해당 없음(v1). v2 구현 시 DEC-003 §7 원칙(설계한 실패만 처리, 그 밖은 전파) 승계.

## 8. 연결 정책

| 방향 | 상대 영역 | 정책 | 근거 |
|---|---|---|---|
| In | 인증·설정(연동 관리) | **닫는다** (v2 — 연동이 목) | DEC-001 §8 |
| Out | 내 업무 · 캘린더 | **닫는다** (v2) | 확정 |
| Out | 홈 | **닫는다** (v2 — 홈 자체가 제외) | — |

## v2 로 넘긴 것 (연동 열릴 때 이어서)

| 항목 | 근거 |

| 읽음 처리 규칙(열 때만 기록, 자동 선택 금지, #33AAFF 도트) | 15-messages §읽음 처리 |

| AI 업무 추출 패널 · 답장 컴포저(채널 변경·AI 초안) · 연결된 기록 | **Q-35 해소 — 전부 v2** |
