# 인증·설정 정책

BASE-001 의 기능 13개에 대한 영역 정책. 2026-09-03 사용자 논의로 확정된 것을 표로 압축, 안 닫힌 것은 Open Questions.

> 근거 표기: `P/C/S/F/Q-xx` = 분석 리포트(`orchestration/work/docs-v1/docs-v1-design-report.md`), 「확정」 = 2026-09-03 사용자 논의.

## 1. 범위

- In: 자체 로그인·세션·로그아웃, 프로필·경력(실구현), 비밀번호 변경, **유형·프로젝트 관리(실구현)**, 목소리·연동 관리·계정 삭제·소셜 버튼(UI만 목)
- Out: 회원가입·비밀번호 찾기(제거), 소셜 로그인 실동작, 연동 API, 실녹음·학습, 계정 삭제 실동작, 다른 기기 로그아웃 실동작, 2FA·기기 목록·백업(디자인 단계에서 이미 제외) — 전부 v2

## 2. 권한·소유 정책

| 결정 | 내용 | 근거 |
|---|---|---|
| 데이터 소유 | 모든 데이터는 계정 소유. 유저 간 공유 없음(단일 사용자) | F-1 · 00-README §전제 |
| 접근 | 유효한 세션(JWT 쿠키)만 전 화면·API 접근. 로그인 화면만 예외 | 확정 |
| 계정 생성 | 앱에서 못 만든다 — **DB 시드로만 생성** | 확정 |

## 4. 생명주기

| 결정 | 내용 | 근거 |
|---|---|---|
| 세션 | access **1시간** / refresh **7일**. 「로그인 상태 유지」 체크 시 refresh 저장, 미체크 시 세션 쿠키 | 확정 |
| 로그인 실패·잠김 | **정책 없음(논외).** 실패 화면·잠김 미구현 — Q-20 도 대상 아님 | 확정 |
| 유형·프로젝트 삭제 | **소프트 딜리트.** 기존 참조(업무·회의록 등)는 삭제된 유형/프로젝트의 이름·색을 그대로 표시. 생성·변경 시 선택 목록에서만 제외. 복구 가능 | 확정 |
| 기본 유형 3종 | 시드(미팅·회의=미팅 / 개인 업무·문서·보고=업무). **삭제 불가·수정 잠금** | 확정 |

## 5. CRUD 정책

| 행위 | 정책 | 근거 |
|---|---|---|
| 생성(C) | 유형·프로젝트·경력: 본인 세션에서 자유 생성. 유형은 종류·이름·색 필수. 계정: DB 시드만 | 확정 |
| 조회(R) | 본인 것 전부. 삭제(소프트)된 유형·프로젝트는 참조 표시용으로만 조회됨 — 선택 목록 제외 | 확정 |
| 수정(U) | 프로필·경력·설정: 인라인/자동 저장(포커스 해제 시). 기본 유형 3종은 수정 잠금. 비밀번호는 드로어에서 현재 비밀번호 검증 후 | 확정 · F-2(자동 저장 원칙) |
| 삭제(D) | 커스텀 유형·프로젝트만, 소프트 딜리트(§4). 경력 행은 하드 삭제 허용. 계정 삭제는 버튼만(v2) | 확정 |
