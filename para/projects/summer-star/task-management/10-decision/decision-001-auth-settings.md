# 인증·설정 정책

BASE-001 의 기능 13개에 대한 영역 정책. 2026-09-03 사용자 논의로 확정된 것을 표로 압축, 안 닫힌 것은 Open Questions.

> 근거 표기: `P/C/S/F/Q-xx` = 분석 리포트(`orchestration/work/docs-v1/docs-v1-design-report.md`), 「확정」 = 2026-09-03 사용자 논의.

## 1. 범위

- In: 자체 로그인·세션·로그아웃, 프로필·경력(실구현), 비밀번호 변경, **유형·프로젝트 관리(실구현)**, 목소리·연동 관리·계정 삭제·소셜 버튼(UI만 목)
- Out: 회원가입·비밀번호 찾기(제거), 소셜 로그인 실동작, 연동 API, 실녹음·학습, 계정 삭제 실동작, 다른 기기 로그아웃 실동작, 2FA·기기 목록·백업(디자인 단계에서 이미 제외) — 전부 v2

## 4. 생명주기

| 결정 | 내용 | 근거 |
|---|---|---|
| 세션 | access **1시간** / refresh **7일** | 확정 |
| **전송 방식** | ~~JWT 쿠키~~ → **Bearer 토큰**. `Authorization: Bearer <access>`, 쿠키를 쓰지 않는다(CORS `allow_credentials=False`). **2026-09-03 개정** — Tauri 웹뷰 origin(`tauri://` 계열)과 API origin 이 달라 쿠키에 `SameSite=None; Secure` + 웹뷰별 서드파티 정책이 걸리고, 「앱 종료 시 로그아웃」을 세션 쿠키 수명에 맡기면 웹뷰 구현에 따라 갈린다 | 확정(개정) · 아키텍처 SYS-3 |
| **「로그인 상태 유지」** | **체크 시** refresh 토큰을 **OS 키체인(Tauri)** 에 7일 저장 — 앱을 껐다 켜도 로그인 유지. **미체크 시 메모리에만** 둔다 — 앱을 끄면 사라져 로그아웃. (기준은 브라우저 종료가 아니라 **앱 종료**) | 확정(OQ-5 해소, 09-03 전송 방식 개정 반영) |
| **웹 개발 단계 보관** | 개발은 웹 기준으로 하고 **Tauri 래핑은 마지막**이므로(09-03 확정), 그동안은 OS 키체인이 없다. **「유지」 체크 시 개발 환경에서만 브라우저 저장소를 임시로 쓰고, 래핑 시 키체인으로 교체**한다 — 저장 위치를 한 곳(토큰 저장소 추상화)에서만 다루어 교체가 한 파일에서 끝나게 한다 | 확정(09-03) |
| **XSS 노출 완화** | Bearer 는 httpOnly 보호가 없다. **정적 번들에 외부 스크립트를 싣지 않고**(CDN 금지) CSP 로 외부 origin 을 막는다 | 아키텍처 SYS-3 |
| 로그인 실패·잠김 | **정책 없음(논외).** 실패 화면·잠김 미구현 — Q-20 도 대상 아님 | 확정 |
| 유형·프로젝트 삭제 | **소프트 딜리트.** 기존 참조(업무·회의록 등)는 삭제된 유형/프로젝트의 이름·색을 그대로 표시. 생성·변경 시 선택 목록에서만 제외. 복구 가능 | 확정 |
| 기본 유형 3종 | 시드(미팅·회의=미팅 / 개인 업무·문서·보고=업무). **삭제 불가, 이름·종류 고정, 색만 편집 가능** | 확정(삭제 불가) · 시안(「기본」 칩+색 편집) |

## v2 스코프 — 프론트만 구현 (전 영역 공통 규칙)

**v2 기능의 UI 는 v1 에서 그대로 그린다.** 원래 화면·컴포넌트를 만들되 비활성 처리하고,
조작하면 「v2에서 제공됩니다」 토스트를 띄운다. **숨기지 않는다** — 제품의 형태를 온전히 보이게 하고,
v2 에서 뒤(백엔드)만 붙이면 되도록 앞을 미리 세워 둔다.

이 영역의 v2 스코프: 소셜 로그인 버튼 · 목소리 녹음(드로어 포함) · 연동 관리 · 계정 삭제 ·
「다른 기기 모두 로그아웃」 토글.
다른 영역: 문서함 AI 색인 상태·버전 카드·검색·휴지통(DEC-004), 메시지함 전체(DEC-006).
