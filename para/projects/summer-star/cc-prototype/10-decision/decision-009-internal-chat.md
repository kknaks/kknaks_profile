# 직원 앱 내부 채팅 — 결정

> 기능 계약은 SPEC(시안 확정 뒤 작성), 작업 순서는 WORK 가 갖는다. 이 문서는 무엇을 정했는지만 갖는다.
> 결정 원천은 `orchestration/work/internal-chat/_RESUME.md` §2 — **이 문서와 `_RESUME` 가 다르면 `_RESUME` 가 맞다.**

## Context

직원 앱(SPEC-004 · procedure/app)에 직원끼리 쓰는 메신저를 넣는다. 텔레그램처럼 메시지와 사진만 보내면 된다. Mattermost 를 참고하되 개념만 가져온다(BASE-010).

근거 칸 표기: **사용자 지시** = 사용자가 말하거나 고른 것 / **코디 기본값** = 코디 제안 · 사용자 이의 없음. `R:X-n` = researcher 리포트 §6 의 그 줄.

## 근거 개념

없음. 사용자 지시와 조사 리포트에서 나왔다.

## Decision

### 범위

| ID | 결정 | 근거 |
|---|---|---|
| D-01 | **자리 = `procedure/back` + `procedure/app`**. 앱(iOS)만 만들고 웹 화면은 없다. back API · SSE 는 웹이 나중에 붙을 수 있는 모양으로 둔다 | 사용자 지시 |
| D-02 | **방 = 1:1 + 그룹방**. 그룹은 사람을 골라 만들고, 참여자를 추가하고, 나갈 수 있다. 그래서 Mattermost 의 G(멤버 고정)가 아니라 P(비공개 채널) 동작을 따른다 | 사용자 지시 · R:C-3 |
| D-03 | **보내는 것 = 텍스트 + 사진(카메라 · 앨범)**. 파일 · 음성 · 영상 · 반응 · 스레드 · 수정 · 타이핑 표시 · 상대 읽음 표시 · 알림에서 바로 답장은 없다 | 사용자 지시(「메신저, 사진, 이런 것만」) · 코디 기본값 · R:U-3 · U-4 · P-9 |
| D-04 | **사람 = 기존 ccc `account`**(다섯 역할). 새 계정 체계는 만들지 않는다 | 코디 기본값 |
| D-05 | **상대 목록 = `active` 이고 로그인할 수 있는(비밀번호가 있는) 계정, 나 빼고**. 지금은 역할별 PoC 계정뿐이지만, 나중에 전 직원이 계정을 받으면 코드 변경 없이 목록에 나타나야 한다. 로그인이 필요한 목록 API 를 새로 두고 `{id, name, role}` 만 준다 | 사용자 지시(「나중에 전체 직원들 다 채팅」) · R:A-1 · A-2 |
| D-06 | **디자인 = claude design 시안을 먼저 만든다**. 시안이 확정되면 그 시안이 화면 정본이고, SPEC 은 확정 시안을 근거로 쓴다 | 사용자 지시 |
| D-07 | **Mattermost 는 개념만 참고한다**. 코드를 복사하지 않고, 표 · 필드 이름도 우리 말로 새로 짓는다. 출처는 리포트로 남긴다 | 코디 기본값 · R:L-1 |

### 방

| ID | 결정 | 근거 |
|---|---|---|
| D-08 | 1:1 은 같은 상대면 기존 방을 다시 쓴다. 그룹은 같은 사람들로 만들어도 매번 새 방이다 | 코디 기본값 · R:C-6 |
| D-09 | 그룹방 이름은 만들 때 선택해서 입력한다. 비어 있으면 참여자 이름을 나열한다 | 코디 기본값 · R:C-1 |
| D-10 | 방장은 없다. 누구나 참여자를 추가할 수 있고, 내보내기(강퇴)는 없다. 인원은 2~20명 | 코디 기본값 · R:C-2 · C-9 |
| D-11 | 초대 · 나감은 대화에 시스템 메시지 한 줄로 남긴다 | 코디 기본값 · R:C-4 |
| D-12 | 그룹에서 나가면 멤버 행을 남기고(`left_at`) 내 목록에서 숨긴다. 다시 초대되면 옛 메시지도 전부 보인다. 마지막 사람이 나간 방은 행만 남는다 | 코디 기본값 · R:C-5 · C-8 |
| D-13 | 1:1 「나가기」는 내 목록에서 숨기기다. 새 메시지가 오면 다시 보인다 | 코디 기본값 · R:C-7 |
| D-14 | 계정이 비활성이 되면 그 사람의 메시지 · 멤버 행은 남기고 이름 옆에 「(비활성)」을 붙인다. 새 방 상대 목록에서는 빠진다 | 코디 기본값 · R:A-3 |

### 사진
