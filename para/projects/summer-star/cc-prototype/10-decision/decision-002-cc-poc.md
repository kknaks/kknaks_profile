> 무엇이 열려 있는지만 갖는다.

2026-10-16(금) 지점 방문 시연. 병원 현황판(BASE-003)과 직원용 통역(BASE-002 · DEC-001 D-06)을

### 데이터 · 상태

| ID | 결정 | 근거 |
|---|---|---|
| D-08 | 시드 = 캡처의 **2026-10-09 하루치** | 사용자 「10월 9일로 하자」 |
| D-09 | **가짜는 고객명뿐.** 같은 고객은 어디서나 같은 가짜 이름. 시술 · 메모 · 시술 이력 · 직원은 실데이터. **메모 본문 속 고객·동행인 이름(로마자 · 「이름 :」 줄 · 한글 음역)도 가짜 이름으로 치환한다.** 전화 · 생년월일 · 차트번호는 화면에 띄우지 않는다 | 사용자 「고객명만 가짜로 하라니까」 |
| D-10 | ~~시술 이력은 KOS API 로 그날 고객들의 과거 이력을 받아 시드에 넣는다~~ — 2026-10-13 뒤집음: 10-09 고객 26/27 이 첫 시술이라 받아도 빈 값. **KOS 호출 안 함.** 시술 이력 = 「첫 방문」 + 상담 메모의 타 병원 이력. KOS 는 운영 DB — 읽기 호출만, 쓰기·수정 절대 금지(원칙은 유지) | 사용자 「실제 운영 디비라 절대 수정하면 안돼」 · `research-patient-detail-report.md` C-5 · 사용자 「추천대로」 |
| D-11 | **back 이 상태를 든다.** 데스크 페이지와 직원 페이지가 같은 상태를 보고, 한쪽 조작이 다른 쪽에 바로 반영된다 | 사용자 「나 로 연결 까지 해야해」 · 「현황판이랑 연동 되는거지」 |
| D-12 | **초기화 = 시드 상태로 복귀.** 시드는 사용자가 앱을 움직인 뒤 「이걸 시드로」라고 하면 그 시점 상태로 바꾼다(코디가 back 명령으로 실행 — 화면 버튼 아님). 첫 시드는 D-08 적재본 | 사용자 「초기화 하면 시드 상태로 … 이걸 시드 상태로 하자고 말할거야」 |
| D-13 | 데이터 방 14개(`A_룸1–9` · `A_트윈` · `A_시술실` · `A_레이저실`)는 도면의 일부 — 코디가 만든 **임시 순서 대응표**(`orchestration/work/sts-prototype/room-map-provisional.md`)로 시안 칸에 끼운다. **직원 페이지도 같은 칸 이름**(관리실 ○○)을 쓴다. 나머지 칸은 빈 방. 실제 대응은 지점 확인 후 | 사용자 「시안 그대로 가고」(2026-10-13) |

### 환자 상세 · KOS 경계

| ID | 결정 | 근거 |
|---|---|---|
| D-20 | 메모 · 시술 · 이력 · 직원은 **KOS 가 원천.** 앱은 KOS 필드를 그대로 보여 주기만 하고 메모 쓰기·수정 기능은 두지 않는다 | 사용자 「코스 api 가져와서 메모랑 충돌 나면」 · 「추천대로」 |
| D-21 | KOS 데이터(일정 상세 · 메모 · 시술 · 직원)는 back 에 **KOS 응답 모양 그대로** 참조 데이터로 둔다. 현황판 상태(위치 · 단계 · 직원 큐)는 KOS 에 없는 것이라 **KOS id(일정 id · 직원 id)로 묶은 덧씌움 모델**로 따로 둔다. 연동 때는 참조 데이터의 원천만 바꾼다 | 같음 · SPEC-001 §5.1 작성 때 구체화(2026-10-13) |
| D-22 | 환자 상세 = **안 A**(질문 순서). 상단 카드(가짜 이름·국적·성별·나이·첫 방문/재방문 · 예약 시각·상태·지금 방 · **아웃 시각** · 상담실장·원장 · [통역][진료 시작]) → 환자 메모: ① **⚠ 주의**(고객 메모 `visitor.memo` 값 있을 때 맨 위 · 오더 메모와 상담 메모 사본 **양쪽**의 `[특이사항]`·`[임플란트]` + 메모 앞에 덧붙인 `**`·`★` 줄) ② **오늘 오더**(`orderMemo` 시술 줄·마취) ③ **상담 요약**(상담 메모 `------` 위쪽) ④ **접수 메모**(`reservationMemo`) → 환자 차트(유입·예약 그룹·동행·시술권·선불·오늘 결제 — 값 없으면 숨김) → 시술 이력(「첫 방문」+ 타 병원 이력) → 오늘 고객 동선(끝난 작업 옆 담당자 메모). 역할별 기본 펼침: 의사 ②③ · 코디 ④. 성별·나이·국적은 상단 카드에만, 차트번호는 어디에도 없음. 의사 칸의 「마취용」 계정은 표시하지 않는다 | `research-patient-detail-report.md` §D 안 A · Q-1~Q-9 · 사용자 「추천대로」 |
| D-23 | 아웃 시각 출처 순서 — 오더 `OUT TIME` → 예약 메모 앞줄 → `desiredDischargeDateTimeUtc` | Q-6 · 「추천대로」 |
