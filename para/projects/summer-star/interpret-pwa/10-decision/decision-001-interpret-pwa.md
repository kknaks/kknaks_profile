# 통역 PWA — 새 레포 · 양방향 통역(언어는 시작 때 고름) · 용어집 context · 단일 계정

> 계약은 `20-spec/`, 작업 순서는 `30-work/` 가 갖는다. 이 문서는 무엇을 정했고
> 무엇이 열려 있는지만 갖는다.

## Context

ccc(cc-prototype)의 통역은 피부과 시술 용어를 직역한다(BASE-001 입력 1). 통역만 떼어 따로 쓸 수 있는
PWA 를 만들고, Procedure Hub 용어집을 Soniox 에 번역 용어로 넣어 직역을 막는다.

## Options — 상대 언어 정하기

| Option | Description | 판단 |
|---|---|---|
| A | 통역 시작 화면에서 환자 언어를 고르고 `two_way`(ko ↔ 그 언어)로 연결 | **채택** — 사용자 「a로 가자」 |
| B | 처음엔 `one_way`(→ ko)로 열고, 첫 외국어 발화의 `language` 로 `two_way` 재연결 | 기각(지금은) — 첫 발화가 한쪽만 번역되고 재연결 동안 끊긴다 |

## Decision

| ID | 결정 | 근거 |
|---|---|---|
| D-01 | 코드는 새 레포 `kknaksss/interpret-pwa`(private). 로컬 `/Users/kknaks/git/toy_pr2/interpret-pwa`. 레포 루트에 `front/` · `back/` 한 쌍. 문서는 이 폴더 | 입력 4 「새 레포 만들고」 |
| D-02 | front = **Next.js PWA**(홈 화면 추가), back = **FastAPI(uv)** | 입력 2 「pwa로」 · 코디 기본값(cc-prototype 과 같은 스택 — 통역 원형을 옮겨 오기 쉽다) |
| D-03 | 통역은 **back 이 WebSocket 으로 Soniox 를 중계**한다 — STT(번역 `two_way` ko ↔ 고른 언어) + 확정 발화 번역문 TTS. TTS 재생 중에는 마이크를 멈춘다(반이중). Soniox 키는 back env 에만 | ccc 통역 원형(BASE-001 확인한 사실) |
| D-04 | 상대 언어는 **Procedure Hub 용어집 `langs` 6개(en · ja · zh · th · vi · yue)** 중 통역 화면의 드롭다운으로 고른다(Option A) | 입력 3 · 용어집에 표기가 있는 언어만 용어 보정이 된다 |
| D-05 | 용어집은 back 이 `GET /api/v1/glossary/matrix`(stg, 인증 없음)에서 읽어 Soniox `context` 로 넣는다 — `terms` 는 ko 표기, `translation_terms` 는 ko → 고른 언어. 한도(8,000토큰)를 넘으면 `terms` 를 줄인다 | 입력 1 · BASE-001 확인한 사실 |
| D-06 | **로그인은 통역앱에만, 계정 하나.** 사용자 지정 계정 하나이고, 아이디 · 비밀번호 값은 back env 로 넣는다 — 코드 · 문서에 값을 적지 않는다 | 입력 2(계정값은 대화에만 — public 이라 생략) · 이 레포는 public |
| D-07 | 화면은 **로그인 → 통역 화면** 둘. 통역 화면은 위에서부터 헤더(햄버거: 로그아웃 · 용어집) · 외국어 영역(언어 드롭다운 · 화면 전환 아이콘) · 가운데 원 · 한국어 영역 | 입력 3 · 입력 4 |
| D-08 | 외국어 영역은 기본 **180° 뒤집힘**(맞은편 외국인이 읽는 방향). 화면 전환 아이콘으로 바로 보기(옆에서 볼 때)와 바꾼다 — 렌더 방향만 바뀐다 | 입력 3 「외국인이 맞음편에서」 · 입력 4 「랜더만 바꾸면」 |
| D-09 | 가운데 원: 말하는 동안 **음량에 따라 커졌다 작아지고**, 외국어 · 한국어 발화에 **다른 색**. TTS 재생 중에는 그 언어 색 + 「〈언어〉로 출력 중」 안내 | 입력 3 |
| D-10 | UI 는 **medikit** 디자인 시스템, 단순하게 | 입력 3 |
| D-11 | 키(Soniox · 계정값)는 사용자가 `.env` 에 넣는다 — 워커 · 코디는 `.env.example` 만 | 입력 2 |
| D-12 | **로컬에서 실물 통역 확인 → 마지막에 Mac Studio(k8s_infra_mac) 배포** | 입력 2 |
| D-17 | **중국어 번체는 back 에서 변환한다.** Soniox 의 중국어 전사 · 번역은 간체로만 나온다 → ccc 처럼 OpenCC 류 라이브러리로 **화면 자막만 번체**, TTS 에는 간체를 넣는다(번체를 넣으면 발음이 깨진다). 번체를 쓰는 언어(광둥어 `yue` 등)와 용어집 번체 표기를 Soniox 에 넣을 때의 처리는 SPEC 이 정한다 | 사용자 2026-10-26 「소니옥스는 번체가 간체만 제공해서 별도 라이브러리 필요하긴해 ccc 에서 만든거 처럼」 · ccc 실물 확인(2026-10-13, `procedure/back/app/service/interpret/chinese.py`) |

## Scope

- In: 로그인, 통역 화면(양방향 실시간 통역 · 자막 · TTS), 용어집 context, 용어집 메뉴, PWA, 로컬 실행, Mac Studio 배포.
