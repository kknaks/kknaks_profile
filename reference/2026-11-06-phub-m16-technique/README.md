**조사 2026-11-06 (사용자가 별도 세션에서 웹 조사 · 이 파일로 전달)** — 「조사 답」·「출처」 칸을 채움. 조사 전 판은 `README-조사전.md`. 아래 「조사 결과 요약」과 「확인 수준」을 먼저 읽을 것.

## 왜 조사가 필요한가
- 계열 M16 「수액치료」의 기법은 원장상 정맥주사(intravenous) 하나로 되어 있지만, 실제 항목에는 근육주사·피하주사·지방층 주사·진피 주입·가스 주입·기기 관리가 섞여 있다. 계열 전체에 정맥주사를 상속하면 틀린 데이터가 된다.
- 원장 문장에 경로가 적힌 항목만 「원장 표기」로 옮겼고, 나머지는 조사로 채웠다.
- 「조사 답」 값이 결정 레코드(근거 = 조사 출처)로 실버 9차에 들어간다.

## 답으로 쓸 수 있는 기법 값(ERD v3.3 기법 사전 12개 중 해당)
`intravenous`(정맥주사·정맥 수액) · `injection`(주사 일반 — 근육·피하·진피·지방층) · `infusion`(주입) · `topical`(도포) · 그 밖 기기 기법(`mechanical` 등). 근육/피하/진피/지방층을 나눠 적어 주면 기법은 `injection`, 깊이는 v3.3 「무엇을·어떻게 세분」 설계(F)에서 받는다.

## 확인 수준(조사 답 칸 앞머리 표시)
- **[라벨]** 허가 문서·약학정보원 제품 페이지·허가보고서·해외 공식 라벨 원문으로 확인
- **[기사]** 신뢰할 만한 의약 전문지·일간지 기사로 확인(라벨 원문은 미확인)
- **[추정]** 같은 성분·적응증 제품 또는 일반 설명을 적용한 판단 — 이 항목만의 근거는 없음
- **[원장]** 조사 대상 밖. 원장 표기를 유지하고 따로 검증하지 않음
- **[미확인]** 근거를 찾지 못함
- 한계: 식약처 의약품안전나라(nedrug)는 접속이 막혀 원문을 열지 못했다. 강남언니 이벤트 페이지도 열지 못해 마케팅명 주사의 병원별 성분표는 직접 보지 못했다.

## 조사 결과 요약

**질문 1 · 경로 표기 없던 34 항목** — 표 참고. 허가 의약품 성분은 라벨로 대부분 확인. 마케팅명 지방분해주사는 「피하지방층」으로 추정, 성분은 병원마다 다름.

**질문 2 · DCA 11 제품** — 전부 **턱밑 피하지방층 주사**(`injection`, 피하지방층). 원문 라벨로 확인한 것은 뉴비쥬(식약처 허가보고서)·키벨라(FDA 라벨) 둘이고, 나머지는 기사 또는 같은 성분·적응증 근거. 국내 허가 사용 부위는 턱밑 한정. 원장 정정 필요:
- 「카이벨라」 → 정식명 **키벨라(Kybella)**. 「한국 철수(2020)」는 키벨라의 국내 허가명인 **벨카이라** 이야기(2017.08 허가 → 2020.12 자진 취하). 즉 **벨카이라와 카이벨라는 같은 제품 중복** — 하나로 합치고, 국내 현재 미판매로 표시 권장.
- 「벨라콜린」 → LG화학 허가 전문의약품(2024.01).
- 「뉴비쥬」 → 허가일 2025.09.19(국산 신약 40호), 개발명 뉴브이(MT921).

**질문 3 · 지방분해주사(마케팅명) 9 항목 + 기타 부위별 4 항목** — **병원마다 다름.** 흔히 쓰이는 성분은 DCA·PPC·GPC(콜린 알포세레이트)·히알루로니다제·아미노필린·카페인·(스테로이드) 조합이고 배합 기준은 정해져 있지 않다(한국보건의료연구원 발언). 주입 층은 피하지방층. 허가 성분은 DCA뿐이고 PPC는 허가 외 사용(국내 허가 적응증은 간성혼수 보조).

**질문 4 · 비타민D 상충** — 국내 콜레칼시페롤 주사(비오엔주·비엠하이디주)는 **근육주사만** 허가. 정맥용 비타민D 주사는 찾지 못함(전수조사는 아님). → M16-1 「비타민D주사」(근육)가 맞고, M16-4 「비타민D」의 「정맥주사」는 **오류일 가능성이 높음**. 둘은 같은 성분의 같은 시술로 보이므로 **중복 통합** 검토 권장.

**질문 5 · 수액에 어울리지 않는 항목**
- LDM초음파관리: **주사가 아닌 비침습 초음파 기기**(젤 바른 피부 위 핸드피스) → 기법 `mechanical`(기기), M16에서 메디컬스킨케어 등 기기 계열로 이동 권장. 제조사 「제이시스」는 확인 못 함.
- 카복시테라피: CO2 **피하 주입**(지방 감소 목적. 피부 개선 목적은 진피까지 주입하는 경우도 있음) → `injection`(가스). 지방 감소 계열과 함께 두는 편이 자연스러움.
- 미녹시딜 두피 메조: **두피 진피(피내) 주사** → `injection`(진피). 탈모 계열로 이동 검토. 미녹시딜 주사제는 FDA 허가가 없음(외용만). 국내 허가 여부는 미확인.
- DCA·지방분해주사 22 항목도 수액이 아니라 국소 피하지방층 주사 → 하위분류 단위로 기법 `injection` 지정 권장.

**그 밖에 발견한 원장 문제**
- 「태반주사(라엔넥)」 → 정식명 **라이넥주**. 허가 경로 피하·근육, 정맥은 허가 외(2026.04 기사: IV 용법 3상 투여 완료, 허가 변경 전).
- 「징크주사」 원장의 「정맥 또는 근육」 → 국내 황산아연 주사 라벨은 **정맥(TPN 첨가용)**만, 근육 용법 없음.
- 「프로락틴주사(프로작 탈모주입)」 → 해당 제품 확인 안 됨. 프로락틴은 호르몬, 프로작은 경구 항우울제라 **명칭 오기 의심** — 원장 작성자 확인 필요.
- 「HP주사(감초주사)」 → 감초 주사(글리시리진, 강력네오미노파겐씨)는 정맥용 간 질환 약인데 원장은 「지방분해 주사」라고 적어 성분과 용도가 맞지 않음 — 원장 확인 필요.
- 중복 의심: NAD+ / NAD+ 주사 / 나드주사(3건) · 셀레늄 주사 / 셀레늄(2건) · 비타민D주사 / 비타민D · 벨카이라 / 카이벨라 · 고농도C / 고용량 비타민C 주사 · 종합비타민수액(detail이 「마이어스칵테일」) / 마이어스칵테일.
