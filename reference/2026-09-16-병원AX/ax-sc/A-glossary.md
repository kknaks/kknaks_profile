# 부록 A. 용어

> SC-AX 제품 정의서 v0.1 · 검증 전 초안
> 허브: [`00-overview.md`](./00-overview.md)
>
> **회의에 없던 사람이 읽는다고 가정한다.** 문서 안에서 특정한 뜻으로 쓴 말만 모았고, **혼동되기 쉬운 것과의 차이**를 함께 적었다.

---

## 이 프로젝트를 부르는 말

| 용어 | 뜻 | 주의 |
|---|---|---|
| **AX** | AI를 써서 일하는 방식을 바꾸는 것 | **도구를 도입하는 것이 아니다.** 도구만 넣고 일하는 순서가 그대로면 AX가 아니다 |
| **차수** | 만드는 구간을 나눈 단위. 1차 · 2차 · 3차 · 4차 | **차수 안의 주차 일정은 이 문서가 정하지 않는다.** 각 차수를 맡는 기획이 만든다 |
| **1차 ~ 4차** | 네 구간. **1~3차는 전 부서 공통, 4차부터는 부서별 맞춤** | **시범 운영이 아니다.** 1차에 만든 것은 그대로 쓰고 뒤 차수에 더한다. **1~3차는 전 부서 공통, 4차부터는 부서별 맞춤**이다 |
| **통합 리뷰** | 1차가 끝나는 자리에서 **본개발 착수와 2차 범위를 정하는 회의** (9월 말, 경영진 포함) | **보고 자리가 아니라 결정 자리다.** 여기서 정하지 않으면 2차가 시작되지 않는다 |
| **트랙 A** | **만드는 일** — 기능을 만든다 | |
| **부서별 맞춤** | 특정 부서만 쓰는 기능. **4차부터** 붙는다 | **순서는 요구가 들어온 순서다.** 4차가 경영관리부인 이유는 그 부서 요구가 먼저 들어왔기 때문이다 |
| **트랙 B** | **알아내는 일** — 어느 부서가 어떤 자료를 어디에 갖고 있는지 조사한다 | **자료를 옮기는 일이 아니다.** 존재와 위치만 확인하고 **내용물은 받지 않는다** |

## 만드는 것을 부르는 말

| 용어 | 뜻 | 주의 |
|---|---|---|
| **모듈** (`M-n`) | 기능을 묶은 단위. 조직 정보와 권한 · 업무일지 · 회의실 · 대시보드 · 데이터 지도 등 열넷 | **화면 하나가 아니다.** 한 모듈 안에 여러 화면이 들어간다 |
| **역량** (`C-n`) | 모듈이 실제로 해내야 하는 능력. "조직 구조를 등록한다" 같은 단위 | **기술이나 화면을 정하지 않는다.** 무엇을 할 수 있어야 하는지만 적는다 |
| **데이터 지도** (데이터 맵) | 어떤 자료가 **어느 부서에 어떤 형태로 어디에 있는지**를 정리한 것. 눌러서 실제 자료로 갈 수 있다 | **자료 저장소가 아니다.** 자료를 보관하지 않고 **어디 있는지만** 안다 |
| **파생** | 사람이 따로 입력하지 않아도 **한 일에서 업무일지·보고서가 만들어지는 것** | **자동 작성이 아니다.** 만들어진 것을 **본인이 확인하고 고칠 수 있다** |
| **이월** | 그날 끝내지 못한 일이 다음 날로 넘어가는 것 | 넘어간 일은 **원본과 한 흐름으로 묶여** 목록에 최신 것 하나만 뜬다. 안 그러면 같은 일이 날짜별로 쌓인다 |
| **접근 기록** | **누가 무엇을 열어봤는지** 남는 것 | **반출 기록과 다르다.** 열어본 것과 밖으로 내보낸 것은 별개다 |
| **반출** | 자료가 **회사 밖으로 나가는 것** — 메일·메신저·외장 매체 등 | 시스템 안에서 나가는 것만 다룬다. **개인 PC에서 나가는 것은 범위 밖**(`OUT-5`) |
| **권한** | 누가 무엇을 볼 수 있고 바꿀 수 있는지 | 조직 정보와 **같은 뿌리다.** 누가 어느 부서에서 무슨 일을 하는지가 곧 권한의 근거다 |
| **간이 화면** | 요구가 맞는지 확인하려고 만드는 **눌러볼 수 있는 화면** | **완성품이 아니다.** 실제 자료와 연결되어 있지 않다 |

## 만드는 것과 켜는 것

| 용어 | 뜻 | 주의 |
|---|---|---|
| **점등** | 만들어 둔 기능을 **실제로 켜서 쓰게 하는 것** | **만드는 것과 시점이 다를 수 있다.** 1차에 만들고 2차에 켜는 기능이 둘 있다 |
| **전사 현황 화면** | 회사 전체 진행 상황을 한눈에 보는 화면 | 1차에 **만들되 켜지 않는다.** 기록이 쌓이기 전에 켜면 감시로 읽혀 **기록 자체가 안 남는다** |

---

## 재는 것을 부르는 말

| 용어 | 뜻 | 주의 |
|---|---|---|
| **기준선** | **바뀌기 전이 어느 정도였는지** 재어 둔 값 | **목표가 아니다.** 기준선이 없으면 나아졌는지 말할 수 없다 |
| **사전값 · 사후값** | 기준선(사전값)과 그 뒤에 다시 잰 값(사후값) | **같은 문항으로 물어야** 비교된다 |
| **North Star** | 하나만 본다면 이것을 본다는 대표 지표 | 이 문서에서는 **「손이 덜 간 일의 비율」** |
| **입력 지표** | 팀이 직접 움직여서 바꿀 수 있는 선행 지표 | |
| **건강·보호 지표** | 다른 지표를 밀다가 **망가뜨릴 수 있는 것**을 잡는 지표 | 없으면 **압박으로 만든 성과가 성공처럼 보인다** |
| **활동량 지표** | 로그인 수·기록 건수처럼 **많이 하면 오르는 값** | **이 문서는 쓰지 않는다.** 위에서 시키면 오르기 때문에 가치와 무관하게 좋아 보인다 |
| **이중 상태** | 새 시스템에도 넣고 **원래 하던 것도 그대로 하는 상태** | **지표상으로는 성공처럼 보인다.** 기록도 늘고 사용도 는다. 손만 더 간다. **시스템 기록으로는 안 잡히고 사람에게 물어야 안다** |

## 진행 방식을 부르는 말

| 용어 | 뜻 | 주의 |
|---|---|---|
| **게이트** | **되돌리기 어려운 결정**이 일어나는 지점 | **보고 시점이 아니다.** 다르게 고를 수 있어야 게이트다 |
| **마일스톤** | 무엇이 가능해지는지로 표시한 진행 지점 | 만든 것이 아니라 **되는 것**으로 적는다 |
| **보류** (`HOLD-n`) | **조건이 풀려야 정할 수 있는 것** | **"안 한다"가 아니다.** 하지 않는 것(`OUT-n`)과 구분한다 |
| **변경 요구** (`CH-n`) | 제품이 아니라 **회사 쪽에서 바꿔 주어야 하는 것** | 조직 정보 제공·설문 응답·지시를 남는 자리에 하기 등 |
| **레거시 자료** | 지금까지 쌓여 있는 과거 자료 | **옮겨 넣는 것을 전제하지 않는다.** 어디 있는지는 알아내되(`D-1`·`D-2`) 이전은 별개다 |

## 표에서 쓰는 머리말

| 말 | 뜻 |
|---|---|
| **AS-IS** | **지금** 이렇게 하고 있다 |
| **TO-BE** | **바뀐 뒤** 이렇게 된다 |
| **NEED** | 그렇게 되려면 **필요한 것** |

> **TO-BE는 약속이 아니라 판정 기준이다.** 이 문서에는 수치 목표가 없고, **TO-BE가 실제로 그렇게 되었는지**로 판정한다.

---

## 정보의 상태 표기

**이 표기가 이 문서의 핵심 규칙이다.** 확정되지 않은 것을 확정처럼 쓰지 않기 위해 문장마다 붙인다.

| 표기 | 뜻 |
|---|---|
| `[사실]` | 원자료로 확인된 것 |
| `[해석]` | 사실을 근거로 한 분석 — **판단이 들어가 있다** |
| `[가설]` | 아직 검증되지 않은 것 |
| `[결정]` | **권한자가 확정한 것** — 현재 **0건** |
| `미확인` | 물었으나 답이 없거나 아직 묻지 않은 것 |

> `[해석]`이 많은 것은 정상이다. **`[가설]`을 `[결정]`처럼 쓰는 것이 결함이다.**

## 쓰지 않기로 한 말

`[해석]` **주 독자가 비개발 경영진**이므로 아래 표현을 본문에서 걷어냈다. 원자료 인용문은 원문을 유지한다.

| 안 쓴 말 | 대신 쓴 말 |
|---|---|
| 온보딩 | 처음 쓰기 시작할 때 |
| 마이그레이션 | 옮겨 넣기 |
| 대시보드 | 현황판 · 현황 화면. **「대시보드」는 모듈 이름과 원자료가 쓴 표현에만 남겼다** |
| 워크플로우 | 일하는 순서 |
| 인터페이스 · UI | 화면 |
| 프로토타입 | 간이 화면 |
| 리텐션 | 계속 쓰는지 |
| 아카이빙 | 보관 |
| 싱글 소스 오브 트루스 | 원본이 한 곳에 있는 상태 |
