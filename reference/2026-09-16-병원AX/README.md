# 병원 AX 전략 수립 — 이관 전 기록

이 폴더는 병원 AX 전략 수립의 초기 구상·참고자료와 문서 초안을 보존한다.

2026-09-17에 합의한 전략 문서와 PARA 구조를 별도 [ax-clinic-project 레포](https://github.com/kknaks/ax-clinic-project)에 구성했다. 이후 문서 작성·수정의 원본은 해당 레포다. 이 폴더의 초안은 이관 당시 기록으로 남긴다.

- `ax-clinic/`: 병원 AX 추진 계획과 산출물 초안
- `ax-sc/`: 별도 SC-AX 문서 세트 — 참고용
- 그 외 파일: 구상 대화, 직무 자료, 조사 메모 및 이전 초안

이 자료들은 검증된 병원 현황이나 확정된 실행계획을 뜻하지 않는다. 출처와 검증 상태는 각 문서에서 확인한다.
