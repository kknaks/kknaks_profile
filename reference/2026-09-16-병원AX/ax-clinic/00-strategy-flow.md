## 1. 추진 목적과 방향

병원 AX 전환 사업을 추진하고자 한다. 병원의 매출 향상과 비용 절감을 목표로, 업무와 데이터를 정비하고 AI를 실제 운영에 적용하는 체계를 구축한다. 명동점을 우선 검증 대상으로 삼고, 검증된 방법과 기능을 다른 병원에도 적용할 수 있도록 모듈화하는 방향을 제안한다.

이를 위해 먼저 자료조사·인터뷰·현장조사로 현황과 개선 기회를 파악한다. 조사 결과를 바탕으로 추진 과제와 우선순위를 정하고, 전체 로드맵과 단계별 마일스톤·성공지표를 수립한다. 첫 실행 단계는 담당자·일정·예산·검증 방법까지 구체화한다.

### 1.1 사업 목표

| 구분 | 추진 목표 | 전략 수립 과정에서 구체화할 사항 |
|---|---|---|
| 비즈니스 | 매출 향상과 비용 절감을 통한 수익성 개선 | 현재 실적, 개선 기회, 목표 수준, 달성 기간 |
| 기술·운영 | 병원 데이터와 업무의 관계를 정의하는 온톨로지 및 AI 운영 기반 구축 | 적용 업무, 필요한 데이터와 연동, 직원과 AI의 역할, 운영·관리 방식 |
| 확장 | 명동점에서 검증한 방식의 모듈화 및 타 병원 적용 | 공통 적용 범위, 병원별 조정 범위, 도입 비용, 재현성 검증 방법 |

세부 목표 수치와 기술 구축 범위는 조사 및 과제 평가 후 제안한다.

### 1.2 이번 보고의 범위

이번 보고에서는 사업의 추진 방향과 전략 수립 방법을 제안한다. 경영진과 조사 범위·참여 인력·자료 제공 및 현장 협조 사항을 협의한 뒤 전략 수립에 착수한다.

전략 수립 결과 보고에서는 전체 추진 계획과 첫 단계 실행안을 제시하고, 실행 범위와 투자 규모에 관한 의사결정을 요청한다.

## 3. 전략 수립 진행 방식

**작성 원칙:** 각 단계에서 문서를 작성·수정할 때는 반드시 [ax-clinic 작성 규칙](./00-rules.md)을 확인하고 따른다.

자료조사 → 인터뷰 → 현장조사 순으로 근거를 보강한다. 각 단계에서 가설을 갱신하며, 근거가 부족하거나 서로 일치하지 않는 항목은 추가 확인한다.

### 3.1 자료조사

**목적:** 인터뷰와 현장조사에 앞서 현황 문서의 초안을 만들고, 확인할 질문과 1차 가설을 도출한다.

- 공개 자료를 통해 클리닉 시장과 관련 서비스·사례를 조사한다.
- 제공 가능한 내부 자료를 확인하고 매출·지출·인력·재고·고객 관련 기록을 검토한다.
- 고객여정과 병원 운영의 초안을 작성한다.
- 자료에서 확인한 내용과 아직 확인하지 못한 내용을 구분하고, 후속 확인 항목을 정리한다.

**완료 기준:** 현황 초안, 자료 부족 항목, 1차 가설 및 인터뷰 확인 항목을 정리한다.

### 3.2 인터뷰

**목적:** 1차 가설을 검증하고, 자료만으로 드러나지 않는 업무 방식과 문제를 파악한다.

- 경영진에게 사업 기대 성과, 우선 관심 과제, 투자·운영 조건을 확인한다.
- 업무별 담당자에게 실제 처리 과정, 반복 작업, 예외 상황, 협업 방식과 불편 사항을 확인한다.
- 같은 문제에 대한 직무별 설명을 비교하고, 자료와 일치하지 않는 항목을 정리한다.
- 1차 가설을 유지·수정·기각하고 새로운 가설을 추가한다.

**완료 기준:** 인터뷰 근거를 반영한 현황 문서, 2차 가설 및 현장 확인 항목을 정리한다.

### 3.3 현장조사

**목적:** 인터뷰에서 파악한 문제가 실제 업무에서 어떻게 발생하는지 관찰하고, 과제 평가에 필요한 근거를 확보한다.

- 실제 업무 흐름과 담당자 간 인계, 시스템 사용, 대기와 재작업을 관찰한다.
- 측정 가능한 항목은 발생 빈도, 처리 시간, 대기 시간 등을 기록한다.
- 인터뷰 내용과 관찰 결과의 차이 및 예외 상황을 확인한다.
- 조사 기간에 확인하지 못한 항목은 미검증 상태로 남기고 추가 확인 방법을 정한다.

**완료 기준:** 근거를 종합한 현황 문서와 우선순위 평가 대상 가설을 정리한다. 각 가설에는 검증 상태와 남은 불확실성을 표시한다.

## 4. 가설 평가와 추진 과제 선정

### 4.1 평가 항목

각 가설은 다음 항목으로 평가한다. 수치가 없는 항목은 추정 근거와 확인 방법을 함께 기록한다.

| 평가 항목 | 확인할 내용 |
|---|---|
| 문제와 근거 | 어느 업무에서 누구에게 어떤 문제가 발생하며, 무엇으로 확인했는가 |
| 현재 손실 | 발생 빈도, 소요 시간, 직접 지출, 누락·재작업 및 기회손실 |
| 개선 가설 | 어떤 업무·데이터·시스템 변화가 문제를 줄일 수 있는가 |
| 예상 효과 | 추가 이익, 실제 비용 절감, 확보 가능한 업무 시간, 서비스 품질 개선 |
| 실행 비용 | 구축·연동·도입·교육 비용과 지속 운영·유지 비용 |
| 실행 조건 | 데이터 확보, 시스템 연동, 담당 인력, 업무 변경 및 적용 제약 |
| 선행 과제 | 먼저 완료해야 하는 데이터 정비·업무 표준화·기반 구축 |
| 검증 방법 | 효과를 어떤 지표와 기간으로 확인할 것인가 |
| 확장 가능성 | 다른 병원에서도 공통으로 적용할 수 있는가 |

절감된 업무 시간은 인건비 지출 감소와 구분해 평가한다. 매출 증가 효과는 추가 비용을 반영한 이익 기여와 함께 검토하고, 여러 과제에서 같은 효과를 중복 계산하지 않는다.

### 4.2 우선순위 결정

효과의 규모, 근거의 신뢰도, 실행 비용·기간, 선행 과제 및 확장 가능성을 함께 검토한다. 평가 결과를 바탕으로 우선 실행할 과제, 먼저 갖춰야 하는 기반 과제, 추가 검증이 필요한 과제, 보류할 과제를 제안한다.

기반 구축 과제는 그 기반을 필요로 하는 후속 과제와 연결해 투자 필요성을 설명한다.

## 5. 전체 로드맵과 단계별 실행계획 수립

선정한 과제의 선후관계와 필요한 자원을 바탕으로 전체 로드맵을 작성한다. 단계별 과제 배치와 목표 수치는 전략 수립 결과로 제시한다.

### 5.1 전체 로드맵

- 사업을 통해 달성할 사업 성과와 병원 운영의 목표 상태
- 단계별 추진 과제, 예상 기간, 선행 조건 및 주요 산출물
- 단계별 투자·인력·운영 자원 추정
- 명동점 검증 결과를 바탕으로 한 타 병원 적용 범위와 확대 조건

### 5.2 마일스톤과 성공지표

각 단계에 완료 조건과 성과 확인 기준을 설정한다. 지표별로 현재 기준값, 목표값, 측정 방법, 측정 주기 및 책임자를 정한다. 현재 기준값을 확보할 수 없는 항목은 측정 체계 마련을 선행 과제로 반영한다.

단계 종료 시 결과를 평가해 다음 단계 착수, 보완 또는 계획 조정 여부를 결정한다. 명동점에서의 성과와 타 병원에서의 재현성은 각각 확인한다.

### 5.3 첫 단계 상세 실행계획

첫 단계는 실행 범위, 담당자, 일정, 예산, 업무 변경 사항과 성과 검증 방법까지 작성한다. 이후 단계는 앞 단계의 결과를 반영해 실행 착수 전에 상세화한다.
