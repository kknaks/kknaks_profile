# reference

외부 자료(영상·책·아티클)를 정리한 재료층. 여기 놓이는 노트의 타입: `reference`.

## 여기 두는 것
- 읽고/본 외부 자료의 정리 노트. 출처는 frontmatter `source: <url>` 속성으로 둔다.

## 여기 두지 않는 것
- 내 언어로 재서술한 영구 생각 → `permanent/` (reference는 종착지가 아니다).
- 미정제 생각 → `inbox/`.

## quick-rule
- reference는 종착지가 아니라 **인용되는 재료**다. permanent/product 본문에서 `[[reference-stem]]`으로 인용되고, 기반이면 그쪽 `up:`에 stem이 들어간다.
