Endpoints

API 목록과 요청·응답

HTTP 70개와 WebSocket 1개. 엔드포인트를 펼치면 파라미터, 요청 본문, 응답 필드와 JSON 예시를 볼 수 있습니다.

직원 API는 Bearer 토큰을 사용합니다. 공개 문진은 X-Questionnaire-Token 헤더, SSE는 ?token=을 사용합니다. 파일 업로드는 multipart, 다운로드는 바이너리 응답입니다. 오류는 {"error":{"code":"...","message":"..."}} 형식이며 요청 검증 오류는 400입니다.
