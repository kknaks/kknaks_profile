# 상태 모델 (WP-126, 머지 완료 — 이번 작업에서 변경 없음)

## 5개 값
| 값 | 라벨 | 의미 |
|---|---|---|
| `todo` | 대기 | 생성 초기값. 예외 없이 전부 todo로 태어남(시스템 생성 포함) |
| `in_progress` | 진행 중 | 명시적 [시작]으로만 진입. 자동 전환 없음 |
| `blocked` | 중단 | 사유 필수 |
| `done` | 완료 | terminal |
| `canceled` | 취소 | terminal. "하기로 했다가 안 하기로 함" — 기록엔 남고 칸반엔 미노출 |

## 전이
```
todo         → [시작] in_progress   [중단] blocked
in_progress  → [완료] done          [중단] blocked
blocked      → [재개] todo          [시작] in_progress
done         → (없음)
canceled     → (없음)
```
- 재배정 = `todo`로 리셋 + `started_at` 클리어. terminal 태스크는 재배정 금지.
- 수락/거절 없음(`accept_pending` 폐지). 거부 = 재배정 요청.
- 삭제는 상태가 아니라 `deleted_at` soft delete — 조회·판정에서 완전히 제외(취소와 다름).

|---|---|---|
| 대기 | `#9F9F9F` | `#F3F3F3` / `#6E6E6E` |
| 진행 중 | `#476CFF` | `#F0F4FF` / `#476CFF` |
| 중단 | `#FF4E51` | `#FFEFEF` / `#FF4E51` |
| 완료 | `#22C55E` | `#E7F8EE` / `#15803D` |
| 취소 | `#9F9F9F` | `#F3F3F3` / `#9F9F9F` |

## 상세 화면 액션 버튼 (상태별)
- 대기: **시작**(primary, 채움) · 중단(outline)
- 진행 중: **완료**(primary) · 중단(outline)
- 중단: **재개**(primary) · 시작(outline)
- 완료·취소: 버튼 없음 + `상태 변경 불가` 텍스트(12px `#9F9F9F`)
- 항상: `···` 오버플로 메뉴 — 재배정(대기로 리셋) / 취소 / 삭제(danger). terminal이면 재배정·취소 비활성(`#CFCFCF`, `not-allowed`), 메타 스트립의 "재배정" 링크도 동일 비활성.

버튼 스펙: height 34, padding 0 14, radius 6, 13px. primary `#476CFF`/흰글자/600, outline `1px #E3E3E3`/`#3E3E3E`.

## 모달
### 1) 완료 — 요약 모달 (620px, 3분할: 헤더/스크롤 본문/푸터)
- 헤더: eyebrow `완료 처리`(11/600/uppercase/`#476CFF`) → 타이틀 19/700 "이렇게 마무리하는 걸로 기록됩니다" → 설명 13/`#6E6E6E`
- 본문 섹션(각 섹션 라벨 12/600/uppercase/`#9F9F9F` + 우측 카운트)
  1. **한 일** — 체크리스트 전체. 체크된 항목은 파란 체크박스 + `#3E3E3E`, 미체크는 빈 박스 + `#CFCFCF`
  2. 미체크가 있으면 경고 박스: "체크되지 않은 항목이 N개 있습니다. 그대로 완료하면 미완 항목으로 기록됩니다." (`#FFF9EC`/`#FFE6B8`/`#B45309`)
  3. **참고한 자료** — 링크/파일 목록(아이콘 26px, 우측에 출처·날짜)
  4. **제출자료** — 동일 형식 + "제출자료 추가"
  5. **한 줄 요약** (필수, `*` 표시) textarea 3행
- 푸터: 취소(outline) / **완료로 전환**(primary, 요약 비면 `#DDE6FF` + `not-allowed`)

### 2) 중단 / 취소 — 사유 모달 (480px)
- 타이틀 17/700, 설명 13/`#6E6E6E`, 사유 textarea 4행(필수), CTA `중단으로 전환` / `취소로 전환`
- 문구
  - 중단: "왜 멈췄는지 남기면 재개할 사람이 덜 묻습니다." / placeholder "예) phase 재정의 결론 대기 중"
  - 취소: "하기로 했다가 안 하기로 한 경우입니다. 기록에는 남고 칸반에서는 빠집니다."

### 확정 후
입력한 사유·요약은 상세 헤더 아래 배너로 상주.
- 중단: 배경 `#FFF6F6`, 보더 `#FFD7D7`, 라벨 `중단 사유`(`#FF4E51`)
- 완료·취소: 배경 `#FBFBFB`, 보더 `#F3F3F3`, 라벨 `완료 근거`/`취소 사유`(`#6E6E6E`)
- terminal이면 그 아래 12px `#9F9F9F` 안내문 1줄.
