## 고르는 법

1. 2단계 계열 정의(`step2-families.json` `families[].definition` · 문헌 기준)의 **전달 동사**를 본다 — 「주사」「주입」 → K01 · 「실을 피하에 넣어」 → K02 · 「미세침 … 찔러」 → K03 · 「조사」 → K04 · 「뚫지 않고 … 가열」 → K05 · 「전자기 · 전기 자극」 → K06 · 「표면에 직접 전달」 → K07 · 「냉각」 → K08 · 「바르거나」 → K09
2. procedure-profiles `mechanism` 태그로 확인 — injection · mechanical · thermal · ablative · intravenous · electromagnetic_stimulation · plasma_energy · cooling · topical · infusion
3. 정의가 둘을 말하면 보조(`also`) — M4 「(또는 무바늘 제트 주입)」 → K01c · M5 · M17 「주입·도포」 → K09 · M15 하위 계열별(화학 박피 · 외용제 = K09 / 기계적 박리·클렌징 = K11 / 흡수 보조 기기 = K10)
4. 세부가 단위 시술마다 갈리는 계열(M7 코그 · 모노 · 볼륨 · M8 토닝 · 프락셔널 · 광역학)은 기본을 **큰 기법**으로 두고 세부는 5단계에서
5. 기본 층은 속성(원문)이다 — 키를 가르지 않는다. 층이 부위마다 다르면 「부위 safe_layers」(M2 · M3)

새 계열이 2단계에 서면 `family_defaults[]` 에 한 줄이 없어서 open 「결정 없는 계열 기본 기법」이 난다 — `family_name` 은 step2 이름 그대로.
