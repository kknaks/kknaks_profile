## 2. 키 — 계열 × [안 C 하위 · 성분] × 부위 × 기법

`key = {family, sub_family, ingredient, ingredient_of, site, technique}` — 결정 `key_rule` 「J1 안 C」.

| 칸 | 규칙 | 근거 |
|---|---|---|
| `family` | step2 계열 24(M1 ~ M17 · N1 ~ N7). **없으면 시술을 빼지 않고 계열을 늘린다** — `procedure-hub-family-check` 로 계열부터 | 5단계 원칙(10-29) · U1 |
| `sub_family` | **「무엇을」 자체를 바꾸는 계열만** — M5(혈소판 / 엑소좀) · M8(매질) · M9(HIFU · RF · 마이크로웨이브 · SUPERB) · M13(콜드 / 핫). 그 밖 계열은 null | J1 안 C — 안 A(하위 없음 · 89) 는 CO2 프락셀 + 피코프락셀 · 울쎄라 + 써마지 · PRP + 엑소좀이 한 키 · 안 B(하위 전부 · 130) 가 더 가르는 5키는 제품 재질로만 갈림 |
| `ingredient` | **M16 만** — 성분이 「무엇을」. 모르면 「미상」 + `ingredient_of`(원천 이름)로 가름 | J1 안 C · U7 |
| `site` | step3 노드(묶음 아님) 또는 특수 부위 「해당 없음」 · 「병변 단위」 | S5 · F3 · U4 · DEC-003 OQ-306 |
| `technique` | 원천이 부르는 **가장 좁은 노드**, 없으면 4단계 계열 기본 | S4 |

- 재질 · 성분 차이(M2 HA · M3 PLLA/CaHA · M4 PN/HA · M7 PDO · M15 박리 종류)는 **제품 속성** — 키에 넣지 않는다
- 실 디자인은 키에 넣지 않는다(4단계 장비 속성 `thread_design`) — 실 브랜드 14 · 형태 3 = K02 한 갈래
- **키를 만드는 원천 = 이름 칸만**(S2): 원장 이름 · detail · 시장가 이름 · 쁘띠시술 메뉴(`problem_P1`) · 1단계 `moved_to`. 적응증 문장 · 고민 트리 · 위험 부위 zone 은 키를 만들지 않는다(초안 적응증 생성 78 · 고민 트리 7 철회)
- **전 조합을 만들지 않는다** — 원천에 있는 조합만. 키마다 `sources` 가 비면 open(「원천 근거 없는 키」)
- 장비 쪽 예외 아닌 예외: 추천 가능 장비가 이어질 키가 없으면 그 장비 원장 행을 「제품 + 단위 시술」로 두고 키를 세운다 — 원천 근거 = 원장 장비 행(브이빔 → `U5-141` 얼굴 전체 PDL 레이저)
