## 1. 두 가지 연결

| 연결 | 언제 | 칸 | 현재 값(`check_units.py` 출력) |
|---|---|---|---|
| **저장 uses_product** | 원천 이름이 「이 제품 × 이 부위(시술)」를 부를 때만 — 시장가 이름 · 원장 이름(장비 행 「제품 + 단위 시술」) · 1단계 메뉴명(`extra_stored`). 품목을 부르면 품목, 라인을 부르면 라인(S7 · SPEC-004 §3.3.3 D) | `units[].uses_product` | `inheritance.stored_pairs` · `stored_products` |
| **조회 때 상속** | 나머지 전부 — 아래 세 조건을 **다** 채울 때 | `product_links[].inherited_candidates` | `inheritance.pairs` · `products_with_pairs` · 뺀 쌍 `excluded_pairs`(`technique_excluded`) |

> 숫자는 여기에 적지 않는다 — 현재 값 = `scripts/check_units.py` 출력(`inheritance.*`). 문서에 박은 숫자는 결정이 바뀔 때마다 낡는다(예: 6단계 보강 U2 에서 리쥬란 → U5-018 쌍이 「저장 uses_product」로 옮겨 가 상속 쌍이 하나 줄었다 — 상속 후보에서 빠진 것이라 맞는 변화).

상속 세 조건(`inherit`):

1. **계열** — 제품의 2단계 주 계열 또는 보조 계열(`also_families`)이 키 계열과 같다
2. **키 하위** — 키에 하위가 있으면 제품의 주 · 보조 하위(`also_sub_families`)가 같다. 키 하위 null 이면 계열 전부가 후보
3. **기법 근거** — §2. **근거 없으면 상속 안 함**(추정 금지)

가드(`guards`)가 걸린 제품은 허용 기법 밖 키에 저장 · 상속 둘 다 안 한다 — 지금 1건: ASCE+ · EXOSOME SKIN = K09 도포만(U5 · 4단계 H13).

## 4. 키 하위 있음 — 매질 일치가 근거인가

**매질이 기법을 정할 때만** 매질 일치가 근거다(재검수 v2 F1). 매질이 기법을 못 정하는 경우:

- 그 매질의 키 기법이 **서로 갈리는 둘 이상**(상하위 관계 아님) — 알렉산드라이트 K04a · K04b · M5 엑소좀 K01 · K09
- 그 매질 키 기법 중 하나라도 **조건이 있음**(`requires`)
  - K04b 프락셔널 — `modes_any: [프락셔널]`(가능 방식은 없는 장비가 있어 늘 조건)
  - K04a 토닝 — `pulse_mode_any: [피코초, Q스위치(나노초)]` + 매질별 `pulse_mode_by_medium` 엔디야그 = 롱펄스. 펄스 사전 3값을 다 허용하는 매질(엔디야그)에서는 조건 아님

못 정하면 → ④ 계열 근거 · ⑤ 가드 · ⑥ 장비 속성 · ① 제품 출처가 채울 때만 상속. 장비 속성이 조건과 어긋나면 뺀다.

예: 엔디야그 × K04a 는 매질로 충분(펄스 사전 전부 허용 · K04 는 K04a 의 상위라 안 갈림) / 젠틀맥스 프로 플러스(알렉산드라이트 · 장비 속성 없음)는 알렉스토닝 K04a · 알렉산드라이트 프락셀 K04b 에서 빠지고(「매질만 · 기법 근거 없음」) 엔디야그 키(보조 하위) · 제모 · 병변 키(제품 출처)로 이어진다.

## 5. 키 하위 null(매질 미지정) — 장비 속성이 조건을 채울 때만

- `requires` K04a · K04b → 장비 속성이 채우면 상속
- `requires` K04(`evidence: null`) — 조사(제모 · 병변 · 일반 레이저)를 가르는 장비 속성 값이 없음 → **장비 속성으로는 상속 안 함**. 목적 키만 ① 제품 출처로
- `requires` K04c(`evidence: null`) — 광역학 근거 없음 → 상속 안 함

## 6. 제품 출처(`product_evidence`) — 출처가 목적을 채우면 잇는다

`product_evidence_rule`(코디 10-29 · step5-fix4 추가):

- **단위 시술 0 이 아니어도 잇는다** — fix4 원안 「기법 근거로 거른 결과 0 이 된 제품만」이면 제모 키 장비는 젠틀레이즈 하나 → 출처를 읽으니 11
- 대상 = 매질 미지정 K04 **목적 키** — 겨드랑이 · 전신 레이저 제모(`U5-100` · `U5-101`) · 병변 레이저(`U5-131`)
- 출처 = M8(주 · 보조) active 제품의 1단계 `1_identity.detail` · 1단계 evidence(웹) · 같은 id 원장 행 detail · extracted overview · indications · taxonomy products extracted
  - 「제모 · 체모」 → 제모 키 / 「문신 · 타투 · 점 제거 · 검은점」 → 병변 키
  - **문구 · 필드를 그대로 기록**(`evidence[{purpose, field, text}]`)
- 근거 아님: 「색소성 병변」 · 「기미」만(점 · 문신 제거 단위 아님) · 오기로 적힌 표기(리팟 「이전 '차세대 제모 레이저' 표기는 오기」) · 정체 미상 기기의 계열 기재(슬렌더엑스) → `product_evidence_excluded[]`
- K04a · K04b · K04c 매질 미지정 키는 기법 조건이라 목적 문구로 잇지 않는다(장비 속성만)
- 지금: 제품 31 · 쌍 44 = 겨드랑이 제모 11 · 전신 제모 11 · 병변 레이저 22 · 제외 2

  {"purpose": "제모", "field": "원장 행 M8-5-3 extracted.indications", "text": "체모제거"},

## 7. 추천 가능 제품인데 단위 시술 0 — 예외 목록뿐

「클리닉에서 쓰는 장비 → 시술은 전부 단위 시술」(10-29 원칙을 장비 쪽에서). 1단계 `4_license.recommendable` 제품(지금 236)이 저장 · 상속 둘 다 0 이면:

1. 이어질 키를 세울 수 있으면 세운다 — 원장 장비 행 `dest` 「제품 + 단위 시술」 + `uses_product: true` + 새 키(브이빔 → PDL · 온다 · 소프웨이브 → M9 · ASCE+ → M5 엑소좀 도포 · AAPE → M17 도포 · 루비 · KTP)
2. 출처로 시술 방식이 안 닫히면 **예외** — 원장 행 `origin_question` 한 줄(원천 질문) + note. 추정으로 잇지 않는다
3. 계열 밖(진단 장비)은 단위 시술 없음 그대로

예외 결정도 없으면 `step5-apply.py` open 「추천 가능 제품인데 단위 시술 0 · 예외 결정 없음」.
지금 5 = 진단 장비 2(3D 메타뷰 · 마크뷰) + 예외 3(셀엑소좀 · 미라셀 — 투여 방식 / 스마트자이드 — 프락셔널인가 전면 박피인가).

## 8. 규칙을 고칠 때 — 닿는 곳 전부 · 반대 방향 셈

F1 이 네 번에 나눠 닫혔다(`mistakes.md` #4). 상속 규칙 한 줄을 고치면 결정 목록 전에 아래 셋을 **전부** 센다:

- 계열 안 기법이 둘 이상인 곳 전부(4단계 `also` 있는 계열 + 키 하위 있는 계열)
- 하위 키 안에서 매질이 기법을 못 정하는 곳 전부(`medium_decides` 거짓)
- **반대 방향** — 출처에 목적 낱말이 있는데 그 목적 키에 안 이어진 제품 전부(v3 「빠뜨린 것 역방향 셈」 = 제외 결정 2뿐이어야)

그리고 「추천 가능 · 단위 시술 0」 전수(§7)를 같이 돌린다.
