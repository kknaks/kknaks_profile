# 패키지 판정 규칙 — 6단계

출처: 결정 `orchestration/work/phub-recommend/step6-decisions.json` `rules`(R1~R11) · `_RESUME.md` §2 10-29 6단계 행(U1~U4) · 기록 `para/projects/company/procedure-hub/log/2026-10-29-silver-step6-package.md` §3.
규칙 문장의 정본은 결정 파일이다. 여기는 판정 때 보는 요약 · 실제 예다. 셈은 `scripts/check_packages.py` 출력에서 본다.

## 1. 다섯 갈래 — 실제 예

| 갈래 | 기준 | 실제 예 | 행선지 |
|---|---|---|---|
| 일반 패키지 | 이름이 구성을 말하거나 detail 이 서로 다른 단위 시술을 「A+B」로 적음 | 꿀광토닝(레이저토닝 + 스킨부스터) · 텍스쳐스무딩(포텐자 + 서브시전 + 필링) · 넥큐레이션(목주름 + 턱선) · 시장가 「MTS + 스킨부스터」 | `packages[]` kind 「일반 패키지」 |
| 회차 묶음 | 같은 단위 시술 × N회 한 가격 | 시장가 「스컬트라 (3회 패키지)」 · 「이모드 (4회 패키지)」 · 「줄기세포 3회 패키지 (전체얼굴)」 | kind 「회차 묶음」 · 구성 `sessions` · 5단계 1회 가격과 섞지 않음(U4) |
| 병원 시그니처 | 원천 라벨 「시그니처」 + 고정 가격 + 고정 용량 | 셀리부트프로그램(「950만원」) · DNA리셋프로그램(「2000만원」) — 웹 검색에 같은 이름 상품 없음 = 「일반 근거 없음」(「특정 병원」 근거 아님) | kind 「병원 시그니처」 · `recommendable: false`(U3) · 소속은 원천 질문 |
| 묶음 이름 | taxonomy 하위 라벨 — 묶어 파는 상품 아님 | 메뉴 분류 「색소/토닝」 · 「혈관」 · 「제모」 · 「미백/항산화」 … / 시그니처 묶음 「시그니처 프로그램」(M9) · 「시그니처프로그램」(M15) | `non_packages[]` — 메뉴 분류 = 7단계 목적 원문 · 시그니처 묶음 = 패키지 속성 `menu_group` |
| 단위 시술 | 한 장비 · 한 회 · 한 이름 · 한 가격, 또는 두 제제가 같은 키 | 포토나4D(Er:YAG + Nd:YAG 단계 — 제네오X · 올타이트 · SP 다이나미스와 같은 꼴 → U5-099 동의어 + 보조 매질 속성) · 리쥬하이(리쥬란 + HA = 같은 스킨부스터 키 — 꿀광주사 · 아기주사 선례) | `backport_step5[]` + 5단계 결정(unit-check) |

판정이 갈리는 표지:
- 「+」 · 「조합」 · 「복합」 · 「프로그램」 · 「콤보」 · 「풀코스」 · 「코스」 · 「N회」가 있어도 **구성이 서로 다른 단위 시술인지**로 가린다. 장비 파장 표기(「532+1064nm」) · 제제 성분(「HA+PN」) · 성분 혼합 한 주사 · 필링 성분은 패키지가 아니다(조사 때 같은 표지 전수 — 기록 §4 ③)
- 패키지 아님으로 돌릴 때는 **같은 꼴 선례**를 댄다(제네오X · 올타이트 · 꿀광주사)

## 2. 구성 — 원천 칸

| 원천 | 구성으로 쓰는 칸 | 쓰지 않는 칸 |
|---|---|---|
| 원장 패키지 | 이름 · detail · extracted `overview` · `mechanism` | extracted `indications`(7단계 근거) · aftercare · safety |
| 시장가 패키지 | 행 이름 | category(분류일 뿐) |
| 회차 묶음 | 시장가 행 이름 + 5단계 시장가 행 `to`(「구성 = U5-NNN × N회」) · `sessions` | — |

- 부위: 원천 부위 → 없으면 J2 — 얼굴 계열은 「얼굴 전체」 기본값 · **M1(톡신) · M2(필러) · 몸 계열은 기본값 없음 → 슬롯**(풀페이스큐레이션 · 인형피부관리 보톡스 · 필러 · 쿨핏 · 이모드 4회)
- detail 나열 끝의 「등」 = 나열이 열림 → 적힌 것만 엣지, 나머지는 슬롯 + 질문(바디큐레이션 「승모근/종아리 등」)
- 매질 없는 「토닝」은 매질 미지정 토닝 키, mechanism 이 「레이저토닝」이라 부르면 레이저 토닝 키 — 원천이 부르는 가장 좁은 키

## 3. 키 · 슬롯 · 근거 약

| 경우 | 구성 칸 | 예 |
|---|---|---|
| 5단계 키로 풀림 | `unit` | 레이저토닝 → 얼굴 전체 토닝 · MTS → MTS 키 |
| 키는 있는데 정체 · 투여 방식 미상 | `unit` + `evidence_level: 약` + `origin_question` | 튠(튠페이스인가) · 줄기세포(주사 / 도포) · 엑소좀(주사 / 도포) |
| 부위 · 구성 미상 | `unit` 없음 + `candidates` + `origin_question` | 풀페이스큐레이션 · 프리미엄 스킨케어 풀코스 |
| 5단계에 키 없음 | `unit` 없음 + `missing_unit`(필요한 키 서술) + `origin_question` | 인모드바디(바디 RF 키 없음) |

5단계 키를 6단계에서 만들지 않는다 — 원천 질문 답이나 원천 행이 키를 부르면 `procedure-hub-unit-check` 로.

## 4. 가격 · 같은 날 · 수량

- 가격: 원장 `price_raw` = detail 안 글자 그대로(「950만원」) · 시장가 = 행 low · mid · high · unit 원문. 합산 · 추정 없음
- 같은 날 `same_day_raw`: 원천 문구 그대로 + 읽은 결과 한 마디. 「동시」(이모드 「복부+힙 동시」 · 페이스앤넥 mechanism 「동시에 보톡스로」)만 같은 날 · 「순차적으로 시행」 = 같은 날인지 원천 없음 · 「결합 · 복합」 = 명시 없음 · 회차 묶음 = 「회차 간격 원천 없음」
- 수량 `quantity_raw`: 「600(단위 원문 없음)」 · 「2병」 · 「24cc」 · 「3회」 — 단위가 원천에 없으면 그렇게 적고 질문(써마지600 · 소프웨이브200 = 샷 수인가)
