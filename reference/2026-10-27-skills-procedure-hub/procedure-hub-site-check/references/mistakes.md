## 결정이 남고 행이 사라진 경우(틀린 것 아님 — 헷갈리지 말 것)

- **엉덩이 → 힙** · **무릎 → 다리**: 결정(U1 · B5)은 그대로인데 등장이 전부 설명 문장 칸이라 최종 strings 에 행이 없다 → `strings_out_of_scope`. 이름 칸에 나타나면 그 결정을 strings 로 되돌린다(새로 판정하지 않는다)
- **입가**: 이름 칸 근거 0 — 묶음 자리 예외(`name_field_exception`). DEC-002 「원천 근거 없음」 정정(B11)은 v5 에서 철회
- **셈**: 500 → 519 → 525 → 175 → 176. 앞 셋은 사전 변경, 175 는 범위 바로잡기, 176 은 코조각주사. `step3-sites.md` 「동의어 칸 77 · 부위+다른 축 칸 82」는 **노드 표 칸 수**라 행 수(동의어 14 · D-07 79)와 다르다. 숫자에는 단위(행 / 칸 / 회)와 판을 붙인다
