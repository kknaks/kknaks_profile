# 1. 현황 진단 — 업무 흐름 단절 지점

## 1.1 계약 — 단계별 기록·이력 단절 `문제 7건`

```
작성 ──→ 검토 ──✂→ 예외 승인 ──✂→ 체결 ──✂→ 보관
         │          │               │           │
         ✂ 수정 대조 불가   구두 확정·기록 없음   체결 상태 별도 확인    이력본·클린본 부재
         (매건 전문 재검토)  (승인·실수 구분 불가)  (별도 로그인 필요)     (변경 지점 확인 불가)
```

- 핵심 수치: **단절 4곳** · 매건 **전문 재검토**
- 원인: 승인 기록 경로·수정 대조 기능 부재
- 문제: 부록 #3 · 4 · 5 · 6 · 7 · 8 · 9

## 1.2 정산 — 조건 변경 미전파로 연쇄 지연 `문제 3건`

```
거래처 조건 변경 ─✂(전파 안 됨)→ [정산 시점에야 발견] → 가결산 정지 → 확정결산 정지 → 실적 보고 정지
```

- 타임라인: **7월분 정산 → 8월 말까지 미마감** (인터뷰 시점 실측) — 매월 반복
- 원인: 조건 변경의 회계 전달 규칙·경로 부재
- 문제: 부록 #13 · 14 · 16

## 1.3 입퇴사 — 절차 시작 신호 부재 `문제 8건 (외국인 서류 4 포함)`

```
입·퇴사 확정 ─✂(신호 없음)→ [절차 문서 ✓ 이미 정비됨] → 장비·계정·자리·급여·자산
```

- 타임라인: 퇴사 통보 **D+29일** 도착 — 급여 이체 하루 전 / 입사 신고 **당일** 접수 — 장비 없이 출근
- 원인: 확정 시점 자동 통보 부재
- (인사 하위) 외국인 서류: 계약서 **2벌** 이중 작성 · 영문 증명서 **수기+재작성** · 비자 갱신 **연 1회 × 인원수**
- 문제: 부록 #17 · 18 · 19 · 20 (입퇴사) · #24 · 25 · 26 · 27 (외국인 서류)

## 1.4 소통·의사결정 — 승인·확인의 대표 1인 집중 `문제 8건 (해소 2 포함)`

```
계약 예외 승인 ┐
정산 컨펌      ├──→ 대표 1인 ←── 확인 시간대 고정 불가 (이동 중 포착)
전결 판단 상향  │
구두 지시 재확인┘
```

- 핵심 수치: 구두 지시 1건 = **대기 2회** (지시 대기 + 재확인 대기)
- 원인: 위임 기준 적용 근거 부재
- 문제: 부록 #1 · 2 · 10 · 11 · 12 · 15 · #30 · 31 (해소)

## 1.5 근태·외근 — 신청·승인 경로 부재 `문제 5건 (일일보고 2 포함)`

```
외근·출장 ─ ─ ─ (신청·승인 경로 없음) ─ ─ ─ 기록 공백     현장 인력 재직 확인 수단 없음
```

- 원인: 신청·승인 규칙 미제정
