## A. Google Cloud — 프로젝트 `mediness` (메일 · Gmail API)

### A-1. 운영용 웹 OAuth 클라이언트
- [x] ★ Google 인증 플랫폼 → 클라이언트 → **클라이언트 만들기** → 유형 **웹 애플리케이션**, 이름 `strong-hajin-mail`
- [x] ★ 승인된 리디렉션 URI 두 개 (2026-10-06 코디가 구글 인증 주소로 두 개 다 확인)
  - `http://127.0.0.1:8000/api/integrations/mail/callback` — (처음 등록 · 쓰지 않음)
  - [ ] ★ **추가 필요** `http://127.0.0.1:8001/api/integrations/mail/callback` — 로컬 확인용 (SPEC 이 로컬 포트를 8001 로 정함 · BE-1 실물에서 redirect_uri_mismatch 로 확인됨 2026-10-06)
  - `https://ax.medisolveai.xyz/api/integrations/mail/callback` — 운영
- [x] ★ 클라이언트 ID · 클라이언트 보안 비밀 (코디가 채움 · JSON 은 `~/.config/google/oauth-web-client.json` 으로 옮김) → `~/.config/google/env` 의 `GOOGLE_OAUTH_CLIENT_ID` · `GOOGLE_OAUTH_CLIENT_SECRET`
- 참고: 다운로드 폴더의 데스크톱용 JSON(`client_secret_109643108894-tsr16…json`)은 **시험용**이다. 서버 연결엔 위 웹 클라이언트를 쓴다. 시험이 끝났으니 데스크톱 클라이언트는 지워도 된다
