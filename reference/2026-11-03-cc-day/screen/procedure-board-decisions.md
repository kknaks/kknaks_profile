## 결정 — 시술 현황 1차 기본 권한 (사용자 2026-11-08)

| 직무(데모 지점 KOS 이름) | 보기 | 수정 | 수락 | 근거 |
|---|---|---|---|---|
| 간호 · 피부관리 · 마취과 | ✓ | ✓ | ✓ | 시술실에서 시작 · 종료 · 마취 · 대리 수락 |
| 원장 · 대표원장 · OWNER | ✓ | ✓ | ✓ | 수락 · 시작 |
| 관리자 · ADMIN | ✓ | ✓ | ✓ | 전체 |
| 코디 · 상담실장 · 상담총괄실장 | ✓ | | | 데스크 · 상담은 KOS — 판은 보기만 |
| CS팀 · 경영지원 · 마케팅 · 촬영팀 | | | | 시술 현황 안 씀 |
