## 화면 참고 — 의사 호출 창 (사용자 2026-11-06 · 스크린샷)

U2 의 원장 고르기 창은 이런 모양으로: **모달 · 왼쪽 = 고르기, 오른쪽 = 선택됨**.
- 머리: 「의사 호출」 + 「방 · 고객 이름」(예: A-룸2 · 고객) · 닫기 X
- 왼쪽: 검색 칸 → 「추천」 묶음 → 맨 위 **「모든 의사」(ALL 아바타 · 설명 「콜 잡은 원장이 집도」)** → 원장 줄(이름 첫 글자 아바타 · 이름 · 오른쪽에 원장 상태 「대기」 등)
- 오른쪽: 「선택됨」 · 「호출할 시술 · N개」 + 시술 이름 목록
- 아래 버튼: 고르기 전에는 꺼진 「의사를 선택하세요」, 고르면 호출 버튼
- 판의 [의사 호출 · N건] 버튼이 이 창을 연다
- 재호출(OQ-04)도 같은 창 — 기본 선택 = 처음 호출 대상
