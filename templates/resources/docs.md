# 공식 문서 요약 양식 — `para/resources/docs/<slug>.md`

공식 문서 · 스펙 · 논문 한 건 = 요약 한 장. 원문은 절 15개 + 표 + 경고박스 수준으로
길다 — **전문 복사가 아니라 학습 가능한 요약으로 접는다.** 원문을 다시 열지 않고도
핵심 개념과 절차를 복기할 수 있으면 된다.

DB 행이 없다 — 케이스 1 에서 `content` 행은 youtube 만 생긴다. 출처는 이 파일 머리의
출처 줄이 갖는다.

## 머리

```markdown
# 제목

> 출처: <url> · YYYY-MM-DD
```

- 제목은 본문 H1 이 갖는다
- 출처 줄에 버전 · 문서 수정일이 있으면 덧붙일 수 있다 — 공식 문서는 버전에 따라
  내용이 갈린다. 예: `> 출처: <url> · v2.1 · 2026-01-15 수정 · YYYY-MM-DD`

**파이프라인 상태를 문서에 두지 않는다.** 처리 상태는 DB `queue` 가 갖고,
문서는 내용만 갖는다.

## 본문 — 순서대로

```text
## 요지                  핵심 문장 3~5개
## 무엇에 대한 문서인가    다루는 범위와 왜 읽었는지 1~2문단
## 핵심 개념·절차         원문의 뼈대를 여기로 접는다. 개념·단계별 H3 분리 권장
## 코드·설정 예시         적용 가능한 블록 + 의미 설명
## 함정·주의             원문의 경고박스·제약·버전 갈림이 여기로 온다
## 참고                  원문이 가리키는 다른 문서. 없으면 "(문서 내 명시 없음)"
```

**섹션을 비워 두지 않는다.** 원문에 없는 항목은 문서 전체 맥락에서 합리적으로 추려 채운다.

## 개념과의 연결

**이 파일이 공식 문서 개념의 출처층이다.** 이 요약에서 자란 개념은
`para/areas/concept/<영역>/` 에 만들고, 그 개념의 `up:` 이 이 파일 stem 을 가리킨다.
만드는 절차는 `para/areas/area.md` 3.3.
