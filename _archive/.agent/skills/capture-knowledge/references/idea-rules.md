# Idea rules

Produce a compact thinking aid, not a finished essay.

- `original`: preserve the complete Slack input after mention removal.
- `refined`: express one primary idea without adding unsupported facts.
- `problem`: name the friction, risk, or unmet need.
- `expected_value`: describe the expected outcome conditionally.
- `open_questions`: list concrete decisions or evidence still needed; use an empty list only when none exist.
- `tags`: use 1–7 stable topical tags without `#`.

Follow-up messages revise the same complete idea snapshot. Preserve the original input and incorporate
corrections into `refined`, `problem`, `expected_value`, and `open_questions`.
