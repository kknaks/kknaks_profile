# MRT-REL-001 mac-remote 1.0.0

> 원본: `mac-remote/doc/Releases.md` (1.0.0 — 초기 릴리즈). 원본에 정확한 배포 일자가 기록돼 있지 않아 프로젝트 시작일(2026-05-24)을 초기 릴리즈 기준으로 둔다.

## 요약

iPhone을 리모컨으로 쓰는 mac-remote의 첫 릴리즈다. Mac 헬퍼(메뉴바 앱)가 WebSocket 서버로 창 목록/포커스/키 입력을 담당하고, iOS 앱이 리모컨 UI를 제공한다.

QR 코드로 같은 Wi-Fi의 Mac과 페어링하고, 창 목록 탭에서 창을 전환하며, 매크로 탭에서 단축키를 버튼으로 전송한다.

배포는 Mac은 Developer ID 사인 DMG, iOS는 TestFlight 내부 테스트로 한다.

## 상세 수정 사항

| Area | Change | Notes |
|---|---|---|
| Mac 헬퍼 | 메뉴바 앱 + WebSocket 서버(포트 8765) | Swifter 기반 |
| Mac 헬퍼 | 창 목록 수집/포커스/키 입력 | CGWindowList, AXUIElement, CGEvent |
| Mac 헬퍼 | QR 페어링 (IP:포트) | CoreImage QR 생성 |
| iOS 앱 | 창 목록 탭 / 매크로 탭 / 설정 탭 | SwiftUI 3탭 |
| iOS 앱 | QR 스캔 + 자동 재연결 | AVFoundation, URLSessionWebSocketTask |
| Hold 모드 | 앱 스위처용 modifier hold/release | [[v1_0_1-work-017-hold-modifiers\|MRT-WORK-017]] |
