# Personal Projects

## 목적

개인 학습의 갈래와 그 경계를 관리한다.

개별 개념이 아니라 **어떤 갈래를 파고 있나**를 둔다. 개념 자체는 `resources/concept/` 가 갖는다.

## 학습 갈래

| 갈래 | 어디서 왔나 | 산출 |
|---|---|---|
| CS 기초 · 자바 | bitcamp 부트캠프 필기 | `resources/concept/` 다수 (클래스·상속·예외·컬렉션 등) |
| 웹 · 서블릿 · 스프링 | bitcamp 후반 · BackendSchool | 서블릿·MVC·트랜잭션·JPA 계열 개념 |
| 네트워크 | 교재 이관 | OSI 계층 8건 |
| 알고리즘 | 코딩테스트 풀이 | 기법 개념 11건 (BFS·그리디·분할정복 등) |
| AI · 에이전트 | 자료 수집(YouTube·문서) | `ai-agent` · `workflow-orchestration` · `human-in-the-loop` |
| 실무에서 배운 것 | 회사 작업 기록 | `async-io` · `idempotency` 등 — 실무 기록이 출처다 |

## 경계

- 이 문서는 **갈래와 경계**만 둔다. 진행 상태는 `context/personal/current.md` 에 둔다.
- 개념 상세·출처는 `resources/` 가 소유한다. 여기에 복사하지 않는다.
- 회사에서 배운 것도 **개념이면** 이 영역이다. 회사 경험 기록과는 축이 다르다.
- **이력(`persona/daily/`)은 여기 없다** — 날짜순 원장이라 갈래로 나뉘지 않는다. 이 문서는 배움 쪽만 갖는다.
