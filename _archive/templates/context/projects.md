# Projects

## 목적

이 문서는 프로젝트 목록, 경계, 상태를 관리한다.

프로젝트의 현재 작업 상태는 `current.md`에 둔다.

## 프로젝트 목록

| Project | Type | State | Role | Repo/Path | Notes |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 상태 값

| State | 의미 |
|---|---|
| idea | 아이디어만 있음 |
| validated | 만들 가치가 어느 정도 확인됨 |
| building | 개발 중 |
| release | 출시 준비 중 |
| live | 운영 중 |
| paused | 보류 |

## 경계

- 이 문서는 프로젝트의 안정적인 목록과 경계만 둔다.
- 현재 우선순위와 진행 상태는 `current.md`에 둔다.
- 프로젝트 상세 문서 구조가 생기면 이 문서에는 링크만 둔다.
