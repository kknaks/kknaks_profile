# Resources

**개인 영역의 산출** — 배운 것이 자료로 남고 개념으로 자라는 자리다. 회사 것도 여름별컴퍼니 것도 아니라 [[context/personal/current|개인 영역]]에 속한다([[decision-020-para-alignment-area-and-personal|KDEV-DEC-020]] D1).

규칙: `rules/knowledge-note-pipeline.md`

## 층

지식은 **출처 → 개념 → 실행** 방향으로 자란다. 이 디렉토리가 앞의 둘을 갖는다.

| 층 | 경로 | `type` | 답하는 질문 |
|---|---|---|---|
| 출처 기록 | `source/` (flat) | `reference` | "이 자료가 뭐라고 했나" |
| 원자 개념 | `concept/` (flat) | `concept` | "이 개념은 뭔가" |

실행층은 `products/` 다 — 제품 결정이 `up:` 으로 개념을 가리킨다.

## 여기 두지 않는 것

- 미정제 생각 → `inbox/`
- 안 쓰게 된 노트 → `archive/` (층이 아니라 **상태**라 `resources/` 밖이다)
- 공개로 나가는 글 → `persona/posts/`

## 층별 안내

- `source/README.md` — 자료 기록의 규약
- `concept/README.md` — 원자 개념의 규약
