# 매개변수와 인수 (Parameter, Argument)

**매개변수(parameter)는 값을 받는 자리**이고 **인수(argument)는 그 자리에 실제로 넘기는 값**이다. 선언 쪽에 있는 것이 매개변수, 호출 쪽에 있는 것이 인수다.

## 정의

| | 어디에 있나 | 무엇인가 | 수명 |
|---|---|---|---|
| 매개변수 | 메서드 **선언**의 괄호 | 값을 받는 **지역 변수** | 호출될 때 생기고 메서드가 끝나면 사라진다 |
| 인수 | 메서드 **호출**의 괄호 | 넘기는 값 (리터럴·변수·식) | 넘긴 시점에 값이 복사된다 |

```java
void names(String name){
		//String name : parameter
}
```

```java
void main(String[] args){
	name("james");
    // "james" : argument
}
```

이 필기의 정리가 그대로 정의다.

```text
parameter : 로컬변수로 메서드를 호출할 때 생성되어 메서드가 종료 될때 JVM stack에서 제거된다.
argument : parameter에 전달되는 값
```

**매개변수가 지역 변수라는 것이 핵심이다.** 선언 자리가 특별해 보이지만 사는 곳은 다른 지역 변수와 같은 스택 프레임이다 → [[jvm-stack]]

## 사용 예시

호출 쪽 변수 이름과 매개변수 이름은 **같을 필요가 없다.** 이 필기의 배열 예제가 그렇다.

```java
int[] values = new int[] {100, 110, 120};
m1(values);                        // values 가 인수

static void m1(int[] value) {      // value 가 매개변수 — 이름이 다르다
  value[0] = 200;
}
```

넘어가는 것은 이름이 아니라 **값**이므로, 맞아야 하는 것은 **개수와 타입**뿐이다 → [[call-by-value]]

## 왜 중요한가

**매개변수가 있어야 메서드가 재사용된다.** 매개변수 없는 메서드는 자기 밖의 상태를 직접 읽어야 하고, 그러면 그 상태를 같이 가져가지 않는 한 다른 곳에서 부를 수 없다. 이 필기의 실습에서 `printMenu()` 가 `static` 필드 `menus` 에 묶여 있던 것이 그 예다 → [[method]] · [[static-member]]

그리고 **두 이름을 갈라 두면 "무엇이 검사되는가"가 정리된다.** 매개변수의 타입은 컴파일러가 호출부를 검사하는 기준이 되고, 인수는 실행 시점의 값이다. `m1("문자열")` 이 실행 전에 막히는 것은 타입이 매개변수 선언과 맞지 않기 때문이고, `values` 안에 무엇이 들어 있는지는 컴파일러가 알지 못한다.

## 경계와 오해

- **매개변수 ≠ 인수** — 한국어로 둘 다 「인자」라 뭉쳐 부르는 일이 많은데, 그러면 **자리와 값**의 구분이 사라진다. 이 구분이 없으면 "매개변수에 새 값을 대입해도 호출한 쪽은 안 바뀐다"를 설명할 말이 없다 → [[call-by-value]]
- **매개변수는 메서드 밖에서 보이지 않는다** — 다른 지역 변수와 같다. 그래서 같은 이름을 여러 메서드가 써도 서로 무관하다.
- **메서드 이름은 선언과 호출이 정확히 같아야 한다** — 이 필기는 선언을 `names`, 호출을 `name` 으로 적었다. 실제로는 컴파일되지 않는다(`name` 이라는 메서드가 없다). 넘기는 값은 이름으로 찾아가는 것이 아니라 **컴파일 시점에 어느 메서드를 부를지 확정**되므로, 이름과 매개변수 타입 목록이 일치하는 메서드가 없으면 실행까지 가지 못한다 → [[method]]
- **인수는 변수가 아니어도 된다** — `name("james")` 처럼 리터럴을 바로 넘길 수 있고 식(`m1(a + b)`)도 된다. 매개변수는 반드시 변수다. 방향이 비대칭이라는 것이 두 이름을 갈라 두는 또 하나의 이유다 → [[literal]]
- **메서드의 인수 ≠ 실행 인자** — `main(String[] args)` 의 `args` 도 매개변수이고, 거기 담기는 것은 **JVM 이 넘긴** 명령행 문자열이다. 코드에서 부르는 호출과 실행 시점에 밖에서 주는 값은 층이 다르다 → [[command-line-arguments]] · [[main-method]]
- **매개변수가 없다는 것이 입력이 없다는 뜻은 아니다** — 클래스 필드나 표준 입력에서 값을 가져오는 메서드는 괄호가 비어 있어도 밖의 것에 의존한다. 괄호는 **의존을 드러낸 부분**만 보여 준다 → [[standard-input]]
