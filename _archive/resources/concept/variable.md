# 변수 (Variable)

데이터를 저장하는 메모리. 그 메모리를 쓰려면 **어떻게 쓸지(타입)와 뭐라고 부를지(이름)를 먼저 정한다.**

## 정의

두 단계로 나뉘어 있다.

1. **선언** — 타입과 이름을 정해 메모리를 확보한다
2. **할당** — 확보한 자리에 값을 넣는다

```java
// Data_type Memory_name;
int a;
float b;
boolean t;
```

선언만 하면 자리는 잡혔지만 값이 없다. 이름에 값을 대입하는 것이 할당이다.

```java
int number;      // 선언
number = 7;      // 할당
```

한 줄로 합쳐 쓸 수도 있다(`int number = 7;`). 두 일이 하나로 보이지만 여전히 다른 일이다.

## 사용 예시

변수의 역할이 저장만은 아니다. **값에 이름을 붙여 설명하는** 데 쓰기도 한다 — 코드 정리 기법으로 「설명하는 변수」라 부른다.

```java
String redAnsi = "\033[31m";
String boldAnsi = "\033[1m";
String resetAnsi = "\033[0m";

System.out.println(boldAnsi + redAnsi + menu6 + resetAnsi);
```

`"\033[31m"` 을 그 자리에 그대로 쓰면 무엇을 하는 줄인지 읽히지 않는다. 이름을 붙였을 뿐 동작은 같은데, 읽는 사람에게는 다른 코드가 된다 → [[ansi-escape-code]]

## 왜 중요한가

**변수는 값이 아니라 자리다.** 이 구분이 되면 대입이 "값을 복사해 그 자리에 넣는 것"으로 읽히고, 같은 변수에 다시 대입하면 앞 값이 사라지는 것이 당연해진다.

그리고 변수는 **설명을 붙이는 수단**이기도 하다. [[comment]] 로 쓴 설명은 검사받지 않고 코드와 어긋날 수 있지만, 이름은 그 값이 쓰이는 자리마다 따라간다.

그리고 선언에 타입이 필요한 이유가 여기서 나온다. 자리를 잡으려면 **얼마나 큰 자리인지** 알아야 하고, 그것을 정하는 것이 [[data-type]] 이다.

## 경계와 오해

- **선언 ≠ 할당** — 선언만 한 지역 변수는 값이 없다. Java 는 값 없이 읽으려 하면 컴파일 오류를 낸다 — 쓰레기 값이 읽히는 것보다 낫기 때문이다.
- **변수 이름은 메모리 주소가 아니다** — 이름은 사람이 쓰는 표시이고, 실제 주소는 컴파일러와 [[jvm]] 이 관리한다.
- **타입은 변수에 붙는다** — 값이 스스로 타입을 갖고 다니는 것이 아니라, 그 값을 담은 자리의 타입이 해석 방법을 정한다.
