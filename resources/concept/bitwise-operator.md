# 비트 연산자 (Bitwise Operator)

값을 비트 단위로 맞대어 계산하는 연산자. `&`(AND) `|`(OR) `^`(XOR) `~`(NOT) 이 있고, 각 자리를 독립적으로 처리한다.

## 정의

같은 자리의 비트끼리 논리 연산을 한다.

| 연산자 | 결과가 1 인 경우 |
|---|---|
| `&` | 양쪽 비트가 모두 1 |
| `\|` | 한쪽이라도 1 |
| `^` | 두 비트가 다를 때 |
| `~` | 모든 비트를 뒤집는다 |

`&`·`|`·`^` 는 논리값에도 쓰이므로 → [[short-circuit-evaluation]] 과 겹친다. 정수에 쓰면 비트 연산, `boolean` 에 쓰면 논리 연산이다.

## 사용 예시

**비트마스킹** — 원하는 자리만 남기거나 켜는 데 쓴다. 픽셀 값에서 색 하나를 제거하는 예다.

```java
int pixel = 0x003f4478;                  // 각 바이트가 '00RRGGBB' 라 가정
System.out.println(pixel & 0x0000ffff);
// pixel = 00000000_00111111_01000100_01111000
//       & 00000000_00000000_11111111_11111111
//         00000000_00000000_01000100_01111000   ← R 자리가 0 이 되었다
```

`&` 는 마스크가 0 인 자리를 **끄고**, 1 인 자리는 원래 값을 **남긴다.** 빨강 자리에 0 을 맞대어 지운 것이다.

반대로 `|` 는 자리를 **켠다.**

```java
int pixel2 = 0x003f4478;
System.out.println(pixel2 | 0x00000057);
// pixel2 = 00000000_00111111_01000100_01111000
//        | 00000000_00000000_00000000_01010111
//          00000000_00111111_01000100_01111111   ← B 자리에 비트가 추가되었다
```

## 왜 중요한가

**여러 개의 켜짐/꺼짐을 하나의 정수에 담을 수 있다.** 색의 R·G·B 처럼 한 값 안에 여러 정보가 나뉘어 들어 있을 때, 비트 연산이 그 조각을 꺼내고 바꾸는 수단이 된다. 권한 플래그나 옵션 집합도 같은 방식으로 다룬다.

`&` 로 읽고 `|` 로 쓰는 짝이 기본 패턴이다 — **마스크가 1 인 자리에만 관심을 두고 나머지는 건드리지 않는다.**

## 경계와 오해

- **`&` 와 `&&` 는 다른 연산이다** — 정수에 쓰면 비트 연산이고 `boolean` 에 쓰면 논리 연산인데, 후자일 때도 `&&` 와 달리 뒤쪽을 항상 평가한다 → [[short-circuit-evaluation]]
- **`^` 는 비트 연산에서도 "다르면 1"이다** — 논리 연산에서와 같은 규칙이다. 같은 값을 두 번 XOR 하면 원래로 돌아온다.
- **`~` 는 부호까지 뒤집는다** — 모든 비트를 반전하므로 양수가 음수가 된다. [[twos-complement]] 의 1의 보수를 구하는 것과 같다.
- **비트 연산에도 [[type-promotion]] 이 적용된다** — `byte` 끼리 연산해도 결과는 `int` 다.
