# do~while 문

반복문의 하나. `do` 블록을 **먼저 실행하고** `while` 의 조건을 판단해 다시 실행할지 끝낼지 정한다.

## 정의

```java
do {
    // 루프에서 실행할 코드
    // 첫 번째는 무조건 실행
    // 이후 while 문의 참/거짓에 따라 실행
} while (조건식);
```

조건 판단이 **블록 뒤에** 있으므로 **최소 한 번은 실행된다.** `while` 문은 조건이 처음부터 거짓이면 한 번도 실행되지 않는데, 그 점이 다르다.

끝에 세미콜론이 붙는다 — `while (조건식);` 이다.

## 사용 예시

메뉴를 보여주고 입력을 받는 흐름에 맞는다. **입력을 받아 봐야 끝낼지 알 수 있기** 때문이다.

```java
int menuNo;
do {
    System.out.print("> ");
    menuNo = scanner.nextInt();
    // ... 처리
} while (menuNo != 6);
```

`menuNo` 를 루프 **밖에서** 선언한 것에 주의한다. 조건식이 그 값을 봐야 하므로, 블록 안에서 선언하면 조건식에서 보이지 않는다.

## 왜 중요한가

**"일단 한 번 해 보고 판단하는" 흐름이 실제로 자주 나온다.** 사용자 입력, 메뉴, 재시도 같은 것은 값을 얻기 전에는 조건을 평가할 수 없다. `while` 로 쓰려면 루프 앞에 같은 코드를 한 번 더 두거나 조건을 억지로 참으로 시작해야 하는데, `do~while` 은 그 중복이 없다.

## 경계와 오해

- **`while` 과 실행 횟수가 다르다** — 조건이 처음부터 거짓일 때 `while` 은 0번, `do~while` 은 1번 실행한다. 이 차이가 곧 선택 기준이다.
- **세미콜론을 빠뜨리기 쉽다** — `} while (조건)` 뒤에 `;` 가 필요하다. 다른 제어문 블록에는 없는 것이라 빠뜨리면 문법 오류가 난다.
- **조건에 쓸 변수는 밖에서 선언한다** — 블록 안에서 선언한 변수는 조건식에서 보이지 않는다.
