# ANSI 이스케이프 코드

터미널과 콘솔에서 텍스트 형식을 제어하는 문자열. 색상·스타일·배경색을 바꾼다. 화면에 글자로 나타나지 않고 **터미널이 명령으로 해석**한다.

## 정의

형식은 `\033[` 로 시작하고 `m` 으로 끝난다.

```plaintext
\033[<코드>m
\033[<코드>;<코드>m     여러 개를 쓸 때는 ; 로 구분
```

**사용이 끝나면 반드시 초기화해야 한다.** 초기화하지 않으면 그 이후의 출력 전체에 계속 적용된다 — 프로그램이 끝난 뒤 터미널까지 물든다.

### 색상

| 색상 | 텍스트 | 배경 |
|---|---|---|
| 검정 | 30 | 40 |
| **빨강** | **31** | 41 |
| 초록 | 32 | 42 |
| 노랑 | 33 | 43 |
| 파랑 | 34 | 44 |
| 자주 | 35 | 45 |
| 청록 | 36 | 46 |
| 흰색 | 37 | 47 |

### 텍스트 스타일

| 스타일 | 코드 |
|---|---|
| **리셋** | **0** |
| 굵게 | 1 |
| 흐리게 | 2 |
| 기울기 | 3 |
| 밑줄 | 4 |
| 반전(배경/전경) | 7 |
| 숨기기 | 8 |
| 취소선 | 9 |

## 사용 예시

코드를 [[variable]] 에 담아 이름을 붙이면 무엇을 하는 줄인지 읽힌다.

```java
String redAnsi = "\033[31m";
String boldAnsi = "\033[1m";
String resetAnsi = "\033[0m";

System.out.println(boldAnsi + line + resetAnsi);
System.out.println(boldAnsi + appTitle + resetAnsi);
System.out.println(menu1);
System.out.println(boldAnsi + redAnsi + menu6 + resetAnsi);   // 굵게 + 빨강
```

`boldAnsi + redAnsi` 처럼 **이어 붙여 겹쳐 적용**할 수 있고, `resetAnsi` 로 한 번에 되돌린다.

## 왜 중요한가

**CLI 도구가 색을 쓰는 방법이 이것이다.** 컴파일 오류를 빨갛게 보여주는 것부터 `git diff` 의 색까지 전부 같은 방식이고, 별도 라이브러리가 필요한 일이 아니라 문자열을 출력하는 것뿐이다 → [[cli]]

그리고 **초기화를 빠뜨리면 프로그램 밖으로 영향이 새어 나간다**는 점이 특이하다. 출력이 터미널의 상태를 바꾸는 것이라, 내 프로그램이 끝나도 그 상태가 남는다.

## 경계와 오해

- **빨강은 31 이고 33 은 노랑이다** — 옛 필기 §3.2 본문에 "빨강색 : `\033[33m`" 이라 적혀 있는데 표와 어긋난다. 같은 노트의 코드에서는 `redAnsi = "\033[31m"` 으로 맞게 썼다. **표와 코드가 맞고 본문 한 줄이 틀렸다.**
- **이스케이프 코드는 글자 수에 포함된다** — 문자열 길이를 세면 보이지 않는 코드까지 세어진다. 자리를 맞춰 출력할 때 어긋나는 원인이다.
- **모든 터미널이 지원하는 것은 아니다** — 지원하지 않는 곳에서는 코드가 그대로 글자로 찍힌다. 로그 파일로 리다이렉트할 때도 그렇다.
- **`\033` 은 이스케이프 문자 하나다** — 8진수 표기이고, `\e` 나 `` 로도 쓴다.
