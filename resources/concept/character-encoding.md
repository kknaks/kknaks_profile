# 문자 인코딩 (Character Encoding)

글자를 바이트로 바꾸는 규칙. 같은 바이트를 다른 규칙으로 읽으면 다른 글자가 나오므로, 쓴 쪽과 읽는 쪽이 같은 규칙을 써야 한다.

## 정의

규칙이 여러 개인 것은 **담을 문자를 늘려 오는 과정에서 하나씩 덧붙었기 때문**이다.

| 방식 | 담는 것 | 한계 |
|---|---|---|
| **ASCII** | 알파벳. 7비트로 128자 | 영어만 |
| **ISO-8859-1** | ASCII + 라틴 계열 문자 | 여전히 서구권만 (`~4` 버전까지 있다) |
| **EUC-KR** | 한글 완성형 2350자 | 한글 음절은 11,172자다. `똡`·`똣` 같은 일부가 담기지 않는다 |
| **조합형** | 초성·중성·종성을 조합. 2byte = 한글 1bit + 각 5bit | **국제 표준이 아니다.** 16비트의 절반을 한글이 쓰면 다른 나라 문자가 들어갈 자리가 없다 |
| **MS949 (CP949)** | EUC-KR + 알파로 11,172자 전부 | EUC-KR 기반 2byte. **국제 표준이 아니다** |
| **유니코드 / UTF-8** | 전세계 문자 | → [[unicode]] |

앞의 것들이 **각자 자기 나라 문자만 담으려 한 결과** 같은 바이트가 지역에 따라 다른 글자가 되었고, 그것을 끝낸 것이 유니코드다.

### 기본값이 어긋날 때

규칙이 여러 개 남아 있으니 **도구마다 기본값이 다르다**는 문제가 생긴다.

| 주체 | 기본 인코딩 |
|---|---|
| `javac` (컴파일러) | UTF-8 |
| Windows | MS949 |

Windows 에서 소스를 저장하면 MS949 로 저장되는데 `javac` 는 UTF-8 로 읽으려 하니, 한글이 든 소스를 컴파일할 때 문자 집합 오류가 난다. 규칙을 명시해 맞춰 주면 해결된다.

## 사용 예시

컴파일할 때 소스가 어떤 인코딩인지 `-encoding` 으로 알려준다.

```bash
$ javac -encoding UTF-8 Hello.java
```

**읽는 쪽과 쓰는 쪽을 따로 지정해야 하는 경우도 있다.** [[javadoc]] 은 소스를 읽어 HTML 을 만드므로 옵션이 둘로 갈린다.

```plaintext
-encoding [소스 파일의 문자집합]        # 읽을 때
-charset  [생성될 HTML 파일의 문자집합]  # 쓸 때
```

입력과 출력의 인코딩이 같을 이유가 없기 때문이다. 한쪽만 맞추면 다른 쪽에서 깨진다.

## 왜 중요한가

**깨진 글자는 대개 데이터가 손상된 것이 아니라 읽는 규칙이 틀린 것이다.** 이 구분을 하면 고칠 자리가 달라진다 — 파일을 다시 만들 게 아니라 읽는 쪽 설정을 맞추면 되는 경우가 많다.

그리고 이 문제는 **경계를 넘을 때마다** 다시 나온다. 소스와 컴파일러 사이뿐 아니라 브라우저와 서버 사이, 서버와 DB 사이, 파일과 프로그램 사이에서 같은 형태로 반복된다. 층마다 기본값이 다르다는 것이 원인이라 한 번 겪으면 다음에 어디를 볼지 알게 된다.

## 경계와 오해

- **인코딩 ≠ 폰트** — 글자가 이상하게 보일 때 원인이 갈린다. 인코딩이 틀리면 **다른 글자**가 나오고(`한글` → `ÇÑ±Û`), 폰트가 없으면 자리는 맞고 **모양만** 안 나온다(`□□`).
- **UTF-8 이 기본값인 것은 도구마다 다르다** — "요즘은 다 UTF-8"이 아니라, 각 도구가 자기 기본값을 갖는다. OS 기본값이 다른 것이 [[platform-dependency]] 가 문자 층에서 나타나는 모습이다.
- **완성형 ≠ 조합형** — EUC-KR·MS949 는 완성된 글자에 번호를 붙인 **완성형**이고, 조합형은 초성·중성·종성을 조합해 만든다. 완성형은 목록에 없는 음절을 담을 수 없고(`똡`), 조합형은 표준이 되지 못했다.
- **문자 인코딩과 줄바꿈은 다른 축이다** — 둘 다 "OS 마다 기본값이 다르다"에 걸리지만 별개 문제다 → [[newline-character]]
- **파일 자체에 인코딩이 적혀 있지 않다** — 텍스트 파일은 바이트 나열일 뿐이라, 무슨 규칙으로 저장했는지 파일이 알려주지 않는다. 그래서 읽는 쪽이 추측하거나 지정받아야 한다.
