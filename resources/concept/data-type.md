# 데이터 타입 (Data Type)

[[variable]] 이 잡을 메모리의 **크기와 해석 방법**을 정하는 것. 같은 값을 담아도 타입이 다르면 메모리에 놓이는 2진 코드가 다르다.

## 정의

Java 의 타입은 크게 둘로 갈린다.

- **기본 타입 (Primitive Type)** — 값을 그 자리에 직접 담는다
- **참조 타입 (Reference Type)** — 값이 있는 곳을 가리키는 것을 담는다

**한쪽만 닫혀 있다.** 기본 타입은 여덟 개로 고정이지만 참조 타입은 클래스를 선언할 때마다 늘어난다 — 클래스 이름이 그대로 타입 이름이 되고, 이 필기는 그것을 「사용자 정의 데이터 타입(User-defined Data Type)」이라 배웠다 → [[class]]

**그리고 늘어나는 쪽만 하나의 계층을 이룬다.** 참조 타입은 몇 개가 되든 전부 [[object-class]] 를 뿌리로 갖지만, 기본 타입 여덟 개에는 그런 공통 조상이 없다 — 서로 관계가 없는 여덟 개다. 그래서 「무엇이든 받는 타입」(`Object`)이 참조 타입에만 통한다.

기본 타입이 담을 수 있는 범위는 크기로 정해진다.

| 타입 | 크기 | 최소 ~ 최대 |
|---|---|---|
| `byte` | 1 byte | −128 ~ 127 |
| `short` | 2 byte | −32,768 ~ 32,767 |
| `int` | 4 byte | −2,147,483,648 ~ 2,147,483,647 |
| `long` | 8 byte | −9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| `float` | 4 byte | ±3.4028235E+38 → [[floating-point]] |
| `double` | 8 byte | ±1.7976931348623157E+308 |
| `char` | 2 byte | 0 ~ 65,535 → [[unicode]] |
| `boolean` | (명세 없음) | `true` / `false` |

여덟 개가 전부다. `boolean` 만 크기가 규격에 정해져 있지 않다 — JVM 구현에 맡겨져 있고, `MAX_VALUE` 처럼 한계값을 물어볼 상수도 없다. Day08 실습이 `MAX_VALUE`·`MIN_VALUE` 를 출력하는 방식이었기 때문에 그 자리에서는 `boolean` 이 빠졌다.

정수 타입의 범위가 음수 쪽으로 하나 넓은 것은 [[twos-complement]] 때문이다. `char` 가 2바이트인 것은 Java 가 문자를 UTF-16 으로 다루기 때문이다.

각 타입의 한계값은 코드로 확인할 수 있다.

```java
System.out.println("max : " + Integer.MAX_VALUE + ", min : " + Integer.MIN_VALUE);
// max : 2147483647, min : -2147483648
```

## 사용 예시

**같은 30 을 담아도 타입이 다르면 메모리의 2진 코드가 다르다.**

```java
int i = 30;      // memory : 0x0000001E
float f = 30;    // memory : 0x41F00000
```

`0x1E` 는 30 을 그대로 2진수로 쓴 것이고, `0x41F00000` 은 IEEE 754 로 부호·지수·가수를 나눠 담은 것이다. 컴퓨터는 2진 코드만 받으므로, **이 두 30 이 다르다는 것을 구별해 주는 것이 데이터 타입**이다.

## 왜 중요한가

**타입 선언은 메모리 사용을 제어하는 일이다.** 필요한 만큼만 잡으면 되고, 넘칠 값을 담으려 하면 미리 막힌다. 크기를 정하지 않고 값을 담는 언어에서는 이 통제가 실행 시점으로 밀린다.

그리고 **같은 비트열을 어떻게 읽을지가 타입으로 결정된다**는 것이 핵심이다. 메모리에 저장된 것은 숫자도 문자도 아니고 그냥 비트이고, 그것을 정수로 볼지 소수로 볼지 문자로 볼지가 타입이다.

## 경계와 오해

- **`float` 의 `MIN_VALUE` 는 최소값이 아니다** — 가장 작은 **양수**(`1.4E-45`)다. 정수 타입의 `MIN_VALUE` 가 음의 최소값인 것과 의미가 다르다. 같은 이름이라 같은 뜻으로 읽기 쉽다.
- **크기가 크면 항상 정확한 것은 아니다** — `float` 는 4바이트로 `long`(8바이트)보다 작은데 표현 범위는 훨씬 넓다. 범위를 넓히려고 정밀도를 내준 것이다.
- **기본 타입 ≠ 참조 타입** — 기본 타입 변수는 값을 직접 갖고, 참조 타입 변수는 위치를 갖는다. 대입할 때 무엇이 복사되는지가 갈린다.
- **기본 타입은 여덟 개로 닫혀 있다** — `byte`·`short`·`int`·`long`·`float`·`double`·`char`·`boolean` 이 전부이고, **그 밖의 모든 타입은 참조 타입**이다. 새로 만들 수도 없다. 목록을 외우는 값이 여기 있다 — 목록에 없으면 참조 타입이라는 판정이 바로 나온다.
- **`String` 은 기본 타입이 아니다** — 리터럴로 쓸 수 있고 `+` 로 이어 붙일 수 있어서 기본 타입처럼 보이지만 참조 타입이다. 그래서 `==` 비교가 값 비교가 아니고, 이것이 초보자가 가장 자주 걸리는 자리다 → [[object-reference]] · [[string-comparison]]
- **타입을 만드는 것 ≠ 기본 타입을 늘리는 것** — 클래스로 정의한 타입은 예외 없이 참조 타입이다. 「`int` 처럼 쓸 수 있는 내 타입을 만들었다」로 읽으면 `==` 가 내용 비교가 아니고 매개변수로 넘긴 쪽에서 내용이 바뀌는 것이 둘 다 설명되지 않는다 → [[class]] · [[call-by-value]]
- **기본 타입에는 메서드가 없다** — Day08 시점에는 「값을 직접 담는다」가 크기와 2진 코드의 이야기였는데, 그 차이가 **부를 수 있는 것이 있는지**로도 나타난다. `int` 에는 `getClass()`·`toString()`·`equals()` 가 없다 — 참조 타입만 `Object` 를 상속하므로, 여덟 개는 물려받을 곳이 없다. 「참조 타입은 위치를 갖는다」에 「참조 타입은 메서드를 갖는다」가 얹히는 자리다 → [[object-class]] · [[method]]
- **`Integer.MAX_VALUE` 를 부를 수 있는 것은 `int` 가 아니라 `Integer` 다** — 이 노트의 `System.out.println(Integer.MAX_VALUE)` 가 그것이다. `int` 의 한계값을 묻는데 클래스 이름을 쓰게 되는 이유가 여기 있고, 「기본 타입에는 메서드가 없다」와 어긋나 보이는 것이 이 대비다. 여덟 개마다 짝이 되는 클래스가 따로 있고, **그 여덟 개의 이름과 용도를 정면으로 배우는 것이 Day22 다** → [[wrapper-class]]
- **두 갈래는 갈라져 있지만 건너갈 수는 있다** — Day08 시점에는 「기본 타입은 값을 담고 참조 타입은 위치를 담는다」로 끝났고, Day21 에서 「참조 타입만 공통 조상이 있다」로 한 층 내려갔다. 그 다음 회차가 **건너가는 방법**을 준다 — `Integer.valueOf(100)` 으로 기본 타입 값을 참조 타입 계층 안으로 넣고, 컴파일러가 그것을 대입 한 줄로 줄여 준다. **경계는 여전히 있고 문법이 그것을 안 보이게 하는 것**이라, 「같은 것이 되었다」로 읽으면 `null` 언박싱이나 `==` 비교가 왜 어긋나는지 설명되지 않는다 → [[wrapper-class]] · [[autoboxing]]
- **`byte.class` 는 예외가 아니라 대체 문법이다** — 기본 타입에 `getClass()` 를 부를 수 없으니 타입 정보를 얻는 다른 통로를 준 것이다. 필기가 「static 변수인 class」라 적었는데 필드가 아니라 클래스 리터럴이라는 문법이며, `int.class`·`boolean.class` 처럼 여덟 개 전부에 쓸 수 있다 → [[class-metadata]] · [[literal]]
- **기본 타입 배열은 참조 타입이다** — `int` 는 `Object` 의 서브클래스가 아니지만 `int[]` 는 그렇다. `new int[10].getClass().getName()` 이 `[I` 를 돌려주는 것이 그 증거다. **원소가 여덟 개 중 하나인 것과 배열 자체가 무엇인가는 다른 층**이고, 「기본 타입이니 기본 타입 배열도 그렇겠지」가 여기서 깨진다 → [[array]] · [[class-metadata]]
