# 슬랙으로 유튜브 콘텐츠 정리하기

## 원문

아이디어 슬랙으로 유투브 정리

## 정리된 아이디어

슬랙 채널(또는 봇 멘션)에 유튜브 링크를 올리면 영상 내용을 자동으로 요약·태그하여 지식 베이스에 쌓는 워크플로를 구축한다.

## 해결하려는 문제

유튜브 영상을 나중에 참고하거나 팀과 공유할 때 링크만 남기면 내용이 휘발되고, 별도 도구를 열어 직접 정리해야 하는 번거로움이 있다.

## 기대 효과

슬랙에서 링크 하나만 공유하면 요약·핵심 개념·태그가 자동으로 생성되어 검색 가능한 지식 아카이브가 형성될 수 있다.

## 열린 질문

- 슬랙 트리거를 멘션, 특정 채널 감지, 슬래시 커맨드 중 무엇으로 설정할 것인가?
- 정리 결과를 슬랙 스레드에 인라인으로 반환할지, Notion·DB 등 외부 문서 시스템에 저장할지?
- 유튜브 자막이 없거나 자동 생성 자막만 있는 영상은 품질을 어떻게 보장할 것인가?
- 팀 공유용인지 개인 지식 관리용인지에 따라 접근 권한 설계가 달라지는데 어떤 범위를 우선할 것인가?
