# 구글 클라우드 파일 실시간 후킹 및 메타데이터 구조화 프로젝트

## 원문

구글클라우드에 올라간 파일을 실시간 후킹 해서 파일메타데이터를 만들고 구조화를 하는 프로젝트
왜냐하면 구글클라우드에 트리구조로 넣으라고 하면 아무도 안쓰니까 일단 데이터라도 넣어주거 우리쪽 서버에서 트리구조를 만드는 거야

## 정리된 아이디어

사용자에게 사전 분류를 요구하는 대신, GCS 파일 업로드 이벤트를 실시간으로 후킹해 파일 메타데이터를 자동 생성하고, 자체 서버에서 트리 구조를 재구성한다. 데이터 입력 장벽을 낮춰 실제 사용률을 높이는 것이 핵심 목적이다.

## 해결하려는 문제

사용자에게 트리 구조로 파일을 직접 분류하도록 요구하면 사용하지 않음. 입력 마찰이 높아 데이터 자체가 쌓이지 않는 채택 실패 문제.

## 기대 효과

사용자는 파일만 업로드하면 되고, 구조화는 서버가 자동으로 처리하므로 데이터 축적률과 서비스 채택률이 높아질 것으로 기대됨.

## 열린 질문

- GCS 이벤트 후킹 방식으로 Pub/Sub 알림과 Cloud Functions 중 어떤 것을 사용할 것인가?
- 메타데이터 추출 범위는 어디까지인가? (파일명, MIME 타입, 업로더, 업로드 시각, 콘텐츠 분석 등)
- 트리 구조 생성 규칙은 누가 정의하며, 자동 분류 로직은 어떻게 결정되는가?
- 기존에 쌓인 파일에 대한 소급 처리 계획이 있는가?
- 메타데이터 저장소는 별도 DB인가, GCS 오브젝트 메타데이터 필드인가?
