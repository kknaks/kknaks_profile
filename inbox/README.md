# inbox

미정제 아이디어가 머무는 **보류함**. 여기 놓이는 노트의 타입: `idea`. 층에 속하지 않는다.

## 여기 두는 것
- 떠오른 생각을 정제 없이 빠르게 적은 노트 (한 줄이어도 된다).

## 여기 두지 않는 것
- 정제·연결을 끝낸 영구 생각 → `permanent/`.
- 외부 자료 정리 → `reference/`.
- 발행할 글 → `persona/posts/`.

## quick-rule
- 빨리 던진다. 리뷰해 종착지로 분류하면 원본은 종착지로 옮겨간다.
- **inbox는 항상 미정제만 보유한다.** 종전 "미분류만 보유"에서 개정 — 승인 대기(미분류)는
  DB 큐가 맡고, 여기에는 *"지금은 정제 못 하지만 버리긴 아깝다"* 로 **승인된** idea만
  남는다(KDEV-DEC-011 D1). 즉 inbox 도 하나의 목적지이지 대기열이 아니다.
- idea는 `up:` 을 가질 수 없고, 다른 노트가 idea를 `up:` 할 수도 없다(휘발 — 검증 L4).
