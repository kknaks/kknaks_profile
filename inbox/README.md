# inbox

미정제 아이디어를 빠르게 던지는 휘발 inbox. 여기 놓이는 노트의 타입: `idea`.

## 여기 두는 것
- 떠오른 생각을 정제 없이 빠르게 적은 노트 (한 줄이어도 된다).

## 여기 두지 않는 것
- 정제·연결을 끝낸 영구 생각 → `permanent/`.
- 외부 자료 정리 → `reference/`.
- 발행할 글 → `persona/posts/`.

## quick-rule
- 빨리 던진다. 주기적으로 리뷰해 종착지로 분류하면 **원본 idea는 폐기**(inbox는 항상 미분류만 보유).
- idea는 `up:` 대상이 아니다(휘발이라 상류가 될 수 없다).
