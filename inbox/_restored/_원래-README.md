# reference

외부 자료(영상·책·아티클)를 정리한 **출처 기록층**. 타입: `reference`, 층: `source`.

"이 자료가 뭐라고 했나"에 답한다. 자료 하나 = 노트 하나이며, 생성 후 거의 변하지 않는다.

## 여기 두는 것
- 읽고/본 외부 자료의 정리 노트. 출처는 frontmatter `source: <url>` 속성으로 둔다.

## 여기 두지 않는 것
- 내 언어로 재서술한 영구 생각 → `permanent/` (reference는 종착지가 아니다).
- 미정제 생각 → `inbox/`.

## quick-rule
- reference는 종착지가 아니라 **인용되는 재료**다. 여기서 뽑은 `[[concept]]` 가 이 노트를 `up:` 으로 가리킨다.
- **SoT 위임** — 개념 상세를 여기 길게 쓰지 않는다. 요지만 적고 `[[concept]]` 로 넘긴다.
- `up:` 을 두지 않는다. 출처 기록층이라 상류가 없다.
- 아직 개념을 안 뽑은 reference는 검증에서 **미소화 큐**로 집계된다 — 위반이 아니라 정제 작업 후보다.
