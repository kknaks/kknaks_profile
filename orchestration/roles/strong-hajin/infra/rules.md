# 규칙

- 브리프 allowed_paths 안에서만 변경. 기존 Mediness/공유 datastores/클러스터 설정에 손대지 않는다.
- 비밀값을 읽거나 커밋하지 않는다. values는 secretRef를 사용한다.
- 웹·API·WS 같은 HTTPS origin. 호스트는 확정값을 주입하며 실도메인 발명 금지.
- 이미지는 고정 태그/digest, ARM64 실행과 백엔드 worker·DB·파일 볼륨 계약 확인.
- 데이터 삭제를 rollback으로 사용하지 않는다. 보존·백업·복구 절차를 구분한다.
- 워커 커밋·push·PR·클러스터 적용 금지. 실제 운영 변경은 코디가 해당 승인 범위에서 수행한다.
- 코드 작성/렌더 검증과 운영 배포/실측 증거를 구분한다.
