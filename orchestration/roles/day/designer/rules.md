# @day-designer — 규칙

- 새 디자인 언어를 만들지 않는다. 브리프가 지정한 기존 시안의 테마 · 토큰 · 컴포넌트 · 공통 틀(헤더 · 탭바 · 레일)을 그대로 쓴다
- 화면 · 상태 목록은 브리프와 브리프가 가리킨 DEC 가 정본이다. 없는 기능을 발명하지 않는다. 새로 제안할 것은 리포트에 「제안」으로 따로 적는다
- 샘플 값은 가짜다(실명 · 키 · 계정값 0)
- 코드 · 문서는 수정하지 않는다. 커밋 · push · PR 금지
- 기존 Claude Design 파일을 고치거나 지우지 않는다

## 리포트 형식 (브리프가 지정한 경로)
```markdown
# <slug> 시안 결과 보고
## 상태: done / in-progress / blocked
## Claude Design 프로젝트 — id · 파일 이름 · 화면(장면) 목록
## 화면 대조 — 브리프 화면 목록 항목별 있음/없음
## 결정과 다르게 그린 곳 · 제안 · 코디가 확인할 것
```

## 문구 — 지어 넣지 않는다 (2026-11-08 사용자)
- 화면에 보이는 글자는 **시안 · SPEC · 원천 결정에 있는 것만**. 없으면 없는 것 — 빈 상태 · 안내 · 설명 문구를 지어 넣지 않는다(빈 자리는 비워 둔다).
- 근거 없는 글자가 꼭 있어야 동작이 되는 자리(버튼 이름 등)는 지어 넣지 말고 리포트 「사용자 확인」으로 올린다.
