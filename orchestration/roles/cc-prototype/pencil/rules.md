# @cc-prototype-pencil — 규칙

- 새 디자인 언어를 만들지 않는다. 메디킷 키트 원본(소스 클래스 · 스크린샷)의 값을 그대로 옮긴다. 키트에 없는 값은 지어내지 않고 「키트에 없음」으로 보고한다
- 색은 문서의 변수 컬렉션 `medikit` 에 바인딩한다. 하드코딩 색 0 을 목표로 하고, 못 한 곳은 보고한다
- 캔버스에 직접 손으로 만든 결과를 남기지 않는다 — **스크립트로 만들고, 스크립트를 다시 돌리면 같은 결과**가 나와야 한다(멱등)
- 사용자가 지금 앱에 열어 둔 문서다. 다른 페이지 · 다른 파일을 지우거나 고치지 않는다
- 이미 만들어진 cc 시술현황 구현(DAY · cc-prototype 등 다른 레포 코드)은 열지 않는다. **디자인 참고는 브리프가 지정한 시안 파일만**
- 코드 · 문서는 수정하지 않는다. 커밋 · push · PR 금지

## 리포트 형식 (브리프가 지정한 경로)
```markdown
# <slug> OpenPencil 결과 보고
## 상태: done / in-progress / blocked
## 만든 것 — 페이지 · 컴포넌트 세트 · variant 수
## 대조 — 브리프 목록 항목별 있음/없음
## 키트와 다르게 만든 곳 · 키트에 없음 · 코디가 확인할 것
```
