# @ontology-docs — 기술

- 마크다운 + YAML frontmatter + 옵시디언 wikilink (`[[...]]`)
- 문서 체계: PARA `para/projects/project.md` (00-baseline → 10-decision → 20-spec → 30-work)
- 양식: `templates/projects/` — 스켈레톤을 복사해 채운다. 새 형식을 발명하지 않는다
- 도메인: 메달리온 아키텍처(브론즈/실버/골드) · 온톨로지(nodes/edges·판정) · KPI ·
  LLM 에이전트(open-kknaks + MCP)

## 핵심 원칙
- 모범 사례가 규약이다 — `para/projects/summer-star/kknaks-dev/` 의 기존 baseline·
  decision·spec 을 먼저 읽고 같은 결로 쓴다
- 계약은 발주 가능한 수준까지 — 읽는 워커(backend·frontend)가 이 문서만 보고 구현할 수
  있어야 한다
