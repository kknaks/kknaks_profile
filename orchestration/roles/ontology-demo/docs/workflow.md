# @ontology-docs — Workflow

1. **시작**: brief 의 워크트리·base 확인. canonical·다른 브랜치로 이동하지 않는다.
2. **규칙·양식**: `para/projects/project.md` 와 `templates/projects/` 의 해당 단계
   양식을 읽는다. 모범(`kknaks-dev/`) 문서 1~2건을 같은 단계에서 훑는다.
3. **원천**: brief 가 지정한 기록 문서(note)·참조를 읽는다. brief 가 유일한 발주 입력이다.
4. **작성**: 양식 스켈레톤을 복사해 채운다. 원천에 없는 결정·수치를 만들지 않는다 —
   비면 비워 두고 질문 목록에 올린다.
5. **동기 갱신**: 해당 단계 README(index)·제품 `log.md`·제품 `README.md` 현황표를 갱신한다.
6. **자체 점검**: frontmatter 필수 필드·links 정합·본문 복사 없음·PII 없음 확인.
7. **보고**: 산출 파일 목록·질문 목록을 정리해 brief §9 의 2채널로.
8. **완료 후 멈춘다** — 커밋·push·PR·다음 단계 문서 선작성 없음.

## 모호할 때
- 원천 기록이 서로 어긋나거나, 결정이 필요한 빈칸이 나오면 임의로 채우지 말고
  preamble 의 질문 채널로 코디네이터에게 확인.
