## 3. R-1 — 닫힘 확인

현재 코드(`BrowserRecordingPage.tsx:38-44`):

```ts
const mounted = useRef(true);
useEffect(() => {
  mounted.current = true;        // ← StrictMode 두 번째 mount 에서 되살아난다
  return () => {
    mounted.current = false;     // ← 언마운트 뒤 늦은 호출은 계속 차단
  };
}, []);
```

- **요구를 정확히 충족한다.** mount→cleanup→mount 에서 `true` 가 복원되므로, 개발 빌드에서
  U-3·정리 실패 한 줄이 다시 보인다.
- **차단 기능을 희생하지 않았다** — 정리에서 `false` 로 내리는 줄이 그대로 남아 있다.
- **회차 가드(`wakeSession.current !== session`)도 그대로**라 두 가드가 함께 선다.
  `holdWake`·`dropWake` 의 나머지 로직은 **무변경**임을 확인했다.
- 보고서가 「회의 경로에는 왜 이 문제가 없는가」(`stream.ts` 의 `stopped` 는 effect 지역
  변수라 ref 처럼 인스턴스에 눌어붙지 않는다)를 코드 주석으로 남긴 것도 적절하다.
