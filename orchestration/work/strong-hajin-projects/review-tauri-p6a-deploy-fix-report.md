### 3-2. `/health` probe 와 한계 (PASS — 지적보다 더 나아갔다)

**§4-5 [기본값] probe 경로** 가 신설됐다: back `livenessProbe`/`readinessProbe` = `GET /health`,
front(nginx) = `GET /`(「정적 서빙이라 앱 상태와 무관하다」).

> ⚠ **바로 그 이유로 probe 만 믿으면 안 된다.** §3-1 의 교착이 풀리기 전에는
> **`/health` 는 200 인데 `/api/*` 는 전부 404** 인 상태가 가능하다. **probe 초록 = 제품 정상이
> 아니다.** 6b 는 배포 확인에 `/health` 말고 **실제 API 한 개와 WS 핸드셰이크**를 함께 본다.

- **한계 진술이 들어갔을 뿐 아니라 «대체 확인 수단»까지 지정**했다(실제 API 1개 + WS 핸드셰이크).
  6b 가 그대로 쓸 수 있는 형태다. **요구 이상으로 닫혔다.**
