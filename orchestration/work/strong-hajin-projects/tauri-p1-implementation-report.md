## 4. 실측 — 잰 것과 **못 잰 것**

### 4-1. ⚠ M-1 은 **미측정**이다. 통과로 쓰지 않는다

탐침 셸을 실제로 띄운 로그 전부:

```text
[probe][boot] t=1790071549152 url=https://localhost:5180/probe.html nav_allow=["https://localhost:5180"]
[probe][nav]  t=1790071550578 navigate url=https://localhost:5180/probe.html origin=https://localhost:5180 allowed=true
```

**여기서 멈춘다.** `[probe][load] started` 가 **오지 않았다** — 즉 문서가 열리지 않았고,
따라서 **커맨드 왕복을 한 번도 재지 못했다.**

**원인(추정이 아니라 구조상 확실한 것)**: 로컬 CA 를 시스템에 신뢰시키지 않았다. WKWebView 가
TLS 에서 막는다. **이 워커는 신뢰 설치를 하지 않았다** — 시스템 인증서 신뢰는 전역 보안 설정
변경이고, 브리프가 「몰래 바꾸지 않는다 · 필요하면 보고한다」로 못박았다.

> **이것은 「IPC 불성립」이 아니다.** TLS 앞에서 멈춘 것이라 SPEC-006 구조에 대한 부정적 신호가
> 아니다. **즉시 판정 게이트를 여는 사유(WORK Phase 1 「실패 시 다음 조치」)에 해당하지 않는다.**

**사용자/코디가 해야 할 한 가지** — 아래를 사람이 실행해야 M-1 을 잴 수 있다:

```bash
security add-trusted-cert -d -r trustRoot -k ~/Library/Keychains/login.keychain-db \
  "<워크트리>/frontend/.dev-certs/dev-ca.pem"
# 되돌리기
security remove-trusted-cert -d "<워크트리>/frontend/.dev-certs/dev-ca.pem"
```

**TLS 검증을 끄는 우회를 만들지 않았다.** 셸에도 fixture 에도 그런 스위치가 없다 —
검증을 무력화하고 얻은 성공은 M-1 의 증거가 되지 못하기 때문이다.

### 4-2. 덤으로 얻은 M-7 의 선행 관측

같은 로그가 **M-7(연결 실패를 셸이 감지할 수 있는가)** 에 대한 첫 신호를 준다.
**TLS 실패에서 `on_page_load` 가 아예 발화하지 않았다.** 지금 탐침은 페이지 로드 사건으로만
관측하므로 **이 경로로는 연결 실패를 감지할 수 없다.** SPEC-006 U-2 가 「⚠ 실측 전제 … 감지
수단이 없다고 판명되면 구현 차단 사유」로 표시해 둔 바로 그 지점이다.
**Phase 2 가 정식으로 재고, Phase 3 이 감지 수단(별도 훅·타임아웃 없는 다른 신호)을 정해야 한다.**

### 4-3. 그 밖의 M 항목 — 전부 **미측정**

## 6. 구현 판단 — **Phase 3 이 검수해야 할 것**

### 6-1. 원격 문서는 앱 커맨드도 ACL 로 막힌다 (중요)

tauri 2.11 소스(`src/webview/mod.rs`)를 직접 읽어 확인했다:

```rust
if (plugin_command.is_some() || has_app_acl_manifest || !is_local) && invoke.acl.is_none() { reject }
```

`!is_local` — **원격 문서는 우리 앱 커맨드도 capability 에 명시돼야 부를 수 있다.** 그래서
`build.rs` 에서 `AppManifest::commands` 로 `allow-shell-info` 등 4개를 자동 생성하고 capability 에
나열했다. 이 사실은 **경계가 실제로 작동한다는 증거**이기도 하다(`E-06`·AC-T24).

### 6-2. 절전 방지를 전용 스레드가 소유한다

Windows `SetThreadExecutionState` 는 **호출한 스레드**의 요구를 바꾼다. Tauri 커맨드는 async
런타임의 아무 워커에서나 돌 수 있으므로, OS 호출만 `scax-wake-guard` 스레드 하나로 모았다.
macOS IOPMAssertion 은 스레드에 매이지 않지만 같은 구조로 뒀다.
`os_호출은_언제나_같은_스레드에서_돈다` 가 8개 호출 스레드로 이것을 강제한다.

### 6-3. ⚠ 실행 중 교착을 하나 만들었다가 고쳤다 — 같은 실수를 Phase 3 이 베끼지 않게

- **증상**: `cargo test` 가 약 3분간 CPU 0% 로 멈춤
- **확정 방법**: `sample <pid>` 스택 — `power.rs:407 drop(power)` → `PowerThread::Drop` → `handle.join()`
- **원인**: 처음 `Drop` 은 「원래 `Sender` 를 버리면 채널이 닫힌다」에 기댔는데, 테스트가 `tx.clone()`
  을 살려둬 `rx.recv()` 가 끝나지 않았다 → `join()` 영구 대기
- **수정**: 종료를 **명시 사건 `Op::Shutdown`** 으로 바꿨다. 바깥에 sender 사본이 몇 개 남아 있든
  스레드가 스스로 끝난다. 어느 길로 나가든 마지막에 `backend.disengage()` 를 부른다
- **회귀 시험 2건**: `바깥에_sender_사본이_남아_있어도_종료가_끝난다`(10초 상한) ·
  `스레드가_없으면_매달리지_않고_실패로_답한다`
- **행 프로세스 2개(90477 · 91208)를 정리했다.** 최종 실행에 잔류 없음

> **Phase 3 이 이 셸을 흡수한다면 `Op::Shutdown` 을 반드시 같이 가져가야 한다.**
> 「채널을 닫아 스레드를 끝낸다」는 구조는 sender 사본 하나에 매달린다.

### 6-4. 코디 보완 지시 반영 — 자체 URL 파서 제거

`tauri-p1-url-note.md` 지시에 따라 직접 만들던 `url_lite` 파서를 버리고 **Tauri 가 이미 쓰는
표준 `Url`**(`tauri::Url` = `url` crate)로 바꿨다. `on_navigation` 이 받는 타입과 같아서
**커맨드 허용 origin 과 네비게이션 허용 목록이 한 기준으로 비교**된다.
`origin_은_표준_직렬화를_그대로_쓴다` 가 기본 포트 생략 · `userinfo` · 대소문자 · opaque origin(`"null"`)
을 함께 고정한다. `open_external` 의 `http`/`https` 만 허용하는 계약은 그대로다.

### 6-5. 계측 로그를 **표준출력**으로만 낸다

셸이 관측하는 것(네비게이션 훅 · 창 닫기 요청 · 점유 정리)을 원격 문서에 이벤트로 쏘지 않았다.
이벤트 채널을 열면 그것이 **다섯째 표면**이 되어 I-2 가 흐려진다. Phase 2 는 터미널의
`[probe]` 줄과 화면 로그를 **시각으로 맞춰** 읽는다.

### 6-6. 제품 포맷과의 drift 를 테스트로 묶었다

계측 페이지는 제품 모듈을 `import` 하지 않는다(번들 경계). 대신 `?raw` 로 **문자열만 읽어**
`microphone.ts` 의 단일 MIME · `liveTranscription.ts` 의 후보 셋과 순서 · `CHUNK_MS` 가
계측 상수와 같은지 검사한다. **제품이 포맷을 바꿨는데 계측이 옛 값을 재면 측정 기록 자체가
거짓이 되기 때문이다.**

### 6-7. 남겨 둔 판단 — Phase 3 이 정할 것

- **AC-T41(문서 교체 전 요청이 새 문서 점유를 만들지 않는다)의 네이티브 보상 수단을 넣지 않았다.**
  네이티브는 커맨드가 어느 «문서»에서 왔는지 구분할 수 없다(webview label 만 안다). 후보로
  「새 문서의 첫 `shell_info` 를 hello 로 보고 그 세대의 이전 세션을 쓸어내기」를 검토했으나,
  **호출 순서에 새 계약을 얹는 것**이라 Phase 3 의 결정으로 남겼다. 지금은 웹 쪽 직렬화(I-7)와
  L-09 정리까지만 있고, **그 한계를 보고서에 적는다.** 측정은 Phase 5(M-14)다
- **연결 실패 감지 수단**(§4-2) — 지금 구조로는 감지되지 않는다
- **아이콘·제품 ID·번들 타깃** — 자리만 만들었다

## 7. Phase 2 재현 절차

```bash
cd <워크트리>/frontend

# ① 최초 1회 — 로컬 인증서 생성(커밋되지 않는다)
npm run probe:cert
#   ↑ 출력된 `security add-trusted-cert …` 를 **사람이** 실행한다. 스크립트가 대신 하지 않는다.

# ② https fixture (M-1 전용 · 5180)
npm run probe:fixture           # https://localhost:5180/probe.html

# ③ 탐침 셸 — 로그를 파일로 받는다
cd src-tauri && cargo run 2>&1 | tee /tmp/probe-shell.log
#   취소된 창 닫기(AC-T36)를 보려면:  SCAX_PROBE_CANCEL_FIRST_CLOSE=1 cargo run
#   다른 주소를 열려면:               SCAX_PROBE_URL=… cargo run
#     ⚠ 주소를 바꾸면 capabilities/probe-fixture.json 의 remote.urls 도 같이 바꾼다

# ④ 마이크·녹음(M-2·M-4)은 평문 localhost 스택에서도 된다 — localhost 는 secure context 다
cd <워크트리> && make local-stack
```

**기록할 때 지킬 것** (WORK Phase 2 측정 규칙 그대로)

- **M-1 은 https fixture 에서만** 잰다. 평문 `localhost` 결과로 대신하지 않는다
- **M-2 는 두 경로 × 세 갈래 = 여섯 칸.** `isTypeSupported` 참으로 닫지 않는다
- **M-9 관찰 시간**은 설정된 `T` 에 대해 `max(3T, 30분)` 이상. `T` 를 숫자로 적는다
- **OS 축을 접지 않는다.** Windows 실기가 없으면 「검증 불가(장비 없음)」
