## 2. 정정 전에 확인한 «현재의 사실»

문장을 고치기 전에, 지금 저장소에서 스크립트가 실제로 무엇을 찍는지 먼저 봤다.

| 실행 | 종료 코드 | 출력 |
|---|---|---|
| `make shell-verify` | **0** | `문제 0건 · 구성 미비 1건 · 호스트 한계 1건` |
| `make shell-verify SHELL_STRICT=1` | **≠ 0** | `구성 미비를 실패로 올렸다(호스트 한계는 올리지 않는다)` · `실패 1건` |

- **구성 미비 1건** = macOS `.icns` 아이콘 부재 — **채우면 사라진다**. strict 가 **승격하는 것은 이것뿐**이다
- **호스트 한계 1건** = 이 기기가 Windows 번들을 굽지 못한다 — **기기의 성질**이라 채울 수 없다.
  승격하면 이 기기에서 strict 가 **영원히 붉어** 경보로서 죽으므로 **정보(ℹ)로 남긴다**

**즉 「2건 승격」이라고 적힌 문장은 실제 동작보다 한 건 많게 말하고 있었다.**
