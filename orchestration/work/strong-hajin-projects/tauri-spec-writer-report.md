## 2. 구현 요약 — SPEC-006 이 고정한 것

### 2-1. 중심 판단 — 방향 A 는 기존 계약을 **0줄** 바꾼다

DEC-005 D-01 이 고른 「배포 https 웹을 창에서 연다」를 따르면 창의 문서 origin 이 운영 origin
그 자체가 된다. 그래서 상대경로 `fetch` 9곳 · `new WebSocket` 1곳 · 세션 쿠키 · 딥링크 검증 ·
CORS 부재가 **전부 그대로 성립한다.** 「고칠 곳이 없다」를 목록이 아니라 **전수로 세어** §1 관계표에 적었다.

참조 제품이 Bearer + OS 키체인으로 간 것은 방향 B 를 골라 origin 이 갈렸기 때문이고,
**그 선택을 계승하지 않는다**(D-02). 쿠키를 「원천적으로 불가능」하다고 쓰지 않았다 —
반대로 이 방향에서는 쿠키가 **가장 자연스러운 선택**임을 근거로 적었다.

### 2-2. 셸 ↔ 웹 인터페이스 — 커맨드 다섯, 그 이상 열지 않는다

`shell_info` · `wake_lease_acquire` · `wake_lease_renew` · `wake_lease_release` · `open_external`.

- 점유는 **셀 수 있다**(reference count). 녹음 표면이 둘이라 동시 점유가 실재한다
- `release` 는 **항상 성공**한다 — 중복·만료·모르는 id 도 성공(`E-08`). 해제하는 쪽이 실패를 처리하지 않게
- 셸이 **마지막 방어선**이다 — 창 닫기(L-06) · 네비게이션(L-09) · TTL 만료(`E-09`) · 프로세스 종료
  중 하나가 반드시 푼다. **점유가 영구히 남는 경로를 두지 않았다**
- 허용 origin 은 **운영 origin 정확히 하나.** 와일드카드 서브도메인을 금지로 명시(AC-T19)
- **범용 shell·파일 권한을 열지 않는다**를 인수조건으로 박았다(AC-T18) — 설정 파일을 사람이 읽어
  확인할 수 있어야 한다고 검증 방법까지 적었다
- 웹·앱 버전 호환은 **`features` 목록 기반 기능 탐지**로 갔다. 숫자 비교만 하면 같은 판 안에서
  플랫폼별로 빠진 기능을 못 가린다. **웹이 앞서 나가는 것이 기본**이고, 모르는 기능은 그것만 끄고
  나머지는 정상 동작한다

### 2-4. 화면 꺼짐과 시스템 잠자기를 갈랐다 — 공식 문서 근거로

DEC-005 D-03 이 요구한 경계(자동 절전만 막고, 화면 꺼짐은 허용하고, 수동 잠자기·덮개 닫기는
막지 않는다)가 **두 OS 의 API 경계와 정확히 일치한다.** 조사에 verbatim 인용과 URL·확인일을 남겼다.

- **Windows**: `ES_CONTINUOUS | ES_SYSTEM_REQUIRED`. `ES_DISPLAY_REQUIRED` 를 넣으면 D-03 을 어긴다.
  문서가 못박는 문장 — *"cannot be used to prevent the user from putting the computer to sleep …
  respect that the user expects a certain behavior when they close the lid"*
- **macOS**: idle system sleep 방지 assertion. 화면은 dim·잠들 수 있고, 덮개 닫기·Apple 메뉴 ·
  저전력으로는 여전히 잠든다
- **웹 표준 Screen Wake Lock 은 답이 아니다** — 그것은 *화면*을 켜 두는 API 다. **래퍼가 필요한
  이유의 근거**로 SPEC §1 에 넣었다
- **공식 Tauri 절전 방지 플러그인이 없다.** 커뮤니티 크레이트뿐이라 「플러그인 하나 붙이면 된다」고
  쓸 근거가 없다. SPEC 은 **계약만 고정하고 수단을 지정하지 않았다**

### 2-5. 새 UI 는 둘뿐

## 5. 주요 판단 — 리뷰어가 볼 자리 (검수 포인트)

리뷰어가 **동의하지 않을 수 있는 판단**을 먼저 꺼낸다. 아래 여덟이 이 SPEC 의 무게중심이다.

| # | 판단 | 근거 | 뒤집히면 |
|---|---|---|---|
| **R-1** | **D-03 의 「일시정지 시 해제」를 조건부(L-10)로 내렸다** | 회의 스트림 상태가 `idle\|connecting\|live\|closed` 넷뿐이고 `paused` 가 없다. 마이크 핸들에 `stop` 만 있다. 확정 계약으로 쓰면 **검증할 방법이 없는 인수조건**이 된다 | 일시정지를 이번에 만들기로 하면 범위가 커진다 — 웹 변경이 따라온다 |
| **R-2** | **점유 획득 시점을 「마이크가 실제로 열린 순간」으로 잡았다** (스트림 연결이나 `ready` 가 아니라) | 마이크가 거부되면 화면은 `live` 인 채로 남는다. 그 상태에서 기기를 깨워 두면 **녹음도 없는데 배터리를 쓴다** | 「회의가 도는 동안」으로 바꾸면 L-03 이 사라지고 AC-T05 가 없어진다 |
| **R-3** | **브라우저 인터랙션 녹음도 점유 대상에 넣었다** (L-07·L-08) | 그 경로는 오디오를 **메모리에만** 쌓다가 종료 시 올린다. 끊기면 회차가 통째로 사라져 **회의 라이브보다 손실이 크다** | 「회의 녹음만」으로 좁히면 AC-T09 가 빠진다 |
| **R-4** | **업로드가 끝날 때까지 점유를 유지한다** (L-08) | 오디오가 아직 메모리에 있고 재시도 중이다 | 「녹음 종료 시 즉시 해제」가 더 단순하다 — 대신 업로드 중 절전을 허용한다 |
| **R-5** | **TTL + 갱신 계약을 넣었다** (`wake_lease_renew`) | 창 닫기·네비게이션은 셸이 잡지만 **문서가 살아 있는 채로 멈춘 경우**를 잡을 길이 그것뿐이다. 없으면 기기가 영원히 안 잠들 수 있다 | 빼면 커맨드가 넷으로 줄고 웹의 의무가 가벼워진다 — 대신 leak 경로가 하나 열린다. **값은 이미 OQ-T08 로 열어 두었다** |
| **R-6** | **U-2 연결 실패 화면을 계약으로 요구했다** | 없으면 웹뷰 기본 오류나 빈 창이 노출돼 「앱이 고장났다」로 보인다 | 감지 수단이 없다고 판명되면(M-7) **구현 차단 사유**다. SPEC 에 그렇게 적었고 조용히 빼지 않는다 |
| **R-7** | **U-3(실패 시 한 줄)을 새 UI 로 넣었다** | 조용한 실패는 **원래 문제의 완전 재현**인데 아무도 모른다 | 「아무것도 안 보인다」로 가면 새 UI 가 U-2 하나로 줄지만, 실패가 보이지 않는다 |
| **R-8** | **셸 버전 하한 2.11.1 을 계약에 박았다** (AC-T20) | GHSA-7gmj-67g7-phm9 — 영향 `>=2.0, <=2.11.0`, 패치 `>=2.11.1`. **원격 URL 을 웹뷰에 싣는 앱이 정확히 영향 대상**이다. 참조 제품이 이미 2.11.3 이라 계승에 무리가 없다 | 없다 — 이건 뒤집을 자리가 아니라고 본다 |

**리뷰어가 특히 봐 줬으면 하는 것 셋**

1. **§4 의 커맨드 다섯이 정말 최소인가.** 더 줄일 수 있나(예: `renew` 를 빼고 `acquire` 에 TTL 만
   두기), 아니면 빠뜨린 것이 있나(예: 알림을 위해 지금 열어야 할 자리가 있나 — 나는 **없다**로 갔다)
2. **L-01 ~ L-10 이 지금 제품의 상태를 하나도 안 빠뜨렸나.** 조사 §5-2 의 전수표가 근거다.
   빠진 전이가 있으면 그것이 곧 깨어 있는 채로 남는 기기다
3. **OQ-T07(macOS 녹음 포맷)을 「차단 요인」으로 올린 것이 맞나.** 나는 **래퍼 목적 전체가 여기
   걸린다**고 보고 실측을 첫 순서로 제안했다

> 공식 문서가 보증하는 「ACL 에 `remote.urls` 라는 자리가 있다」까지만 적었다. M-1 이 그 자리다.

## 8. 한계 — 이 산출물이 하지 않은 것

- **실행·빌드·설치·서버 기동을 하나도 하지 않았다.** M-1 ~ M-10 이 그 목록이다
- **적용 코드가 미커밋 작업 중(69건)이다.** 인용은 §0 의 HEAD·시각 기준이고, 계약에 해당하는
  자리만 골라 인용했지만 구현 착수 시 재확인이 안전하다
- **Tauri 의 원격 URL + IPC 동작을 단정하지 않았다** (§6-3)
- **대상 OS·운영 주소·배포 채널·서명 신원을 발명하지 않았다.** 전부 OQ 로 남겼다
- **`.env`·인증서·키를 열지 않았다.** 환경변수는 이름만 인용했다
- **구현 계획(WP)을 쓰지 않았다** — 브리프가 범위 밖으로 둔 그대로다
