## 참고 (지적 아님)

1. **태그 ② 문구가 원천과 조금 다르다.** 원천은 「`counselor` · `coordinator` · `call_counselor` **만이면** 보기」, SPEC ⑩ 은 「그 밖에 … 가 **있으면** 보기」다. 태그가 고정 7개(DAY-SPEC-001 규칙 9)라 ① 강한 태그가 하나도 없을 때 남는 태그는 이 셋뿐이다. 그래서 결과는 같다. 태그 종류가 늘어나면 다시 볼 자리다.
2. **DAY-SPEC-001 「전체 권한 계정」 줄의 「권한 표 시드는 만들지 않는다」**와 이번 「기본값 행을 넣는다」가 글자로는 부딪혀 보인다. 그 줄은 「가짜 계정 · 시드로 우회하지 말고 env 로 연다」는 전체 권한 계정 문맥이다. 다음 SPEC-001 판에서 「(전체 권한 계정을 위한) 권한 표 시드」처럼 범위를 좁혀 적으면 읽는 사람이 헷갈리지 않는다.
