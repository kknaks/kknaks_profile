### 회귀 테스트

- day.js 동작 자체(위치 · 개수 · X)는 pytest 에서 브라우저를 돌리지 않아 자동 테스트가 없다(리뷰어도 받아들임). 대신 **위 재현 스크립트를 남겼다**(같은 명령으로 old/new 비교).
- 자동 테스트로 지키는 것:
  - 페이지 `meta asset-version` 과 판 조각 `data-day-asset-v` 가 같은 판인지(형식 = 해시 12자리)
  - 판이 다르면 새로 읽는 코드가 day.js 에 있는지
  - **새 `test_정적_파일_판은_내용_해시다`**: mtime 만 바뀌면 같은 판 · 내용이 바뀌면 다른 판

### 새로 읽기 장치의 범위(리뷰어 위험 지적)

- `asset_v` 를 **파일 mtime → 정적 파일 4개 내용의 sha256 앞 12자리**로 바꿨다(`web.py`).
  - 이미지 · 레플리카마다 mtime 이 달라도 같은 내용이면 판이 같다. 그래서 응답마다 새로 읽기를 되풀이하지 않는다.
  - 해시는 mtime 이 바뀔 때만 다시 계산한다(개발 중 고치면 바로 반영).
- 지금 판: `a736240dc565`.
- 받아들인 것(리뷰어와 같음): 조작 응답에서 새로 읽기가 나면 그 순간의 체크 등 화면 상태가 사라진다. 배포 직후 한 번뿐이다.
