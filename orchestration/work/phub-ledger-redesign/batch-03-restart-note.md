# batch-03 재시작 범위

사용자 지시: taxonomy·literature-evidence·problem-packages·problem-combos의 중간 결과를 삭제하고 원본부터 새 Opus 워커로 재조사한다. pih-risk는 실행 중이므로 제외한다.

네 태스크의 기존 dispatch는 failed·실행 프로세스 exited를 확인했다. 삭제 범위는 first-pass/ 아래 해당 네 폴더뿐이다. 원본·앞선11개 결과·스킬·발주 기록은 유지했다. 새 결과도 같은 네 경로에 만든다. 구획분할·coverage·progress 기록은 기존 브리프대로 수행한다. 이전 수동 조사·완료 주장은 근거로 사용하지 않는다.

기존 Task를 --retry-of로 재시도한다. pih-risk 원 태스크·dispatch·결과는 그대로다.
