## C. 기술 선택 — 2026-09-03 확정 (spec 진입 게이트, 닫힘)

| # | 결정 | 내용 |
|---|---|---|
| Q-28 | **정적 빌드** | Next.js `output: 'export'` 로 구워 Tauri 에 싣는다. 서버 컴포넌트 런타임 페칭·Route Handler·미들웨어를 쓰지 않고, **데이터는 전부 클라이언트에서 FastAPI 로 fetch**. Node 서버 동봉 안 함 |
| Q-33 | **shadcn/ui 도입** | 분석 리포트의 컴포넌트 매핑 C-01~49 유효(그대로 28 / 커스텀 21). Tailwind + **디자인 토큰을 CSS 변수로 매핑**해 shadcn 테마에 연결 |
| Q-34 | **유동 레이아웃(반응형이 기본)** | **작은 맥북 · 중간 모니터 · 큰 모니터를 모두 지원.** `00-README` L51 의 「1920 실측 좌표를 그대로 구현 기준으로」는 **치수 근거로만** 쓰고 absolute 로 박지 않는다 — `08-responsive` L19(본문 유동, 여백 240→80→48)가 기준. **정정 대상**(A-13) |

> **A-13 (정정)** — `00-README.md` §전제 L51 「좌표·크기는 1920×1080 실측값이며 그대로 구현 기준으로 사용한다」를
> 유동 레이아웃 기준으로 고쳐야 한다. 좌표는 비율·최소폭을 잡는 참고값이다.
> 이에 따라 **1280 반응형이 안 그려진 영역(회의록·인증/설정·캘린더·문서함·메시지함)의 규칙이 더 중요해진다** — B-6 참조.
