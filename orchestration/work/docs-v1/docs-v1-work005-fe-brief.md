## 3. 서버가 이미 정한 것 — 화면이 맞춰야 할 셋

백엔드 워커가 구현·실측하며 확정한 것들이다. **모르고 붙이면 화면이 어긋난다.**

1. **같은 상태로 다시 보내면 `409`** 다(전이 그래프에 자기 자신이 없다).
   **칸반에서 같은 컬럼에 다시 놓을 때 요청을 내지 마라** — 내면 사용자가 아무것도 안 했는데 에러 토스트를 본다.
   드롭 대상 컬럼이 현재 상태와 같으면 **조용히 아무 일도 일어나지 않는다**
2. **`typeCounts` 는 그 기간에 업무가 **있는** 유형만 담는다**(+전체). 0건 유형은 **행이 아예 없다** —
   **화면이 0 을 그려야 한다.** 없는 키를 `undefined` 로 두고 탭을 감추면 안 된다
3. **`overdueDays` 는 목록 응답에만 있다** — 상세 계약에는 없다(SPEC-003 이 안 정했다).
   상세에서 지연을 그려야 하면 **목록에서 받은 값을 쓰거나, 없으면 안 그린다.** 화면이 다시 계산하지 마라(T-4)

## 4. 특히 못박을 것

- **`PATCH /api/tasks/{id}/status` 를 호출하는 곳이 `useTaskStatus.ts` 하나**여야 한다. **grep 결과가 완료 증거다**
- **낙관적 갱신을 하지 않는다** — 완료 게이트·전이 그래프가 **거부할 수 있다**.
  칸반은 **드래그 고스트가 즉각성을 주고**, 놓은 뒤 응답까지 그 자리를 로딩(불투명도 0.6)으로 유지한다.
  (WORK-004 에서 낙관적으로 만든 세 자리 — 할일 체크·메모·인라인 텍스트 — 와 **정반대 축**이다. 그 구분이 §5 표의 요점이다)
- **드롭 차단 vs 서버 판정** — 전이 그래프로 막히는 컬럼은 **드롭 자체를 막는다**(흐림 + `not-allowed`).
  **완료 컬럼은 드롭을 허용하고 게이트가 서버에서 판정한다** — 결과자료 유무를 화면이 미리 판단해 막으면 서버와 어긋난다
- **조건은 전부 `?` 에 남는다**(기간·유형·상태·프로젝트·정렬·뷰). 컴포넌트가 자체 상태로 들고 있지 않는다.
  **뷰를 바꿔도 기간·유형이 유지되고 새로고침해도 그대로**여야 한다
- **화면당 Ink(`--tm-ink`)는 유형 탭 하나**다 — **뷰 토글은 Ink 를 쓰지 않는다**(선택은 `#F4F5FF`+`#4B52A8`).
  **grep 결과가 완료 증거다**
- **거부 토스트의 「결과 입력」**은 WORK-004 가 내보낸 **`useCompletionCardFocus()`** 를 부른다
  (`features/tasks/index.ts` 에 있다). **네가 스크롤·포커스·강조를 새로 만들지 마라** — 만들면 규격이 둘이 된다
- **무효화** — 전이·삭제 뒤 `['tasks', …]` 를 다시 읽는다. **기한이 바뀐 게 아니면 `['schedules']` 를 건드리지 않는다**
- 캐시 키는 **`lib/api/queryKeys.ts` 에서만** 만든다(컴포넌트에 배열 리터럴 0)

## 8. 완료 보고 — **문구 변경 금지**

> **⚠ 핸들은 dispatch preamble 의 값을 믿어라.** preamble 의 코디네이터 핸들과 아래 값이 다르면 **preamble 이 맞다.**

- 끝나면 **아래 두 명령을 모두** 실행한다.

```bash
orca orchestration send \
  --to term_6a4ac855-2a13-4484-b808-4c25182cbb2b --from <네 워커handle> \
  --type worker_done \
  --task-id <이 태스크의 taskId> --dispatch-id <이 태스크의 dispatchId> \
  --subject "frontend 완료: <한 줄>" \
  --body "변경 파일 목록 / 구현 요약 / 검증 결과(수치) / 계약 준수 / 미결·주의점"

orca terminal send --terminal term_6a4ac855-2a13-4484-b808-4c25182cbb2b \
  --text "[worker_done] frontend 완료 — <한 줄 요약>. 상세는 인박스." --enter
```
