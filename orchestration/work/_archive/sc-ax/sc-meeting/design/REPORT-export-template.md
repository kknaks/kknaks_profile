## 2. 자리별 구성

```
.page
├ .sheet-head        회의명(17 Bold, 왼쪽)  ·  .sheet-when 날짜(요일)/시작~종료(11, 오른쪽)
├ .sheet-people      참석 · 이름들 (11) — 아래에 --border-default 한 줄
├ .sheet-summary     요약 문단 (없으면 이 블록째 뺀다)
├ .thread            왼쪽 1px dashed 세로축
│ └ .thread-item     ::before 로 축 위에 점(7px, --action)
│   ├ .agenda-head   안건 제목(14 Bold) + 상태 칩 + 시각 칩 최대 3 + .stamp.more 「+N」
│   ├ ul.lines       줄마다  ·  본문(12)  …  오른쪽 시각(11, --text-disabled)
│   └ .todos         「다음 할 일」 + .todo × N
│       .todo        [액션] 칩 · 제목 · 기한 · (시각 칩 | 「근거 없음」 | 「요청됨」 칩)
└ .sheet-foot        페이지 번호 · 「SCAX · 회의록」 · 내보낸 시각 (absolute, bottom 10mm)
```

- **이어지는 장**은 `.sheet-head.cont` 로 회의명만 12px 로 줄여 반복하고 참석자·요약을 다시 내지 않는다
- 안건은 `break-inside: avoid` 라 한 안건이 두 장에 걸쳐 쪼개지지 않는다
- 「다음 할 일」이 0건이면 `.todos` 블록을 만들지 않는다(샘플 안건 4가 그 경우)
- 근거가 없으면 시각 칩 자리에 `.stamp.none` 「근거 없음」, 이미 업무로 선 것은 `.chip.requested` 「요청됨」

## 3. BE 가 치환할 자리

주석으로 표시했다 — `<!--{{path}}-->샘플값` 꼴이라 주석을 지우고 값만 갈면 된다. 반복은 `{{#each}}`, 조건은 `{{#if}}`.

| 자리 | 표시 | 비고 |
|---|---|---|
| 회의명 | `{{meeting.title}}` | 장마다 반복 |
| 날짜 | `{{meeting.date}}` | `YYYY. MM. DD.(요일)` |
| 시작·종료 | `{{meeting.startAt}}` · `{{meeting.endAt}}` | `HH:MM` |
| 참석자 | `{{#join meeting.attendees ", "}}` | 한 줄 |
| 요약 | `{{#if meeting.summary}}` ~ `{{/if}}` | **없으면 블록째 뺀다** |
| 안건 반복 | `{{#each agenda}}` ~ `{{/each}}` | |
| 안건 제목 | `{{agenda.title}}` | |
| 상태 칩 | `{{#if agenda.decided}}` 결론 남 `{{else}}` 결론 안 남 `{{/if}}` | |
| 시각 칩 | `{{#each agenda.stamps limit 3}}` + `{{#if agenda.stampsOverflow}}` | 4개째부터 「+N」 |
| 본문 줄 | `{{#each agenda.lines}}` | 줄 하나 = `<li>` 하나 |
| 할 일 | `{{#if agenda.todos}}` ~ `{{#each agenda.todos}}` | 0건이면 상자 없음 |
| 페이지 번호 | `{{page.current}}` | §5 미결 1 |
| 내보낸 시각 | `{{export.at}}` | 장마다 반복 |

**페이지 나누기 계약** — 이 템플릿은 `.page` 하나 = A4 한 장이다. BE 가 내용을 재어 `.page` 를 나눠야 한다. 한 장에 들어가는 본문 높이는 **986px**(261mm)이고, 대략적인 소모량은 아래와 같다.

| 요소 | 대략 높이 |
|---|---|
| 첫 장 머리 + 참석자 + 요약(3줄) | 162px |
| 이어지는 장 머리 | 28px |
| 안건 하나의 머리 | 36px |
| 본문 줄 하나 | 21px |
| 「다음 할 일」 상자(테두리·라벨) | 46px + 할 일 하나당 21px |

샘플 실측: 1장 690px(70%) · 2장 403px(41%) — 두 장 다 여유가 있다.

## 5. 미결

1. **페이지 번호를 CSS 가 못 센다.** `counter(page)` 는 `@page` 마진 박스에서만 도는데 Chrome 이 그걸 지원하지 않는다. 지금은 `.sheet-foot` 에 `{{page.current}}` 를 박아 **BE 가 채우는 값**으로 뒀다. Chrome 의 `printToPDF` 로 뽑는다면 `footerTemplate` 로 넘기는 길도 있는데, 그러면 「SCAX · 회의록」·내보낸 시각도 같이 그쪽으로 가야 한다 — 어느 쪽으로 갈지 정해야 한다.
2. **전체 쪽수(`N/M`)를 뺐다.** 1번과 같은 이유로 총 장수를 BE 가 세야 해서, 지금 꼬리는 현재 쪽 번호 하나만 낸다. 필요하면 `{{page.total}}` 자리를 열어 두겠다.
3. **줄 오른쪽 시각이 한 개씩이다.** 브리프대로 「줄마다 우측에 시각 하나」인데, 한 줄이 여러 발화에서 나온 경우 무엇을 고를지는 BE 규칙이다(첫 발화 기준을 권한다).
4. **긴 줄의 줄바꿈 여유.** 추정 높이는 한 줄이 안 접힌다는 가정이다. 본문 폭 178mm 에서 한글 약 60자가 한 줄이니, BE 가 잴 때 실제 렌더 높이로 재야 한다.
