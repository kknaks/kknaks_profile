### 1.1 항목 6 정정 (2026-09-11 · 사용자 실물 확인)

첫 반영은 「── 직원 정보 없음 ──」 가운데 정렬 라벨 + 아바타 행(이름 왼쪽 · 「사외 참석자로 추가」 오른쪽)이었다. **틀렸다.** 맞는 모양은 구분선으로 갈린 **줄 둘**이다.

```
──────────────────────────────
직원 정보 없음                      ← 일반 텍스트 행 · 비활성 · 클릭 불가
──────────────────────────────
이건학 사외 참석자로 추가             ← 한 줄로 이어 쓴 클릭 행 · 아바타 없음 · 좌우 분리 없음
──────────────────────────────
```

- 「직원 정보 없음」은 `t-meta` · h34 의 `div` 다 — `popover-item` 이 아니라 눌리지 않고 호버도 안 걸린다
- 사외 추가 행은 `popover-item` 하나에 「{친 이름} 사외 참석자로 추가」를 **한 문장으로** 담았다. 아바타·오른쪽 라벨을 떼서 좌우로 갈리지 않는다
- 구분선은 위·사이·아래 셋. `--border-subtle` 1px
- **찾은 직원이 있을 때는 그대로다** — 아바타 행이 결과 목록에 이어 붙는다(`canAddGuestInline`). 두 줄 블록은 매칭 0건일 때만 선다
- 이미 사외로 담은 이름을 다시 치면 안내 줄만 서고 추가 행은 안 선다(중복 방지)

### 1.2 항목 18 — 날짜 칸을 한 칸으로 (2026-09-11 · 사용자 실물)

첫 반영은 DS `SCAX.DateField` 를 그대로 썼는데, 그 부품은 **「텍스트 칸(`2026/09/11`) + 바깥 달력 아이콘 버튼」 두 조각**이라 사용자가 말한 모양이 안 나온다. 부품을 바꿔 한 칸으로 다시 세웠다.

```
┌──────────────────────┐   ┌──────────┐
│ 2026-09-10        📅 │   │ 15:00  ⌄ │   ← 아이콘 자리·크기(12)가 시각 칸과 같다
└──────────────────────┘   └──────────┘
     날짜 칸(168)              시각 칸(104)
```

- 트리거는 시각·회차와 **같은 `.field-select`** 다. 아이콘만 `calendar` 로 바뀌고 자리(오른쪽 안쪽)와 크기(12)는 같다
- **칸 어디를 눌러도 열린다** — 아이콘이 따로 버튼이 아니라 칸 전체가 버튼 하나다
- 표기는 **하이픈**(`2026-09-10`). 비어 있으면 `YYYY-MM-DD` 를 `--text-tertiary` 로 안내한다
- 달력 판은 DS 의 `date-picker-head` · `calendar-weekdays` · `date-picker-row` · `date-picker-cell`(`outside`/`today`/`aria-selected`) · `date-picker-foot` 클래스를 그대로 써서 DS `DatePicker` 와 같은 모양이다. 6주 42칸 짜임도 `DatePickerPanel` 과 같다
- [지우기]·[오늘] 도 DS 판과 같은 자리에 둔다. 날짜를 지워도 달력이 설 달을 잃지 않게 기준일의 달로 되돌린다

**DS 에 되돌릴 것** — `DateField` 가 두 조각인 것이 이 화면에서 안 맞았다. DS 쪽에 **「한 칸 + 안쪽 아이콘」 변형**이 필요하다(`DS-16`).

- 코드의 `TimeField.tsx` 는 **이 워크트리에 `frontend/` 가 없어 확인하지 못했다.** 있으면 위 규격과 대조해 하나로 합쳐야 한다(미결 1).
