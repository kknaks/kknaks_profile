### F-1 ④ 가 조사를 먹는다 — 「한 음절 빠진 꼴 + 조사」

- 재현(레포 시드 `.10` · zh · 외 → 한 · 원문에 그 term 의 zh name):
  - 보톡스: 「보톡을 맞고…」 → **「보톡스 맞고…」**(을 사라짐) · 「보톡이 좋아요」 → **「보톡스 좋아요」**
  - 써마지: 「써마를 받고…」 → **「써마지 받고…」**(를 사라짐)
  - 피코웨이: 「피코이에요」 → 「피코웨이에요」

- 권고: 같은 거리면 **짧은 앞부분**을 고른다. 키를 `(d, i, k)` 처럼 하거나, 「k = n 인데 끝 음절만 다른 바꾸기」 보다 「k = n−1 넣기」 를 먼저 둔다. 「빠진 꼴 + 조사」 시험을 한 건 더한다.
