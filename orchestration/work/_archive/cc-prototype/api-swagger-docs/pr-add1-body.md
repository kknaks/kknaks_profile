| `GET /api/ext/availability?date=YYYY-MM-DD` | 날짜(오늘 ~ 90일) | 외부 예약 기본 그룹의 칸 · 칸마다 남은 자리(0 칸 · 지난 시각 제외) |

- **정원 규칙 하나**: 가능 시간대는 요청마다 KOS 슬롯을 1번 받아 공유 사본을 갈고(날짜 잠금 안), 예약 생성과 같은 함수로 남은 자리를 센다. 목록에 있는 시각으로 예약하면 정원으로 거절되지 않는다(동시 요청 경합만 예외).
- **고객 찾기**: 1차 조회와 같은 함수. 없음 · 틀린 입력 404 는 세 경로가 바이트까지 같다.
- **내보내지 않는 것**: 예약 · 상담 메모 · 의사 이름 · 담당자 · 그룹 이름 · KOS 고객 id.
- **KOS 응답**: 일정 `{}` · `[]` = 빈 목록 · `data` 가 배열 아님 또는 원소 모양 깨짐 = `502 kos_unavailable` · `deleted` 일정은 뺀다.
