## 고객이 실물에서 만날 자리

- 외국인 이름처럼 띄어쓰기가 든 이름(데모 215/493명)은 KOS 에 저장된 띄어쓰기와 다르게 보내면 `404` 다(N2). 예약에서는 `0명` 갈래로 가서, 이메일이 KOS 에 있으면 `409`, 없으면 **새 고객이 하나 더 생긴다**. 협업자 문서에 「이름은 KOS 에 등록된 그대로(띄어쓰기 포함)」를 적어야 한다.
- 같은 이름이 1000명을 넘는 경우(짧은 이름 · 흔한 성)는 `404` 다. 정확 일치라 실제로 걸릴 일은 드물다(데모 최대 37건 · R4 §2.1).
- `bundlePrice` 는 「고객이 낸 돈이 아님」을 설명에 적는다. 연동처가 이것을 「잔액 · 환불액」으로 쓰지 않도록, 협업자 공유 때 한 번 더 말하는 편이 안전하다(SPEC 이 Swagger 에 이미 싣는다 — 좋다).
