# [backend] SPEC-008 0.2.0 보정 1 — 문서 검수 r2 반영(지금 작업에 바로 적용)

1. **N1 키 없는 기록 · IP 제한 범위**: `ext_call` 「같은 IP · 같은 결과 1분 1줄」 줄이기와 IP 카운트는 **`request.state` 에 연동처가 없는 `/api/ext` 오류 응답 전부**(401 · 404 · 깨진 JSON 400 · 405 · IP 차단 429)에 건다. 401 · 404 만 고르지 않는다. T27 「JSON 이 아닌 본문 400 도 1줄」 → 「같은 IP 에서 5번 → 1줄」. T31 에 깨진 본문 · 405 경우 추가. Swagger 오류 표에 `405 http_error`(지금 코드 code) 한 줄
2. **N2 이름 공백**: `tests/fake_kos.py` 의 `get-visitors` 검색 규칙(공백 그대로 · 부분 일치)은 **고치지 마라**. T12 의 공백 경우는 가짜 KOS 응답을 직접 지정해 「KOS 가 돌려준 고객이면 공백 차이 무시하고 200」으로 시험하고, 「가운데 공백이 다른 입력 → KOS 0건 → 404」 시험을 하나 더한다. Swagger 조회 · 예약 설명에 「공백은 무시한다」고 약속하지 말고 「이름은 KOS 에 등록된 띄어쓰기 그대로 보내야 한다」를 적는다
3. **N3 `syncedAt`**: `sync_state("menu")` 는 작업 하나라도 실패해도 **이전 `last_ok_at` 을 남긴다**(`last_error` 만 갱신 · `set_sync(key, None, …)` 로 덮지 않음). 뜻 = 「메뉴 동기화가 마지막으로 전부 성공한 시각 · 한 번도 없으면 null」. T6 에 「성공 → 작업 하나 실패 → syncedAt 그대로」 추가
