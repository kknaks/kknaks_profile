3. **배정됐고 시작 전 문구** = 「<직군> <이름> 대기 · <단계>」(예: 「원장 권태윤 대기 · 원장 상담」). 칸 안 사람 표시는 진행 중 직원 = 진한 점, 배정 대기 직원 = 「대기 ○○」 흐리게
4. **방에 넣었는데 아무 단계도 배정 안 된 상태** = 「<첫 단계> 대기 · 배정 필요」(손 필요). SPEC §5.1 표에 없는 경우라 정했다
5. **순회형의 손 필요**에 「원장 대기 · 세팅 준비」도 넣었다(SPEC 은 「다음 단계 대기」의 한 갈래로 봄)
6. **배정 목록 = 그 단계 직군 전원**(바쁜 사람 포함, 지금 일을 옆에 표시). 바쁜 사람을 막지 않는다
7. 시술 단계 목록은 **의사 + 피부관리사를 한 목록**에(직군 이름을 옆에)
8. **환자 상세 상단 「상담사 · 원장」 줄 = 관제 배정에서** 뽑는다(KOS 사후 값 아님). 배정이 없으면 줄 숨김. 「내 단계 · ○○ · 대기/진행 중」 한 줄을 버튼 위에 둠
9. **메모 기본 펼침**: 배정형 3직군 모두 ②③ 펼침 · ④ 접힘(SPEC 은 의사만 정함 — 상담사 · 피부관리사도 같게) / 순회형 2직군 ④ 펼침 · ②③ 접힘(② 접힘 때 마취 한 줄)
10. **잠긴 메모는 접기 버튼 없이** 「상담 후 공개」 자리표시. 타 병원 이력도 상담 후 공개(상담 메모에서 오므로)
11. 접수 모달의 ⚠ = 그때 볼 수 있는 것만(고객 메모 · 예약 메모 앞줄). 오더 · 상담 쪽 ⚠ 은 상담 뒤에
12. 「현장 접수」 버튼은 남겼지만 눌러도 시안에서는 안내 토스트만(이슈 3)
13. 배정형 「다음」 행의 시각 = 배정 시각, 「완료」 행 = 종료 시각
14. 귀가 확인 상자는 패널 안에 펼치는 꼴(모달 위 모달 대신)

## 이슈

1. **렌더링 눈 확인 필요.** 특히 확인할 곳: 인라인 `background:{{ … }}` 점 색 · 3단 중첩이 아닌 2단 `sc-for`(메모 굵게 조각) · `disabled` 버튼(접수 · 귀가 처리 · n개 추가) · v4 의 넓어진 방 패널(640px)
2. **재내원 예시가 없다.** 10-09 재내원 고객은 1명(취소, 시술권 없음)뿐이라 「재내원 기본 = 보유 시술권」 체크는 규칙만 있고 화면 예시가 없다. 보유 시술권이 있는 고객(박서윤)은 첫 방문이다
3. **현장 접수** — SPEC 0.2.0 에 언급이 없다. v3 에서는 가짜 고객을 만들었는데 0.2.0(KOS 예약이 원천)과 안 맞아 시안에선 동작을 그리지 않았다. 둘지 뺄지 정해야 한다
4. **[초기화]** — SPEC §3 표 `/desk` 에는 있지만 이번 브리프 §2 그릴 것에 없어서 그리지 않았다
5. 시술 후보의 출처 표기 — 박서윤처럼 KOS 에서 **취소된 작업**의 시술권은 보유 시술권(AVAILABLE)과 같은 장이라 「오늘 결제 시술권 · 순번 n」 으로 한 번만 보인다. 문구를 「시술권」 하나로 줄일지 확인
6. 예약 탭 「시술 - · 원장 -」 가 27행 모두 같다(데이터가 비어 있음 — SPEC 원칙대로). 칸을 아예 숨길지 사용자 확인
7. 통역 모달 상태 파일은 r3 그대로라 샘플 데이터 블록이 옛 꼴(작성자 칸 포함, 화면엔 안 보임)이다
