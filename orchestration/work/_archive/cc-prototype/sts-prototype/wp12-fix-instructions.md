# WP12 — 근거 없는 표시 빼기 · 「예약 메모」 이름 (E2E #27 · #28)

근거: `e2e-feedback-batch-2.md` #27 · #28 (같은 폴더). 사용자: 「근거 없는 거 빼, 그냥 상담사 중에 고르면 되잖아」.

## backend (`cc/back/` 만)
- `mentionedStaffIds` · `riskWords` · `riskHits` 와 그 계산 · `CC_RISK_WORDS` 설정 **삭제**(응답 · README · .env.example · 시험 정리)
- `uv run pytest` · `uv run ruff check .` 1회 · 리포트 `wp12-be-report.md`

## frontend (`cc/front/` 만 — backend 끝난 뒤)
- 셀렉터: 「지정」 배지 · 맨 위 정렬 삭제 → **그 단계 직군 직원 목록 + 지금 일**만(상담 → 상담사 · 원장 상담 → 의사 · 시술 → 의사 · 피부관리사)
- 메모 강조(위험 단어 빨강 · 직원 이름 파랑) **삭제** — 원문 그대로(`**` 굵게만 유지)
- 「접수 메모」 → **「예약 메모」**(방 패널 · 예약 상세 · 직원 환자 상세 전부)
- `npx tsc --noEmit` · `npm run lint` · `npm run build` 1회 · 화면 문자열 「지정」 · 「접수 메모」 0(grep) · 리포트 `wp12-fe-report.md`

공통: 커밋 · push 금지 · KOS 금지 · 사용자 포트(3600 · 8600) 금지. 완료 보고는 각자 지난 브리프의 두 명령(subject 「backend/frontend 완료: WP12 …」, taskId/dispatchId 는 각자 직전 판 것).

## frontend 추가 (#29 — 사용자 캡처)
- 방 패널 동선 단계 줄의 **열 배치를 모든 상태에서 같게**: `[번호] 단계 이름 · 시각 | 담당(셀렉터 — 진행 중 · 완료면 잠긴 이름) | ↑↓ | 상태 배지(맨 오른쪽 끝 정렬)`. 지금 진행 중 줄은 배지가 가운데 · 담당 이름이 오른쪽 끝이라 다른 줄과 어긋난다
- 패널 위 「지정 · 상담사 ○○」 칩도 삭제(#27)

## frontend 추가 (#30 — 사용자 캡처)
- **방 패널 모달 크기 고정**: 화면 비율로 — 너비 약 84vw · 높이 약 85vh(캡처 크기). 내용이 길어도 모달은 안 커진다
- **왼쪽 · 오른쪽 열이 각자 스크롤**(모달 전체 스크롤 금지 — 지금은 오른쪽 메모가 길면 왼쪽 동선이 화면 밖으로 올라가 빈 칸만 보인다)
- **메모 카드 접기/펴기**: 예약 메모 · 상담 내용 · 오늘 오더 · 히스토리 방문 카드 각각 — 기본은 **접힘(첫 3줄 정도 미리보기)** + [펼치기]. 직원 환자 상세도 같은 방식
