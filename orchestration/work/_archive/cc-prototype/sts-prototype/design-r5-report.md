## 내가 정한 것 — 코디가 사용자에게 확인

1. **⚠/지정 요약 칩의 범위**는 화면에 보이는 원문 전부다(예약 · 고객 · 지난 방문 · 오늘 상담/오더 공개 뒤). 문자열 일치라서 **작성자 서명 · 「실장 : ○○」도 「지정」으로 잡힌다.** 예: S7 · S8 예약 메모 끝 「민현우」, S1 상담 메모 「실장 : 류하린」. SPEC #5 규칙 그대로라 걸러내지 않았다
2. **셀렉터 목록**: 「미배정」 → 〈지정〉 → 직군별. 바쁜 사람은 흐리게(0.55) 보이고 선택은 된다(r4 「막지 않음」 유지)
3. 셀렉터는 **팝오버**(단계 줄 오른쪽 아래에 뜸)다. 고르면 닫힌다. 같은 사람을 다시 고르면 아무 일도 없다
4. **후보 칩**은 남은 장 수가 0이면 숨긴다. 칩을 누르면 바로 붙는다(확인 없음, 토스트에 되돌리기)
5. 보유 시술권 **n/m 표기가 두 곳에서 다르다**: 후보 칩 = 동선에 붙인 것을 뺀 남은 수(6/10), 히스토리 · 예약 상세 · 차트 = KOS AVAILABLE 수(7/10, 시술 완료 전에는 차감 안 됨)
6. 오늘 상담 · 오더가 아직 없을 때는 **자리표시 문구 없이 칸 자체가 없다**(메모 원칙 「그 시점에 이미 존재하는 메모만」 + #21)
7. **오늘 담당자 메모**는 동선 줄 대신 「오늘」 카드의 「담당자 메모」 칸에 보인다(SPEC 0-b 1 방문 카드 구성). SPEC 원칙 줄 「오늘 담당자 메모 = 히스토리에만」을 「방문 카드에만」으로 읽었다
8. 방 패널 오른쪽 오늘 칸 이름은 SPEC대로 「**접수 메모**」, 예약 상세에서는 「**예약 메모**」다(원천은 같은 `reservationMemo`)
9. 귀가 모달을 띄우면 방 패널을 닫고(모달 위 모달 회피), [취소]하면 다시 연다
10. 직원 상세 순서를 **동선 먼저**로 바꿨다: 고객 카드 → 오늘 고객 동선 → 오늘(메모) → 지난 방문 → 환자 차트. 「동선이 메인 데이터」에 맞췄다. 「시술 이력」 카드는 지난 방문 카드로 합쳤다
11. 환자 차트 = 유입처 · 보유 시술권 n/m · 오늘 결제([결제 완료] 뒤). 동행 · 예약 그룹 줄은 메모를 잘라 읽던 값이라 뺐다

## 이슈

1. **렌더링 눈 확인 필요.** 특히 볼 곳: 셀렉터 팝오버(모달 `overflow:auto` 안의 `position:absolute` — 아래쪽 단계에서 잘리는지) · 2열 폭(1100px) · 메모 강조 `class` 조각 · 귀가 모달이 방 패널을 대신 띄우는 흐름
2. **S6 귀가 예시**는 장면 시각(12:10)이 예약(15:30)보다 앞선다. 화면 예시용이다
3. **[현장 접수]를 없앴다.** SPEC 0.2.0 · 0.3.0 어디에도 없고 v4에서는 눌러도 내부 안내 토스트만 떴다. 다시 둘지 정해야 한다(r4 이슈 3 이어짐)
4. **예약 탭 「귀가 · 노쇼」 행**은 장면(12:10)에 귀가한 사람이 없어 처음에는 비어 있다. [노쇼] · 귀가 조작으로 채워지는 것은 node로 확인했다
5. **로그인 파일**의 시연 카드는 r4 그대로(피부관리사 안건우 등 10-09 직원)다. 시나리오 직원 14명과 맞추려면 손봐야 한다(이번 범위 밖)
6. **통역 모달 상태 파일**은 r3 그대로다(SPEC §8)
7. 위험 단어 목록은 back 설정(`CC_RISK_WORDS`)의 기본값을 시안 코드에 그대로 박았다. 지점별로 바꾸는 화면은 없다
