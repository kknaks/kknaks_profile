# planner r5 추가 지시 (사용자 10-26)

1. **웹이 정본 · 앱은 나중에 웹에 맞춘다** (`_RESUME.md` §2 10-26 새 줄). SPEC-003 에서 웹/앱 차이(OQ-523 공유 순서 · OQ-526 작업 type · 이번 되돌리기)는 「열린 질문」으로 두지 말고 **「앱 후속 — 웹 기준으로 맞춘다」** 로 정리(§10 에 후속 목록 한 표 · 해당 OQ 는 닫음 처리). SPEC-003 머리말 우선순위에 「웹 계약이 정본, SPEC-004(앱)는 따른다」 한 줄.
2. **KOS 확인**: 되돌리기의 KOS 반영(`change-tasks-complete complete:false` · 시작 되돌리기 · flowStep 되돌리기)은 **데모 지점 실호출 확인이 구현 완료 조건**. WORK-006 에 별도 WP(예: WP-KOS — backend 가 구현 전에 데모 지점에 1회 호출해 응답 · KOS 화면 상태를 리포트로 남김)로 **맨 앞에** 둔다. OQ-528(ETCETERA 호출 · 완료 받는지)도 같은 WP 에서 확인.
