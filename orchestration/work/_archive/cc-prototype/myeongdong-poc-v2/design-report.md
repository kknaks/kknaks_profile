## workflow-v2 와 다른 점 · workflow 에 없는데 시안에 있는 것 (사실만)

1. 헤더 메뉴를 `현황판 | 시술 현황 | 예약관리` 로 두었다 · `current-path=/procedures` · 사용자 칸 「간호 스테이션」 — workflow 에 메뉴 자리 · 경로 · 로그인 계정이 없다
2. 현황판의 [마취 시작 · 종료] 는 **시술 대기 카드에만** 있다. 시술 진행 카드는 마취 줄이 읽기 전용 — workflow 는 「버튼은 현황판과 태블릿 · 폰 양쪽」, 원칙은 「현황판 제어 = 시술 시작 전 · 귀가」
3. [의사 호출] 은 시술 진행 카드에서도 대기 시술이 남아 있으면 활성이다
4. 이미 호출한 시술도 모달 기본 체크에 들어간다(다시 호출 가능)
5. 원장이 콜을 잡은 뒤 대기 시술 줄에는 원장 이름만 보인다(「수락」 같은 표시 없음). 「호출함」 → 수락 전후 구분이 화면에 따로 없다
6. 귀가 대기 카드에 「귀가 대기 14:12」 시각을 적었다 — 출처(KOS `flowStepUpdatedDateTimeUtc` 인지 ccc 기록인지)는 정하지 않았다
7. 입실 시각 · 방은 카드(고객) 하나에 하나로 그렸다 — KOS 는 방이 작업 단위다(`tasks[].room` · `roomAssignedDateTimeUtc`)
8. 카드 상단 「n / m 완료」, 카드 윗선 상태 색, 토스트, 새로 바뀐 카드 강조(1.6초) — 브리프에 없던 보조 표시
9. `all-done` 은 별도 순간이다 — A-룸2 의 남은 시술 완료 시각을 14:22~14:44 로 당겨 그렸다(board 에서는 써마지가 14:38 시작). 다른 카드는 board 와 같다
