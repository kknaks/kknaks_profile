의사 계정 = **원장마다 하나**(DB 에 전원 · 각각 KOS 원장과 연결). PoC 는 그중 **원장 한 명의 로그인 값만** 넣어 쓴다 → 로그인한 계정 = 그 원장 · [수락]은 그 원장 이름으로(원장 고르기 없음 · 나에게 온 호출에만 [수락]). 간호사도 같은 방식(한 명 값만).

걸리는 것(사실): ① 통역 코드는 D-01 상 `procedure/back` 으로 복사 ② 통역 WS 인증이 Origin 만 — 앱은 토큰 확인 필요 ③ Flutter 마이크 PCM16 송신 · 24kHz PCM 재생 · 권한 — 실기기 1회 확인이 완료 조건 ④ Flutter 에 EventSource 없음 — HTTP 스트림으로 SSE 읽기 ⑤ 동의서 · 시술 메모 · 다시 알림 · 간호사 요청은 결정 없음 → PoC 에서 뺀 것으로 둠.

### 9-1. 권한 체크 (사용자 「권한 체크는 중요」)

- **권한은 back 이 조작 API 마다 막는다** — 앱에서 버튼을 숨기는 것만으로는 안 된다
- 로그인 응답 · 토큰에 **역할(어드민 · 의사 · 간호사) + 연결된 원장 id**
- **수락**: 의사 계정은 back 이 `doctorId` 를 **로그인한 원장으로 정한다**(요청 값이 다르면 403). 지정 호출은 지정된 원장만 · 전체 호출은 아무 원장. 간호사 계정은 수락 403. 어드민(웹 의국 화면)은 지금처럼 원장을 골라 수락
- 그 밖의 조작(마취 · 호출 · [시작] · [종료] · 귀가 대기)의 역할별 허용은 기본값 「간호사 · 의사 · 어드민 모두」 — 다르게 하려면 사용자 결정
- 조작 로그 `actor` = 로그인 계정(누가 눌렀는지)
- PoC 의사 계정에 연결할 원장 = **KOS 데모 지점의 실제 원장**(시스템 계정은 원장 목록에서 빠지므로 안 됨)
- 시험: 역할마다 허용 · 거부(403)를 back 단위 시험으로

### 9-2. E2E · 배포 (사용자)

- E2E = **로컬 + 아이폰 + 아이패드**(iOS 만 — Android 없음)
- 사용자 맥북에서 **로컬 빌드 → TestFlight 등록**, 기기는 **TestFlight 초대**로 설치
- 걸리는 것(사실): ① TestFlight 기기는 맥북 `localhost` back 에 못 붙는다 — **기기가 닿는 back 주소**(같은 Wi-Fi 의 맥 IP 또는 배포 https 주소)를 앱 빌드 설정으로 ② iOS 는 http 를 기본으로 막는다(ATS) — https 가 아니면 예외 설정 필요 · 통역 WS 도 같은 주소 규칙(`wss`) ③ 마이크 권한 문구(`NSMicrophoneUsageDescription`) 없으면 통역 불가 ④ TestFlight = Apple 개발자 계정 · 번들 id · 서명. 내부 테스터(App Store Connect 사용자)는 심사 없음 · 외부 테스터는 베타 심사
- **결정(사용자)**: back 주소 = **같은 공유기 Wi-Fi 의 맥 IP**(http · 맥에서 띄운 `procedure/back` 8700)
  - 앱: iOS 로컬 네트워크 http 허용(ATS `NSAllowsLocalNetworking`) · 로컬 네트워크 권한 문구(`NSLocalNetworkUsageDescription`) · 통역은 `ws://<맥 IP>:8700`
  - back: `0.0.0.0` 으로 열기(docker compose 포트 공개) · 맥 방화벽에서 8700 허용 · 맥이 잠들지 않게
  - 맥 IP 가 바뀌면 앱이 못 붙는다 → 공유기에서 맥 IP 고정, 또는 앱에 서버 주소 입력칸(기본값) — 빌드에 박으면 IP 바뀔 때마다 TestFlight 다시 올려야 함
- **결정(사용자)**: 오늘 다 만들면 **최종 back · front 를 ccc 도메인에 배포**(D-03 그대로)
  - 그 뒤 앱은 https 배포 주소로 → 앱 **서버 주소 입력칸(기본값 = 맥 IP)** 으로 두면 TestFlight 다시 안 올리고 바꾼다
  - 배포 쪽 확인: 통역 `wss` · SSE 가 ingress 를 지나가는지(버퍼링 끄기 · 유휴 끊김 시간) · `SONIOX_API_KEY` Secret 추가 · 계정(의사 · 간호사 로그인 값) Secret
