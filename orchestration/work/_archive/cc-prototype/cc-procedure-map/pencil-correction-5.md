# pencil 정정 5 — 2026-11-12 (사용자 지시 · 작업 구조 변경)

사용자: 「워커 하나에 다 맡기니 안 되는 것 같다. 각각 만들고 연결 관계를 맞추자. 코디 - 워커 - 서브에이전트 n. 기본 디자인은 있어야 한다.」

**너는 이제 리드다. 화면을 혼자 다 그리지 말고 서브에이전트에게 나눠라.** 정정 1~4 의 내용(메디킷 디자인 · 컴포넌트 + 인스턴스 · 관문 없음 · 린트)은 그대로.

## 1단계 — 기본 디자인 (리드 혼자, 먼저 닫는다)
- `medikit/components/_lib.js`(이미 시작) + **맵 전체에 쓰는 메디킷 컴포넌트 세트**를 「components」 페이지에 만든다.
- `screens.json` · `edges.json` · `notes.json` 을 56행 전부 채운다(research §1 · §2 기준).
- **레이아웃 계약** `cc-procedure-map/layout.json`: 섹션(기획안 절)마다 「시술현황 맵」 페이지 위 영역(x, y, w, h)과 화면별 슬롯(screenId → x, y, w, h) · 메모 슬롯. 서브에이전트는 자기 영역 밖에 그리지 않는다.
- 섹션 렌더 함수의 꼴(입력: 섹션 id · 출력: 노드 이름 `screen/<screenId>` · `note/<id>`)을 `_lib.js` 에 고정한다.

## 2단계 — 나눠 그리기 (서브에이전트 n, 병렬)
- 섹션 단위로 나눈다: 1 · 2 · 3 · 4 · 5 · 6 · 7+CC 모바일(참고) (절이 크면 더 쪼개도 된다).
- 서브에이전트는 네 Agent 도구(또는 `orca orchestration worker-start --spec` 헬퍼)로 띄운다. 각자 받는 것: 이 브리프 · 정정 1~5 · `_lib.js` · `layout.json` 의 자기 영역 · 자기 섹션 screens/notes.
- 산출물: `cc-procedure-map/sections/<섹션>.js`(자기 섹션 화면 · 메모를 그리는 스크립트). **같은 페이지에 동시에 쓰지 않는다** — 시험 렌더는 각자 임시 페이지 `draft/<섹션>` 에서 하고 끝나면 지운다.
- 서브에이전트도 기획안 · 메디킷 키트만 본다. 기존 시술현황 페이지 · 시안 열람 금지.

## 3단계 — 합치기 · 연결 (리드)
- `render.js` 가 「시술현황 맵」 을 지우고 sections/*.js 를 순서대로 돌린 뒤 **edges(화살표)를 마지막에** 그린다. 고아 엣지 0.
- 린트 정리(정정 4) → `documents save` → 리포트에 서브에이전트별 섹션 · 화면 수 · 소요 시간도 적는다.
