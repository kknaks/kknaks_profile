# pencil 정정 3 — 2026-11-12 (사용자 지시)

사용자: 「컴포넌트까지 다 넣고 가는 거지?」 → **컴포넌트를 만든다.** 정정 2 의 「컴포넌트 라이브러리 안 만들어도 된다(네 판단)」는 이 항목만 뒤집는다. 나머지(관문 없음 · 전체 한 번에)는 그대로.

- 화면에 쓰는 메디킷 요소는 **컴포넌트(세트 + variant)로 만들고, 화면은 인스턴스로** 짓는다. 이름 규칙 · 값 뽑는 법 · 변수 바인딩 · 멱등은 `cc-procedure-map-pencil-components-brief.HOLD.md` §3 · §6-2~4 대로.
- 범위: research §5 의 21종(Chip 제외) 중 **맵 화면에 실제로 쓰는 것 전부.** 「components」 페이지 · 스크립트 `reference/2026-11-12-open-pencil/medikit/components/`.
- 메디킷에 없는 요소(보드 칸 · 타이머 등)는 `custom/` 접두로 토큰만 써서 — 반복되면 이것도 컴포넌트로.
- 리포트에 컴포넌트 세트 목록 · variant 수 · 화면에서 인스턴스가 아닌 직접 그린 요소 수를 넣는다.
