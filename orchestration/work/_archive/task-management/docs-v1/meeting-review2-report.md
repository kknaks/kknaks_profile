## 시안에 없어서 정해야 하는 자리

- **회의 「장소」 필드** — 시안 **L795**(= L1082 · L1232) 메타에 「회의실 A」가 있다. `decision-003` §3 필드 정책(**L44~54**)과 `meeting.md` Entities(**L33**) 에 장소 컬럼이 없다. 시안에만 있고 문서 어디에도 근거가 없다
- **첨부 리소스의 필드 계약** — 시안 **L1169~1187** 은 파일 타입 배지 · 이름 · 용량 · 시각 · **출처 경로**(「자료함 › 소개서 개정」)를 그리는데, `spec-007-meeting-live.md` Data Contract(**L366~371**)에 첨부 리소스 행 자체가 없다. `POST …/attachments`(**L223**) 의 요청·응답 규격도 없다
- **첨부 파일 크기 상한** — 시안 **L1192** 「최대 50MB」. 문서에 값도, 초과 시 에러 코드도 없다(Case Matrix **L289~302**)
- **화자가 3명 이상일 때의 색 배정** — 시안은 2명분만 그렸고(M-21), `meeting.md` **M-10** 은 최대 15명을 전제한다
- **AI 요약 탭에서 프롬프트 바를 감추는지** — 시안 **L1155**(AI 탭)는 프롬프트 바 자리에 48px 안내 푸터를 둔다. SPEC U-3(**L111~120**)은 프롬프트 바가 어느 탭에 속하는지 말하지 않는다
- **사람 줄의 시각 표시가 계약인지** — 시안 **L861·L866·L871·L889·L894·L899** 는 줄마다 우측에 「09:34」를 찍고, 안건 헤더(**L854·L882**)에도 시각이 있다. SPEC Data Contract 줄 필드(**L370**)에 `createdAt` 은 있으나 화면 규격(**L111~120**)에 시각 표시가 없다
- **안건 헤더 체크박스가 조작 가능한지** — 시안 **L850·L878·L906** 은 체크박스로 그렸다. SPEC 에서 안건 상태를 바꾸는 경로는 팝오버의 「다음 주제로」(**L119** · `PATCH` **L261**) 하나뿐이라, 체크박스 직접 클릭이 두 번째 진입점인지 장식인지 정해져 있지 않다

## 판단하지 않은 것

- **탭 밑줄 Ink 가 한 화면에 2개** — 시안 **L835**(좌 패널 회의록 탭)와 **L978**(우 패널 실시간 스크립트 탭)이 둘 다 `border-bottom:2px solid #1E1E1E` 다. SPEC **L87** 은 「선택된 탭의 밑줄이 `#1E1E1E`(위치)이고, **화면당 Ink 는 이 축 하나뿐이다**」인데, 「이 축」이 *탭 밑줄이라는 축 하나*를 뜻하는지 *화면에 밑줄 하나*를 뜻하는지 문장으로 갈리지 않는다. 사이드바 활성 항목(**L777** `background:#1E1E1E`)도 같은 판단에 걸린다
- **메타의 「미팅 · 회의」 2단 표기** — 시안 **L795**. 「종류(미팅) + 동적 유형명(회의)」로 읽으면 정정 A-7(`design-requests.md` **L21**)과 맞고, 폐기된 3종 enum 의 「미팅·회의」 한 값으로 읽으면 어긋난다. 문자열만으로는 어느 쪽인지 정할 수 없다
- **결정 줄 배경(M-15)·안건 기준선 3색(M-16)에서 어느 쪽이 정본인지** — 시안과 디자인 시스템이 서로 다르고, 둘 다 `00-design/` 안의 문서다. 판정은 하지 않았다
- **안건 상태 라벨(M-23)에서 「논의 중」·「진행 중」 중 어느 쪽인지** — 두 화면이 서로 다를 뿐 문서에 라벨 문구 정의가 없다
- **상태 바 파형(M-18)이 회의록 탭 전용인지** — 회의 중 화면(**L813~829**)에는 있고 AI 탭 화면(**L1100**)에는 없다. 의도된 분기인지 시안 누락인지 판단 근거가 없다
- **`GET /api/meetings/{id}/transcript` 복구 경로의 화면 표현** — SPEC **L263~269** 가 새로고침 복구를 정의하고 **L465**(S007-OQ-5)가 아키텍처 미반영을 열어 두었다. 복구 중 화면(스켈레톤·로딩)이 시안에도 SPEC 에도 없으나, 이것이 내 담당 화면의 누락인지 SPEC-006 소관인지 경계가 불분명하다
