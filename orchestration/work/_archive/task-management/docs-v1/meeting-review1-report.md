## 시안에 없어서 정해야 하는 자리

시안에도 문서에도 답이 없거나, 한쪽만 있어 **추측 없이는 그릴 수 없는** 것들.

1. **동적 유형이 4개 이상일 때의 컨트롤 모양** — 시안은 칩 3개 나열(L464~469), SPEC L316 은 「유형 **셀렉터**」를 전제. 유형이 늘면 칩 줄이 넘치는데 그 규격이 없다(M-9)
2. **안건 행 자체의 규격** — 시안 시작 전 화면은 **안건 0개 상태만** 그려져 있다(L601~614). SPEC L132 이 요구하는 안건 행의 hover 「이름 바꾸기」·「삭제」·**드래그 재정렬**이 어디에도 없다(SPEC 자신도 OQ-4 L443 에서 「디자인에 안건 재정렬 규격이 없다」고 적음)
3. **목록 로딩·빈 상태·실패 표시** — SPEC L87~89(스켈레톤 6줄 · 「2026년 8월에 회의록이 없습니다」 + 「이전 달 보기」 · 「다시 시도」)에 대응하는 시안이 없다
4. **행 상태 표시가 들어갈 자리** — 유형 배지가 그 자리(L87)를 이미 쓴다(M-10)
5. **삭제 확인 모달(U-5, 600)** — 시안 없음. SPEC L137~147 이 전부다
6. **1280~1439 반응형** — 시안은 1920 한 벌뿐(L24·L232·L542·L650 전부 `width:1920px`). SPEC U-6(L149~160)이 유일한 근거이고, 그 안의 400~464 출처는 M-2 대로 흔들린다
7. **프리뷰 「원문」 탭의 시작 전·기록 중 내용** — 시안 L162 는 탭 라벨만 있고 눌린 화면이 없다. SPEC 도 OQ-3(L442)으로 열어 둠
8. **회의 취소 행위의 화면** — 시안에 결과(L120~127)만 있고 취소하는 입구가 없다(M-4)
9. **첨부 정렬·개수 배지** — 디자인 시스템 L720 은 「라벨에 개수를 붙입니다(0개면 숫자 생략)」인데, 첨부가 1개 이상인 시작 전 화면이 시안에 없다

## 판단하지 않은 것

- **어느 쪽이 맞는지**는 한 건도 판정하지 않았다. 특히 M-2(프리뷰 폭)·M-6(시작 버튼 자리)·M-16(빈 상태 문구)은 시안이 낡은 것일 수도, SPEC 이 시안을 안 보고 쓴 것일 수도 있다
