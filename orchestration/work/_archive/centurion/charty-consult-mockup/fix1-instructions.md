# frontend 수정 1판 — reviewer FAIL/WARN 처리

먼저 `review-report.md`(같은 폴더)를 읽어라. 아래가 코디 결정이다. 범위는 이것뿐.

## 고칠 것
1. **F-1 AC-11** — 태블릿 연결 판정 tick 500ms · 무응답 판정 4초(ping 2초보다 길게) · e2e timeout **5초**로 되돌림. 최악 지연 계산을 리포트에 적어라
2. **잔주름 오버레이가 얼룩** (AC-21 WARN, 코디 눈 확인 — `screens/overlay-fine-wrinkle.png` 에서 선이 아니라 방울 6~7개) — **blur 로 키우지 말고 선 모양을 유지**하라: 풀해상도에서 **팽창(dilate/max filter)** 으로 선을 굵힌 뒤 축소(축소도 평균이 아니라 max 계열이 낫다). 굵은주름도 같은 방식. 범례 「보라 선 = 찾아낸 잔주름」 그대로 맞게. 위치 불변. **AC-20(모든 쌍 >1%) 은 계속 통과**해야 한다. 전후 스크린샷 남김
3. **W-1 터치 대상** — 태블릿에서 누르는 것(할인 select·무료·삭제·할인율 버튼·칩·필터 칩) 최소 **32px** 높이(SPEC §3-1). 차티 구조·문구는 유지, 크기만
4. **W-2** — 피부 분석 탭 대분류 4칸에 등급 배지 추가 · 항목 측정치는 **2개까지**(SPEC 대로)
5. **W-3** — `setFilter`(어느 쪽에서든) 하면 `focusItem` 을 비운다. 필터·C 강조·B 테두리·A2 가 같은 대상을 가리키게
6. **테스트 빈틈** — AC-15 큰 화면 필터 7개 전부 순회 + 태블릿 `-1` 검사 추가 · AC-16 큰 화면 정규식에 「좌/우」 포함
