## 1. 카드 새 모양 (U-1·U-3·U-4)
```
┌──────┬─────────────────────┐
│ 부위  │ 눈가/눈밑  관리 시작 │   머리: 왼쪽 부위 확대 사진(정사각) + 부위명·등급·대표 점수
│ 확대  │ 눈물고랑 61.4        │
├──────┴─────────────────────┤
│ [보톡스][필러][스킨부스터]… │   시술 탭 한 줄 — 작은 글씨(지금 칩보다 확실히 작게), 넘치면 가로 스크롤(줄바꿈 X)
├───────┬────────────────────┤
│ 사진  │ 보톡스              │   선택 시술: 왼쪽 [사진 자리] + 오른쪽 이름·간단 설명 2~3줄(말줄임)
│ 자리  │ 근육을 일시적으로…  │
│       │           [자세히] │   [자세히] → 기존 procedure-modal
└───────┴────────────────────┘
```
- **탭**: 카드마다 첫 탭 기본 선택. 탭 클릭 = 설명만 교체(모달 안 열림). 선택 탭 표시 분명하게
- **간단 설명**: Hub 스냅샷에서 — 모달 머리의 한 줄 요약에 쓰는 값이 있으면 그것, 없으면 `overview` 앞부분. 상향 대체(modality 값)면 모달과 같은 「◯◯ 전체 기준」 표시. 출처 필드를 리포트에 적어라
- **사진 자리(U-3)**: 제품/기기 사진 원본이 없다. **자리표시만**(회색 박스 + 아이콘/「사진」 글자). 나중에 이미지 경로만 넣으면 되게 데이터에 `image?: string` 자리를 둔다
- **부위 확대 사진(U-4)**: 우리 3D 텍스처에서 잘라 쓴다
  - 앵커 6점의 텍스처 UV 를 구한다(`pickAt`/raycast 의 `uv` — `face-anchors.ts` 에 uv 를 같이 저장하거나 런타임 계산). 그 UV 둘레 정사각형을 `public/m3d/tex/*.jpg` 에서 CSS `background-position/size` 또는 canvas 로 잘라 보여 준다. **잘라낸 이미지를 파일로 저장·커밋하지 마라**(본인 얼굴)
  - 현재 필터의 텍스처를 따라간다(자연광/냉광/붉은기/색소/UV). 오버레이(주름·모공 선) 합성은 되면 하고, 어려우면 텍스처만 — 리포트에 적어라
  - flipY·좌우 반전 주의(이전 SPEC §6 좌표 주의점). 잘린 자리가 앵커 부위와 맞는지 스크린샷으로 확인
  - 측정값/에셋 없음·`anchorsUsable=false` 면 회색 자리표시
- 흐린(dim) 카드에서도 탭·[자세히]는 동작

## 2. 카드 선택 (U-2)
- 카드(빈 곳 포함) 클릭 = 그 카드만 strong, 나머지 dim(지시선 포함). 같은 카드 재클릭 = 해제. **필터를 누르면 카드 선택 해제**
- 3D 필터는 바꾸지 않는다. 태블릿 동기화 없음(큰 화면 로컬 상태) — 단, 태블릿에서 필터가 바뀌어 오면 카드 선택 해제
- 탭·[자세히] 클릭이 카드 선택을 같이 일으켜도 된다(같은 카드). 선택된 카드는 테두리 등으로 표시

## 3. 검수 보류분 (code-review-report §7)
- **W-5** 흐린 지시선이 안 보인다 → dim 선·점 opacity 0.45 이상 또는 점선. 「피지 세균」 필터(6장 dim)에서도 선이 보이게
- **W-6** 모달: 「◯◯ 전체 기준」 글씨 대비 올림 · 내용이 넘치면 아래 페이드 등 스크롤 신호 · 닫기 버튼 크게(1920 화면 기준)
- **W-7** 카드 아래 빈 공간 → 위 새 카드 모양으로 채운다. 긴 지시선(이마/미간·피지)은 무릎 위치·앵커 자리 조정으로 덜 가로지르게(카드 칸 순서는 바꾸지 마라)
