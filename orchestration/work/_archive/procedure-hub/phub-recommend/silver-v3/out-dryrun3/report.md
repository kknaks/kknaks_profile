## 0. 3차 규칙을 기계로 옮긴 방식(2차와 다른 곳만 · 나머지는 2차 report §0 그대로)

- **판정 순서** T3 → T4 → N2 → T1 → N1 → R2(+N4) → N3 → R1 → R3 → R4 → S · 겹치면 먼저 적용된 규칙에 센다(1·2차와 같은 관례). 7차 노드 하나의 자리들 중 7차 이름이 하나라도 그대로 서면 「남음」.
- **어절 종류(word_kind)** — 어절마다 마지막 어미로 가른다(뒤 기호·접속 조사 JC 는 떼고 봄). `N1` = 용언 어간 + -ㅁ/-음(ETN·EF)로 끝남(뒤에 명사·접미 「감」만 허용 — 「따가움감」) · `ETM` 관형형 · `ADV` 「-게」 부사형 · `CLAUSE` = 용언 + 연결 어미(EC · 「-게」 뺌)·종결 어미(EF · -ㅁ/-음 뺌)·「-기」 · `ARG` = 격조사(JKS·JKO·JKB)로 끝나는 어절(N1+격조사 「막힘으로」 포함). 어절 안 보조 용언 연결(「붉어짐 = 붉/VA+어/EC+지/VX+ᆷ」·「어색해지는」)은 마지막 어미로만 본다. VCP(「일시적인」)는 관형형·부사형일 때만 용언으로 본다(2차처럼 종결·연결은 용언 아님).
- **N2 문장꼴 = 절이 있을 때만** — 멤버에 `CLAUSE` 어절이 있거나, `ETM`·`ADV` 어절 앞에 `ARG` 어절(그 용언의 논항)이 있거나, `ETM` 의 뒤 어절 머리가 의존명사(NNB · 그 어절 내용이 의존명사 하나일 때만 — 「거상 → 거/NNB+상/XSN」은 아님) 또는 「현상·느낌·증상·경우」(발주서 예 그대로 · 넓히지 않음)일 때. 나머지 `ETM`·`ADV` 어절은 **관형어·부사어 하나 = 수식어** → R1 목록에 없으면 「R1 후보(새)」로 떼고 따로 셈(§3.4). 여러 수식어가 겹쳐도(「일시적인 가벼운 따가움」) 절이 없으면 수식어. R1 목록 말(「심한」「경미한」…)은 2차처럼 판정에서 뺀다. 2차와 같게 **멤버 단위**로 읽는다 — 「시술 중 당기는 느낌과 냉감」은 멤버에 절(당기는 느낌)이 있어 「냉감」 토막도 (b).
