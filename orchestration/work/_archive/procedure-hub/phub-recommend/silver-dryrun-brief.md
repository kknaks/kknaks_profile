# 드라이런 발주 — 묶음5 432자리를 규칙으로 얼마나 닫히는지 세기 (2026-11-05)

읽을 것(순서): `HANDOFF-2026-11-05.md` → `ERD-FROZEN.md` v3.2 절 → `silver-v3/README.md` → `silver-v3/out/gate/batch5.md` 앞부분.

## 목적
`silver-v3/out/gate/batch5.json`(432 자리 = 새 사건 노드 260 · ⑦ strong 96 · 씨앗 61 · 묶음3 15)이 아래 규칙을 넣으면 몇 자리가 기계로 닫히고 몇 자리가 남는지 **센 값**으로 보고한다. 결정이 아니라 **드라이런**이다.

## 절대 규칙
- `silver-v3/out/`·`decisions/`·`baseline/`·`build.py` 기본 경로·ERD 파일(`erd-v3.2*`)·브론즈를 **수정하지 않는다**. 7차 산출물이 바뀌면 실패다(끝에 `python3 build.py && python3 check.py && python3 tests/run_tests.py` 로 7차 그대로임을 확인하고 determinism key 가 `baseline/manifest-7차.json` 과 같음을 보인다).
- 드라이런 코드는 `silver-v3/dryrun/` 아래에, 산출은 `silver-v3/out-dryrun/` 아래에만 쓴다. 기존 lib 를 import 해서 쓰되 고치지 않는다(필요하면 dryrun 폴더에서 감싸거나 복사).
- 추정 매칭 금지. 아래 규칙 밖의 동치(홍조=홍반 등)는 절대 적용하지 않는다.
- 수치는 센 값만. 추정이면 「추정」이라 쓴다.
- 게시·커밋·아티팩트 금지. 보고는 `silver-v3/out-dryrun/report.md` 한 파일과 종료 메시지.

## 적용할 규칙(사용자 승인 · 2026-11-05)
R1 **정도·경과·빈도 수식어는 사건이 아니다.** 사건 노드 이름 앞뒤의 수식어(장기간·장기적·임시·일시(적)·지속(적)·영구(적)·중등도·중증·심한·경미(한)·과도(한)·이상·불규칙·미세(한)·약간(의)·광범위(한)·초기·드문·높음·증가·덜 …)를 떼어 R15 속성(course/qualifier_text)으로 보낸다. 목록은 **원장 전수에서 실제로 사건 핵심어 앞뒤에 붙은 말을 뽑아** 만들고 report 에 표로 싣는다(이미 있는 stopwords 138 과 합집합 · 새로 추가된 말마다 원장 횟수).
R2 **구조·부위 말은 부위 칸이다.** 사건 앞에 붙은 신경·하악변연신경·안면신경·감각신경·눈·안구·결막·눈썹·눈꺼풀·표정근·근육·두피·피부·진피·혈관·전신·표면·주사 부위·시술 부위 는 site 로 보낸다(이미 사전에 있으면 그 값, 없으면 드라이런용 임시 site 값으로 — 임시 값 목록을 report 에 표로. 실제 사전 추가는 사용자 승인 뒤 dictionary_add). 「신경 손상」→ (손상, 신경) · 「혈관 손상」→ (손상, 혈관) 이 같은 꼴이 되어야 한다.
R3 **원장에 그 말 하나로 쓰인 적이 0회인 핵심어는 노드가 아니다.** R1·R2 를 적용한 뒤에도 단독 출현 0 이고 더 긴 말의 조각일 뿐이면(손상·반응·자극·표정·감각·알레르기·약화·마비·염증·합병증·최소·실의·CO2·눈썹·주름 류) 노드로 세우지 않는다. 단, R1·R2 적용 뒤 남는 핵심어가 사건이면 그것이 노드다(「혈관 손상」의 손상은 R2 뒤 사건 「손상」 — 이 경우 「손상」은 단독 노드가 **된다**. 즉 R3 는 「분해 뒤에도 아무 문구의 사건 칸을 차지하지 않는 토막」만 버린다 — 버린 토막은 보존 목록에 남긴다).
R4 **괄호 병기는 동의어.** 원장이 「안검하수(눈꺼풀 처짐)」처럼 괄호로 나란히 쓴 쌍은 같은 사건(ERD 병기 쌍 106 과 같은 처리).
**가정 S(사용자 지시 · 세어 보기 위한 가정 · 결정 아님)**: ⑦ 접미사 규칙 쌍(suffix_감 14 · suffix_증 4 · suffix_형성 5 = 23쌍)은 **전부 같다**고 놓는다. 자모(jamo1 3쌍)는 같다고 놓지 **않는다**(박피≠박리 · 자국≠자극).
