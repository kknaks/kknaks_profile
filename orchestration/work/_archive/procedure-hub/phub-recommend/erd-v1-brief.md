## 3. 층의 경계 (확정)
- 브론즈 = 원장 21개 그대로. 바이트 보존, 수정 금지. 파일 SHA256 이 식별자. 스냅샷 2026-10-26.
- 시맨틱 = 이 ERD + 값 사전. 문서이며 사용자 승인이 정본 조건. 버전으로 개정.
- 실버 = ERD 를 따르는 정규화 레코드. **모든 값은 원장 파일·키 경로 출처를 가진다.** 출처 없는 값 금지.
- 골드 = 실버 조합 뷰. 실버에 없는 사실을 만들지 않는다.

## 4. 개체 기준 (확정)
- 개체 = 독립적으로 세고 식별할 수 있는 것. 최소 포함: 제품 · 계열 · 부위 · 기법 · 단위 시술 · 고민 · **부작용(합병증)** · **금기 조건(사람 조건)** · 문헌 인용. 설명문 · FAQ · 가격 · 환자 교육문은 속성.
- **부작용은 독립 개체.** 시술·계열·제품·부위와 엣지로만 연결. 등급·발생률·시기·대처는 개체 속성 또는 엣지 속성. 원장에서 흩어진 complications · literature adverse_effects · consent-checklist · post-procedure-timeline · pih-risk · extracted safety 를 전부 이 개체로 모은다.
- **충돌(conflict) 과 결정(decision) 도 개체.** 충돌 = 같은 사실에 원장 값이 다를 때 기계가 남기는 레코드(대상·값들·출처들·해결 규칙·상태). 결정 = 사람이 판정한 레코드(무엇을·왜·누가·언제·적용 대상). 원장은 안 고치고 결정만 쌓는다.
- 식별자 = 결정론 새 ID (타입 접두 + 정준 이름 해시 또는 일련). 원장 id·이름·코드는 전부 `aliases` 로 보존.
- 「같은 것」판정 = 정규화 완전 일치 + 사전 동의어만 자동. 유사도·추측 매칭은 충돌 후보.
- 시술 = 무엇을(계열/제품) × 어디에(부위) × 어떻게(기법) 의 가장 작은 행위 단위. 패키지는 단위 시술 묶음. 목적은 고민→시술 엣지.
- 시너지·순서·간격·시술간 금기는 **시술↔시술 엣지 하나의 속성**.

## 5. 품질 · 충돌 규칙 (확정)
자동 확정: ① 정규화 완전 일치 병합 ② 사전 동의어 병합 ③ 형식 교정(타입·단위·날짜) ④ 신뢰 순위로 풀리는 충돌 ⑤ 빈값 = null(추측 보완 금지)
자동 탐지·표시(사람은 목록만): ⑥ 순위로 안 풀리는 값 충돌 → 충돌 개체, 실버에 둘 다 보관, 골드 제외 ⑦ 유사도만 높은 중복 후보 ⑧ 사전 밖 값 → 「사전 미등록」 격리 ⑨ 참조 깨짐
사람만: ⑩ 임상 내용의 참·거짓 (⑥~⑨ 목록만 봄)
빈값과 「없음」 구분: 안 적힌 것 = null(미입력) · 명시적으로 없다고 적힌 것만 빈 목록.
단계 끝 = 컬럼 행선지 미정 0 · 충돌 미판정 0.

**원장 신뢰 순위** (충돌 자동 해결용 · ERD 에 파일별로 명시)
1. literature-evidence.json (PubMed 인용 있음 · 단 계열 17 단위뿐 · 파일 스스로 「전문의 검토 별도 필요」 명시)
2. 식약처 허가 정보 (products.json mfds 등 공식 원천 필드)
3. 사람이 적은 원장: taxonomy · products · market-pricing · problem-packages · problem-combos · procedure-profiles · synergy · treatment-sequence · pih-risk · contraindications · consent-checklist · pre-procedure-checklist · patient-education · combo-recipes · procedure-comparison · extracted
4. 3-AI 컨센서스 표시 파일: anatomy-danger-zones · post-procedure-timeline · treatment-optimization · complications (파일 안 「교과서」표현은 AI 합의 라벨이지 실제 교과서 아님)
파일 성격이 3·4 어디인지는 원장의 source_method·consensus_method 키로 판단해 ERD 에 근거와 함께 적는다. 확신 없으면 3 으로 두고 표시.
