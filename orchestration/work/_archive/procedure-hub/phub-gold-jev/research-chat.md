### 1-2. SDK 캐시 적중 조건(스킬 `shared/prompt-caching.md` · 공식 prompt-caching 문서)

| 조건 | 값 |
|---|---|
| 무엇이 접두가 되나 | `tools` → `system` → `messages` 순서로 그린 글자. 표시(`cache_control`)한 블록까지가 한 덩이 — **앞에서 한 글자라도 바뀌면 그 뒤는 전부 미적중** |

| 값 | 쓰기 1.25×(5분) · 읽기 Sonnet 5.5 0.05×($0.10 / 백만) · Haiku 5.5 0.1×($0.01 / 백만) |
| 표시 수 | 요청당 4 개까지 · 요청 맨 위에 `cache_control` 을 주면 마지막 블록에 자동으로 붙고 대화가 자라면 따라 움직인다 |
| 깨뜨리는 것 | 시스템 프롬프트에 시각 · 세션 id 넣기 · 정렬 안 된 JSON · 모델 바꿈 · 추론 / effort 설정 바꿈(메시지 캐시가 깨짐) · 앞 메시지 고치기 |
| 확인하는 법 | 응답 `usage.cache_read_input_tokens` 가 0 이 아닌지 |

### 4-3. 템플릿 · 조각 · 스트리밍

- **Jinja2 는 `uv.lock` 에 없다** — 쓰려면 의존을 더한다. 안 쓰면 `html.escape` 로 손수 잇는다(조각 셋이라 가능은 하다). 폼 본문을 받는 `python-multipart 0.0.33` 과 `sse-starlette 3.7.0` 은 `uv.lock` 에 딸려 와 있으나 `pyproject.toml` 의 직접 의존은 아니다.
- 한 턴의 꼴(제안):
  1. 보내기 → 서버가 곧바로 「내 말풍선 + 빈 답 말풍선」 조각을 돌려준다. 빈 답 말풍선이 그 턴의 SSE 에 붙는다.
  2. 허브 읽기가 끝나면(약 0.5초) **시술 목록 조각 · 얼굴 점 조각**을 SSE 로 보낸다 — LLM 을 기다리지 않는다.
  3. LLM 글자 조각을 답 말풍선 끝에 덧붙인다.
  4. 끝 이벤트로 닫는다.
- 세 칸을 한 응답에서 갈아 끼우는 htmx 길은 「자리 밖 바꾸기」(`hx-swap-oob`)이고, SSE 는 htmx 의 SSE 확장(`sse-connect` · `sse-swap`)이다. **이 조사에서는 htmx 문서를 열어 확인하지 않았다 — 확인 안 됨**: ① SSE 로 온 조각 안의 `hx-swap-oob` 가 처리되는지 ② SVG 안의 요소(`<g>` · `<circle>`)를 조각으로 갈아 끼울 때 제대로 그려지는지(안 되면 SVG 를 감싼 `<div>` 통째로 바꾼다) ③ 판 번호. 구현 첫 걸음에서 빈 화면으로 확인할 것.
- 글자 조각은 HTML 이스케이프를 해서 보낸다(답에 `<` 가 들어올 수 있다).
- htmx 싣기: CDN(판 고정 주소) / 로컬 파일. 로컬 파일은 오프라인에서도 돌고 판이 안 바뀐다 — 라이선스 글을 함께 둔다(라이선스 종류는 확인 안 됨).
- 화면 문구는 넣지 않는다 — 조각에는 자리와 값만.
