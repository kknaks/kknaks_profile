# SPEC-006 — 상담 채팅 0.3

경로 접두어: `$W` = 이 폴더 · `$A` = clinic_chat 워크트리 `phub-gold-jev`(읽기만 · HEAD `68a31b1` = 0.1 + 수정 1 + 0.2) · `$SM` = `orchestration/work/_archive/procedure-hub/phub-ledger-redesign/silver-model`(gitignore · 로컬).
「지시서」 = `$W/spec-chat-v03-instructions.md` · 「0.1」 = SPEC-004 · 「0.2」 = SPEC-005 와 그 구현 · 「장부」 = `$A/runs/consult/turns.jsonl` · 「재셈」 = 이 워커가 `$SM` 의 CSV 로 다시 센 값(허브 · Jev · CLI 를 부르지 않았다).

이 문서에는 비밀값 · 키 · 내부 주소가 없다. Procedure Hub 데이터(코드 · 이름 · 행 수)는 공개 정보라 적었다.

프롬프트 문구는 전부 **초안**이다(사용자 확인 — U6-2).
