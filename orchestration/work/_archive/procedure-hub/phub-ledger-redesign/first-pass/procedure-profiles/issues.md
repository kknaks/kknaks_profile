# procedure-profiles.json — 미결 기록 (1차, 보정판)

> 2026-11-09 보정: 독립 검토 리포트 F1~F7 반영. 처리 내역은 [보정 리포트](../../procedure-profiles-correction-report.md).
> 보정 뒤 독립 재검토는 **아직 없다.**

분류는 [스킬](../../ledger-first-pass/SKILL.md) §5와 재개 노트의 세 갈래를 따른다.
- **A** 조사·추출 오류: 에이전트가 먼저 해결한다.
- **B** 원문 정보 부족: 무엇이 없는지와 제한되는 활용만 남긴다. 사용자에게 사실을 추측해 정하라고 묻지 않는다.
- **C** 사용자 결정 필요.
- **후속**: 원문에 판단 재료가 있고 후속 의미 조사에서 해석할 항목. 해결로 세지 않는다.

상태 표기는 다음과 같다.
- `표시됨`: 오류를 출현 단위로 표시했다. 교정한 것은 아니며 원시 Kiwi 토큰은 그대로다.
- `기록됨`: 열린 채로 둔다.
- `잠정`: 에이전트가 원문 근거로 해석 후보를 붙였고 후속 확인이 필요하다.
- `후속`: 후속 의미 조사로 넘겼다.
- `보류`: 결정이 필요한 시점까지 미뤘다.

**사용자 결정은 받지 않았다.**
