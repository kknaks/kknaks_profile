# combo-recipes.json — 미결·한계 기록 (1차)

상태 문자: **A** 에이전트 추출/해석 오류 · **B** 원문 정보 부족 · **C** 현재 사용자 결정 필요 · 보조 **K** 알려진 분석 한계 · **P** 잠정 · **F** 후속 의미 조사 · **I** 원문 내 불일치.
「원문 보존」만으로 닫은 항목은 없다. B·P·F·I 는 **열린 상태**로 남는다.

## 0. 처리 상태 요약

| 상태 | 건수 | 처리 |
|---|---|---|
| A | 4 | 4 모두 수정·재검증 완료(§1) |
| B | 10 | 열림 — 원문에 정보가 없다. 외부 자료로 채우지 않았다 |
| P | 8 | 열림 — 근거 위치를 붙인 잠정 해석. 확정 데이터로 쓰지 않는다 |
| F | 7 | 열림 — 원장 간 비교·의미 모델 단계에서 판단 |
| I | 1 | 열림 — 원문 안에서 맞춰지지 않는 서술. 원본은 고치지 않았다 |
| K | 14규칙(출현 29) + 태그 비일관 5형 + 필드명 1 | 기록 완료 — 형태소 출력은 교정하지 않음(§6) |
| **C** | **0** | 아래 근거로 0 |

**C 가 0인 근거 (잔여 항목 영향 검토 후):** B 는 원장에 없는 정보라 사용자가 고를 선택지가 아니라 출처 확인 과제다. P·F 는 원장 간 비교(특히 M 코드가 가리키는 원장) 뒤에 판단할 의미 과제이고, 지금 선택을 받아도 근거가 늘지 않는다. I-1 의 원본 수정 여부는 현재 「원본 보존」 지시 아래 후속 확인 후보이며 지금 선택 대기로 올리지 않는다. 도구·분할·정규식 같은 수집 방법 판단은 에이전트가 정했다(§7). 따라서 이 원장 1차 수집을 진행하는 데 지금 필요한 사용자 결정은 없다. 이것은 「미결 없음」이 아니다.

출현별 Pointer·구간·원시 토큰은 `morphology.json` → `segmentation_flags`(29건), 규칙은 `segmentation-review.json`.

- 태그 비일관(표면·구간은 정상): 보톡스·스킨부스터·필러·유지·토닝이 출현마다 NNG/NNP 로 갈린다(`morphology.json` → `tag_inconsistency`).
- 필드명: 영문 camelCase 라 Kiwi 가 SL 한 토큰으로만 낸다. 대소문자 경계 분할(`rule_split_not_kiwi`)은 Kiwi 출력이 아니다.
- 이 표 밖 토큰의 형태소 정답을 전수 검증했다고 주장하지 않는다. 961 토큰은 값마다 원문과 나란히 열람했고(§validation 3), 의미 영향이 있는 것만 규칙으로 남겼다.

## 7. 에이전트가 정한 수집 방법 (사용자 결정 아님)

- 구획: 상위(S0) + 레시피당 1구획(S1~S7). 원장이 6,486 bytes 라 더 쪼개지 않았다.
- 형태소 제외: version·updated·id·goal(영문 코드)·procedures(M 코드) 35값. goal 은 영문 단어이지만 코드값으로 쓰여 제외했고 원문은 source-map·review 에 그대로 있다.
- 문장·구 분할 정규식, 숫자·단위·기호·키워드 정규식, 형태소 기반 수식·조건 어절 후보 — 방법은 expressions.json `methods`. 기계 후보이며 전수 의미 해석이 아니다.
- 사용자 사전 미사용(브리프: 기본 결과 보존).
