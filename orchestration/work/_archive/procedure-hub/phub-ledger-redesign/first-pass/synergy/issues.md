## A'. 알려진 형태소 분석 오류 (표시됨, 교정 아님)

[review.md §7.1](./review.md) 표와 morphology `segmentation_review`(391출현: issue 253 · ok 138)·`pos_review`(135출현: issue 10). 주요 영향:

- 명칭 분절·동사화: 필러(`M2-필러`), 더블로, 볼뉴머, 인모드, 써마지(timing), 울쎄라, 리쥬란, 쥬베룩, 슈링크, 올리지오. → 형태소만으로 명칭을 세면 누락·오탐.
- 허위 부정·수식: 써마지 → `말다/VX`(부정 오탐 2), 실로 → `실로/MAG`(부사 오탐 6, 시술 수단 소실).
- 수량 오탐 위험: 코드 접두 `M\d+-` 의 숫자 171출현, `CO2` 의 2 8출현, `열부하` 의 열/NR 1.
- 수식 소실: `자가` → 자/NNB+가 2출현, `통한 전달` → 전/MM+달 1출현(금지 대상 핵심어), `둘 다` → 두/VV 1출현.
- 동형어: `동안` 6출현(童顔/시간 구분 불가).
- 기본형 미제공: `에 한해`(한하다) 1출현.
- **범위 밖**: NNP/NNG·VA/VV 구분, 위 규칙 밖 명사 분절의 정확성은 출현별로 판정하지 않았다.
- **알려진 한계 추가(batch-01 독립 묶음 검토 §3.5):** `/links/55/reason` [35,37) 「전층」(「… = 전층 관리」) → 원시 토큰 전/MM [35,36) + 층/NNG [36,37). 全/前 혼동 유형이고, 전/MM 이 수량·지시 관형사로 오인될 수 있다. 토큰은 **교정하지 않았다**(원시 Kiwi 출력 그대로). `morphology.json` 은 바꾸지 않았다 — 이 출현은 구절 규칙(`segmentation_review`)에 없고, `pos_review` 에 작성자 판정 `verdict: ok`(note 「'전층'의 전(全) 관형사(#55)」)로 남아 있다. 그 판정은 지우거나 고치지 않고, 검토가 이 분절을 알려진 한계로 본다는 점만 여기 함께 적는다. 깊이·범위 표현을 형태소로 세면 「전층」이 한 낱말로 잡히지 않는다(원문은 reason 값·표현 후보 구간에 보존). complications 의 같은 유형(「전층」)과 같은 규칙으로 처리할지는 후속 원장 간 비교에서 정한다.

## U. 원본 수정 관련 후속 검토 후보 (현재 사용자 선택 대기 0)

두 건 모두 **원장(브론즈) 원본을 고칠지**에 관한 것이다. 원본 수정은 사용자 권한이고 이번 작업 범위 밖이라, 에이전트가 정하지 않았다. 1차 수집 결과에는 영향이 없다(원문 그대로 기록함).

**재분류(batch-01 독립 묶음 검토 §3.5 반영 · 코디 확인 전):** 처음에는 「사용자 결정 필요(선택 대기)」로 적었다. 사용자가 이미 원본·기존 작업 보존을 지시했고(재개 노트 §2), 아래 추천안 (a) 「원본 유지·후속 판단」이 그 지시와 같으므로 지금 다시 고를 것이 없다. 그래서 두 건을 **후속 검토 후보**로 옮긴다 — **U1 → F1(관계 방향, LO01~LO04) 후속 의미 검토 후보**, **U2 → 실버 변환 규칙 검토 후보**(접두를 같은 link 의 category 와 대조해 분리). U 번호·원문·이유·선택지·영향은 재분류를 추적할 수 있게 아래에 그대로 둔다.

- 이 재분류는 **삭제·수정 승인이 아니고, 관계 방향 확정도 아니며, 사용자 결정을 받았다는 표시도 아니다.** 원본은 사용자 지시대로 보존한다.
- README 와 원본 중 어느 쪽을 맞출지(U2), `/links/54` 를 지우거나 고칠지(U1)는 **실제 원본 수정 제안이 필요해질 때만** 원문·이유·선택지와 함께 사용자에게 올린다.
