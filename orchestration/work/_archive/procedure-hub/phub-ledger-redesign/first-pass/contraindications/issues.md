# contraindications.json — 미결·한계

> **1차 범위 종료: 예(코디 확인 전)** · **원장 전체 완료 아님**. 현재 사용자 선택 대기 **0** — 아래 항목을 하나씩 처리 상태·영향으로 검토한 뒤의 값이며, 미결이 닫혔다는 뜻은 아니다.

분류: **A** 에이전트 추출/해석 오류 · **B** 원문 정보 부족 · **C** 현재 사용자 결정 필요 · 보조 **K** 알려진 분석 한계 · **P** 잠정 해석 · **F** 후속 의미 조사 · **I** 원문 내 불일치. 원본 변경 제안은 원본 보존 지시 아래 후속 확인 후보일 뿐 선택 대기로 올리지 않는다.
