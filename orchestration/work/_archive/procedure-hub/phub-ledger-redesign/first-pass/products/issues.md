# products.json — 미결·알려진 오류 기록 (1차)

분류: **A** 추출 오류(에이전트가 해결) · **K** 알려진 형태소 분석 오류(표시, 교정 아님) · **B** 원문 정보 부족 · **P** 잠정 해석 · **F** 후속 의미 조사·연결 · **C** 사용자 결정 필요.
잠정 관찰 원문은 `review.md` §4(O01~O28), 근거 Pointer 도 거기 있다. 이 문서의 어떤 항목도 확정 데이터로 쓰지 않는다.

## 요약

| 분류 | 건수 | 상태 |
|---|---|---|
| A 추출 오류 | 3 | 전부 해결·재검증 |
| K 알려진 형태소 오류 | 32출현(`segmentation-review.json` K00~K31) | 표시됨(교정 아님) |
| B 원문 부족 | 7묶음 | 열림 — 원문으로 닫을 수 없음(B5 는 외부 사실 확인 과제, B6 일부는 후속 해석 과제 병기 · 번호·건수 유지) |

| C 사용자 결정 | 0 | 아래 근거 |

| A2 | review.md 의 묶음별 category_id 말단 값 10개가 표 행에 없었다(제목에만 있음). verify 의 말단 값 대조가 8건 FAIL 로 잡음(나머지 2건은 §2 예시 칸과 같은 문자열이라 통과했었다. 이후 verify 대조 범위를 §1·§3 로 좁혀 이 한계를 없앰) | 묶음 표 첫 행에 `category_id`(배열은 원소별) 행 추가 | review 말단 행 338/338, failure 0 |

## K. 알려진 형태소 분석 오류 — 표시됨(교정 아님)

작성자가 `morphology.json` 적용 225값의 **전 토큰 558개를 한 번 직접 열람**해 찾은 것이다. 여기 없는 토큰의 정답은 보장하지 않는다(별도 검토자 없음). 출현별 Pointer·구간·원시 토큰·영향은 `segmentation-review.json`.

| 묶음 | 출현 | 대표 | 영향 |
|---|---|---|---|
| 고유명 과분절 | 휴젤 5(K00~K04) · 메디톡스 2 · 볼뉴머 · 인모드 2 · 에버라인 | 휴/NNP+젤/NNG | 제조사·제품명 토큰 매칭 불가. '볼'·'디톡스' 같은 일반어 오탐 |
| 고유명 오분석(조사·용언·대명사 복원) | 제테마(저/NP+의/JKG) · 벨로테로(…로/JKB) · 벨피엔(…에/JKB+ㄴ/JX) · 채움(채우/VV) · 더채움 | 원문에 없는 형태소·기본형(저, 채우다) 생성 | lemma 를 도메인 이름으로 쓰면 오류 |
| 길이 0 서술격 복원 | 리쥬란 3 · 울쎄라 · 아이닉 — 이/VCP span [2,2) | 원문 구간 0 | 표면형 빈 문자열 토큰 5개(verify `zero_length_tokens` 5). 토큰 수를 글자 수로 세면 어긋남 |
| **수식어 오탐** | 더채움 '더'/MAG (K10) | 제품명 접두가 비교 부사로 | 수식어 수집에서 비교 표현으로 잘못 잡힘. manual 표현 M145 에 '비교 수식어 아님' 표시 |
| **전문어 오분절** | 경피 → 경/NNG+피/NNG (K21·K23, legal_warning 2값) | 전달 경로 표현 소실, '피' 오탐 | 표현 기록 '경피 전달'(route) 로 구절 보존 |
| 어미 오태깅 | '없음' 의 음/EF (regulatory_status 2) · 채움 ᆷ/EF | 부정 '없/VA' 는 보존 | 경미 |
| 품사 오태깅·불일치 | 매핑/NNP · 키트/NNP 3 · 보톡스 NNP(note) vs NNG(name) · '제조사' 같은 값 안에서 제조+사 / 제조사 | 품사·분절로 같은 말을 묶으면 어긋남 | 경미 |
| 분해(정오 판단 보류) | 초음파 → 초/XPN+음파/NNG | 의미 손실 미확인 | 기록만 |

부정·한정·가능성 형태소는 보존을 확인했다: 아니/VCN(description·note·legal_warning), 만/JX(regulatory_status·legal_warning '로만'), 없/VA, 있/VA+으며(소지가 있으며), 등/NNB, 시/NNB, 후/NNG, -어야 하(의무).

정규식 후보의 경계 잡음(오탐 아님, 경계만 부정확): `regex.operator.middot` 이 `'도포(MTS·니들RF`·`경고·단속한` 처럼 따옴표·괄호·어미를 포함한다. 같은 구절의 정확한 구간은 `manual.*` 표현(MTS·니들RF, 경고·단속)에 있다. 정규식 후보는 수집 보조이며 의미 분류가 아니다.

## C. 사용자 결정 — 0건

0건인 근거: B 는 원문에 없는 사실이라 사용자 선택으로 채울 대상이 아니고, P·F 는 다른 원장과 비교하는 공통 모델 단계에서 판단할 과제다. 도구·추출 방식(제외 규칙·분석기 설정)은 작성자가 정하고 기록했다. 따라서 지금 사용자에게 올릴 선택지가 없다. 이것은 미결이 닫혔다는 뜻이 아니다 — B 7·P 2·F 7·K 32 가 열려 있다.
