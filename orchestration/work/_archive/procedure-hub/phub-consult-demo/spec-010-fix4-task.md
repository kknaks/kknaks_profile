## 사용자 결정(11-20 — 다시 묻지 마라 · 0.2.0 「담기 때 고름」 을 대체)
- 흐름 = **담기 → 장바구니 → 옵션 「+」 눌러 추가 → 최저가 계산.**
- 예(사용자 그대로): 제모 → 「겨드랑이 제모」 담기 → 장바구니 드로어에 「겨드랑이 제모」 줄 · 그 아래 **[옵션 추가 +]** · 누르면 **옵션 드롭다운**(그 진료항목을 가리키는 single 옵션 — 옵션 제목 · 가격 원문) 고르고 **[추가]** 버튼 → 그 옵션 줄이 진료항목 아래 붙음. 한 진료항목에 옵션 여러 줄 가능(예 겨드랑이 1회 + 5회는 손님이 고른 대로). 줄 지우기 가능.
- 버튼 문구 「옵션 추가 +」 · 「추가」 는 사용자가 준 문구다(시안 밖이지만 사용자 지정 — slot 아님).
- **최저가** = 장바구니에서 고른 옵션 줄 전부를 같은 진료항목 · 같은 회차로 덮는 KOS 옵션 조합 중 합계 최소(가격 = 이벤트가 있으면 이벤트가 · 없으면 정가). 고른 옵션 자체 + 같은 진료항목을 같은 회차로 덮는 다른 single(이벤트 상품 등) · group(장바구니 밖 진료항목 품으면 제외) 이 후보. 카드 2 장.
- 옵션을 아직 안 고른 진료항목은 최저가 계산에서 빼고 표시(문구 slot).
- 그래서 「대상 축 판정」(PK4 · O-11)은 **없앤다**(손님이 옵션을 직접 고름). 0.2.0 의 담기 고르기 칸(PK2 · U-31)도 장바구니 드로어 쪽으로 옮겨 고친다.
- 봇: 장바구니에 옵션 안 고른 진료항목이 있으면 회차 · 대상을 물을 수 있다(좁히기 질문 축 그대로).
