## 4. 지적

### P1-A HQ0 물음 끝 꼴이 평서문을 물음으로 읽어 결정 #13 을 깬다

- **근거**:
  - SPEC §3-A H3 HQ0 은 물음을 「끝이 의문(「?」 · 「~가능해 · 돼 · 있어 · 없어 · 뭐야 · 얼마야」 꼴)이고 원함 표지가 없음」 으로 정한다.
  - 「있어 · 없어 · 돼」 는 반말 평서 어미와 꼴이 같다. 실제 시나리오에서도 이렇게 읽힌다:
    - S01 T1 「팔자주름에 대해서 고민이**돼**」 → 물음 꼴(첫 턴이라 지금은 해 없음)
    - S06 T2 · S01 T4 「…만 관심이 **잇어**」 → 오타라 안 걸림
  - 맞춤법대로 「있어」 면 물음이다. 그러면 HQ1(부위 · 고민 없음 = 「같거나 없음」)이 주제 · 목록을 얼리고, 고르기 셋이 답 재료로만 간다 → 결정 #13 · 기준 3 · 5 fail.
  - 같은 꼴로 「그중에 써마지만 돼」 · 「볼이 처지는 건 없어」 처럼 고르기 · 고민이 든 평서문이 얼어 버린다.
  - D5(판단 = 소넷 · 앱은 허브 사실 · 상태)와 볼 것 3(낱말 · 문장 목록 땜질 금지)에도 걸린다 — 어미 낱말 목록이 앱의 뜻 판정을 맡는다.
- **고칠 방향**:
  - 동형 어미(있어 · 없어 · 돼 …)로 물음을 가르지 않는다.
  - 물음은 문장 끝 부호 「?」 와 1차 `kinds`(정보 종류 있음)가 함께일 때만으로 하거나, 데이터로 가른다 — 이번 턴 고르기 값이 지금 목록을 좁히지 않을 때(대상 진료항목 ⊇ 지금 목록 또는 ∩ = 0)만 얼린다.
  - 시험에 맞춤법 꼴 「…만 관심이 있어」(고르기 셋 · 「?」 없음) → 고르기 교체 를 더한다.
