## 주제 = 칸 묶음(튜플) — 사용자 결정 11-22 (TP1 ~ TP14 의 판단 규칙을 대체)

**배경(실물 대화 a7d7e253 8 턴):** 「팔자주름 → 미간주름」 이 같은 칸 교체(CD2)로 덮어써져 주제가 하나뿐 · 새 주제 조건이 「더하면 0」 뿐 · LLM new 를 규칙이 이김 · 미간 주제 「보톡스」 가 팔자주름에 섞임(8 개).

1. **주제 = (부위, 고민, 시술, 효과, 제품, 국가, 회차 …) 칸 묶음** — 칸마다 값 0 개 이상. 케이스와 같은 구조.
2. **손님 말 → 이번 턴 칸 묶음**(이해 호출 결과 · follow 로 채운 대상은 뺌).
3. **부딪힘 기준 칸 = 부위 · 고민 · 시술**(둘 다 값이 있고 다르면 부딪힘). 제품 · 효과 · 국가 · 회차는 같은 주제 안의 좁힘 · 교체(새 주제 아님).
4. **판단(위에서 처음 맞는 것):**
   - 칸 0(정보 질문 · 「그게 뭐야」) → 주제 그대로(조건 안 바뀜).
   - 지금 주제와 부딪힘 없음 → **깊게**(빈 칸 채움 · 좁힘 칸은 교체).
   - 지금 주제와 부딪히고 **앞 주제 하나와 부딪힘 없음** → 그 주제로 **되돌림**(저장 상태 그대로 + 빈 칸 채움).
   - 앞 주제 둘 이상과 맞음 → 이해 호출 `topic.to` 로 고름 · 없거나 무효면 봇이 짧게 물음(어느 주제인지 · 조건 안 바꿈).
   - 어느 주제와도 부딪힘 → **새 주제**(이번 턴 칸만으로).
5. **이해 호출 판단은 참고 · 규칙(4)이 정본** — 다만 4 의 「둘 이상과 맞음」 만 LLM `to` 를 씀. LLM 이 규칙과 다르면 장부 표지.
6. **주제끼리 칸은 섞이지 않는다**(되돌림 때 지금 주제 칸을 끌고 가지 않음). 각 주제는 마지막 좁힌 상태 저장 · 되살림.
7. **이해 호출에 넘기는 것** = 주제 목록 튜플 + 각 주제 진료항목 수 + 지금 주제(resume 아님 · 매 턴 장부에서 정리). 답 호출은 세션 resume 그대로 + 지금 주제 · 주제 목록 블록.
8. 점 · 목록은 지금 주제 기준(테스트 고침 A 규칙 그대로 — 점 = 주제의 부위 · 고민 부위 · 진료항목 ↔ 점은 품음 계산).
9. **시험:** 실물 8 턴(「팔자 주름이 고민이야」 → 「미간에 주름도 너무 깊어」 → 「보톡스로 맞고 싶어서」 → 「아니 팔자주름 말고 미간에 보톡스 얘기한건데」 → 「아니 팔자주름 시술 추천은 그대로 두라니까」 → 「팔자주름에 보톡스 말고 다른 시술은 없어서 그대로 둔거지 ?」 → 「팔자주름에 보톡스 말고 다른 시술 알려달라니까」 → 「볼뉴머가 머야」) 기대: 주제 ① (팔자주름 · 팔자주름) · ② (미간 · 미간주름 · 보톡스) · 5 턴 ①로 되돌림(44) · 7 턴 ① 에서 보톡스 제외로 좁힘 · 8 턴 주제 그대로 · 미간 「보톡스」 가 ① 에 안 섞임. + 「아까 미간 보톡스는 제오민이 나아?」 → ② 되돌림 + 제품 제오민. + 「제오민 말고 하이톡스」 → 같은 주제 제품 교체.
