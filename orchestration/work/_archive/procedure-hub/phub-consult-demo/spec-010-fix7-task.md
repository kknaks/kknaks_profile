## 문제(코디 실측 · 사용자 질문)
지금 CD2 「같은 칸만 교체」 로는 손님이 관심을 바꾸면 앞 조건이 끼어든다 — 예: 「볼 꺼짐 때문에 필러」(부위 볼 · 고민 볼륨 손실 · 시술 필러) → 「그리고 기미도 고민」 → 고민만 교체 · 부위 볼 · 시술 필러 그대로 → 0 → LS 로 앞 목록 유지 → 기미 진료항목이 안 나옴.

## 사용자 결정(11-20)
1. **상담 안에 주제(topic)를 둔다.** 조건 칸(CD1)은 주제마다 따로 쌓인다.
2. **주제는 자동으로 넘어간다**(묻지 않음): 이번 턴 조건을 지금 주제에 더하면 0 인데 이번 턴 조건만으로는 진료항목 ≥ 1 이면 → 새 주제(이번 턴 조건만으로 시작). 「다른 것도」 · 「그리고 ~도」 같은 새 관심 표지 규칙도 정한다(시험 가능한 꼴 · 낱말 목록은 제안). 봇은 넘어갔다는 것을 한 줄 말한다(문구는 LLM 답 · 화면 문구 아님).
3. **앞 주제의 진료항목도 목록에 보인다.** 왼쪽 진료항목 목록 = 지금 주제(맨 위 · 펼침) + 앞 주제들(아래 · 접힘 · 머리 = 그 주제 조건 요약). 앞 주제 머리를 누르거나 「아까 볼 필러 다시」 처럼 말하면 그 주제가 지금 주제가 된다(조건 되살림).
   - 시안에는 주제 머리 자리가 없다 → 시안의 KOS 시술 접기(`cs-kind`) 꼴을 한 단 위로 쓰는 안을 제안하고, 머리 글(조건 요약 꼴)은 원문 조건 이름을 잇는 규칙(짓지 않음) · 꾸밈 문구는 slot.
4. 장바구니 · 최저가는 주제와 상관없이 하나(그대로). 봇 「같이 받기」 는 장바구니 전체.
5. 장부: `consult.topics[{id, conditions, items, created_turn}]` · `active_topic` · 서버 재기동 복원. 얼굴 점 · 몸 목록은 지금 주제 기준(앞 주제는 접힘 머리만).

E 표 · C 표 · WP-3 시험에 주제 줄 넣기(볼 필러 → 기미 → 「아까 볼」 되돌리기 · 같은 주제 안 좁히기는 그대로 · 0 인데 이번 턴만도 0 이면 LS 그대로).
