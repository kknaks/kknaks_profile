## 2. 새 지적

### P1-A TP14 에 ⑤(조건 없는 되돌림 = LLM)가 없다
- 근거: TP3 2(줄 395)는 「머리 누름(1)과 이해 호출 return(**TP14 ⑤**)으로만 한다」 고 한다. T17(줄 521)은 「TP3 7(규칙 continue) · **TP14 ⑤** → return → 주제 1」 이다. 변경 기록 0.2.6(줄 1038)에는 「TP14 ⑤ 예외는 …」 이 있다. 그런데 TP14 본문(줄 390)에는 ① 같으면 그대로 · ② 다르면 규칙 · ③ LLM 없으면 규칙 · ④ 되돌림 대상, 이렇게 넷뿐이다.
- 결과: WP-3 워커가 TP14 본문대로 짜면 T17 은 ② 때문에 continue 가 된다(시험 줄과 규칙이 서로 어긋남). 조건 없는 되돌림(「아까 그거 다시 보여줘」)을 할 길이 머리 누름 하나만 남는다. 코디 판단 (가) 「머리 누름 · LLM return 으로만」 의 절반이 빠진 셈이다.
- 고칠 방향: TP14 에 「⑤ 예외 — `rule_move = continue` 이고 `llm_move = return` 이며 `to` 가 유효한 앞 주제 id 이면 return(대상 = `to` · `to_from: llm`) · `to` 가 null 이면 ② 대로 continue」 를 넣는다. ② 에 「⑤ 밖에서」 를 붙인다.

### P2-B 「`PICK_HEADER_EXTRA` 에 넣되 선택 키로」 는 코드상 불가능하다
- 근거: `prompt.py:90` `_pick` 은 `(*PICK_HEADER_KEYS, *PICK_HEADER_EXTRA)` 가 **하나라도 비면 `pick = None`** 을 낸다. 그래서 EXTRA 는 필수 목록이다. TP13 손댈 자리(줄 389)는 「주제 블록 머리 키는 `PICK_HEADER_EXTRA` 에 넣되 필수 목록이 아니라 선택 키로」 라고 해서 앞뒤가 맞지 않는다. 워커가 EXTRA 에 넣으면 r6 P2-4 가 막으려던 「키 없는 프롬프트 파일 → 켠 대화 시작 못 함」 이 그대로 난다.
- 고칠 방향: 「`PICK_HEADER_EXTRA` 밖의 새 선택 키 묶음(예 `PICK_HEADER_OPTIONAL` — `_pick` 필수 검사에 넣지 않음)」 으로 고친다. `test_v04_prompt.py` 에 「주제 머리 키 없음 → `pick` 은 None 아님」 단언 한 줄을 넣는다.

### P2-C ⑤ 경우(규칙에 대상이 없음)에 TP6 `cond_dropped` 판정이 정의되지 않았다
- 근거: TP6 은 「`to_from: llm` 이고 대상이 **규칙 대상**과 다르면 이번 턴 조건을 더하지 않는다」 고 한다. ⑤ 는 `rule_move = continue` 라 규칙 대상이 없다. 그런데 ⑤ 는 조건이 0 인 턴(TP3 7)에서만 나는 것이 아니다. 조건이 있고 A ≥ 1 이라 TP3 5 continue 가 된 턴에 LLM 이 return 을 내도 맞는다. 예: 써마지 주제에서 「아까 그거, 턱 쪽으로」. 이때 턱을 `to` 주제에 더할지 정의가 없다.
- 고칠 방향: ⑤ 줄에 하나를 고른다. (가) 「규칙 대상 없음 = 다름으로 본다 → 이번 턴 조건 안 더함(`cond_dropped`)」 (나) 「⑤ 는 이번 턴 조건이 0 일 때만」. (나)를 고르면 ⑤ 가 코디 판단 문구(조건 없는 되돌림)와 그대로 맞고 경우도 하나 줄어든다. T 줄 하나(조건 있는 ⑤)를 더한다.

### P2-D 조건 없는 되돌림 옛 문구 · 옛 목록이 남아 있다
- TP14 ④(줄 390) 「이번 턴 조건이 비었으면 가장 최근 앞 주제」 — 0.2.6 에서는 조건이 0 이면 규칙이 return 을 내지 않으므로 이 갈래에 닿지 않는다. 지우거나 「(⑤ 에서 `to` 가 무효면 해당 없음)」 으로 바꾼다.
- T11(줄 515) 데이터 칸 「조건이 없으면 가장 최근 = 주제 2」 — 지금 규칙에서는 조건이 없으면 rule_move = continue 이고 ⑤ 로 간다. 갈래를 지우거나 「조건이 없으면 ⑤ → `to` = 주제 1 · 조건 0 이라 `cond_dropped` 무관」 으로 바꾼다.
- T12(줄 516) 「`to` = null → 규칙 대상(가장 최근 맞는 앞 주제)」 — 규칙이 return 일 때만 맞다. 줄 앞에 「규칙 return(조건 ≥ 1 · 표지) 상황에서」 를 붙인다. 규칙 continue + `to` null 이면 ⑤ 를 타지 않고 continue 다.
- TP14 끝 장부 `consult.topic{llm_move, llm_to, rule_move, used, to_from: llm · rule}`(줄 390) — 옛 다섯 칸 목록이다. TP10 한 정의를 가리키도록 「장부 = TP10 `consult.topic` · `to_from` 값은 llm · rule」 로 바꾼다(r6 P2-1 마무리).
