# 확인 시험 — 고민 15 → 케이스 → 명동점 진료항목 (researcher · 2026-11-20)

기준: silver(케이스 보충 뒤 · gold `1a81ae83…`) · 명동점 매핑 JSON `myeongdong-mapping-20261119.json` 324 항목(진료항목 → `hub.case_codes`).

- **지금** = silver 의 케이스 고민 줄(indication · procedure_case)만으로 고민 → 케이스 → 진료항목.
- **적용 뒤** = `concern-link-map.csv` 의 `규칙` 판정만 적용(케이스 줄 C1 + 위층 줄을 케이스로 내림). 사람 판단 줄은 넣지 않았다.
- 고민은 그 고민 + 아래 고민(고민 계층)으로 찾는다(여드름 → 염증성 여드름 · 블랙헤드 …).
- **엉뚱** = 기계 검사다. 다음 넷 중 하나에 걸리면 엉뚱으로 셌다.
  - 제모 항목인데 체모 고민이 아님
  - 얼굴 고민인데 몸 케이스
  - 케이스가 여럿인 시술에서 케이스 조직이 고민의 표적 조직 밖
  - 부위 고민인데 「특정 부위」 항목의 부위가 고민 부위 밖
- **낱말 빠짐** = 진료항목 이름에 그 고민을 가리키는 낱말이 있는데 적용 뒤에도 안 걸리는 것. 사람이 볼 후보다. 이름 낱말이 고민과 맞지 않는 것도 섞여 있다(얼굴제모의 「턱밑」).

**읽은 것**

1. **늘어남** — 15 전부 진료항목이 늘거나 같다. 같은 것은 입꼬리 처짐 · 사각턱 · 피부 건조 셋이다. 0 에서 생긴 것은 팔자주름 0 → 4 · 이중턱 0 → 3 · 셀룰라이트 0 → 3 · 홍조 0 → 7 · 볼륨 손실 0 → 6 이다. 크게 는 것은 피부 탄력 저하 3 → 24 · 잡티 1 → 7 이다.
2. **줄어든 것은 없다.** 지금 걸리던 항목은 적용 뒤에도 다 걸린다(케이스 줄은 C1 로 그대로 · 각 고민 `빠짐` 줄 없음).
3. **엉뚱한 것**
   - 기계 검사 엉뚱은 다한증의 바디보톡스 2 뿐이다. CAS-096(전신 · 근육)에 원장 `taxonomy.json` 바디보톡스 항목이 다한증을 직접 적어 그대로 둔 것이다(C1).
   - 조직(땀샘 ≠ 근육)이 어긋나 보이지만 원장 근거라 규칙은 손대지 않았다. 사람이 볼 것으로 남긴다.
   - 표적 조직 거르기 덕에 **제모 케이스(모낭)에는 색소 · 여드름 · 모공이 하나도 안 붙었다.** 기미 · 잡티는 토닝 · 피코 · 프락셀 항목에만 걸린다.
4. **빠지는 것의 원인** — 거의 다 「케이스에 고민 0」이다(`concern-link-empty-cases.csv`).
   - 원장이 그 시술에 고민을 말하지 않았거나, 사람 판단 줄에 묶여 있다.
   - 온다리프팅(마이크로웨이브 CAS-3051 · 3052) · 티타늄리프팅 · BBL(근적외선 CAS-064 · IPL 일반 CAS-129 · 130) · 스컬트라 · 올리디아(PLLA CAS-1053) · 풀페이스 외 스킨부스터(CAS-1021 · 1026 · 1054 · 1057) · 미백관리(CAS-5063)가 그렇다.
   - 이들은 계열 줄 사람 판단(G2 M3 · M4 · M9)이나 고민 0 케이스 보충으로 닫힌다.
5. **매핑 쪽 원인 하나** — 명동점 BBL(페이스)이 IPL 「일반」 케이스 CAS-129 에 매핑돼 있다.
   - CAS-129 의 조직은 data 워커 보충으로 피지샘이 됐다.
   - 그래서 홍조(표적 혈관)가 혈관 케이스 CAS-061 로만 가고 BBL 항목에는 안 닿는다.
   - 매핑을 CAS-061 · 060 쪽으로 옮길지, CAS-129 조직을 고칠지는 사람 몫이다.
6. **염증주사(여드름주사)** — CAS-5076 스테로이드 병변내 주사에는 원장이 흉터 · 켈로이드만 말했다. 여드름은 보충 근거가 있어야 붙는다.
