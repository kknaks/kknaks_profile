## 3. 지적

### P1-1 T6 이 데이터로 성립하지 않는다(B = 3)
- 근거: §5-3 T6(스펙 줄 508). SF3 은 몸 부위를 물으면 조상 「몸」 SITE-001 에 `site_scope` 「얼굴 · 몸 가능」 인 진료항목을 넣는다. 그래서 써마지 FLX 3 이 종아리에 맞는다. 결과는 B = 3 이고 TP3 3 · 4(새 주제)를 타며, 기대한 TP3 6(LS)이 아니다. 「써마지 + 아무 부위」 는 얼굴 · 몸 어느 쪽이든 FLX 3 이 맞아 B = 0 을 만들 수 없다.
- 고칠 방향: T6 표본을 바꾼다. 실측으로 **「종아리 쥬비덤」**(쥬비덤 PRD-050 진료항목 6 · 전부 얼굴 부위 · 종아리 ∩ 쥬비덤 = 0)이면 B = 0 이 성립한다. A 도 0(다한증 ∩ 종아리 ∩ 쥬비덤)이다. 수는 WP-3 착수 때 다시 센다.

### P1-2 되돌리기 표지가 조건 없는 흔한 말에서 켜지고, 「다르면 규칙」 이라 LLM 이 막지 못한다
- 근거: TP3 2 「이번 턴 조건이 비었으면 모든 앞 주제가 맞음」 + TP5 표지 「다시」 · 「처음」 · 「전에」 · 「앞에」 + TP14 ②(다르면 규칙). 예 하나는 앞 주제가 있는 대화의 「다시 설명해 주세요」 · 「처음 받아보는 거라 무서워요」(조건 0 · talk · follow)다. 규칙은 return(가장 최근 앞 주제)을 내고, LLM 이 continue 를 내도 규칙이 이겨 주제가 바뀐다. TP3 7(조건 없으면 그대로)보다 TP3 2 가 먼저라 7 에 닿지 않는다. TP4 의 한 글자 표지 「또」 도 공백을 지운 말 안 덩이라 「눈매 또렷하게」 같은 말에서 켜진다(고민 · 시술 칸이 함께 있으면 새 주제).
- 고칠 방향(코디 판단). 셋 가운데 하나를 고른다. (가) TP3 2 의 「조건이 비었으면 모든 앞 주제」 를 지운다. 조건 없는 되돌림은 머리 누름과 LLM return(TP14 ④ `to`)으로만 한다. 이때 TP14 에 「규칙 continue · LLM return + 유효 `to` → return」 예외 한 줄을 넣는다. (나) 조건 없는 되돌림은 표지를 「아까 그거」 · 「아까 거」 · 「전에 그거」 같은 지시 덩이로 좁힌다. (다) 「다시」 · 「처음」 을 표지에서 빼고, 「또」 는 낱말 경계(앞뒤 한글이 아닐 때)만 맞춘다. 어느 쪽이든 「다시 설명해 주세요」 · 「처음이라 무서워요」 · 「눈매 또렷하게」 를 T 줄(주제 안 바뀜)로 더한다.

### P1-3 LLM `to` 로 다른 주제를 고를 때 이번 턴 조건이 그 주제에 들어간다
- 근거: TP6 「이번 턴 조건은 CD2 로 그 주제에 더한다(더해서 0 이면 더하지 않음)」 + T11. 「아까 그 볼 필러 **말고** 그 전에 얘기한 거」 에서 이해 호출이 볼 · 필러를 조건으로 내면 대상은 `to` = 주제 1(기미)이 된다. 그러면 손님이 부정한 볼 · 필러가 기미 주제에 CD2 로 더해진다. 0 이 아니면 그대로 남아 저장 상태(TP12)를 망친다. T11 결과 칸에는 이 경우의 조건 처리가 없다.
- 고칠 방향: TP6 에 한 줄을 더한다. 「`to_from: llm` 이고 대상이 규칙 대상과 다르면 이번 턴 조건을 더하지 않는다(저장 상태 그대로 되살림 · 장부 `topic.cond_dropped`)」. T11 결과에 「주제 1 조건 = 기미 그대로 · 목록 = 저장 상태」 를 적는다.

### P2-1 장부 `consult.topic` 칸 정의가 둘이다

### P2-2 TP11(같은 조건 주제 되돌림)이 TP3 순서 안 어디에 오는지, `rule_move` 가 무엇인지 없다
