## 2. 실측

- `$J` 써마지(PRD-416 · 417) 진료항목은 5 다. FLX 3(`26-THM3-300/600/900SHOT`)은 `site_codes` SITE-007 + SITE-001 · `site_scope` 「얼굴 · 몸 가능」 이고, 쁘띠 2(`26-SMJ-THM3-*`)는 SITE-019 「특정 부위」 다. 턱(SITE-072)은 얼굴 부위라 SF2 조상 「얼굴」 규칙으로 FLX 3 이 맞는다. 그래서 **T19 의 A = 써마지 ∩ 턱 ≥ 3** 이고, 「써마지 주제(A ≥ 1) → TP3 5 continue」 가 성립한다.
- ⑤ 의 짝 맞춤을 확인했다. 이번 턴 조건이 0 이면 TP3 은 2 · 3 을 타지 않는다(둘 다 조건 ≥ 1 이 필요하다). 조건 0 에서 B 를 셀 칸이 없으니 TP3 4 도 사실상 타지 않는다. 그래서 `rule_move` 는 5 · 6 · 7 가운데 하나, 곧 continue 다. ⑤ 의 전제 「`rule_move = continue`」 는 조건 0 이면 늘 참이다. 그러니 ⑤ 를 실제로 가르는 것은 LLM return 과 유효한 `to` 둘이고, 앞뒤가 맞다.

## 3. 새 지적

- T19 는 「써마지 주제에서 「아까 그거, 턱 쪽으로」 · `to: 주제 1` · 턱 ⊄ 앞 주제 칸」 이라고만 하고, 주제 1 의 조건이 무엇인지 적지 않았다. 주제 1 이 부위 턱을 품은 주제(예 「턱 쪽 주름」)면 「아까」 표지 + 턱 ⊆ 주제 1 이 되어 TP3 2 return 을 탄다. 그러면 기대 결과(continue)가 바뀐다.
