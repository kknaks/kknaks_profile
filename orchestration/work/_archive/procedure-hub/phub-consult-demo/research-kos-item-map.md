## 1. 받기 확인

- **길 1(open API)로 받았다.** 방식은 ax-clinic-project `kos_collect.py` 와 같다(API 키 → `exchange-token` → 조회 경로 하나).
  - 키는 그 레포 `scripts/.env` 의 명동점 키 `KOS_API_tenent` 다. `_dev`(DEMO) 키는 쓰지 않았다. 키 · 토큰은 출력하지 않았다.
  - 호출은 교환 1 회 · 조회 1 회다. 그 레포 파일은 고치지 않았다.
- **명동점 확인**: open API 진료항목 id 가 내부 API(명동점 테넌트) v2 의 시술 항목 300 개와 **300 / 300 같다.** 우리 300 중 open API 에 없는 것은 0 이다.
- **300 밖의 24 개**(상품 옵션에 안 걸린 진료항목):
  - 턱보톡스 하이톡스 · 침샘보톡스 4(하이톡스 · 코어톡스 · 제오민 · 앨러간)
  - 점 제거 2mm 이하 · 비립종 제거 2mm 이하 · CO2 얼굴/목 전체 50개까지 · 다한증보톡스 하이톡스
  - **바디보톡스 하이톡스** · 스킨보톡스 하이톡스 · 포텐자 펌핑팁+쥬베룩 스킨 · 벨라콜린 이중턱 지방분해주사
  - 필링 1종 선택 · 프로디젠 PRP 양볼(케뉼라) · 국산 주름 보톡스 3부위 (하이톡스) · BBL HERO (2가지 모드)
  - 맞춤형 관리 케어 프로그램 (LDM 6'/SONO/오투덤 택 1) · 아발란체 제모 (턱끝) · 아발란체 제모 (턱밑) · 아발란체 제모 (인중)
  - 프리미엄미백+비타민수액 · 엑소제 · 수액 무제한
- **바디보톡스 2 줄이 둘 다 있다**: `26-BDBT-KR-100UNIT` 바디보톡스(국산) · 약물 보톡스(옵션 ○)와 `26-BDBT-HTS-100UNIT` 바디보톡스 하이톡스 · 약물 하이톡스(옵션 ✗).
- **게시 · 미게시**: open API 응답은 324 개 모두 `PUBLISHED` 다. 요청 칸은 이름 검색뿐이라 미게시를 거르거나 따로 부를 수 없다 → 미게시가 있는지 **확인 안 됨**.

- **진료항목 코드 값은 KOS 원문 그대로다.** 꼴이 다른 코드가 12 있다: `00000000` · `26-` · `26--` · `26---` · `26----` · `26--11` · `26-시트` · `WHITENING IV DRIP + VITAMIN IV DRIP` · `BTX785692 ~ 95`. 그래도 중복은 0 이라 키로 쓸 수 있다.

## 2. 규칙(`build_item_map.py`)

1. **시술 PRC · 부위 SITE 출발점** = 그 KOS 시술의 2판 줄이다. 2판에 없는 시술 7 개는 2판과 같은 분류기로 시술 이름을 나눴다.
2. **진료항목명 부위**는 허브 부위 이름 · 다른 이름과 `research-site-evidence.md` 표 낱말(풀페이스 · 페이스 · 힙 · 상완 · 측두근 · 콧볼 · 맨 앞 「아이 」)로 찾는다.
   - 시술 부위보다 넓은 것은 무시한다(바디/전신 · 위 부위).
   - 근거 표 낱말이 있으면 그 부위를 쓰고 「애매」 로 둔다.
   - 허브 부위가 하나만 나오고 시술 부위와 다르면 그것으로 구체화한다. 허브 위 부위 연결로 확인되지 않으면 「애매」 다. 예: 턱제모 → 「아발란체 제모 (턱밑)」 SITE-077 · 팔지방분해 → 「세라핏 팔뚝」 SITE-101 · 볼뉴머 → 「볼뉴머 턱선」 SITE-075.
   - 허브 부위가 여럿이면(예: 「하관전체/인중+턱끝+…」) 시술 부위를 유지하고 note 에 적는다.
   - 원장 근거 없는 낱말(부유방 · 손가락 · 발가락 · 발등 · 하완 · 뒷목 · 베렛나루)은 허브 기존 상위 부위만 두고 「애매」 로 둔다.
   - 침샘 · 귀밑샘 · 턱밑샘 · 쇄골은 허브 anatomy 에만 있다 → 부위 비움 · 「애매」. 「턱밑샘」 안의 「턱밑」 은 부위로 쓰지 않았다.
3. **제품 PRD = 진료항목의 약물 · 기기로만** 정한다(§3). 그 밖은 허브 제품 `name_ko` · `name_en` 의 정확 · 정규화(공백 · 괄호 · 대소문자) 일치만 쓴다. 허브에 없으면 비우고 note 에 「허브 제품 없음」 을 적는다.
4. **사용자 결정(11-19)**
   - 제모 = PRC-002 + 부위(2판 그대로 · 「애매」 유지 · note 「초안대로 확정」). 2판에 없던 턱끝제모도 PRC-002 로 두었다.
   - 세라핏 지방분해주사(진료항목 설명에 밀리핏) = PRC-123 + 부위 + PRD-729.
   - 설명이 없는 지방분해 진료항목 3 개(「바디 지방분해주사」 · 「벨라콜린 이중턱 지방분해주사」 등)는 시술 줄의 결정만 이어받았다 → 「애매」 + note.
5. **status**
   - 시작은 2판 시술 줄의 status 다.
   - 부위를 근거 표 · 상위 부위 · anatomy 로 정했거나, 확인 안 된 구체화를 했거나, 제품 칸이 「애매」 면 「애매」 로 내린다.
   - 제품이 「허브 없음」 인 것은 status 를 내리지 않고 note 에만 적었다.
