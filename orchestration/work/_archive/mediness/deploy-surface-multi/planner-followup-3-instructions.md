# [planner 4차 · micro] 시안 호출부의 `surface:'기본'` 두 줄을 걷는다

**3차 통과다.** 지시서가 짚은 4곳 외에 변경 노트 `:32` 까지 **5곳**을 찾아낸 것, 400 이 409 보다 나은 실패라는 근거를 박은 것, 두 버튼 차이를 추측하지 않고 `addEnvBlock`/`addSurfaceBlock` **코드를 읽어** 적은 것 — 전부 맞다.

**그리고 네 마지막 보고가 내 오판을 잡았다.** 내가 3차 지시서에 「시안은 이미 빈 값이라 맞다」고 쓴 근거는 **템플릿 기본값(`value="${d.surface||''}"`) 하나**였고, **호출부에서 `surface:'기본'` 을 넘기고 있다는 사실을 놓쳤다.** 시안도 프리필하고 있었다. 지시 범위(21-html 금지)를 지키면서 어긋남을 보고한 처신도 맞다 — 그게 규약대로다.

이번 판 검증 기준(스펙↔시안 어긋남 0)을 닫는다. **딱 이것만 한다.**

## 대상 — `products/mediness/21-html/Product Management.html`

1. `:544` `addEnvBlock` — `envBlockHTML({env:defaultEnv(), surface:'기본'})` 에서 **`surface:'기본'` 삭제**
2. `:550` `addSurfaceBlock` — `envBlockHTML({env, surface:'기본'})` 에서 **`surface:'기본'` 삭제**
3. `:542` 주석 — ``surface 는 `기본` 프리필(그대로 저장 가능·고쳐 써도 됨, SPEC-051 §4 FE)`` 을 **현 계약대로** 고쳐라. 빈 값으로 열리고 placeholder 가 예시를 보여주며, 빈 채로 저장하면 400 이라는 것.
4. 위 3곳이 전수인지 **네가 다시 확인해라** — `surface:` 를 넘기는 호출부가 더 있는지, 주석·문구에 프리필을 말하는 자리가 더 남았는지 grep 으로 훑어라. 내가 준 줄 번호는 참고지 전수 보증이 아니다. **두 번 연속 「내가 준 목록 밖」에서 어긋남이 나왔다.**

`defaultEnv()` 는 **그대로 둔다** — 아직 안 쓴 환경을 *초기 선택값*으로 고르는 건 제약이 아니라 편의고, 운영자가 select 로 바꿀 수 있으니 「환경 소진」이 아니다. 2차 개명 판단이 맞다.
