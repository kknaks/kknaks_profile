# [planner 3차 지시] 스펙 §2·§4 를 시안에 맞춰 내린다

**2차 통과다.** 코디가 직접 `lint --strict`(0 error, 263 warning — 1차와 동일) · JS 문법 · 「제품 × 환경」 유니크 가정 grep(잔존 0, 걸린 건 전부 새 3축 표현) 확인했다. `commitDeploys` 6케이스 시뮬레이션까지 돌린 건 좋은 판단이었다 — 목업 JS 를 논리로만 따라가지 않고 실제로 돌려서 확인한 게 맞다.

**네가 신고한 미결 2건, 둘 다 네 판정이 옳다. 처분은 같다 — 시안이 정본이고 스펙을 내린다.**

특히 ②는 **네가 직접 쓴 문장의 약점을 스스로 신고한 것**이다. 그대로 두면 FE 가 구현했을 때 `[+ surface 추가]` 의 기본 동작이 100% 409 를 부른다. 신고 안 했으면 2루프에서야 나왔을 자리다.

## 처분 ② — `기본` 프리필을 걷어낸다 (시안이 이미 옳다)

시안의 surface 입력은 `value="${d.surface||''}"` = **빈 값** + placeholder `기본 · 고객 홈페이지 · 운영자 어드민 …` 이다. **시안이 맞다.** 「`기본` 프리필」은 스펙에만 있는 서술이고, 그대로면 이미 `기본` 행이 있는 그룹에 `기본` 을 또 만들어 **반드시 409** 다.

`spec-051` 에서 프리필을 말하는 자리를 **전수로** 찾아 고쳐라. 내가 grep 으로 본 것은 아래 4곳이고 **전수가 아니다** — 네가 다시 훑어라.

- `:126` Wireframe 각주 — `신규 행의 surface 입력은 `기본` 프리필 …`
- `:192` UX Contract 기대 결과 — `(`surface_key` 는 `기본` 프리필)`
- `:377` Frontend Implementation — `신규 행 프리필` 항목
- `:391` Functional Rule — `모달 신규 행의 **프리필 문자열**일 뿐`

바꿀 내용:

- **신규 행의 surface 입력은 빈 값으로 연다.** placeholder 로 예시만 보여준다(시안 문구 그대로 — `기본 · 고객 홈페이지 · 운영자 어드민 …`).
- **`기본` 은 오직 「확장 시 기존 행 백필 값」 하나로만 남는다.** 프리필도 아니고 sentinel 도 아니다 — `:391` 의 sentinel 부정은 유지하되 「프리필 문자열」 부분만 걷어내라.
- 빈 값으로 저장 시도 → **400**(§Validation 「비어 있지 않음」). 이게 409 보다 나은 실패다 — 운영자에게 「이름을 지어라」라고 말하지 무의미한 중복 충돌을 던지지 않는다. 이 판단 근거를 한 줄 남겨라.
- 관련 AC 가 프리필을 전제하고 있으면 같이 고쳐라.

## 처분 ① — §2 Wireframe 을 평평 구조로 내린다 (시안이 정본)

현재 스펙 §2 Wireframe 은 **환경 그룹 박스 안에 surface 행 박스가 들어가는 중첩**을 그리고 있는데, 시안은 **평평한 카드 나열 + (환경 → surface) 정렬로 시각적 그룹**이다(`renderEnvBlocks` 주석: `시각적 그룹, DOM 은 평평`). 카드 1장 = `(환경, surface)` 1조합이고 카드마다 환경 칩·`[surface 추가]`·`[삭제]` 를 갖는다.

**시안이 정본이다. 스펙을 시안에 맞춰라** — 시안을 중첩으로 다시 그리지 마라(내가 2차에서 「새 컴포넌트 발명 금지」를 건 결과가 평평이고, 그 판단을 유지한다).

- §2 Wireframe ASCII 를 **평평 카드 나열**로 다시 그린다. 같은 환경 카드가 정렬로 붙어 보인다는 것을 명시.
- §2 UX Contract · §4 Frontend Implementation 에서 「환경 그룹」이 **DOM/컴포넌트 계층**인 것처럼 읽히는 서술을 **정렬 기준**으로 낮춘다.
- `[+ 환경 추가]` 와 `[+ surface 추가]` 의 차이를 평평 구조에서 다시 정의해라 — 전자는 환경을 고를 수 있는 새 카드, 후자는 **그 카드의 환경을 물려받은** 새 카드. (시안 `addSurfaceBlock` 의 실제 동작을 확인하고 그대로 적어라.)
- 저장된 행의 환경이 불변(칩만, select 없음)이라는 2차 정합도 스펙에 반영돼 있는지 확인. 없으면 넣어라.
