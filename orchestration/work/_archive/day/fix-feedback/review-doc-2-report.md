## 3. 새 모순 · 넘침 · `sort=room`

- **새 화면 글자 없음**: `visit_not_home` 글자는 비워 두었다(:765). 토스트는 「기존 코드 글자」로 적었다. 웹 권한 거절은 「안내 없음」이다. OS 알림 글자는 기존 행의 `title` · `body` 그대로다 — **PASS**.
- **모순**: 문서 안에서 새로 생긴 모순은 없다. 바로 시작 검사 순서(:742) · 응답(:583) · 매트릭스(:719-723) · 규칙 34(:922) 가 같은 말을 한다. 귀가 대기 취소 ⓔ ⓕ 는 :292 · :724 · :726 · :765 · :928 · :988 이 같다.
- **`sort=room` ↔ 코드**: `board_page`(`routers/board.py:260-267`)는 지금 쿼리를 받지 않는다. `view` 는 `WebView = Depends(required_web_view)` 인자 이름이다(`session.py:135`). 그래서 `?view=` 를 쓰면 파이썬 인자 이름과 겹치고, `sort` 를 쓰면 겹치지 않는다 — **부딪히지 않음 · 판단 맞음**. 남는 것은 응답 경로(D1)와 `hx-params="none"`(D2)뿐이다.
