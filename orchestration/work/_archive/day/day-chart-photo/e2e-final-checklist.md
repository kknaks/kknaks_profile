# 최종 e2e 체크리스트 (2026-11-24 · 로컬 http://127.0.0.1:11040 · KOS 데모 지점)

원천: `review-code-3-report.md` §7. 이후 고침 반영:
- P1: 21번은 이제 「나머지 사진은 들어옴」
- C25: 24번은 다음에 탭을 열 때 KOS 재삭제
- C26: 삭제 확인 창
- C27: KOS 실패 토스트

로컬은 저장소 = disk(`.local/chat/beforeAfter/…`)다. Azure 확인은 dev 배포 뒤에 한다.

## 핵심 (사용자)

### 차트
1. 간호관리 여러 줄 [저장]
   - 그 탭 「최근 저장」만 바뀐다
   - KOS 메모 = 쓴 글
2. 의사차트 따로 [저장]
   - 간호관리 「최근 저장」은 그대로
3. 수락 · 진행중 줄에서 의사차트 집도의 변경 → [저장]
   - 판 카드 · KOS 집도의가 바뀐다
4. 충돌: 창 연 뒤 KOS 웹에서 같은 줄 메모 수정 → DAY [저장]
   - 저장 안 됨 · 칸 = KOS 글 + 줄바꿈 + 내 글
   - 다시 [저장] → 저장됨
   - 수정 직후(10초 안) / 10초 뒤 두 번 해 본다
5. 미저장 상태로 ✕ · Esc → 확인 창
   - 바깥을 눌러도 아무 일 없음
   - 「버리고 닫기」 → 저장 0
6. [저장] 직후 응답 전에는 칸이 잠긴다
7. 헤더 로그아웃 왼쪽에 「이름 직군」

### 사진
8. 사진 탭 열기 → 「시술 전」 · 「시술 후」 두 묶음
9. JPEG 1장 · PNG 1장 올리기
   - 썸네일이 보인다
   - KOS 웹 그 일정 사진 탭에 보인다
     - 분류 · 장비 「태블릿」
     - 메모 「{고객} 고객 시술 전/후」
10. 썸네일 누르기 → 새 창 원본
11. 삭제 → 확인 창 「사진을 삭제할까요?」
    - [취소] → 그대로
    - [삭제] → DAY · KOS 둘 다에서 사라진다
12. KOS 웹에서 그 일정에 사진 직접 올림 → DAY 사진 탭 다시 열기
    - 몇 초 안에 보인다
    - 다시 열어도 두 장이 되지 않는다

## 선택 (경계 경우 — 시간 되면)
- 응답 유실(DevTools offline 뒤 같은 저장 → 저장됨 · 이력 1)
- 줄바꿈 여러 줄 KOS 메모 → 409 아님
- 담당자 비운 줄 → 오류 토스트
- 보기 권한 계정
- 집도의 둘인 줄 충돌
- 5MB 초과 · GIF → 오류
- KOS 실패 → 「KOS 미반영」 + [다시 시도] + 「KOS 반영에 실패했습니다」 토스트
- 다른 방문 `photo_id` 로 `/file` 직접 열기 → 404
