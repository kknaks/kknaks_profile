  - P6 mobile = P2 · P3 · P4 뒤

  - A4 = 「웹 = OS 알림만」을 더한다
- **Target Delta** 에 M-4 보강(복귀 · 점유 띠), M-6 정정(웹 = OS 알림만), N15 확정을 더한다. M-6 본문 글자는 **「{방} · 호출 취소」**(시술 수 뺌 · N16 닫음)로 바꾼다. 지금 #262 Target Delta · A4 에는 「{방} · 시술 {N}건 · 호출 취소」가 남아 있다.
