# [planner] 고침 4 진행 중 추가 — 사용자 결정 R39 (지금 판에 같이 반영)

결정 파일에 R39 추가(번호 — SPEC OQ-R34 와 겹쳐 R39): **KOS 동기화는 서버 중앙 작업에서만.** 화면 요청은 KOS 를 부르지 않는다 — 「보는 중」 표시 + 처음 보는 날짜면 중앙 작업에 「먼저」 요청을 넣기만. 중앙 작업이 병원마다 오늘 + 보는 중인 날짜를 순서대로 최신화(R26 범위 · 쓰는 쪽 하나 → 잠금 충돌 · 건너뜀 없음). 화면은 DB 사본을 그리고 다음 갱신에 최신.

뒤집는 것: R29 의 「첫 열기 즉시 최신화」 · C4 「세 단계 다 받은 뒤 그림」 · OQ-R28 ⓐ — 취소선 + R39. 한 번도 안 본 날짜의 첫 화면 = 이전 사본(비어 있을 수 있음) · 한 주기 안에 채워짐 — 케이스 매트릭스에 줄로. C1(완성된 상태만 보임) · C3 그대로. C2 는 「요청 경로가 KOS 를 안 부름 · 중앙 작업 안에서 건너뛰지 않음」으로 단순해지는지 확인해 고친다. R27(날짜 잠금 · 받는 중이면 사본) 도 R39 로 단순해지면 그 관계를 적는다.
함수 · 큐 · 잠금 설계는 여전히 WORK 몫 — 조건만.
