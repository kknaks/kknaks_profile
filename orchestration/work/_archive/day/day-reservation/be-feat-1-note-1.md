# [backend] 기능 1 보충 1 — R54 (작업 중 반영)
결정 R54(결정 파일 마지막 행): ⓐ 수납 건 남은 돈의 거래 = 승인 · 취소 · SPENT(선불카드 포함) — REQUESTED · FAILED 안 셈. ⓑ 「덮임」 = 이번 방문의 **살아 있는 수납 건(상태 무관)** 에 같은 상품 옵션이 있으면 ⓑ 에서 뺌(결제 뒤 payment_required 가 늦게 꺼지는 동안 이중 셈 방지). 시험 추가: 수납 완료 건에 옵션 있음 + 그 옵션 작업 payment_required true → 미수 0. R52 기준값은 실측 당시 스냅샷을 fixture 로(데모 DB 는 그 뒤 바뀜). 계약 chips[].count 는 화면에 안 그림(그대로 내도 됨).
