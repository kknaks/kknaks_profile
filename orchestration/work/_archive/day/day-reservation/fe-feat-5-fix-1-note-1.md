# [frontend] 기능 5 고침 1 보충 — 사용자 그림(지금 화면 = 꼬리표가 위 카드에 가려 「동행그룹」 글자 반쯤 잘리고 흐림)
원하는 모양(사용자):
```
     |---------
12:00| 동행그룹  \
     |-----------------------------|
     |[카드]....
```
- 탭 = 띠 왼쪽 위에 붙은 **사다리꼴 책갈피**(오른쪽 끝이 비스듬히 내려옴 「\」) · 진한 파랑 바탕(primary) · 흰 글자 · 흐림(투명도) 없음.
- 탭 바로 아래에 띠 위 테두리가 이어짐 → 그 아래 카드들. 탭은 행 위 여백 안에 온전히(위 행 카드와 겹치지 않음).
- 띠 테두리도 지금보다 진하게(연파랑 X · primary).
