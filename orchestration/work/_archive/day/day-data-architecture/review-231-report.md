## WARN

### W1. 시술 줄 시간 칸(E43)의 「늦음」(빨강)을 템플릿이 정한다 — SPEC 에 없는 규칙 — `templates/partials/board_parts.html:54 · 59 · 67`
- 근거: `recalled = c.lastCalledAt != c.firstCalledAt` → `"late": recalled`(재호출된 시술 줄은 **바로 빨강**). 재호출 아닌 호출은 `late_at = lastCalledAt + callMin`(5분 뒤 빨강)이다.
- SPEC-002 의 E43 은 「호출 = 지금 − 처음 호출」만 정했고, 빨강은 마취 칩(E36 · 20분)과 확인 필요(U12)에만 있다. U12 는 「재호출 · 시술 모두 완료는 확인 필요에 넣지 않는다」이다. 그래서 **재호출한 줄이 즉시 빨간데 카드는 확인 필요가 아닌** 엇갈린 화면이 된다.
- 판정 근거(재호출 여부 · 5분)를 템플릿이 스냅샷에서 다시 계산하는 셈이다. 「판정은 서버 값을 쓴다」(구현 리포트 · 레포 규칙)와도 어긋난다.
- 고칠 방향: 서버 스냅샷 시술 줄에 `call.lateAt`(늦어지는 시각 · 없으면 null)을 싣고, 템플릿은 그것만 쓴다. 규칙은 #230 `board_rules` 에서 SPEC U12 에 맞춘다(재호출은 마지막 호출 + 5분 또는 빨강 없음 — 사용자 · 코디 결정). 1차에 정하지 않을 거면 `late` 를 끄고 시간만 보인다.

### W2. 권한(edit)이 없는 사람의 조작은 403 이고 화면에 아무것도 안 뜬다 — 구현 리포트 「코디 확인」 6
- 근거: `web_errors.forbidden_handler` 가 HTMX 에 권한 없음 **조각 403** 을 준다. 그런데 `X-Day-Error` 가 없어 day.js 가 끼우지 않는다. view 권한만 있는 직원(의국 화면 등)이 [시작] · [수락]을 누르면 버튼이 반응하지 않는다.
- 고칠 방향: #230 쪽 `web_errors` 에서 HTMX + 조작 경로(`POST/PUT /board/…`)의 `Forbidden` 은 토스트 조각 + `X-Day-Error: forbidden` + `HX-Reswap: none`. 문구는 SPEC-001 대응표 「이 화면을 볼 권한이 없습니다…」를 재사용. 더 나은 길은 화면이 edit 권한이 없으면 버튼을 그리지 않는 것이다. 다만 `WebView.permissions` 에 전체 권한이 안 실리는 문제(#230 검수 W1)가 먼저 풀려야 한다.

### W3. 미룬 「판 다시 받기」가 창이 닫힐 때만 풀린다 — `day.js:335-341 · 364-369`
- 근거: `busy()` 는 창 · 메뉴(팝오버) · 끌기를 다 보는데, 미룬 것을 다시 부르는 곳은 `dialog close` 하나다. 메뉴를 닫거나 끌기를 끝내도 다음 10초 신호까지 판이 옛 값이다(10초 뒤에 저절로 맞춰지므로 실해 작음).
- 고칠 방향: 팝오버 닫기 · `endDrag` 에서도 `refreshDeferred` 를 보고 `sse:board` 를 다시 부른다.

### W4. 인수조건 A4 · A6 브라우저 실물이 남았다
- 근거: 데모 계정의 권한이 0이고 `deploy/local.env` 에 `DAY_ADMIN_EMAILS` 가 없어 실제 `/board` 가 403 이다(`00-real-board-forbidden.png`). 그래서 A4(두 화면 SSE 반영) · A6(실물 토스트)은 조각 렌더 테스트 + #230 SSE 테스트로만 확인했다. 견본(`/dev/kit/board`)은 같은 템플릿 · 같은 `BoardRules` 라 화면 상태 확인으로는 충분하다.

- (W1) 재호출한 시술 줄이 바로 빨갛다. 카드는 「확인 필요」가 아니다.
