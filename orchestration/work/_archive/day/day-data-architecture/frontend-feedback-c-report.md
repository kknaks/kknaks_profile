## F11 — 의사 호출 창이 왼쪽 위 · 「0개」 · 판 사라짐

**원인**: 탭을 오래 열어 둔 사이에 새 코드가 배포됐다. 브라우저는 처음 읽은 **옛 day.js** 를 그대로 쓰는데, HTMX · SSE 가 판 조각만 새로 받아 **새 마크업(F1 팝오버)** 을 그렸다. 그래서 옛 동작과 새 마크업이 맞지 않았다.

- 옛 day.js 에는 다음이 없다:
  - `align=start`(버튼 왼쪽 맞춤) → 오른쪽 끝 맞춤으로 계산해 화면 왼쪽(12px)으로 밀렸다. 아래 공간도 없어 위 끝(12px)에 붙었다 → **왼쪽 위**
  - 팝오버를 열 때 「호출할 시술」을 채우는 코드 → **0개**
  - `data-day-pop-close`(F14 의 X)
- 새로 연 페이지(새 day.js)에서는 같은 순서가 맞게 동작한다. 실제 `/board` 에서 확인했다(아래 표).

**고침**: 정적 파일의 판(`asset_v`)을 페이지 `<meta name="asset-version">` 과 판 조각 `[data-day-asset-v]` 에 싣는다.
- 조각을 끼운 뒤 두 값이 다르면 day.js 가 **페이지를 새로 읽는다**. 앞으로는 배포 뒤 오래 열린 탭이 첫 SSE 신호(최대 10초)에 저절로 새 코드로 바뀐다.
- 브라우저 실물: 같은 판이면 그대로 두고, 옛 판으로 바꿔 두면 다음 판 받기에서 새로 읽는다(둘 다 확인).
- **이 장치가 없던 옛 탭(지금 사용자 탭)은 스스로 못 바꾼다 — 한 번만 새로고침해야 한다.**
