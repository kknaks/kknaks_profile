## M1 새 경로 — OQ-01 구조 · SPEC-001 과 맞나

- **OQ-01**: 맞다. 웹은 화면 라우트 `/board/toasts/{event_id}`(HTML 조각)이고 SSE 는 신호, 앱은 `/api/board/stream` 이벤트다. 업무 규칙(언제 `failed` 가 되고 언제 알리나)은 worker · service 한 곳에 있다.
- **권한**: `board` view(L306)다. 판을 보는 사람이면 누구나 받아야 하므로 맞다. GET 이라 CSRF 대상이 아니다(S1 L152 「쓰기 요청(POST 계열)」). 다른 병원 · `outbox.failed` 가 아닌 id 는 케이스 매트릭스 404 줄(「없는 id · 다른 병원 id」)로 걸린다. 검사 순서 401 → 403 → 404 도 그대로 적용된다.
- **`event_log` 행**: worker 가 쌓으니 `actor_staff_id` 는 비어 있다. S0 L785 「시스템이면 비어 있음」이 허용한다. 규칙 21(「조작 1번 = event_log 1행」)은 조작에 대한 규칙이라 충돌하지 않는다.

### P1. 웹 `kos_failed` 신호가 `event_id` 를 어디에 싣는지 없다 — HTMX 로는 이대로 못 만든다
- SSE 표 L470: `kos_failed` 는 「id = `event_log.id`」. L471: 받으면 `GET /board/toasts/{event_id}`. 같은 표에서 웹 `board` 는 「신호(본문 없음)」다. `kos_failed` 의 웹 본문은 정해지지 않았다.
- HTMX SSE 확장의 `hx-trigger="sse:kos_failed"` 는 **고정된 URL** 에 `hx-get` 을 보낸다. SSE `id:` 필드(브라우저의 `lastEventId`)나 본문을 URL 에 끼워 넣는 기본 수단이 없다. 「id」가 SSE `id:` 필드를 뜻한다면 재연결 때 `Last-Event-ID` 로도 쓰여 뜻이 겹친다. L505 의 「재연결 때 다시 보내지 않음」과도 따로 정리해야 한다.
- 고칠 방향(기본값으로): 웹 `kos_failed` 의 **본문(data)에 event id** 를 싣는다고 적는다. 화면이 그 값으로 토스트 조각을 받는다(작은 JS 한 줄이나 `htmx.ajax`). 아니면 SSE `data` 에 토스트 HTML 조각을 바로 싣고 `sse-swap="kos_failed"` 로 끼운다 — 이러면 `GET /board/toasts/{event_id}` 가 필요 없다. 둘 중 하나를 적고 SSE `id:` 필드는 쓰지 않는다고 밝힌다. 어느 쪽이든 OQ-01(화면은 HTML 조각 · JSON 은 앱 전용)과 맞는다.

### P2. OQ-20 기본값 「추천 = 비어 있는 원장」은 근거가 다른 뜻이고, 시안에 다른 근거가 있다
- S2 OQ-20(L569): 「추천 = 비어 있는 원장(cc D-24 「비어 있는 원장 먼저」)」. 그러나 cc D-24 는 원장 목록의 **정렬** 규칙이지 「추천」 묶음의 내용이 아니다. 근거를 다른 뜻으로 빌려 온 것이라 발명에 가깝다.
- 시안에는 「추천」 근거가 있다. 시안 L1064 주석이 「v5: 재호출 팝업 — 선택됨(처음 호출 대상이 기본) / **추천(모든 의사)** / 전체」다. 원천 L43 도 「추천」 묶음 바로 다음에 「맨 위 『모든 의사』」를 둔다. 둘을 같이 읽으면 「추천」 묶음 = 「모든 의사」 한 줄이고, 원장 줄은 그 아래다. 시안 template(L1094)은 v8 이후 「추천」 머리를 지우고 「전체」 아래에 전체 호출을 두었지만, 주석과 원천 순서는 이쪽을 가리킨다.
- 고칠 방향: OQ-20 기본값을 「추천 = 『모든 의사』 한 줄(시안 L1064 주석 · 원천 L43 순서) · 원장 줄은 그 아래 · 비어 있는 원장 먼저(cc D-24 · 규칙 19)」로 바꾼다. 기본값 확인 OQ 로 둔다.
- 상태 글자: 원천의 「대기」와 규칙 19 세 상태의 대응을 디자인에 맡긴 것은 맞다. 시안 `doctorStatus`(L895-901) 글자는 「○○ 시술 중 · ○○ 시작 대기 · 비어 있음」이다. 원천 스크린샷의 「대기」가 이 셋 중 어느 것인지는 원천에서 알 수 없으니 기본값 그대로 둔다.

### P3. 호출 버튼 이름 — 원천이 이기는데 SPEC 은 시안 이름을 쓴다
