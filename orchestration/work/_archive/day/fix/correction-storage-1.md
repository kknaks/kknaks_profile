# 정정 — 저장소 용도 폴더는 셋 (2026-11-11 · 사용자)

사용자(2026-11-11): 「지금 우리 서버에서 할 거는(앞으로 할 거 포함) **고객 전후 사진 · 고객 신분증(여권) · 내부 채팅 사진** 이렇게야」.

→ `fix-spec-7-brief.md` 의 「용도 폴더 — 채팅 · 신분증」 둘을 **셋**으로 고친다.

| 용도(사용자) | 폴더 이름 | 이번에 |
|---|---|---|
| 내부 채팅 사진(· 동영상 — 지금 채팅 첨부) | `chat` (지금 코드 그대로) | **구현**(관리 ID 연결 · 환경 경로) |
| 고객 신분증(여권) | `identity` — 코디 기본값(여권 말고 다른 신분증도 올 수 있어서) | 이름만 예약 |
| 고객 전후 사진 | `before-after` — 코디 기본값 | 이름만 예약 |

- 폴더 **수와 용도**는 사용자 확정이다. `identity` · `before-after` 라는 **이름**은 코디 기본값(통보 · 뒤집을 수 있음 — OQ 로 남긴다).
- 경로 틀은 같다: `{환경}/{용도}/{병원 id}/…`. 고객 것(신분증 · 전후 사진)의 병원 id 아래 세부 경로(고객 id · 방문 · 파일 이름) · 암호화 · 보관 기간 · 열람 기록은 **그 기능을 만들 때** 정한다 — 이번엔 짓지 않는다(SPEC-000 「법적 검토 필요」 그대로).
- 저장소 구조 문서에는 「지금 쓰는 용도 = 이 셋 · 새 용도는 이 문서에 폴더를 먼저 더하고 쓴다」를 규칙으로 적는다.
