## 5. spec-003 title 「직원 앱 (iOS · 1차 시술 현황)」 판단

**지금은 고치지 않아도 된다(권장: 그대로)**. 이유: Android 는 「개발 앱 로컬 에뮬레이터 실행」만이고 출시 대상이 아니다 — 직원에게 나가는 앱은 여전히 iOS 하나다. 본문 :24 「iOS 먼저」 · 개정 ⑭ · §1 범위 표가 Android 개발 앱 · 통역을 적고 있어 오해는 막힌다. 다만 Android 출시(M-17)가 정해지면 그때 title 을 「직원 앱 (1차 시술 현황)」 류로 바꾸는 것이 맞다 — title 은 `doc_no` · id 와 별개라 바꿔도 링크는 안 깨진다. 고칠지 말지는 코디 · 사용자 판단.

## 7. 정할 것 · 주의

- **에뮬레이터 마이크 · 소리**: Android 에뮬레이터는 호스트 마이크 입력을 기본으로 꺼 두는 경우가 있다(에뮬레이터 설정 「Virtual microphone uses host audio input」). A-48 통역 확인이 「앱 문제」로 오판되지 않도록 코드 워커 브리프에 적어 두면 좋다. (일반 지식 — 이번에 공식 문서로 확인하지 않음.)
- **빠른 말하기 TTS 언어**: 에뮬레이터 이미지에 `ja` · `th` 등 음성이 없으면 U-15 의 「이 기기에 <언어> 음성이 없어요」 토스트가 뜬다 — 정상 갈래다. A-48 은 「소리가 나는 언어 하나 이상」으로 볼지 코디가 정할 것(스펙은 언어를 정하지 않음).
- **Dart 변경 가능성**: 통역 플러그인이 Android 에서 iOS 와 다르게 동작(오디오 세션 · 반이중 · 출력 경로)하면 Dart 를 건드려야 할 수 있다 — 지시대로 스펙에는 정하지 않았고, 그 경우 코드 워커가 코디에게 묻는다.
- 1회차 남은 것(정식 앱 id · 빌드 주입 방식 · 세션 저장 위치 [제안] · minSdk(M-7)) 그대로.
