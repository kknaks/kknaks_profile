# 3차 추가 지시 1 (사용자 2026-11-20)

결제는 DAY 가 직접 하지 않는다 — **DAY 화면에서 KOS 수납 화면을 새 창으로 열어 준다(리다이렉트).**

- N6 은 그대로 읽기 경로만 본다(결제 쓰기 경로는 목록만 · 대조 안 함).
- **N6-1 추가**: HAR 의 `pages[]` · 요청 `Referer` 의 **경로 부분만**(호스트 + path · 쿼리의 키 이름만 — 값 · 토큰 금지)으로 KOS 웹의 수납 · 고객 상세 · 예약 상세 화면 URL 모양을 정리하라. 어떤 id(고객 · 일정 · 구매)가 URL 에 들어가는지, 그 id 가 DAY `external_ref` 에 있는지(2차 판정 근거로). 새 창으로 바로 열 수 있는 딥링크 모양이 있는지는 사실만 — 없으면 「확인 안 됨」.
