## 3. 이번 수정이 새로 만든 문제 (브리프 §6 1 ~ 8 재훑기)

### N1. A-55 의 「미저장 없으면 iOS 밀기 = 바로 닫힘」에 표의 조건이 빠짐 — 인수 조건 확인 가능성

- 위치: `S3:1233` A-55 「미저장 없으면 [✕] · 뒤로 가기(iOS 밀기 · Android 뒤로) · … = 바로 닫힘」 ↔ `S3:577` 표 「닫힘(밀 수 있는 화면으로 띄울 때 — 아이패드 가운데 창엔 밀기 없음)」
- 근거: 표는 이 길을 조건부로 둔다. 아이패드 가운데 창과, 폰에서 밀기가 없는 route(예: `fullscreenDialog` · 일반 dialog route)에는 밀기 자체가 없다. A-55 는 조건 없이 「iPhone · iPad ✓」로 적혀 있어서, TestFlight 검수자가 iPad 에서 밀기를 시도하거나 폰 route 종류에 따라 「실패」로 적을 수 있다. 폰 전체 화면을 밀기가 되는 route 로 띄울지는 SPEC 에 정해져 있지 않다(D3 는 「전체 화면」만 정함).
- 고칠 방향: 아래 둘 중 하나다.
  - (a) A-55 에 표와 같은 꼬리를 붙인다: 「(iOS 밀기 = 폰 · 밀 수 있는 화면일 때만 — 아이패드 창엔 없음)」.
  - (b) 폰 차트 route 를 「iOS 밀기가 되는 전체 화면(page route)」으로 기본값을 적는다. 기본값 표시를 붙여 OQ-A66 에 넣는다.

  (a)가 한 줄이라 더 싸다. 결정을 다시 열 필요는 없다.
