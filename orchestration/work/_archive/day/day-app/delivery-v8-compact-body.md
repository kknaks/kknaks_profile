## DAY 직원 앱 — 알림 추가 범위(v8)

기존 PR237의 시술현황·채팅을 유지하며 원형 디자인의 알림 목록·종99+배지·읽음/모두읽음·알림 설정·전용SSE를 추가합니다. 원장 호출/재호출 커밋 뒤 받는 계정별 알림을 기록하고 기존 APNs/기기/재시도 코드를 공유해 푸시합니다.

받는 사람은 기존 호출 대상(전체=병원 원장 목록, 지정=그 원장) 그대로이며 관리자 추가·호출자 제외가 없습니다. 다른 병원/계정 격리, 빈ids=0건·ids/callId AND·모두읽음 전체날짜, 호출당 계정1행, 설정끔·키없음·실패격리를 검증합니다. 앱은 서버 unread/권한을 소비하고 세션 변경시 이전 응답·푸시를 무시합니다.

SPEC: [PR921 b0f71ec3](https://github.com/MediSolveAIDev/mediness/pull/921), DAY-SPEC-005 및003/004 연결. 누적 완료조건·제외·리뷰 원문과 정확digest는 이 이슈의 추적 메타데이터에 보존했습니다. 새 API/화면 계약은 SPEC005 §2~4, 새범위 원문은 v8 scope-delta 댓글을 따릅니다.

서버·앱 분담 구현→독립검수→코디검증→같은 [PR237](https://github.com/MediSolveAIDev/CENTURION_DAY/pull/237) 갱신. 머지는 마지막 사용자 지시까지 하지 않습니다. 실제 키·서명·배포·TestFlight는 사용자 담당. Android/FCM·상담사호출·새모델/migration은 범위 밖입니다.

main baseline은 사용자 마지막머지 순서 때문에 pending이며 실행문서는 위 미머지 검수본입니다. 코드 구현 승인은 현재 대화의 사용자 「응 진행하고」에 결속하고 승인receipt댓글로 기록합니다.
