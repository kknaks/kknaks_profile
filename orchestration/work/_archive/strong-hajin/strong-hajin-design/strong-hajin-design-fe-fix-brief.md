## 1. FAIL-1 — 시안 CSS 129줄이 **전부 죽어 있다** ★ 최우선

`styles/task-detail.css` 의 모든 규칙이 `.scax-td` 스코프 아래인데 **그 클래스를 붙이는 요소가 없다.**
코디가 직접 확인했다.

```
task-detail.css   .scax-td  47회 정의
.tsx / .ts        .scax-td   0회 적용   <- 아무도 안 붙인다
```

CSS 는 `index.css` 가 import 해서 로드되지만 **선택자가 아무 데도 안 맞는다.**
그래서 화면에서 이것들이 전부 죽는다.

- 연관 업무·자료의 **2열**(`.cols`) -> 1열로 쌓인다
- 목록 **3행 상한과 칸 안 스크롤**(`.scroll` 105px/280px) -> 없다
- 「추가」의 **파란색**(`.rel__addlabel`) -> 없다
- 값 한 줄 상자(`.one`) · 빈 상태·점선 상자(`.empty`·`.private`) -> 없다
- 덩어리·칸 머리 활자(`.block__row`·`.cell__head`) · 메타 한 줄 배치 -> 없다

**jsdom 이 CSS 를 적용하지 않아 테스트 1082건이 초록인 채로 시안 계약이 깨졌다.**

### 고칠 방법

**스코프 판단 자체는 옳다** — 전역 이름 충돌을 막는다. 그대로 두고 **클래스를 붙여라.**
드로어 본문에 `scax-td` 한 줄이면 된다. `ds/Modal.tsx` 의 `Drawer` 가 `className` prop 을
받지 않는다면 **본문을 감싸는 요소**에 붙여라 — `Drawer` 의 시그니처를 바꾸는 것보다 가볍다.

**붙인 뒤 반드시 확인해라**: `.cols` 가 실제로 2열로 서는지. 방법은 §5.
