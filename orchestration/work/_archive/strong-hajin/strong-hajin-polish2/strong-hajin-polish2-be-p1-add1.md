# [backend] WORK-009 Phase 1 — 추가 지시 add1 (같은 판에 넣는다)

FE Phase 2b 가 화면 라벨을 「마감일」·`2026/10/06` 으로 통일했다(SPEC-001 U-17, OQ-Q). 그런데 **서버가 라벨·값 문자열을 만들어 주는 자리**는 FE 가 그대로 그린다 — 그 자리는 네 몫이다.

1. 서버가 내는 화면 라벨의 「기한」 → **「마감일」**, 「제안 기한」 → **「제안 마감일」**. FE 가 찾은 출발점: `platform/actions.py` 1288·1386·1466·1621·1623·1755·1986 · 「제안 기한」 1626·2153 · `platform/action_center.py` 429. **이것은 출발점이다 — 서버가 화면용으로 내는 문자열 중 `due_date` 를 부르는 이름을 grep 으로 전부 센다**(미리보기 rows · 편집 계약 field label · 판단 상세 · 알림·활동 문구 등)
2. 같은 자리에서 서버가 **업무 날짜 값을 문자열로 만들어** 주면(미리보기 「10/01 → 10/06」 같은) 형식을 `2026/10/06` 으로. 기간은 그 둘을 잇는다(잇는 기호는 지금 것 유지)
3. **바꾸지 않는다**: 필드 id·API 키(`due_date` 등) · 서버 **오류 문구 중 FE 정규식이 매칭하는 것**(FE `ActionTaskCard` 가 서버 오류의 「기한」을 매칭한다 — 바꾸면 그 매칭이 깨진다. 오류 문구는 그대로 두고 보고에 목록만) · AI 프롬프트/도구 설명 속 영어·내부 표현(1-2 와 별개)
4. 테스트 단언을 함께 고친다. 보고에 **바꾼 자리 / 유지한 자리(이유)** 표를 더한다
