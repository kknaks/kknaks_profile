## 2. 설정 — 카카오톡 연동

메일·슬랙과 같은 틀(design-change-2): 소개 한 줄 → 상태 카드 → 「수집 방」 카드(적재 상태 3칸 · 방 목록 · 「방 추가」) → 방 고르기 창.

- 소개: 「이 Mac 의 카카오톡에서 고른 1:1 · 단체방의 대화를 우리 DB 로 적재한다. 조회만 한다 — 메시지함에서 보내지는 않는다. Mac 에서만 된다.」
- **상태 카드 「수집 상태」**(슬랙 워크스페이스 카드 자리) — 칸 넷
  - `Strong Hajin 앱`: 연결됨(「MacBook Pro · v1.2.0」) / 꺼짐(「마지막 연결 …」)
  - `카카오톡`: 실행 중(「이 Mac 에서 로그인됨」) / 꺼짐(「카카오톡을 켜면 이어 받는다」) / 앱이 꺼졌으면 「알 수 없음」
  - `로그인 계정`: 이름 + 카톡 계정 — 아래 설명 「계정은 지금 이 Mac 카카오톡에 로그인한 계정을 따른다. 다른 계정으로 바꾸려면 카카오톡에서 다시 로그인한다.」(고르는 목록 없음)
  - `마지막 수집`
- **앱 없음**: 상태 카드 대신 「Strong Hajin 앱」 카드 — 「Mac 앱을 설치하고 켜 두면 카톡이 쌓입니다. … 오픈채팅방은 수집하지 않는다.」 + **「Mac 앱 받기」** 링크 자리. 수집 방 카드 없음
- 적재 상태 3칸: `마지막 수집` · `DB 적재 건수` · `수집 실시간` — 꺼지면 **「멈춤 — 카카오톡 꺼짐」 / 「멈춤 — Mac 앱 꺼짐」**(붉은 점)
- 수집 방 줄: 표식(1:1 `1` · 단체방 `∴`) · 이름 · `1:1` / `단체방 · N명` · 적재 N건 · 상태 `실시간` / `과거 대화 채우는 중`(꺼지면 `멈춤`) · **「빼기」**(확인 창 — 더 받지 않는다 · 쌓인 대화는 메시지함에서 사라진다)
- 카드 아래 설명: 「방을 처음 추가하면 「과거 대화 채우는 중」이 된다 — 이 Mac 카카오톡에 남아 있는 만큼 거슬러 가져온 뒤 실시간으로 바뀐다.」
- **방 고르기 창 「카카오톡 방 추가」**: 검색 · 탭 `전체 · 1:1 · 단체방`(전체는 구획) · 줄 = 체크 · 표식 · 이름(1:1 은 상대 이름 · 이름 없는 단체방은 참여자 이름 「, 」) · 「1:1」/「참여 N명」 · 이미 넣은 방은 「추가됨」 · 아래 「이 Mac 카카오톡의 1:1 · 단체방만 나온다 (오픈채팅방 제외)」 · **「선택한 N개 추가」**
  - 앱 꺼짐이면 목록 대신 「Mac 앱이 켜져 있어야 방 목록을 볼 수 있습니다」(검색·추가 잠김)
  - 로딩 · 결과 없음 · 오류(「Mac 앱이 카카오톡을 읽지 못했습니다 …」 + 다시 시도)
- **걷은 것**: 「대화방 이름」 입력 · 「참여자에게 수집 사실이 공지된다」 · 「대화 수집 동의가 필요하다」 StatusNote · 수집 주기 Select · 「받아오기」/「전체 받아오기」 · DS 에 없는 `filled/accent` 단추(→ `solid-primary`·`text-neutral`)
- 상태 토글 `카톡`: **앱 없음 · 앱 꺼짐 · 카톡 꺼짐 · 정상 · 과거 채우는 중** + 창이 열리면 `방 고르기`(기본 · 로딩 · 결과 없음 · 오류 — 슬랙 창과 같은 토글)

## 3. 메시지함 — 카카오톡

- 출처 탭 `전체 · 메일 · 슬랙 · 카톡`
- 레일 카드 = 슬랙 대화방 카드 모양, 배지 **`카카오톡`** · 미읽음 수 · 마지막 3줄(글이 없으면 「사진 5장」·「동영상」·「음성 메시지」·「(이모티콘)」·「파일」)
- 본문 = 슬랙 대화방과 같은 모양(날짜 알약 · 아바타/이름/시각 · 5분 안 묶음) — **입력창 · 스레드 · 「슬랙에서 열기」 없음**. 머리 회색 줄 「카카오톡 · 1:1(단체방) | 참여 N명 | 조회 전용 · Mac 앱에서 수집」
- 답장 상태 토글(보내는 중·실패 등)은 카톡 방에 아무것도 깔지 않는다(조회 전용)
- 첨부
  - 사진: 「파일명 ▾」 + 큰 썸네일(슬랙 이미지와 같은 부품)
  - 앨범: 「사진 N장 ▾」 + 2열 격자(4칸까지, 넘으면 마지막 칸에 「+N」)
  - 파일: 파일 카드(유형 색 · 이름 · 크기 · 받기)
  - 동영상 · 음성: 회색 칩 「▷ 동영상 0:42 · 받지 않음 — 카카오톡에서 보기」 / 「음성 메시지 0:24 · …」
  - 이모티콘 · 스티커: 회색 글자 「(이모티콘)」
  - 만료됨: 점선 흐린 카드 — 이름 취소선 + 「사진 · 만료됨」/「파일 · 만료됨」(받기 없음)
- 목데이터(가상): 1:1 `박지윤`(만료 사진 · 이모티콘 · 사진 · 음성 · 파일 docx · 3일) · 이름 없는 단체방 `김태오, 이수아, 정민재`(만료 파일 · 앨범 5장 · 파일 pdf · 동영상 · 이모티콘 · 내 메시지)

## 4. 확인한 것
- node 렌더(`_ds_bundle.js` 실물 포함)
  - 설정 카톡 × 5상태: 앱 없음 = 설치 안내만, 앱 꺼짐/카톡 꺼짐 = 각 「멈춤 — …」·줄 「멈춤」, 과거 채우는 중 = 방 하나 더 · 「과거 대화 채우는 중」. 다섯 상태 모두 옛 문구(참여자 공지·동의·대화방 이름·수집 주기·filled) 0
  - 카톡 방 고르기 창 × 기본/로딩/결과 없음/오류/앱 꺼짐 — 「추가됨」 2 · 각 상태 문구 나옴
  - 메시지함 카톡 2방 × (답장 상태 없음·보내는 중): 입력창 0 · 스레드 0 · 「슬랙에서 열기」 0 · 내 「보내는 중」 메시지 0 · 첨부 종류 전부 나옴
  - 메일·슬랙·프로필 코드 블록이 앞 판과 같음
- 헤드리스 Edge 캡처 5장: 설정 카톡 꺼짐 · 앱 없음 · 방 고르기 창, 메시지함 1:1 · 단체방

## 5. 일부러 안 그린 것
- 카톡 발송 · 입력창 · 스레드 · 리액션 — 조회만(결정)
- 오픈채팅방 — 고르기 목록에 아예 없다(결정). 화면엔 제외 사실 한 줄만
- 기기 여러 대(Mac 두 대에서 같은 계정) · 앱 버전 업데이트 안내 · 앱 설치 과정 화면
- 카톡 계정이 바뀌었을 때의 처리(다른 계정으로 로그인 → 기존 방은?) — 정해지지 않아 그리지 않음
- 동영상·음성의 길이 외 정보(썸네일·파형) · 이모티콘 그림 · 사진 원본 보기(확대)
- 「Mac 앱 받기」 링크의 실제 주소 — 자리만
- 메시지함 카톡의 「새 메시지 N개」 알약 — 목데이터 0

## 6. 미결·주의
- 상태 카드의 앱 정보(기기 이름 · 앱 버전 · 「마지막 연결」)와 로그인 계정 표기(이름 + 카톡 계정 문자열)를 앱이 실제로 서버에 무엇을 올려 줄 수 있는지는 정해지지 않았다 — 시안은 자리만
- 앱이 켜져 있고 카톡도 켜져 있지만 **카톡 DB 를 못 읽는** 경우(권한·버전) 표시가 따로 없다 — 지금은 방 고르기 창 오류로만 보인다
- 카톡 방 표식 색을 노랑(`warning-soft`)으로 했다(카톡 느낌) — DS 원칙과 부딪히면 중립으로 바꾼다
- 앨범 격자는 4칸까지 보이고 나머지는 「+N」 — 펼쳐 보기는 그리지 않았다
- 설정 상태 토글 「방 고르기」는 슬랙 창과 같은 값을 쓴다(창이 하나씩만 열리므로 충돌 없음)
