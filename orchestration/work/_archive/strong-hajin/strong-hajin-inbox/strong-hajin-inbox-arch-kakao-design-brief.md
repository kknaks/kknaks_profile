## 1. 결정 (사용자 2026-10-06)
- Mac 전용 · **조회만**(입력창·발송 없음) · 사용자가 **고른 1:1·단체방만** 수집 · **오픈채팅방은 제외**(방 고르기에 안 나온다)
- Strong Hajin 데스크톱 앱(Rust)이 백그라운드로 Mac 카톡 로컬 DB 를 읽어 서버로 올린다. 고른 방 정보는 로컬(앱)에 저장. 앱이 **카카오톡 실행 여부**를 확인한다
- 계정 = **지금 카카오톡에 로그인한 계정 기준**(고르는 목록 없음 — 로그인한 계정을 보여 주고 따른다)
- 첨부: **사진·앨범·파일**은 수집 순간 받아 우리 쪽에 저장해 보여 준다 · **동영상·음성**은 「동영상」「음성 메시지」 표시만(받지 않음) · **이모티콘·스티커**는 「(이모티콘)」 글자 · 이미 만료된 옛 첨부는 「만료됨」
- 과거 = 이 Mac 카톡에 있는 만큼 · 참여자 안내·동의 문구 **없음**

## 2. 설정 — 카카오톡 연동 메뉴 (지금 시안의 앞 판 그대로인 카톡 섹션을 다시 그린다)
메일·슬랙 메뉴와 같은 틀(design-change-2):
- **상태 카드**(슬랙 워크스페이스 카드 자리): `Strong Hajin 앱` 연결됨/꺼짐 · `카카오톡` 실행 중/꺼짐 · `로그인 계정`(이름 · 카톡 계정) · `마지막 수집`. 앱 없음 = 「Mac 앱을 설치하고 켜 두면 카톡이 쌓입니다」+ 앱 받기 링크 자리
- 적재 상태 3칸: 마지막 수집 · DB 적재 건수 · 「실시간」(앱·카톡 꺼지면 「멈춤 — 카카오톡 꺼짐」 등)
- 「방 추가」 → **방 고르기 창**: 검색 · 탭 `전체`·`1:1`·`단체방` · 줄 = 방 이름(1:1 은 상대 이름 · 이름 없는 단체방은 참여자 이름 「, 」) · 참여 N명 · 이미 추가됨 · 「선택한 N개 추가」. 목록 출처는 Mac 앱이 읽은 방(앱 꺼짐이면 「Mac 앱이 켜져 있어야 방 목록을 볼 수 있습니다」)
- 수집 방 줄: 이름 · `1:1`/`단체방 · N명` · 적재 N건 · 상태(실시간/과거 대화 채우는 중) · 빼기
- 앞 판의 「대화방 이름 입력」 · 「참여자에게 수집 사실이 공지된다」 · 「대화 수집 동의가 필요하다」 StatusNote · 수집 주기 Select **모두 걷는다**
- 카톡 단추가 DS 에 없는 `filled/accent` 를 쓰던 것도 이참에 메일·슬랙과 같은 단추로
- 상태 토글: 앱 없음 · 앱 켜짐+카톡 꺼짐 · 정상 · 과거 채우는 중 · 방 창 로딩/결과 없음/오류

## 3. 메시지함 — 카톡
- 출처 탭에 `카톡` 다시 넣는다(전체·메일·슬랙·카톡)
- 레일 카드 = 슬랙 대화방 카드와 같은 모양, 배지 `카카오톡`
- 본문 = 슬랙 대화방 렌더와 같은 모양(날짜 구분 · 묶음 · 이름/시각) **단 입력창·스레드 없음**, 머리에 「조회 전용 · Mac 앱에서 수집」 정도의 회색 한 줄
- 첨부 표시: 사진 = 큰 썸네일 · 앨범 = 격자(N장) · 파일 = 파일 카드(받기) · 동영상/음성 = 회색 칩(받지 않음 표시) · 이모티콘 = 「(이모티콘)」 · 만료 = 흐린 카드 「만료됨」
- 목데이터: 1:1 하나 · 단체방 하나(이름 없는 방 포함) · 위 첨부 종류 전부 · 가상 인물
