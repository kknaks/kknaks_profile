## 2. 바꾼 것

### 2.1 본문 폭 전체 사용
- 걷은 제한: 메일 `.scax-mail` `max-width:720px` · 본문 로딩 Skeleton `max-width:720px` · 슬랙 대화 `.scax-room-log__inner` `max-width:880px` · 슬랙 입력창 `max-width:880px`
- 그래서 메일 머리 표 · HTML 본문(표 포함) · 첨부 · 답장 작성 칸, 슬랙 대화 · 입력창이 남은 폭을 다 쓴다
- 카드형 부품(URL 미리보기 520 · PDF 카드 420 · 큰 썸네일 360 · 파일 카드 260)은 카드라 그대로 뒀다 — 대화 폭이 아니라 부품 크기다

### 2.2 슬랙 스레드 = 오른쪽 패널 (3열)
- 평소 2열 `[목록 | 대화]` → 부모 아래 「(얼굴) 답글 N개 · 마지막 답글 … ›」를 누르면 3열 `[목록 | 대화 | 스레드]`
- 스레드 패널(폭 **420px 고정**, 대화 열이 줄어든다 · 왼쪽 구분선)
  - 머리: **「스레드 · #pilot-launch」**(채널명 회색) + **닫기(×)**
  - 부모 메시지 → 「답글 N개 ──」 구분 → 답글들 — 대화와 같은 메시지 모양(아바타·이름·시각 · 5분 안 연속 묶음 · 서식 · 첨부 · 리액션 · 보내는 중/실패)
  - 패널 아래 **답글 입력창** — 채널 입력창과 같은 부품(서식 막대 · 「+」 첨부 창 · 끌어오면 칸 전체 DS `dropzone--over` · 칸 안 DS `FileList` · 보내기). placeholder 「답글 달기…」
  - 패널 안 카드형 첨부(언퍼일 · PDF · 큰 썸네일)는 패널 폭에 맞춰 줄인다
- 한 번에 스레드 하나만 — 다른 「답글 N개」를 누르면 패널 내용이 바뀐다. 열린 부모는 대화 쪽에서 옅은 노랑 바닥으로 표시, 그 줄의 「답글 N개」에도 테두리
- **없앤 것**: 부모 아래 들여써서 펼치던 답글 · 그 아래 작은 입력창(`scax-composer-box--small`·`scax-thread__replies` 규칙도 삭제)
- 보낸 답글은 내 이름으로 패널에 붙고, 부모의 「답글 N개」·「마지막 답글」이 갱신된다

### 2.3 상태 토글 (시안 전용 · 화면 머리 가운데)
- `답장` 그룹: 없음 · 작성 중 · **스레드 열림** · **스레드 작성** · **스레드 보내는 중** · **스레드 실패** · 끌어오기 · 보내는 중 · 보냈음 · 실패
  - 스레드 넷은 `#pilot-launch` 의 「계정 발급」 스레드를 연 채로 시작한다(작성 = 패널 입력창에 글+첨부, 보내는 중 = 첨부 달린 내 답글, 실패 = 「보내지 못했습니다 · 다시 보내기」)
  - DM·그룹 DM 에는 스레드가 있는 메시지가 목데이터에 없어 스레드 상태가 보이지 않는다

## 3. 확인한 것
- node 렌더(`_ds_bundle.js` DropZone·FileList 실물 포함): 답장 상태 10 × 채널 r1 · 메일 m1 — 예외 없음. 스레드 넷에서 패널·머리 「스레드 · #pilot-launch」·부모 강조·입력창 2개(채널+패널)·보내는 중/실패가 나오고, 인라인 답글 마크업(`scax-thread__replies`)은 어디에도 없음. 스레드가 아닌 상태에선 패널 없음
- 헤드리스 Edge 캡처(1600 폭): 3열 스레드 실패 상태 · 2열 채널 · 메일 작성 중 — 메일 머리 표·HTML 표·답장 칸이 내용 열 폭을 다 쓰고, 스레드 패널이 420 으로 서며 대화 열이 줄어드는 것을 확인

## 4. 일부러 안 그린 것
- 스레드 패널 폭 조절(드래그) · 패널을 새 창/전체 화면으로 · 「채널에도 보내기」 체크 — 진짜 슬랙에 있지만 브리프에 없다
- 좁은 화면에서 3열이 넘칠 때의 처리(패널이 덮개로 뜨기 등) — 시안은 1600 폭 기준
- 스레드를 열 때 대화 열을 부모 위치로 스크롤 — 목업은 스크롤 위치를 다루지 않는다
- 「새 메시지 N개」 알약은 앞 판 그대로(대화 열 기준)

## 5. 미결·주의
- 패널 폭 420px 로 정했다(브리프 400~440) — 바꿀 값이 있으면 지시
- 열린 부모 표시를 옅은 노랑(`--scax-color-warning-soft`)으로 했다 — 진짜 슬랙의 「열린 스레드」 바탕과 비슷하게. DS 의 「악센트 하나」 원칙과 부딪히면 `surface-selected` 로 바꾼다
- 메일 본문이 폭 전체를 쓰면 1600 폭에서 문단이 길게 늘어난다(사용자 지시대로) — HTML 메일 자체에 폭이 있는 경우(뉴스레터 600px 표 등)는 그 폭대로 선다
