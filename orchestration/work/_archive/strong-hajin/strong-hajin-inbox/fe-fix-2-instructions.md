# [frontend] FE 수정 판 2 — 메일 원격 이미지 자동 표시 (사용자 2026-10-06)

사용자 결정: 메일 원격 이미지를 **처음부터 자동으로 보인다**(「이미지 보기」 누르지 않음). Gmail 처럼 **우리 이미지 프록시(`/api/inbox/mail/{id}/remote-image`)를 거쳐서만** 불러온다 — 사용자 브라우저가 보낸 쪽 서버에 직접 붙지 않는다(IP 노출 없음, SSRF 규칙은 서버가 이미 지킴).
- 「원격 이미지 N개를 막아 두었습니다 / 이미지 보기」 배너를 없애고 기본 로드
- 샌드박스·CSP 는 그대로(이미지 출처 = 우리 프록시만)
- 프록시가 실패한 이미지는 깨진 아이콘 대신 빈 자리(alt 글자)
- 시험 갱신
