## 2. 바꾼 것

### 2.1 메뉴
- `계정 설정` → **`프로필 설정`** (메뉴 줄 · 화면 머리 제목). 메뉴 id 는 `account` 그대로

### 2.2 머리 — 조직 명부 값(읽기 전용)
- 원형 아바타(이미지 없으면 이니셜) · **이름 · 소속 · 직책 · 직무** · 「조직 명부에서 관리됩니다 — 바꿀 일이 있으면 관리자에게 요청한다.」
- 앞 판의 `이름` · `직무` 입력칸 **삭제**

### 2.3 프로필 이미지
- 왼쪽 96px 원형 미리보기 — 이미지가 없으면 이름 첫 글자(이니셜 아바타)
- 오른쪽 **DS `DropZone`** 그대로: 머리 「이미지를 끌어다 놓거나 고르세요」 + **「이미지 변경」** · hint **「정사각형 1MB 이하 PNG · JPG」**(앞 시안 문구 유지) · `accept="image/png,image/jpeg"`
- 아래 줄: 현재 파일 정보 + **「이미지 삭제」**(이미지 있을 때만)
- **저장 방식 결정: 이미지를 고르면 바로 올라가 저장된다 → 「프로필 저장」 단추 없앰.** 이름·직무 입력이 없어져 이 카드에서 저장할 것이 이미지 하나뿐이고, 캐릭터도 고르면 바로 저장되는 앱 규칙과 맞춘다
- 올리는 중: 미리보기가 흐려지고 「올리는 중…」 · DropZone 잠김
- 용량 초과: 붉은 한 줄 「IMG_2041.jpg 은(는) 2.4MB 라 올릴 수 없다 — 1MB 이하로 줄여서 다시 고른다.」 · 원래 이미지는 그대로

### 2.4 AX 캐릭터 (앱의 「내 AX 캐릭터」 고르기를 옮김)
- 후보 9개 — 앱 `assistantCharacterCatalog` 그대로: 크림 고양이 · 실버 태비 · 턱시도 · 삼색 고양이 · 강아지 · 토끼 · 곰 · 병아리 · 레서판다
- 짜임도 앱(`ax.css` `.scax-character-picker__*`) 그대로: **4열** 카드 · 캐릭터(42px · 같은 둥근 모양) · 굵은 이름 · 「사용 가능」 · 고른 것은 보라 테두리+바닥 · 라디오 그룹
- 설명은 앱 문구 「런처와 AX 답변에 표시할 캐릭터를 선택하세요.」 + 「고르면 바로 저장된다.」
- 고르면 바로 저장(앱 `chooseAssistantCharacter` 흐름): 저장 중이면 카드 머리에 「저장 중…」 · 후보 잠김. 실패하면 **이전 캐릭터로 되돌리고** 붉은 줄 「AX 캐릭터 설정을 저장하지 못했습니다.」(앱 기본 오류 문구)
- 캐릭터 **그림(avif 9장)은 시안 프로젝트에 없다** — 앱 부품이 그림을 못 불러올 때 쓰는 대체 글자(`fallbackLabel`: 크·실·턱·삼·강·토·곰·병·레)로 그렸다

### 2.5 비밀번호 변경 — 앞 시안 그대로 + 오류 둘
- 현재 · 새 · 새 확인 · 규칙 문구 「8자 이상, 영문·숫자·기호를 두 종류 이상 섞는다. 변경하면 다른 기기의 로그인이 모두 해제된다.」 · 「비밀번호 변경」
- 불일치: 확인 칸 붉은 테두리 + 「새 비밀번호가 서로 다릅니다.」 · 단추 비활성
- 현재 틀림: 현재 칸 붉은 테두리 + 「현재 비밀번호가 맞지 않습니다.」
- 앞 판 단추(`variant="filled" tone="accent"` — DS 에 없는 클래스)를 `solid-primary` 로 바꿨다(이 메뉴 안에서만)

### 2.6 상태 토글 (시안 전용 · 프로필 설정 메뉴에서만)
- `이미지`: 없음 · 있음 · 올리는 중 · 용량 초과
- `캐릭터`: 기본 · 저장 중 · 저장 실패
- `비밀번호`: 기본 · 불일치 · 현재 틀림
- 시안 안 동작: 1MB 넘는 파일을 고르면 용량 초과, 아니면 1.2초 「올리는 중」 뒤 바뀜 · 캐릭터 고르기 0.9초 저장(토글이 「저장 실패」면 되돌림)

## 3. 확인한 것
- node 렌더(`_ds_bundle.js` 의 DropZone 실물 포함): 상태 조합 4가지 — 이니셜/이미지 · 올리는 중 · 2.4MB 오류 · 캐릭터 9개 · 저장 실패 문구 · 불일치 · 현재 틀림 · 「조직 명부에서 관리됩니다」 모두 나옴, 이름·직무 입력칸과 「프로필 저장」 없음
- 메일·슬랙·카톡·알림 코드가 앞 판과 같음(블록 비교)
- 헤드리스 Edge 캡처 2장(이미지 없음/기본, 용량 초과+저장 실패+불일치). 오류가 서면 비밀번호 세 칸의 머리가 어긋나는 것을 고친 뒤 올렸다
- 로컬 캡처에서 아바타 그림은 깨져 보인다 — 로컬 사본에 `assets/avatar-person.png` 가 없어서다(원격에는 있다, 앞 판부터)

## 4. 일부러 안 그린 것
- 이미지 자르기(정사각형 맞추기) · 확대 미리보기 — 한도 문구만
- 캐릭터 그림 실물 · 움직임(앱 런처의 숨쉬기 등) — 시안에 에셋이 없다
- 앱의 「저장된 캐릭터를 현재 지원하지 않아 기본 캐릭터로 표시합니다…」 안내 — 시안 목데이터로는 일어나지 않는 경우라 뺐다
- 비밀번호 변경 성공 뒤 화면(토스트·재로그인) · 비밀번호 보이기 단추 · 강도 표시
- 이메일·로그인 계정 정보 — 이번 구획 셋에 없다

## 5. 미결·주의
- 「프로필 저장」 없앰(즉시 저장)으로 정했다 — 저장 단추가 필요하면 말해 달라
- 머리 항목을 이름 · 소속 · 직책 · 직무 넷으로 골랐다(명부 축 중 계층·직급·재직은 뺌). 더 보여 줄 것이 있으면 지시
- 앱에서 캐릭터 고르기가 이 자리로 **옮겨 온다**면 앱의 기존 진입점(런처·머리의 캐릭터 단추 → 모달)을 없앨지 둘 다 둘지는 구현 때 정할 일 — 시안은 설정 쪽만 그렸다
- 사용자 메모(2026-10-06, 이 워커 터미널): 「그래서 우리 rust 앱에서 카카오톡 켜져있는지 확인 해야함」 — 카톡 수집 쪽 이야기라 이번 시안에 반영하지 않고 코디에게 넘겼다
