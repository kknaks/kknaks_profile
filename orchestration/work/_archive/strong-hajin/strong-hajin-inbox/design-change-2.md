## 2. 바꾼 것

### 2.1 메일 연동 — Gmail API · 계정마다 1회 연결
- IMAP 폼 전체(서버 이름 · IMAP 서버 · 계정 · 비밀번호 · 가져올 범위 · 「연결 확인」 · 「추가하고 받아오기」) **삭제**
- 연결 전: 카드 「Google 계정 연결」 + 설명 「한 번 연결하면 받은편지함이 실시간으로 쌓인다. 연결할 때 받은편지함 전체를 가져온다.」 + **「Google로 연결」**
- 연결 후: 「연결된 메일 계정 N개」 — 적재 상태 3칸(`마지막 수집` · `DB 적재 건수` · **`수집: 실시간`**) + 계정 줄 + 아래 **「다른 계정 연결」**
- 계정 줄: G 표식 · 주소 · 「Gmail · 적재 N건 · 마지막 시각」 · 상태 · 「연결 해제」
  - 상태: `실시간` / `과거 메일 채우는 중 · N건`(점 깜빡임) / `연결 끊김 다시 연결`(줄 붉은 바탕 + 아래 설명 「토큰이 만료됐거나 Google 에서 권한을 거둔 경우다 — 「다시 연결」로 한 번 더 동의하면 이어 받는다」)
- 휴지통 → **「연결 해제」** + 확인 창: 「{주소} 에서 더 이상 메일을 받지 않는다.」 · 「이 계정으로 쌓인 메일은 메시지함에서 사라진다.」

### 2.2 슬랙 연동 — 사용자 토큰 · 1회 연결 · 방 고르기
- 워크스페이스 카드
  - 연결 전: 설명 「내 슬랙 계정으로 연결한다. 내가 들어가 있는 채널·비공개 채널·DM·그룹 DM 중에서 고른 방만 가져온다.」 + **「슬랙 연결」**
  - 연결 후: 「노을웍스 · noeulworks.slack.com」 · 범례 `연결됨` · 상태 `실시간` · **「연결 해제」**(확인 창 — 모든 방에서 더 받지 않는다 · 쌓인 메시지는 메시지함에서 사라진다)
  - 연결 끊김: 범례 `연결 끊김` · `연결 끊김 다시 연결` · 설명 「모든 방의 수집이 멈췄다 … 「다시 연결」하면 멈춘 뒤의 메시지부터 이어 받는다」
  - 봇 권한 문구(`channels:history…`) **삭제**
- 「수집 방 N개」 카드 — 머리 오른쪽 **「방 추가」**(채널 이름 입력 + 「봇이 초대된 채널만」 힌트 **삭제**)
  - 적재 상태 3칸, 셋째 = **`수집: 실시간`** (워크스페이스가 끊기면 `멈춤 — 연결 끊김`)
  - 방 줄: 종류 표식(# 공개 · # 비공개(노랑) · @ DM · ∴ 그룹 DM) · 방 이름 · 메타 `채널 · 공개` / `채널 · 비공개` / `DM` / `그룹 DM · N명` + 「적재 N건」 · 상태 `실시간` / `과거 메시지 채우는 중` (끊김이면 `멈춤`) · **「빼기」**(확인 창)
  - 카드 아래 설명 한 줄: 「방을 처음 추가하면 「과거 메시지 채우는 중」이 된다 — 슬랙이 허락하는 가장 오래된 메시지까지 거슬러 가져온 뒤 실시간으로 바뀐다.」
- **방 고르기 창(모달 560)**: 제목 「방 추가」 · 검색 칸(「방 이름이나 사람 이름으로 찾기」) · 묶음 탭 `전체 · 채널 · 비공개 · DM · 그룹 DM` — `전체`에선 묶음별 구획(제목 + 개수)
  - 줄: 체크박스 · 종류 표식 · 이름 · (봇이면 `앱`) · 오른쪽 인원(DM 은 「DM」) · 이미 추가된 방은 회색 체크 + **「추가됨」**(고를 수 없음)
  - 그룹 DM 은 **참여자 실명을 「, 」로**(`mpdm-…` 안 보임) · DM 은 상대 이름 · 봇 DM(「질문 도우미」·「배포 알리미」)도 DM 묶음에 섞여 나온다
  - 아래: 「이미 추가한 방은 「추가됨」으로 표시된다」 · 취소 · **「선택한 N개 추가」**(0개면 비활성) → 추가된 방은 「과거 메시지 채우는 중」으로 목록에 붙는다

### 2.3 네 상태 · 창 상태
- 화면 아래 **시안 전용 상태 토글**(`DevSwitch`, DS `.scax-state-switch` 모양 그대로)
  - `연동`: **연결 전 · 연결됨 · 과거 채우는 중 · 연결 끊김** — 메일·슬랙 메뉴에서만 뜬다. 메일 끊김 = 계정 하나 끊김, 슬랙 끊김 = 워크스페이스 끊김(모든 방 멈춤)
  - `방 고르기`(창이 열렸을 때만): **기본 · 로딩**(줄 Skeleton 5) · **결과 없음**(「찾는 방이 없습니다」) · **오류**(「방 목록을 불러오지 못했습니다」 + 다시 시도)
- 시안 안 동작: 「Google로 연결」 → 새 계정이 「과거 메일 채우는 중」으로 붙음 · 「다시 연결」 → 실시간 · 「슬랙 연결」 → 방 0개로 연결됨 · 「연결 해제」·「빼기」 → 확인 창 뒤 목록에서 빠짐
- 앞 판 `StateSwitch`(기본·비어 있음·로딩·오류 고정 문구)는 이 화면 상태에 맞지 않아 같은 클래스로 이름만 다른 토글을 화면 파일 안에 만들었다

- 슬랙 워크스페이스 「노을웍스」(`noeulworks.slack.com`) · 수집 방 4(공개 · 비공개 · DM · 그룹 DM) · 후보 14(채널 4 · 비공개 2 · DM 5(봇 2) · 그룹 DM 3) — 사람 이름은 메시지함 시안과 같은 가상 인물

## 3. 확인한 것
- node 렌더(react-dom/server): 화면 전체 · 메일/슬랙 × 네 상태 · 방 고르기 창 × 기본·로딩·결과 없음·오류 · 카톡 섹션 — 예외 없음. 네 상태 모두 IMAP·가져올 범위·채널 이름 입력·봇 권한 문구가 남아 있지 않음. 창에서 이미 추가된 방 2개(C01·D01 전달)가 「추가됨」, `mpdm` 문자열 없음
- 헤드리스 Edge 캡처: 메일 연결됨·끊김·연결 전 · 슬랙 채우는 중·연결 전 · 방 고르기 창. 캡처에서 찾은 2건(검색 칸 테두리 이중 · 「추가됨」 체크가 파랗게 보임)을 고친 뒤 올렸다

## 4. 일부러 안 그린 것
- 카카오톡 연동 · 계정 설정 · 알림 설정 — 지시대로 그대로(그래서 카톡은 여전히 수집 주기 Select · 이름 입력 · 동의 안내, 알림 받는 경로의 `haram@thesc.co.kr` 도 그대로)
- Google·슬랙 **동의 화면(OAuth 팝업)** 과 그 사이 로딩 — 외부 화면이라 그리지 않았다. 시안은 단추를 누르면 바로 결과 상태로 간다
- 슬랙 **워크스페이스 여러 개** — 하나만 그렸다(결정 원장에 여러 개 이야기가 없다)
- 「과거 채우는 중」의 진행률 막대·남은 양 — 슬랙·Gmail 이 끝을 미리 알려 주지 않아 건수만 둔다(메일 줄은 「· N건」, 슬랙은 문구만)
- 방 고르기 창의 「전체 선택」·정렬·최근 활동 순
- 계정·방별 「받아오기」 수동 단추 — 실시간이라 뺐다(앞 판의 「받아오기」·「전체 받아오기」 없음)
- 연결 해제 뒤 되살리기 — 소프트 딜리트지만 화면 문구는 브리프대로 「메시지함에서 사라진다」

## 5. 미결·주의
- 메일 「연결 끊김」은 **계정 하나**, 슬랙 「연결 끊김」은 **워크스페이스 전체**로 그렸다 — 슬랙 토큰은 워크스페이스 하나라 방별로 끊기는 경우는 없다고 보았다(방에서 쫓겨난 경우 등 방별 오류 표시는 안 그림)
- 적재 상태 셋째 칸: 슬랙이 끊기면 「실시간」 대신 `멈춤 — 연결 끊김` 으로 바꿨다(브리프는 「실시간」만 말함) — 그대로 「실시간」이어야 하면 고친다
- 종류 표식 글리프(`#` `@` `∴`)는 DS 아이콘 38종에 자물쇠·말풍선이 없어 글자로 대신했다
- 기존 카톡 섹션은 앞 판 그대로 `variant="filled" tone="accent"` 단추를 쓰는데 그 클래스가 DS 에 없다(앞 판부터) — 이번에 손대지 않았다. 새로 만든 메일·슬랙 단추는 `solid-primary`/`outlined-neutral`/`text-neutral`/`solid-danger` 를 쓴다
