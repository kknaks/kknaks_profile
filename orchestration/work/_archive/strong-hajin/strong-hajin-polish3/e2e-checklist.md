## 1. 로그인 (R1)
- [ ] 왼쪽 브랜드 제목 「메디솔브 AX 프로젝트」, 그 아래 설명 문장 없음

## 2. 회의 상세 (R2a · R3)
- [ ] 「내보내기」 단추가 옆 「공유」「다음 회의 예약」과 같은 크기
- [ ] 제목을 클릭 → 그 자리에서 고쳐짐 · Enter/바깥 클릭 저장 · Esc 취소 · 빈 값은 되돌림
- [ ] 제목 없는 회의: 「제목 없는 회의」 + 옆 「제목 후보: … [적용]」 → [적용] 누르면 그 문장이 제목이 되고 후보 줄 사라짐
- [ ] 진행 중·실패 회의 / 참석자가 아닌 회의는 제목이 글자만
- [ ] 긴 제목: 편집 가능한 회의에서 두 줄로 접히는지(알려진 차이 — 보고 정함)

## 3. 업무 상세 (R4·R5·R6) — 「내 업무」에서 열기
공통: 머리 = 제목 + ×(겹이면 「뒤로」) · 푸터 없음 · 「진행과 판단」 없음 · AX 단추 없음 · 머리 아래 여백 줄어듦
- [ ] **A 시작 전**: 메타 정보 2열(진행 상태·버전·담당·시작 예정일·마감일…) · 셀렉트 = 시작 전/진행 중/완료/맨 아래 빨간 업무 취소 · 제목/내용 인라인 저장(「저장 중…」 · 버전 +1) · 날짜 즉시 저장 · 예정>마감 막힘 · 업무 취소 = 사유 모달(필수)
- [ ] **B 선행 미완**: 빨간 배너 없음 · 「진행 중」 고르면 토스트 「끝나지 않은 선행업무가 있습니다: …」 + 「시작 전」 유지
- [ ] **C 진행 중**: 막힘 = 사유 모달 → 「막힘 사유」 상자 · 체크리스트 남은 채 완료 = 「남은 단계가 있습니다」 확인창
- [ ] **D 막힘**: 진행 중/업무 취소만 · 팀장(jiho)으로 담당 셀렉트 → 사유 모달 → 「○○에게 변경 제안 중」 + 「담당 변경 대기」 상자
- [ ] **E 완료**: 진행 중(재개, 사유 선택)만 — 업무 취소 없음 · 「실제 종료일」 행
- [ ] **F 확인 대기**: 진행 상태 글자 · 「완료 확인 대기」 상자(요청자면 완료 인정/보완 요청)
- [ ] **G 요청받은 업무**: 업무 취소 없음 · 완료 = 완료 보고 모달
- [ ] **I AX 제안 업무**: 출처 「AX 제안 · 판단 보기」 → 판단 상세 / 홈·캘린더에서는 글자만
- [ ] **J 마감 지남**: 「마감일 초과」 배지가 마감일 값 옆
- [ ] **K 읽기 전용**(조직 업무·완료 탭·채팅 카드 업무 열기 등): 아무것도 안 열림
- [ ] **L** 사유/완료 보고 모달에서 Esc → 그 모달만 닫힘
- [ ] **N 회귀**: 내 업무 목록 상태 칸·행 단추·선행 문구 그대로 · 프로젝트 우 패널 그대로

## 4. 데스크톱 앱 (g · R2b) — Tauri 창에서
미리 Finder 로 다운로드 폴더를 열어 둔다
- [ ] 회의 상세 「내보내기」 → 다운로드 폴더에 `{제목}.html` · **앱 화면 그대로** · 토스트 「다운로드 폴더에 저장했습니다: …」 · 한 번 더 → `{제목} (1).html`
- [ ] 업무 상세 참고/결과 자료(파일) 링크 → 저장 + 토스트 · 두 번째 창 없음
- [ ] 회의 자료 서랍 **PDF 미리보기가 그대로 보이나**(셸 가로채기로 빈칸이 되면 실패 — W4)

- [ ] 채팅 근거 「원본 열기」·AX 답변 링크 → 앱 화면을 덮지 않나
- [ ] (선택) 로그아웃 상태 등 실패 → 「파일을 저장하지 못했습니다.」
- [ ] 브라우저(웹)에서 내보내기는 지금처럼 브라우저가 내려받음

## 6. 사용자 E2E 지적 (모아서 2루프 — 2026-10-05~)
