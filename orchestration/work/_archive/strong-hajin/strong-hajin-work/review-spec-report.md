## WP 독립성 판정 (브리프 §6-5)

**결론: W1 은 OQ-A·D2 와 완전히 독립해서 WP 를 쓸 수 있다. W2 도 분기 하나만 표시하고 진행할 수 있다.**

| 묶음 | 독립 가능? | 걸리는 미결 |
|---|---|---|
| **W1** — 생성(본인·타인) · 즉시 배정 · 회의 후속 승격 | **가능 (미결 0)** | 없음. 필요한 계약이 전부 확정이다 — 수신자 인자·허용 후보 권한·즉시 활성 담당·수락 gate 부재·**거절 명령 부재**(D-4, 원문 확정 제외)·멱등 키(신규)·활성 담당 유일성(신규)·승격 동일 경로 |
| **W2 완료·승인·보완·재완료·승인 뒤 되돌리기** | **가능** | **승인자 0명 Task 의 되돌리기 한 분기**만 OQ-A. 나머지(승인자 있음 경로)는 원문 확정 |
| **W2 기한 두 값 · 시작일 · 상태 메모** | **가능 (미결 0)** | 없음. `PLAN-001:106`·`:203`·`:207` 로 전부 닫힘 |
| **W2 문의 — 발송 · 회신 대기 부착 · 답변 · 해소** | **가능** | **복수 미응답 시 해소 판정**만 D2. 단 R-4 대로 「하나라도 waiting」을 **잠정**으로 표기해야 WP 가 확정으로 구현하지 않는다 |
| **승인자 지정·변경·승인 대기 뒤 고정** | **가능** | 없음 |
| **위임전결 자동 채움** | **불가** | 값 부재(R-2). 그러나 "빈 채로 사람이 고른다"가 이미 계약이라 **W2 를 막지 않는다** |
| **업무 페이지 — 축 셋 · 축별 칩 · 행 액션 · 상세 구획 · 자료 권한 · 관리자 읽기 전용** | **가능 (미결 0)** | 없음. 전부 `SCR-101`·`SCR-102` 원문 확정. 단 R-3(상세의 `open → done`)을 먼저 정리 |

**다음 WP 가 안전하게 다룰 범위**: W1 전체 + W2 의 완료/승인/보완/재완료 + 기한 두 값 + 시작일 +
상태 메모 + **문의 1건 흐름** + 업무 페이지(축 셋·칩·행 액션·상세·자료).

**미결이 실제로 닿는 단계는 셋뿐이다**:

1. 승인자 0명 Task 의 완료 되돌리기 — **OQ-A**(사용자 답변 대기). 그 분기만 구현 보류.
2. 복수 미응답 문의의 회신 대기 해소·취소 — **D2**. 하나짜리 흐름은 구현하고 복수 분기만 보류.
3. 승인자·문의 수신자의 **자동 채움** — 위임전결 값 부재. 추천 없이 사람이 고르는 경로로 구현.

셋 다 **W1 에는 닿지 않는다.** 코드 발주를 W1 부터 시작하면 미결을 하나도 건드리지 않는다.
