# Phase 5 통합 검증 독립 검수

`tauri-measurement-r2.md`가 생성되면 다음만 검수한다.

- 자동검증 명령·수치가 실제 실행 결과와 일치하는지 확인한다.
- Phase 5가 닫는 21개 AC가 누락·중복 없이 각각 증거 상태(통과/미측정/검증 불가)를 갖는지 확인한다.
- M-1, Windows, 운영 origin, 설치·절전·마이크 실기를 통과로 쓰지 않았는지 확인한다.
- M-2b/AC-T27의 Phase 2 인용이 실제 기록 존재 여부와 맞는지 확인한다. 기록이 없으면 미측정으로 고친다.
- 제품 코드·SPEC·WORK를 수정하지 않고 검수 보고서 한 파일만 작성한다.
- FAIL이 있으면 위치와 수정 방향을 명확히 쓰고, 없으면 WARN과 다음 Phase 이월을 구분한다.
