## 반드시 기록할 규칙

1. M-1은 **https fixture**에서만 잰다. 평문 localhost 결과로 대체하지 않는다. CA 미신뢰로 문서가 안 열리면 TLS 오류 또는 연결 거절 원문을 남기고 `미측정`으로 닫는다.
2. M-2는 회의 라이브와 브라우저 인터랙션을 분리해 지원 여부·장시간·서버 수용의 6칸을 만든다. 회의 라이브 단일 MIME 실패만 중단 조건이며 브라우저 경로만 실패하면 보완으로 연다.
3. macOS와 Windows를 합치지 않는다. Windows 장비가 없으면 해당 축은 검증 불가로 기록하고 통과로 대체하지 않는다.
4. M-9는 실제 자동 절전 대기 `T`와 관찰 시간 `max(3T, 30분)`을 숫자로 기록한다. T가 설정되지 않은 관찰은 무효다.
5. M-2b는 제품 코드를 바꾸지 않고 개발 세션 데이터의 만료 조건을 사용한다. 비밀값과 운영 DB는 건드리지 않는다.
6. 판정은 반드시 `진행`, `보완`, `중단` 중 하나를 선택하고 WORK-006 Phase 2 표의 조건과 근거를 인용한다. 자동계측 성공으로 실기 항목을 덮지 않는다.

## 실행 순서

1. Phase 1 보고서와 R2 검수 보고서를 읽고 현재 변경 파일을 확인한다.
2. CA 신뢰가 이미 설치되어 있지 않으면 M-1을 미측정으로 기록하되, fixture 기동과 `curl --cacert` 결과 및 셸 로그를 분리해 남긴다. TLS 우회나 전역 신뢰 설치는 하지 않는다.
3. 계측 페이지의 자동 가능한 항목(M-2 MIME 지원, M-3 훅, M-7 연결 실패 관측, M-8 외부 링크 호출 경계)을 실행하고 로그와 시각을 기록한다.
4. 마이크 권한·쿠키 재시작·창 닫기·절전·장시간 녹음은 실제 사용자 조작이 없으면 미측정으로 기록한다. Windows 전부는 장비가 없으면 검증 불가로 기록한다.
5. `tauri-measurement-r1.md`에 OS 축별 표, 로그/명령, 미측정 사유, 판정 게이트를 작성한다. 추측을 관측값으로 쓰지 않는다.
