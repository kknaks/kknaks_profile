## 사용자가 실물에서 본 것 (2026-10-01)
채팅의 업무 생성 카드: 기본 정보 페이지가 「내 업무 · 기간 — → —」 한 줄과 「내용 …」 한 줄이 **위아래로 크게 벌어져** 있고(고정 높이 안 균등 배치), 「내 업무」가 라벨처럼 회색으로 보이며, 참조자·결재자는 비어서 아예 안 보인다. 카드는 **파란 배경 + 왼쪽 파란 띠**.
사용자: 「없는 거는 없다고 표시해 줘야지」 · 「파란색 카드 왼쪽 띠 같은 경계가 이상하다 … 검은색 회색으로 안 돼? 통일성이 없잖아」

## 고칠 것 (계약)
1. **기본 정보 페이지 = 라벨·값 2열, 위에서부터 붙여 쌓기**(균등 배치 금지). 순서 고정: **갈래 · 기간 · 담당 후보(요청일 때만) · 참조자 · 결재자 · 내용(2줄 말줄임)**. 라벨은 회색, 값은 검정
2. **빈 값은 「없음」**(옅은 회색) — 숨기지 않는다. 기간이 둘 다 없으면 「없음」, 하나만 있으면 있는 쪽만(「~ 10/06」 등). 다른 세 페이지(체크리스트·업무 연결·자료)도 같은 규칙으로 항목은 늘 서고 빈 값은 「없음」
3. **AX 카드 색을 무채색으로 통일** — 공용 `.scax-actioncard`(`styles/ax.css:244`)의 파란 배경(`--scax-color-accent-08`)과 **왼쪽 3px 파란 띠를 없애고** 앱의 다른 카드처럼 흰 배경 + 1px 회색 테두리(기존 토큰). 이 공용 클래스를 쓰는 AX 카드 **전부**에 같이 적용된다 — 쓰는 곳을 세어 보고(채팅 안 회의실 예약 등 포함), 무채색에서 깨지는 곳이 없는지 확인
   - 배지 「AX」·「초안 · N회차」는 회색 중립 배지로. 4칸 바는 지금처럼 검정/회색
   - 강조색은 주 버튼(「등록」 = DS solid-primary) 하나만 남긴다
