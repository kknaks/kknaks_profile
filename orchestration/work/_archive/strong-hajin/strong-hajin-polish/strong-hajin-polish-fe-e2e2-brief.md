## 고칠 것

**AX 초안 카드 (`AxDraftCard`, `styles/ax.css`)**
- **E2E-3** 「등록」(그리고 채팅 안 AX 카드들의 주 행동 단추)을 **검정 solid** 로 — DS 에 없는 변형이라 `scax-button` 계열에 검정 solid 변형을 하나 세우고(토큰 `--scax-color-ink` 등) **채팅 서랍 안에서만** 쓴다. 채팅 안 파란 단추를 전부 세어 사람 행동이면 검정, AI 진행 표시면 파랑 유지로 가른 표를 보고에
- **E2E-9 + E2E-8 (확정 레이아웃)** 본문 위에 **제목 줄**: 왼쪽 = 현재 페이지 제목(기본 정보·체크리스트·업무 연결·자료) **진하게, 아래 라벨·값보다 한 단계 큰 글씨**, 오른쪽 = **‹ › 아이콘 단추**(늘 보임, 첫 페이지 ‹·끝 페이지 › 는 **비활성**). 본문 안에 겹쳐 뜨던 호버 화살표는 **없앤다**. 스와이프·키보드 ← → 유지
  ```
  기본 정보                      ‹  ›
  갈래    내 업무
  기간    없음
  ```
  헤더의 옛 「기본 정보」 옅은 글씨(`.ax-draft-card__page`)는 이 제목 줄로 옮긴다(중복 금지)
- **E2E-10** 4칸 바 = **채워지는 진행 바**: 현재 페이지까지 검정, 그 뒤 회색(3페이지면 [검정][검정][검정][회색])
- **E2E-7** 체크리스트·업무 연결·자료 페이지는 개수 대신 **실제 목록**: 체크리스트는 항목을 줄마다(☐ 항목명), 업무 연결은 상위·프로젝트·참고·선행의 **이름**, 자료는 파일·링크 **이름**. 고정 높이를 넘으면 마지막 줄을 「외 N개」. 빈 항목은 「없음」
- **E2E-6** 높이는 **고정 유지**하되 줄 간격을 좁혀 **가장 긴 페이지(요청 갈래 기본 정보)에 딱 맞게** 줄인다 — 아래 남는 여백 최소
- 홈·업무 칩에서 여는 같은 카드(모달)도 같은 모양
