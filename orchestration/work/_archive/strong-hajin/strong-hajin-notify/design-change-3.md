## 3. 확인한 것
- node(jsdom + `_ds_bundle.js` 실물)로 렌더해 두 화면 모두 예외 0건을 확인했다
  - 알림 화면: 줄 22, 안 읽음 8, 날짜 구간 4, 머리 「안 읽음 8」, 필터 「업무 3 · 메시지 4 · 회의 1」
  - 꼬리표 14종이 나온다(`메일` · `배정자` · `공유받음` 포함)
  - 「모두 읽음」을 누르면 0이 되고, 빈 · 로딩 · 오류 상태도 그대로 선다
  - 설정 알림: 업무 8 · 메시지 3 · 회의 5, 전체 스위치를 끄면 16개 모두 비활성이다
- 헤드리스 Edge 전체 높이 캡처로 a07 · a21 · a22 · a19 줄과 꼬리표를 눈으로 확인했다. 임시 서버(127.0.0.1:48931)는 `--directory` 로 띄워 사본 폴더에 파일을 남기지 않았고, 끝나자마자 껐다

## 4. 참고 (손대지 않음 — 코디 판단)
- 목데이터에 「참조(CC)」 꼬리표를 쓰는 줄이 이제 없다. CC 는 댓글만 받는데 댓글 항목이 기본 꺼짐이라 넣지 않았다. 꼬리표 정의(`cc`)는 그대로 남아 있다
- 설정 업무 `answer` 의 라벨·설명(「내 요청이 수락·거절됐을 때 / 내가 보낸 업무 요청에 받는 사람이 답하면」)은 요청자 기준이다. 표를 보면 **배정자의 담당 수락·거절**과 **제안 응답**도 이 항목으로 온다. 지시서가 다른 설정 항목은 손대지 말라고 해서 그대로 두었다. 손질할지, SPEC 문구로 맞출지는 코디·사용자가 정한다
