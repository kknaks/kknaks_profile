## 2. 바꾼 것 — 설정 → 알림 설정 · 「메시지」

- 항목 셋, 모두 기본으로 켜 두었다
  - `메일` — 「연동한 메일 계정에 새 메일이 오면 (받는 사람·참조 모두)」
  - `슬랙` — 「수집 중인 DM·멘션·채널에 새 메시지가 오면」
  - `카톡` — 「수집 중인 1:1·단체방에 새 대화가 오면」
- 「연동이 끊기거나 수집이 실패했을 때」 항목은 **걷었다**. 테마 카드 아래에 작은 안내 한 줄 「연동이 끊기면 해당 채널 알림으로 알려 준다」를 두었다(카드 note 모양)
- 머리 셈은 데이터에서 계산하므로 「3개 중 3개」가 된다. 하나를 끄면 「3개 중 2개」, 테마를 끄면 「꺼짐」이다
- 업무·회의 테마 · 전체 스위치 · 다른 메뉴는 그대로다

## 3. 알림 목록 목데이터 — 손대지 않았다

관계 꼬리표(메일 받는 사람/참조 · 슬랙 DM/멘션/채널 · 카톡 1:1 · `내 연동`)는 지시대로 그대로 두었다. 설정 항목과 어긋나는 문구도 찾지 못했다.
- 메일 받는 사람·참조 줄(a04 · a10)은 설정 `메일` 하나에 들어간다
- 슬랙 DM·멘션·채널 줄(a08 · a02 · a18)은 설정 `슬랙` 하나에 들어간다
- 카톡 줄(a14)은 설정 `카톡` 에 들어간다
- 메일 연동 끊김 줄(a15)은 「메일 연동 … 의 연결이 끊겼습니다」라서 메일 채널 사건으로 읽힌다

## 4. 확인한 것
- node(jsdom + `_ds_bundle.js` 실물) 렌더 결과 예외 0건이다
  - 카드 머리는 「업무 8개 중 7개 / 메시지 3개 중 3개 / 회의 5개 중 5개」, 항목은 모두 16개다
  - 전체를 끄면 체크 16개가 모두 비활성이 된다
  - 메일·카톡·프로필 메뉴는 그대로 선다
- 헤드리스 Edge 캡처(1600 폭)로 메시지 카드의 세 항목과 아래 안내 한 줄을 확인했다. 임시 서버(127.0.0.1:48931)는 `--directory` 로 띄워 사본 폴더에 파일을 남기지 않았고, 끝나자마자 껐다
