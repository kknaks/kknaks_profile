# [architect] 알림 시안 수정 1 — 설정 「메시지」 테마 항목을 셋으로

앞 판 `design-change-1.md` 에 이어서 한다. 같은 방식(Claude Design `7e839512` 쓰기 + 로컬 사본 `package 2/` 같은 바이트 · `cmp`). 사용자 승인 받음(2026-10-08).

## 바꿀 것

1. **설정 → 알림 설정 · 「메시지」 테마 항목 7 → 3** (`handoff/settings/js/data.js` `NOTIFY_GROUPS` message)
   - `메일` — 「연동한 메일 계정에 새 메일이 오면 (받는 사람·참조 모두)」
   - `슬랙` — 「수집 중인 DM·멘션·채널에 새 메시지가 오면」
   - `카톡` — 「수집 중인 1:1·단체방에 새 대화가 오면」
   - 셋 다 기본 켬. 「연동이 끊기거나 수집이 실패했을 때」 항목은 **걷는다** — 끊김 알림은 그 채널 항목에 딸린다(메일 끊김 = `메일` 항목). 설명 한 줄에 녹이지 말고, 필요하면 테마 아래 작은 안내 한 줄 「연동이 끊기면 해당 채널 알림으로 알려 준다」
   - 머리 「N개 중 M개」 셈이 맞게
2. **알림 목록 목데이터** (`handoff/alerts/js/data.js`) — 관계 꼬리표는 그대로 둔다(메일 받는 사람/참조 · 슬랙 DM/멘션/채널 · 카톡 1:1/단체방 · 연동 끊김 `내 연동`). 설정 항목과 어긋나는 문구만 있으면 맞춘다
