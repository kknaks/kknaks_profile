## 지금 코드(front/)와 달라지는 곳

1. 헤더: 「월별 매출」 제목 → 메뉴 탭 2개 · 오른쪽 문구 「운영 명동점 · 조회 전용」 → 「세라미크 명동점」 + 「운영 · 조회 전용」 칩
2. 본문 폭: 코드 `max-w-[1440px]` → 제한 없음
3. **표 구조**: 코드 = 10칸 `<table>` 한 판(품목 줄은 왼쪽 5칸이 비고, 머리는 오른쪽 5칸을 합침) → 시안 = **두 층**(머리 6칸 줄 + 들여 쓴 줄 6칸). 칸 머리도 두 줄
4. 결제 · 취소 · 환불 줄: 코드는 상품 `—` · 품목 종류 빈칸 → 시안은 품목 종류 자리에 **결제 수단**(카드 등), 상품 자리에 「이 달 결제」 · 「결제 취소」 · 「반환」 글. SPEC §3.2 는 상품 `—` — 받아들이면 SPEC 개정 필요
5. 0원 구성품 흐리게 — 코드에 규칙 없음(금액 0 인 품목 줄 = 구성품으로 본다는 판정이 새로 생김)
6. 결제 수단 이름 「간편결제」(EASY_PAY) — 코드는 KOS 값 그대로. 브리프 지시로 이름을 붙임
7. 음수 표기 `−`(U+2212) · 굵게 — 코드는 `-` 보통 굵기
8. 건수 줄 → 칩 · 안내 줄을 같은 줄 오른쪽으로
9. 상태 화면에 원형 아이콘(! · ? · ⚙ · —) · 잘못된 월은 별도 문구(코드는 back 400 `message` 를 오류 화면에 그대로)
10. 로딩 스피너는 CSS 원(번들이 없어 대역) — 코드는 medikit `Loading`
11. 「품목은 다른 달에」 를 머리 오른쪽이 아니라 줄 영역 첫 줄에 · 취소만 있는 수납은 「이 달엔 취소 · 환불만」 덧붙임
12. 유입 칸에서 「(에이전시)」 로 끝나는 값은 파랑 글자로 강조
