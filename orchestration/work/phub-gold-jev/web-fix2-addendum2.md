# [코디 추가 지시 2] 화면은 열을 동시에 · 기준 = 누른 순간부터 첫 글자

사용자: 「옛날에 테스트 할때는 첫글자 바로 떴는데 첫글자 뜨는 기준으로 봐야 체감상 누가 빠른지 알지」. 옛 hub-evals 화면은 열을 **동시에** 돌렸다(SPEC-002 O-13 메모 「옛 README §3 은 동시」). 지금 runner 는 차례로 + 순서 섞음(runner.py:62-69)이라 뒤 열 카드가 앞 열이 끝날 때까지 「대기」.

할 것(이번 수정에 함께):
- **화면(정확도 · 속도 탭 모두)** 에서 고른 열을 **동시에** 시작(asyncio 동시 · 같은 run_id · 기록 한 줄). CLI 동시 실행 상한은 기존 `cli_max_concurrent` 설정을 따르되 화면 실행에서는 고른 열 수 이상으로(모자라면 설정값 올리는 길만 · 기본값 결정은 보고).
- **batch(채점용) · CLI runner 는 그대로**(차례로 · 순서 섞음 — SPEC 결정).
- 기록에 열마다 `click_to_first_text_ms`(화면 요청을 받은 순간 → 그 열 첫 글자) 추가. 카드 머리 **맨 앞 · 크게** 이 값, 그 뒤 전체 ms · 열 시작 기준 첫 글자.
- 동시 실행이라 서로 간섭할 수 있다는 한 줄은 화면 고정 표시 자리에 — 새 문장 대신 「동시 실행」 표지 하나로.
- 시험(동시 시작 · 기록 한 줄 · batch 는 차례로 그대로 · 모의 CLI).
