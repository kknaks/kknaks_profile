# case3 「정보 없음」 개선 계획

작성: 2026-11-02 · 대상: fullrun-v2(`b202611020020-edc407`)의 case3

## 목표와 현재 근거

상담 질문에 답할 근거가 있는데도 case3가 「정보 없음」이라고 답하는 일을 줄인다. 원천에 없는 사실을 추측으로 채우지 않는다. 허브는 결정론을 유지하고, Jev는 의도·시작·이웃 노드를 고르며 섹션 양은 규칙으로 정한다.

[전수 조사](../../../reference/2026-10-30-hub-evals/build-out/info-absence-audit/all-claims-report.md): 239문항 중 부재 표현이 나온 질문 185개. 문장 조각 270개에서 추출 오탐 2개를 빼면 실질 검토 대상은 268개다.

| 조사 판정 | 건수 | 작업상 의미 |
|---|---:|---|
| 직접 답하는 원장 근거 있음 | 45 | 골드에 있으나 미전달 42 · 원장에 있으나 골드 fact 미확인 2 · 골드 fact ID 전달 1 |
| 일부 항목의 근거만 있음 | 89 | 답할 항목과 유보할 항목을 나눠야 함 |
| 범위 검색에서 직접 근거 미발견 | 104 | 원장 전체에 절대 없다는 확정은 아님 |
| 미해결 | 30 | 표현·근거 관계 추가 검토 |

수치는 **문장 단위**다. 질문 수나 답변 오류율로 읽지 않는다. 부분 근거를 문장 전체의 반증으로 세지 않는다. 조사 원본은 `reference/2026-10-30-hub-evals/build-out/info-absence-audit/`에 있다(gitignore).

## 순서

### 1. 수정 작업표 확정

- 45개 직접 근거 사례의 원장 경로 → 골드 fact ID → 해당 실행 전달 ID → 답변 문장을 한 행으로 연결한다. 42개 미전달은 **입구/시작 노드, 이웃 선택, 섹션 선택, 예산 절단** 중 실제 누락 지점을 trace로 판정한다.
- 89개 부분 근거 문장은 질문의 항목을 쪼개 **답할 수 있는 항목 / 원천에 없는 항목 / 환자별 판단이 필요한 항목**으로 나눈다. 해당 fact의 전달 여부도 적는다. 문장 전체를 무조건 오류 처리하지 않는다.
- 104개 미발견과 30개 미해결은 원천 검색 범위·동의어·상품/시술 구분을 재검토한다. 끝까지 직접 근거가 없을 때만 원천 공백 후보로 둔다.
- 산출: 질문별 `claim → source → gold → delivered → answer → 원인 → 수정 대상` 작업표와 확정/부분/미확정 구분. 검수자가 표본이 아닌 **수정 대상 전 행**의 근거 관계를 확인한다.

### 2. 계약과 구현을 순서대로 발주

- 작업표에서 반복되는 누락 원인을 묶어 SPEC-006(앱 걷기·답변) 또는 SPEC-005(골드 적재·도구)의 변경안을 만든다. 이미 골드에 있는 42개는 앱 걷기 원인을 우선 본다. 원장에만 있는 2개는 골드 빌드 규칙을 따로 본다.
- 스펙 검수 → WORK 계획·사용자 리뷰 → 코드 워커 구현·코드 검수 순으로 진행한다. 외부 레포(`clinic_chat`, `PROCEDURE-HUB`)는 코디네이터가 `orchestration/runbook.md` 절차로 워커에게 발주한다. 이 프로필 레포의 분석·기록은 코디네이터가 관리한다.
- 답변 생성 계약: 받은 사실로 답할 수 있는 항목은 먼저 답한다. 유보는 **근거가 없는 항목만 특정해서** 말한다. 환자별 적합성은 일반 원천 사실과 구분한다. 안전 사실을 생략하지 않는다.

### 3. 원천 공백 처리

- 104개 미발견·30개 미해결 중 실제로 원장에 답이 없는 항목을 확정한다. 정의·시술 시간·개별 제품 조건처럼 상담에 필요한 항목은 출처나 의료진 확인을 받아 원천 보강 후보로 낸다. 근거 확보 전에는 골드에 사실을 만들지 않는다.
- 일부 근거만 있는 89개는 전체 답을 억지로 채우지 않고, 확인된 내용과 남은 공백을 분리해 답변 계약에 반영한다.

### 4. 검증 관문

1. **결정론 확인:** 수정 대상으로 확정한 골드 fact가 예상 질문의 case3 입력에 전달되는지 ID와 본문으로 확인한다. 미전달 42개는 개별 재생으로 회복 여부를 본다.
2. **답변 확인:** 해당 질문의 답에서 확인된 사실을 쓰고, 그 사실을 다시 「정보 없음」이라 하지 않는지 직접 대조한다. 부분 근거 사례는 답할 항목과 유보할 항목이 분리됐는지 본다.
3. **작은 재측정:** case3 50문항을 한 번 실행한다. 핵심 지표는 `원장에 직접 근거가 있는데 정보 없음이라고 답한 건수`이며 안전·정확성·첫 글자 시간도 함께 기록한다.
4. **전체 재측정:** 앞 관문이 통과된 큰 단계에서만 239문항 × 3케이스를 실행한다. 기존 W-4 기준(정확성 ≥58%, 안전 ≥90%, 첫 글자 ≤7초)과 case1 대비 차이를 보고한다.
