# [researcher] 실버 7단계 — 「그 부위 단위 시술 없음 → 계열 후보 전부」 규칙 고치기 (사용자 10-29)

## 문제(사용자 지적 · 연결 구조 페이지)
고민 「이중턱」(부위 턱밑) → M9 · M7 · M4 가 턱밑 단위 시술이 없어 **계열 후보 전부**로 열림 → 겨드랑이 마이크로웨이브 · 바디 HIFU · 두피 스킨부스터 · 코 실리프팅 등이 붙음. 7단계 검수 W2 규칙(R8 「계열 후보 전부 + no_unit_at_site」)이 부위를 아예 무시한다. 셈: site_check 「그 부위 단위 시술 없음 · 후보 전부(표시)」 54 엣지.

## 새 규칙(사용자 승인 · 결정 파일 rules 에 문장으로 · W2 규칙 대체)
1. 앵커 부위에 그 계열 단위 시술이 없으면 **3단계 부위 트리의 상위로 올라가며** 찾는다(예: 턱밑 → 턱(묶음) → 얼굴 전체). 처음 찾은 층의 단위 시술만
2. **얼굴 · 바디 · 두피(최상위 영역) 경계를 넘지 않는다** — 얼굴 고민에 바디 · 두피 단위 시술 0
3. 최상위 영역까지 없으면 **계열 엣지만**(to_units 비움 · to_family 유지) + 표시 「이 부위 단위 시술 없음」 · 단위 시술 후보 붙이지 않음
4. lowering · site_check 칸에 어느 층에서 찾았는지(「상위 부위 턱(묶음)」 등)

## 같이 할 것
- **같은 성격 전수**: 7단계 엣지 전부(① ~ ⑦ 경로) + 추천 조합 · 8단계 끝점 해석(`step8-apply.py` 의 부위 · 계열 내림)에 같은 「후보 전부」 꼴이 있는지 grep — 있으면 같은 규칙으로(8단계는 결정 파일 → 재실행)
- 검사 가드: 엣지마다 「단위 시술 부위의 최상위 영역 == 앵커 부위의 최상위 영역」 아니면 open
- 7 → 8 재실행 · open 0 · 결정론 cmp · 고정 시험(이중턱 M9 → 얼굴 층 · 얼굴 고민에 바디 0 · 끝까지 없으면 계열만) · 스킬 concern-check · relation-check errors 0 · md 셈. 키 이름 지우지 말 것 · 원천 · DEC 수정 금지
