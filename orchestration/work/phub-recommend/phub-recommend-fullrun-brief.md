# 발주서 — hub-evals 전체 질문 실행(239문항 · Claude CLI · 밤샘 순차)

목적: 골드 데이터의 약점을 답변 품질로 찾는다. 결과는 사용자가 아침에 본다.

## 준비(코드 · 로컬 커밋 · push 금지)
1. 일괄 실행이 `QUESTION_SET_JSON`(=…/reference/2026-10-30-hub-evals/question-set.json, .env 에 비밀 아닌 한 줄 추가 가능) 를 읽는다.
   형식 `{questions:[{no, src_id, topic, question, reference_answer, source_kind, group}]}`.
   기록(runs.jsonl · quality.jsonl)에 `question_no · src_id · topic · reference_answer` 를 남긴다. 화면 기록 표에 번호 칸.
   참고 답은 **채점에 넣지 않는다**(채점 기준은 원장 그대로).
2. 단어 검사 거짓 경보: 허브 시맨틱 정본 이름(SEMANTIC_JSON 의 단위 시술 이름 — 예 「무바늘 스킨부스터」「고주파 리프팅(RF)」)은 「허브 이름」으로 분리해 「없는 이름」에서 뺀다. 세 케이스 같은 규칙. 시험 1.
3. 일괄 실행 = **순차 1문항씩**: 답 세 열 + 열마다 ①② 채점이 **모두 끝난 뒤** 다음 문항 · 간격 15초 · 실패 재시도 2번 · 구독 한도에 걸리면 대기 후 이어서(기존 기능) · 중단 · 재개 시 끝난 번호는 건너뜀.
   provider = claude-cli 만(Sonnet · effort medium) · 채점 Opus 자동.
4. 시험 · ruff · 18210 재시작(결과 파일은 코디가 이미 비움 — runs/ 에 _archive 만 있음. 서버가 메모리에 옛 기록을 들고 있으면 재시작으로 비울 것).
