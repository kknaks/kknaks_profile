## 구현 전 닫을 결정

**계약·기술 결정(공식 SPEC 반영 전):** (1) T4 기본/evidence/all 중 관계 claim·대안·출처의 실제 수신 경로와 응답 칸, 생략 쌍 재호출·global step8 메모 경로(F-1/W-1). (2) 관계 원문이 15KB를 넘는 경우 필수 facet 상태·인용·stop 규칙(F-3). (3) `received`를 지원 fact가 확인된 상태로 한정하고 미확인 사유를 unresolved/blocked로 전파하는 상태 기계(F-2). (4) page metadata 도입 여부와 계산·호환성, 없을 때 실제 호출 후 제외 정책(W-2). (5) span/role 해석, 필수 target seed, ambiguous와 명시 쌍 확정 순서(W-3). (6) 안전 다음 페이지의 rank 재계산·재수집 시점, deadline·호출 timeout 숫자(초안 70,74,76,139~142행).
