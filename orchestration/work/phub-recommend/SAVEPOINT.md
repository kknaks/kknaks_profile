# 작업 보존 체크포인트 — 2026-11-03

사용자 요청에 따라 현재까지의 조사·설계·코드·후보 데이터·검수·HTML을 보존한다. **완료 또는 승인된 설계로 표시하는 커밋이 아니다.**

사용자는 새 실버의 엔티티 경계와 관계가 충분히 정리되지 않았고, 코디네이터가 설계 HTML과 실제 첫 이관 후보판을 혼동해 모순된 설명을 한 점을 지적했다. 원문 필드 목록 조사·원문 보존 검증·검증기 반례 폐쇄를 도메인 모델 설계의 완성으로 취급하면 안 된다.

현재 실제 후보판은 `silver-batch1-candidate/records.json`이다. `claims`는 설명·가격·안전정보 등을 담는 범용 원천 레코드이며 부작용 전용 엔티티가 아니다. 부작용 원문 배열도 이 컬렉션에 저장한다. `attachments`를 통한 시술 참조 연결은 일부 있으며 모든 필드가 연결된 것은 아니다. 설계 HTML의 `complication` 타입과 관계는 첫 후보판에 구현된 것으로 간주하지 않는다. 전체 엔티티·관계 이관, 원문 의학적 정확성, 사용자 설계 승인, 정본 전환, 골드/서비스 적용은 완료되지 않았다.

기존 P5 BR-H1/BR-M1 검증기 결함은 별도 보완·독립 폐쇄 검수 PASS지만 위 설계 의미의 완성이나 임상 승인을 뜻하지 않는다. HTML 검토 카드와 제안은 사용자 검토 과정의 작업물이며 승인된 데이터 결정이 아니다. 자동 테스트 JSON은 사용자 선택으로 적용하면 안 된다.
