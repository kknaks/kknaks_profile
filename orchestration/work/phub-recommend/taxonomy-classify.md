# taxonomy 시술 항목 521 → 축별 분류표 (DEC-002 기준 제안)

> 정본은 `taxonomy-classify.json` 이다. 이 문서는 그 요약이고 수치는 JSON `summary` 와 같다.
> 원천: `phub-stg-2026-10-26/taxonomy.json` `modality[].subcategories[].items[]`(name · detail · extracted.indications · 추가 필드). 교차 확인으로 `products.json` 제조사만 읽었다.
> 이 표는 **제안**이다. 항목마다 사용자 답(맞음 / 고침 / 보류)을 받는 원료다. 결정하지 않는다.

## 판정 규칙

- **where** — name + detail 문자열에서만 뽑는다(적응증 문장은 source_text 에만 두고 where 에 넣지 않는다). 트리에 없는 표현은 where_unmapped
- **how_source** — name + detail 에 실제로 있는 기법 표현만. 없으면 빈 배열
- **purpose** — name + detail 의 목적·고민 표현(원천 그대로). 제품·장비·약물은 비움
- **product** — 제품 · 장비 항목만. maker 는 taxonomy detail(또는 이름 괄호) 문자열 그대로, maker_products_json 은 products.json 교차값
- **unit_procedures** — 제품 · 장비 · 약물 · 패키지 · 판정불가는 비움. where 가 원천에 없으면 빈 문자열
- **kind** — product 제품·브랜드 / device 장비 모델 / site_or_purpose 부위·목적 이름 / technique 기법 변형 / package 조합 / unit_procedure 일반 시술명 / other 약물·외용제 / unclear 판정 불가
- **부위 트리** — DEC-002 37 노드 + `_RESUME` §2 10-27 추가 6(콧등 · 손 · 발 · 다리 · 비키니 · 힙). 자갈턱 = 턱끝의 증상 → purpose 로 둔다

## 10. 미결 — 사용자 답이 필요한 것

1. **재질(M7-1 6 · M3 하위 분류)** — 「무엇을」의 하위 계열인가, 제품 속성인가(OQ-203). 지금은 `unclear`
2. **일반명 장비 계열(IPL · 알렉산드라이트 · CO2/어븀야그 프락셔널 · PRP/PRF/CGF · 콜드플라즈마)** — `unit_procedure` 로 두었으나 부위가 없다. 「무엇을」 노드로만 둘지(OQ-203)
3. **토닝 · 프락셀 · 코그 · 모노 · 롤러/스탬프/펜** — 기법 축으로 올릴지(OQ-201). 표현은 §4
4. **모노폴라 · 바이폴라 · 마이크로웨이브** — 에너지 방식. 기법인가 장비 속성인가(OQ-201)
5. **마케팅명(꿀광 · 아기 · 벨벳 · 백옥 · 마늘 · 신데렐라 · 지방분해 주사류)** — 이름을 동의어로 두고 「무엇을」을 성분으로 세울지
6. **트리 밖 부위 6(§5)** — 노드 추가 · 동의어 · 버림
7. **제품 · 장비의 부위** — 적응증 문장에만 있다. 「쓰는 제품」 엣지 쪽에서 쓸지, 단위 시술 후보를 적응증에서 뽑을지
8. **원천 중복(§9)** — 원천 수정 목록(source-fix-list)에 올릴지
9. **패키지 구성(OQ-204)** — 시그니처 프로그램 2건(M9-SIG)만 detail 에 구성이 적혀 있다. 나머지 패키지는 구성 원천 없음
