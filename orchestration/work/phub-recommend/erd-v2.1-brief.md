# ERD v2.1 발주서 — 시술 튜플 접힘 규칙 수정 1건 (코디 · 2026-11-04)

v2(`erd-v2.*` · 생성기 `*_v2.py` · `erd-v2-tuples.py` · `erd-v2-check.py`)의 **규칙 하나**만 고친다. 구조(개체 21 · 관계 31)는 그대로. 다른 것은 손대지 않는다.

## 문제 (v2 §9.5.2 에서 확인)
분류 항목 이름이 어느 사전에도 안 닿으면 what 을 **부모 하위분류**로 떨어뜨리고 site=none 으로 두어서, 하위분류 아래 항목이 전부 한 튜플로 접혔다.
- M15-1 케미컬필링 60개(AHA/BHA·TCA·블랙필·페놀필링 …) → 튜플 1
- M9-1 HIFU 13개(울쎄라피프라임·슈링크·더블로 …) → 튜플 1
- M1-3 용도별 9개(주름·종아리·다한증·턱선보톡스 …) → 튜플 1
서로 다른 제품·부위가 같은 시술로 접힌 것이고, 「턱 보톡스 = 사각턱보톡스」를 자동으로 하지 않는다는 원칙에 어긋난다. 원인은 v2 발주서의 「제품명이면 product, 아니면 가장 구체적인 계열 층」규칙.

## 수정 규칙 (v2 §1.3 분해 규칙의 what 결정 부분만 교체)
1. 이름 조각이 **전부** 사전에 닿았을 때만 what/site/technique 를 사전 값으로 조립하고, 그때만 다른 항목과 접힐 수 있다.
2. 조각 중 하나라도 미등록이면 **접지 않는다.** what = 그 분류 항목 자신(what_kind=`catalog_item`, 미등록 조각을 `candidate_name` 으로 보존), site/technique 는 닿은 조각만, 상태 `partial`. 식별자는 catalog_item id 기반이라 항목마다 고유.
3. 부모 하위분류로 떨어뜨리는 fallback 은 **삭제**. 하위분류는 항목의 상위 관계(R2)로만 남는다.
4. 참조 자리(②)·market-pricing(③)도 같은 규칙: 미등록 조각이 있으면 해당 참조는 미해결(v1.1 ⑨)로, 부모 층 튜플로 접지 않는다.
5. 규칙 데이터(`erd-v2.1.json → resolve_rules`)에 「fallback_to_parent: false」를 명시.

## 검산
`erd-v2.1-tuples.py` 재실행 → §9.5.1~9.5.5 를 v2 수치와 나란히(521 → N, 접힌 튜플 수, 접힌 표 전부, what_kind 분포 product/subcategory/catalog_item, none 비율). 접힌 표는 **세 칸이 전부 사전 값인 것만** 남아야 하고 사용자가 「같은 게 맞다」고 볼 수 있어야 한다. `erd-v2.1-check.py` 는 v2 항목 전부 + 「fallback 0 · partial 항목이 둘 이상 접힌 튜플 0」 추가.
부작용 튜플(§9.6)은 건드리지 않는다. 같은 원칙이 이미 적용돼 있다(미등록 조각 있는 이름은 partial 로 접히지 않음)는 것만 검산 항목으로 확인.
