# 추가 지시 1 (사용자 지적 · 2026-11-12) — §5 「변인별 손익분기」 표

사용자가 「적자가 시작되는 값이 시간이라는 거냐」고 물었다. 표가 읽히지 않는다.
- 「적자가 시작되는 값」 열에 **변인 단위**를 붙인다(H = 시간/일 · D = 대 · ρ · φ · ψ = 0 ~ 1 비율, 각 비율이 무엇의 비율인지 한 줄).
- 0.05 = 「스윕 첫 칸 — 해피에서 조금만 움직여도 바로 적자」라는 뜻을 문장으로 쓴다. 0.05 간격 격자의 첫 칸이라 실제 경계는 0 과 0.05 사이일 수 있음을 적는다(가능하면 경계를 실제로 구해 쓴다).
- 「넘어가는 값 없음」이 왜인지(시간제 · 토큰제는 매출이 H · D 에 같이 비례) 한 줄.
- φ(발화 밀도) · ψ(세션 분할)는 사용자가 정한 변인이 아니다 — 처음 나오는 곳에 정의와 「계산으로 끌어낸 변인」 표기.
