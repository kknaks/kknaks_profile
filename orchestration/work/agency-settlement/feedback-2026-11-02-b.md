# 사용자 화면 수정 묶음 — 2026-11-02 (2차 · 0.5.x 화면)

> 사용자가 말하는 대로 받아 적는다. 다 들은 뒤 한 번에(문서 → FE/BE).

1. **0원 품목을 앞 유료 품목의 「ㄴ」 하위처럼 그리지 않는다** — 예: 「오투덤」은 KOS 의 **독립 상품**(id …d848 · 늘 0원 · 33줄 · 주름 보톡스 · 포텐자 · 소프웨이브 등 여러 시술과 함께 팔림)이지 쥬베룩 하위가 아니다. KOS 에 구성품 ↔ 부모 연결 없음 → 다른 품목과 같은 줄(들여쓰기 · ㄴ 없음 · 흐리게만) — 사용자 「오투덤이 상품이 아니야? 쥬베룩 하위 상품이야?」
2. (질문 · 미정) 설정 화면 옵션 줄 끝 「— 리투오 전환」 같은 KOS 설명 글자 — 지울지 사용자 답 대기
3. **0원 품목은 데이터로 구분된다**(코디가 「구분할 방법 없다」고 한 것 틀림 · 사용자 「왜 데이터로 구분할 방법이 없다는 거야」) — 10월 수집본 0원 품목 190줄을 같은 수납 ⑤ items 와 짝지어 보면:
   - **할인으로 0원(서비스 처리)** 147줄: ⑤ `priceAdjustments` 있음(예: 정액 할인 −원가 · 정률 −100%) · `source = DIRECT`
   - **원래 0원 상품** 14줄: ⑤ 가격 0 · 할인 없음(예: 오투덤 · 시트팩)
   - 그 밖 ~28줄: ⑤ 가격 > 0 인데 ② 금액 0(환불 · 기타 — 하나씩 볼 것)
   - **어느 것도 다른 품목의 하위가 아니다** → 「ㄴ」 하위 표시 없앰 · ~~대신 배지: 둘 다 「서비스」~~ → **배지 없음 · 보통 줄(0원 그대로) · 서비스 표시는 병원 담당자 확인 뒤**(사용자 「서비스는 뱃지 붙이지 말고 · 이거는 담당자한테 물어봐야 해」) · 원래:(사용자 「원래 0원은 서비스 아니야? 할인 기록도 서비스고?」) · 할인으로 0원인 줄만 옆에 「원래 X원」 회색. ⑤ 에서 `priceAdjustments` · 원래 가격(`basePrice`/옵션 가격)을 더 꺼내 저장해야 함
4. **거래 명세서(PDF) 줄 안 맞음** — 「발행(병원) · 받는 곳」 두 상자가 아래 요약 칸(기간 · 손님 · 실결제 합 · 수수료 합)보다 안쪽으로 들어가 좌우 끝이 안 맞음 · 요약 칸 사이 테두리 두께도 다름 · 「기간」 값이 두 줄로 꺾임(2026-11-01 ~ / 2026-11-30) → 상자 · 요약 · 표의 좌우 끝을 같은 선에 · 기간 한 줄(칸 넓히거나 「11-01 ~ 11-30」) — 사용자 「이거 줄이 안 맞는데?」
5. **「하위 제품」은 0원 줄이 아니라 묶음 옵션 안에 있다**(사용자 「0원인데 하위 제품들도 있지 않아?」 — 운영 10월 확인): 묶음 상품은 ⑤ `optionType = GROUP`(117 품목) — 품목 줄은 **하나**이고 구성 시술은 그 안의 `compositions`(시술 · 횟수)로만 온다(따로 0원 줄로 안 옴). 0원 줄 190 = 서비스 160(할인 147 · 원래 0원 14) + 환불 30(화면엔 안 보임). 시안의 「묶음 + 0원 구성품 ㄴ」 그림은 가짜 데이터 → 구현: 묶음 품목 줄 아래 회색 한 줄 「구성: 울쎄라피 프라임 300샷 · 써마지 FLX 600샷」(compositions) — 금액 · 수수료는 묶음 줄에만

6. 5번(묶음 = 한 줄 + 회색 「구성: …」) **채택**(사용자 「응 그렇게 가자」)

## 병원 담당자에게 물을 것
- 서비스(0원 · 할인 100% 포함)를 화면 · 명세서에 어떻게 보일지(표시 · 원래 가격 · 수수료 대상 여부)
7. **접기 · 펼치기**(사용자 「접기 펼치기 넣었어?」 — 아직 없음) — 수납 묶음(손님)마다 접기/펼치기 · 기본 = 접힘(머리 줄: 결제일 · 손님 · 유입 채널 · 실결제 · 수수료만) · 툴바 [모두 펼치기 · 모두 접기] · 월별 · 유입채널 채널 탭 · 폰 카드 같게 — 기본 상태는 사용자 확인
8. **/channel 결산 표에 정렬** — 칸 머리(유입 채널 · 손님 · 결제 손님 · 실결제 · 수수료 · 미설정 품목) 눌러 오름/내림 · 기본 = 실결제 내림(코디 제안) · 합계 줄은 늘 맨 아래 — 사용자 「여기에 정렬 기능 추가되면 좋을 듯」
9. **/settings 일괄 적용이 위 카테고리 필터와 겹친다** — 일괄 적용 줄의 카테고리 드롭다운 없앰. 대상 = 표에서 고른 상품, 고른 게 없으면 **지금 위 필터(카테고리 칩 · 검색)로 보이는 상품 전부**(「지금 보이는 n개에 적용」 + 확인) — 사용자 「일괄적용 꼭 이렇게 해야 해? 위에 상품 카테고리랑 겹치는데?」 · 코디 제안
10. **0원 줄을 흐리게(gray-400) 그리지 않는다** — 너무 옅어서 안 보였다(사용자 「숫자 0은 왜 안 보이는 거야? 서비스라서?」 → 「0원 말하는 거였어」). 0원 줄도 보통 글자색 · 상태 배지 · 금액 「0」 · 수수료 「0」 그대로(서비스 표시는 담당자 확인 뒤)
