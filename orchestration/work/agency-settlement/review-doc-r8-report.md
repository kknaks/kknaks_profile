## FAIL

### F-1 수동 연결의 「그 키 품목」 범위가 정해지지 않았다 — 자동으로 이은 다른 달 품목이 지금 바뀌나, 나중에 [전체 다시 받기] 때 바뀌나

**근거 줄**
- §5.5 ⓪ `:939`: 대체 키(`option:` · `name:PRODUCT_OPTION:`)가 `product_links` 에 있으면 그 상품 id. 「② ③ **보다 먼저** · 자동이 바꾸지 않는다」
- §4.11 「연결 범위」: 「그 키를 갖는 저장된 품목 전부(지난 달 · 고정된 달 포함) + 앞으로 저장될 품목」 · PUT ②: 「그 키 품목 전부」
- `unlinked[].otherMonths`: 「같은 키가 **보이는** 다른 저장 달(연결하면 거기도 바뀜 · 확인 창 글)」
- #114 「그 키 품목 전부(10월 고정 달 · 11월)」 · #115 「12월에 새로 저장된 o7 품목도 `manual` P2」(12월 스냅샷에 o7 → P3 가 있어도)

**빈칸**
- 품목의 **대체 키**는 그 품목의 옵션 id(또는 이름)로 정해진다. 코드도 그렇다(`items.option_id` · `store.py:63` `link_products`). 그래서 **같은 대체 키 `option:o7` 을 가진 품목이 어떤 달에서는 자동으로 상품에 이어져 있을 수 있다**. 예: 10월 스냅샷에 o7 → P1 이 있어 10월 품목 키는 `product:P1`.
- 이때 「그 키를 갖는 품목」은 두 가지로 읽힌다.
  - (가) 지금 키가 `option:o7` 인 품목(연결 안 된 줄)만
  - (나) 대체 키가 `option:o7` 인 품목 전부(자동으로 이은 10월 줄 포함)
- 문서는 둘을 섞는다.
  - PUT 즉시 범위와 `otherMonths`(「보이는 키」)는 (가)로 읽힌다
  - 저장 때 ⓪ 이 ② 보다 먼저라는 규칙과 #115(12월 자동 P3 를 수동 P2 가 이김)는 (나)다

**실패 길**(가짜 값 · KOS 정상)
1. 10월(고정 · 정산 끝)에는 품목 X 가 o7 로 팔렸다. 10월 스냅샷에 o7 → P1 이 있어 X = `product:P1` 이고 10% 다.
2. 11월에는 o7 이 KOS 목록에서 빠졌다(11월 스냅샷은 앞 달을 복사하지 않음 — OQ-169). 그래서 11월 품목 Y 는 `option:o7` 「연결 안 됨」이다.
3. 사람이 11월 화면에서 o7 → P2(20%)로 연결한다. 확인 창 `otherMonths` 에 10월은 **없다**(10월에는 `option:o7` 이 안 보임).
4. 구현이 (가)로 PUT 을 만들면 그 순간 10월은 그대로다. 그런데 나중에 10월 [전체 다시 받기](§4.5 · 늘 켜짐)를 하면 품목을 다시 저장하면서 ⓪ 이 먼저 돌아 X 가 `manual` P2 로 바뀐다. **10월 수수료가 10% → 20% 로 바뀌고**, 비율 옮기기 · 기록도 없다(PUT 이 아니라서). 확인 창은 「명세서와 달라질 수 있어요」 한 줄뿐이다.
5. 구현이 (나)로 PUT 을 만들면 그 순간 10월이 바뀐다. 하지만 확인 창은 10월을 말하지 않았다.

**왜 막나**
- 돈이 바뀌는 범위를 워커가 추측으로 고르게 된다(rules 「추측으로 메워야 하는 빈칸」).
- 어느 쪽을 골라도 「연결할 때 바뀐 것」과 「다시 받을 때 바뀌는 것」이 같아야 한다. 지금 문서로는 그 둘이 갈릴 수 있다.

**고칠 것**(planner — 정의 한 줄 + 시험 하나 · 코디가 하나를 고름)
- **(권장 · 사용자 말 「연결 안 된 거는 사람이 직접」에 맞음)** 수동 연결은 **자동으로 못 이은 품목에만** 붙는다.
  - ⓪ 의 차례를 「② 가 상품을 못 찾을 때 ⓪」로 바꾼다.
  - 단 「한 번 `manual` 이 된 품목」은 뒤에 스냅샷에 옵션이 생겨도 그대로 둔다(#115 첫 문장 그대로).
  - 새로 저장되는 품목은 ② 가 찾으면 자동이다. 그러면 #115 둘째 문장(12월 자동 P3 가 있어도 P2)은 「12월 스냅샷에 o7 이 없을 때만 P2」로 고친다.
  - `otherMonths` · `result.months` = 그 키가 **연결 안 된 줄로** 있는 달.
- (다른 길) 대체 키가 같은 품목 전부를 이긴다.
  - 그러면 PUT 이 그 순간 자동으로 이은 줄까지 바꾼다(비율 옮기기 · 기록 포함).
  - `otherMonths` 에는 「자동으로 다른 상품에 이어진 n줄도 바뀜」을 따로 싣는다.
  - 확인 창이 그 수를 말한다.
- 시험(#119): 「10월 o7 → P1 자동 · 11월 `option:o7` 수동 P2 → PUT 직후 10월 키 · 수수료와 10월 [전체 다시 받기] 뒤 10월 키 · 수수료가 같음 · `otherMonths` = 실제로 바뀐 달」
