# permanent

내 언어로 정제한 영구노트. 여기 놓이는 노트의 타입: `permanent`.

## 여기 두는 것
- 한 노트 = 한 생각. 자료를 베끼지 않고 내 언어로 재서술하며 "왜 중요한지/맥락"을 덧붙인 노트.

## 여기 두지 않는 것
- 미정제 생각 → `inbox/`.
- 외부 자료 정리 → `reference/`.
- 안 쓰게 된 영구노트 → `permanent/archive/`.

## quick-rule
- 기반 자료·노트는 `up: [stem]` + 본문 `[[]]`로 연결한다. **연결하며 다시 쓰는 것이 정제**다.
- permanent와 product/post는 별개 SSOT로 평행하게 산다(`up:`은 인용일 뿐 중복 아님).
- 안 쓰면 `archive/`로 내린다.
