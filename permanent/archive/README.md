# permanent/archive

안 쓰게 된 영구노트의 cold 장기기억. 여기 놓이는 노트의 타입: `permanent` (archived).

## 여기 두는 것
- 현재 안 쓰지만 버리기는 아까운 영구노트. inbound 링크 보존을 위해 stem을 유지한 채 폴더만 내린다.

## 여기 두지 않는 것
- 현역 영구노트 → `permanent/`.
- 외부 자료 → `reference/`.

## quick-rule
- 내릴 때 파일명 stem을 바꾸지 않는다(stem 기반 링크라 보존된다).
- 부활 = 폴더 한 칸 위로(`permanent/`) 이동.
- LLM은 평소 스캔에서 archive를 제외한다(cold). 명시 요청 시에만 읽는다.
