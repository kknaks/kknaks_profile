# persona/posts

발행물(영구노트→글). 여기 놓이는 노트의 타입: `post`.

## 여기 두는 것
- 공유·발행할 글. 영구노트가 여물어 글로 발전한 종착 SSOT.

## 여기 두지 않는 것
- 미발행 영구 생각 → `permanent/`.
- 미정제 생각 → `inbox/`.

## quick-rule
- post는 종착 SSOT다. permanent와 **평행**(같은 계보를 공유해도 중복이 아님)하며, 계보는 `up:`으로 표시한다.
