# 모두닥 지원 폼 직장경력

지원 폼의 `담당업무` 칸에 아래 본문을 복사한다.

## 1. 메디솔브에이아이 주식회사

| 항목 | 입력값 |
| --- | --- |
| 근무기간 | 2026.02 - 재직 중 |
| 부서 | AX팀 |
| 직급 | 팀장 |

### 담당업무 복붙용

어떤 역할

입사 초기에는 의료 클리닉의 상담 자동화 제품 Charty와 Linky의 백엔드를 맡았습니다. 2026년
6월부터는 4인 AX팀의 리더로 사내 업무 자동화 제품과 고객사 대상 AI 솔루션의 설계·개발을
담당하고 있습니다.

마주한 문제

의료 상담 제품에서는 실시간 음성 처리와 AI 분석이 동시에 돌아가면서 결과가 흔들리거나 세션이
중단되는 문제가 있었습니다. 여러 메신저에서 같은 요청이 다시 들어오면 AI가 중복 답변을 만들
위험도 있었습니다. AX 리더가 된 뒤에는 문서·회의·의사결정·업무가 흩어져 있고, AI가 초안을
만들고 사람이 승인하는 기능을 업무마다 다시 개발하는 문제를 마주했습니다. AI가 허용되지 않은
도구를 실행하거나 응답 형식을 지키지 않으면 전체 업무가 멈출 수 있다는 위험도 있었습니다.

해결한 방향

Charty는 전사·언어 판별·번역을 단계별로 나누고 의료 용어 사전과 AI 분석 실패 시 적용할 대체
처리를 붙여 상담이 중단되지 않게 했습니다. Linky는 수신과 응답을 큐와 워커로 분리하고 같은
대화와 메시지 조합을 한 번만 저장하도록 제한했으며, 위험한 상담은 사람이 이어받게 했습니다.
Mediness에서는 기능 명세 60여 건과 작업 단위 100여 건을 같은 양식으로 관리해 개발 범위와 QA
기준을 맞췄습니다.
반복되던 승인 기능은 공통 기능으로 분리해 회의·장애 대응·의사결정에 재사용했고, AI는 서버가
허용한 작업만 사람의 승인 뒤에 실행하도록 제한했습니다.

## 2. 퀀터스

| 항목 | 입력값 |
| --- | --- |
| 근무기간 | 2025.08 - 2026.02 |
| 직무 | 백엔드 개발자 |

### 담당업무 복붙용

어떤 역할

퀀트 트레이딩 앱의 백엔드 개발자로 ETF 60종의 실시간 시세 수집, 뉴스·공시 수집과 AI 요약,
고부하 조회 성능 개선, 800GB 데이터베이스 이관을 담당했습니다.

마주한 문제

실시간 시세 연결이 끊기면 자동트레이딩 서버가 오래된 가격으로 판단할 수 있었습니다. 뉴스·공시
조회는 MySQL 동기 처리와 중복 쿼리, 메모리 페이지네이션이 겹쳐 사용자가 몰릴 때 서버가 응답하지
못했습니다. 클라우드 계약 변경으로 AWS RDS의 800GB 데이터를 서비스 중단 없이 Azure MySQL로
옮겨야 하는 과제도 있었습니다.

해결한 방향

시세 수집에는 연결 상태를 확인하는 하트비트와 장애 시 10초 폴링으로 전환한 뒤 자동 복귀하는
구조를 적용했습니다. RabbitMQ로 전달을 분리하고 Redis를 복제해 6개월 동안 장 중 데이터 공백
없이 운영했습니다. 뉴스·공시 조회는 MySQL 원장과 Elasticsearch 검색을 분리하고 호출을 3회에서
1회로 줄였습니다. 같은 조건의 k6 테스트에서 처리량은 3.2배로 높아졌고 평균 응답 시간은 68%
단축됐으며 P95는 57% 개선됐습니다. 데이터베이스 이관은 세 가지 방안을 중단 시간·손실·비용으로
비교해 DMS와 CDC를 선택했고, 실시간 복제가 따라잡은 시점에 연결만 바꿔 다운타임 없이 마쳤습니다.
